# AIX PPT Restyle

## 목적

PPT 폴더의 `AIX계열 국비지원 컨택&상담 스피치_김호영 부장_수정용_2페이지시안_v2.pptx`를 새 파일로 복제하지 않고 직접 수정한다. 2페이지를 디자인 시스템의 기준으로 삼아 3–27페이지를 통일한다.

세부 실행 조건과 검수 기준은 같은 폴더의 [subAgent.md](subAgent.md)를 반드시 먼저 읽고 따른다.

## 핵심 규칙

- 작업 대상은 기본적으로 3–27페이지이며, 사용자가 범위를 변경하면 최신 지시를 따른다.
- 작업 파일은 `..._수정용_2페이지시안_v2.pptx` 한 개뿐이다. 새 PPT를 만들지 않는다.
- 원본 PPT는 내용 대조용으로만 사용하고 수정하지 않는다.
- 2페이지의 레이아웃, 색상, 선, 카드, 번호 배지, 타이포그래피 위계를 재사용한다.
- 모든 텍스트의 서체를 `Noto Sans KR`로 지정한다.
- 원문을 요약, 생략, 재작성하지 않는다.
- 겹친 레이어에서는 완전 중복만 제거하고 고유 정보는 모두 합친다.
- 슬라이드 전체를 이미지로 대체하지 않는다. 가능한 모든 요소를 편집 가능한 네이티브 PowerPoint 오브젝트로 만든다.
- 기존 파일에 직접 저장하기 전에 파일 잠금 여부를 확인한다.

## 작업 흐름

### 1. 내용 감사

각 대상 페이지에서 원본과 작업본의 텍스트, 수치, 표 항목, 레이블을 추출한다. 겹쳐진 오브젝트는 Z-order별로 확인하고 고유 내용 목록을 만든다.

### 2. 무손실 병합

완전히 같은 문구만 중복으로 판단한다. 일부 단어, 수치, 조건이 다르면 별도 정보로 보존한다. 레이아웃에 맞지 않는다는 이유로 내용을 줄이지 않는다.

### 3. 디자인 적용

2페이지에서 실제 사용된 오브젝트의 스타일을 복사하거나 동일 속성으로 재구성한다. 페이지별 콘텐츠 구조에 맞게 카드 수와 크기는 조정하되 색상, 시각적 위계, 타이포그래피와 간격 원칙은 유지한다.

### 4. 편집 가능성 확보

텍스트는 텍스트 상자, 배경은 도형, 관계는 선과 연결선, 표는 편집 가능한 표 또는 개별 도형으로 구성한다. 불가피하게 이미지를 사용하는 경우에도 이미지 안의 핵심 텍스트를 별도 편집 가능한 텍스트로 제공한다.

### 5. 저장과 검수

같은 `v2.pptx`에 저장한다. 각 슬라이드를 렌더링해 겹침과 잘림을 확인하고, 원본 대비 고유 텍스트가 모두 남았는지 검증한다. 임시 렌더링 파일은 PPT 폴더에 새 작업본으로 남기지 않는다.

## 스타일 기준

- 글꼴: `Noto Sans KR`
- 메인 네이비: `#0A356A`
- 진한 블루 패널: `#064682`
- 포인트 블루: `#0A4F99`
- 번호 배지 배경: `#DDF0FF`
- 설명 카드 배경: `#EEF7FF`
- 설명 카드 테두리: `#B9D9F5`
- 주요 텍스트: `#111111` 또는 `#1E2B38`
- 보조 텍스트: `#7B8794`

실제 크기, 행간, 자간, 여백은 2페이지의 대응 오브젝트를 우선 기준으로 삼는다. 상단 `CONTENTS`와 페이지 제목 사이에는 분명한 간격을 유지한다.

## 검증 항목

작업 완료 전 다음을 모두 확인한다.

- 대상 페이지 범위가 모두 수정되었는가
- 모든 텍스트에 `Noto Sans KR`가 저장되었는가
- 원본의 고유 텍스트와 수치가 100% 보존되었는가
- 중복이 아닌 내용을 삭제하지 않았는가
- 텍스트 겹침, 잘림, 오버플로가 없는가
- 정렬, 자간, 행간, 굵기가 2페이지와 일관적인가
- 핵심 요소가 선택·수정 가능한 오브젝트인가
- 새 PPT를 생성하지 않고 지정된 v2 파일만 수정했는가

검증에 실패한 항목이 있으면 완료로 처리하지 않는다.
