# AIX 국비지원 PPT 후속 디자인 작업 지시서

## 임무

`AIX계열 국비지원 컨택&상담 스피치_김호영 부장_수정용_2페이지시안_v2.pptx`의 2페이지에서 확정된 디자인을 기준으로 나머지 작업 대상인 3–27페이지를 수정한다.

작업 결과는 반드시 위 `v2.pptx` 파일에 직접 저장한다. 새 PPT, 사본, 시안 버전은 만들지 않는다.

## 기준 자료

- 최종 작업 파일: `AIX계열 국비지원 컨택&상담 스피치_김호영 부장_수정용_2페이지시안_v2.pptx`
- 디자인 원본 이미지: `수정 사항.png`
- 겹침 문제 참고 이미지: `수정 사항2.png`
- 최우선 스타일 기준: 최종 작업 파일의 2페이지
- 내용 대조용 원본: `AIX계열 국비지원 컨택&상담 스피치_김호영 부장.pptx`

기준이 충돌하면 다음 우선순위를 따른다.

1. 사용자의 최신 지시
2. 최종 작업 파일 2페이지의 실제 디자인
3. `수정 사항.png`
4. 원본 PPT의 내용과 구조

## 변경 불가 조건

- 글꼴은 모든 텍스트에서 `Noto Sans KR`로 지정한다.
- 제목, 섹션명, 핵심 문구에는 Bold를 사용하고 보조 설명이나 푸터에는 Regular를 사용한다.
- 제목과 상단 `CONTENTS`가 겹치지 않도록 2페이지의 수정된 간격을 기준으로 한다.
- 글자 두께, 행간, 자간, 정렬, 내부 여백을 슬라이드마다 임의로 바꾸지 않는다.
- 이미지로 평면화하지 않는다. 텍스트, 도형, 선, 아이콘, 표는 가능한 한 PowerPoint에서 수정 가능한 개별 오브젝트로 재구성한다.
- 원문의 문장, 수치, 순서, 강조 의미를 요약하거나 생략하거나 새로 해석하지 않는다.
- 디자인을 위해 텍스트를 짧게 줄이지 않는다. 공간이 부족하면 도형 크기, 열 너비, 여백, 글자 크기를 먼저 조정한다.
- 기존 28–49페이지와 원본 파일은 참고만 하며 수정하지 않는다.
- 작업 파일 이외의 PPT 파일을 만들거나 덮어쓰지 않는다.

## 겹쳐진 페이지 및 오브젝트 처리

두 겹으로 겹쳐진 페이지나 오브젝트가 있으면 보이는 한쪽만 기준으로 삭제하지 않는다.

1. 원본 PPT와 최종 작업 파일에서 해당 페이지의 모든 텍스트와 개체를 대조한다.
2. 앞·뒤 레이어의 문구, 수치, 표 항목, 도형 레이블을 각각 추출한다.
3. 완전히 동일한 중복만 하나로 병합한다.
4. 어느 한쪽에만 있는 내용은 모두 유지한다.
5. 문장이 유사하지만 의미나 수치가 다르면 둘 다 남기고, 한 레이아웃 안에서 읽히도록 재배치한다.
6. 병합 후 원본 대비 누락된 고유 문구가 없는지 다시 검사한다.

## 2페이지 디자인 시스템

- 화면 비율과 슬라이드 크기는 기존 파일을 유지한다.
- 배경은 흰색을 기본으로 한다.
- 상단에는 작은 `CONTENTS`, 큰 네이비 제목, 그 아래 가는 파란 구분선을 둔다.
- 색상 기준:
  - 메인 네이비: `#0A356A`
  - 진한 블루 패널: `#064682`
  - 선·포인트 블루: `#0A4F99`
  - 번호 배지 배경: `#DDF0FF`
  - 설명 카드 배경: `#EEF7FF`
  - 설명 카드 테두리: `#B9D9F5`
  - 본문: `#111111` 또는 `#1E2B38`
  - 보조 문구: `#7B8794`
- 정보 구조는 `분류 패널 → 연결선 → 번호가 있는 핵심 카드 → 화살표 → 상세 설명 카드` 흐름을 우선 적용한다.
- 카드 모서리, 테두리 굵기, 번호 배지, 아이콘 선 스타일은 2페이지와 시각적으로 동일하게 유지한다.
- 모든 페이지에 억지로 같은 개수의 카드를 만들지 않는다. 원본 정보 구조에 맞게 카드 수와 행 수만 조절한다.

## 타이포그래피

- 모든 글꼴 이름과 동아시아 글꼴 이름을 `Noto Sans KR`로 설정한다.
- 2페이지의 시각적 위계를 기준으로 한다.
  - 상단 영문 라벨: 작고 굵게
  - 페이지 제목: 가장 크고 Bold
  - 분류 패널: 흰색 Bold
  - 핵심 카드 제목: Bold
  - 상세 설명: 읽기 쉬운 Bold 또는 Medium 수준
  - 푸터·보조 설명: Regular
- 자간은 과도하게 벌리지 않는다. 제목은 약간 좁게, 본문은 기본값에 가깝게 유지한다.
- 행간은 문장이 겹치지 않도록 확보하고, 도형 밖으로 넘치는 텍스트가 없어야 한다.
- `Noto Sans KR`가 작업 PC에 설치되어 있지 않아도 PPT의 글꼴 속성에는 해당 이름을 저장한다. 렌더링 검수 시 대체 글꼴 가능성을 기록한다.

## 슬라이드별 작업 절차

1. 작업 전 대상 파일이 PowerPoint에서 열려 있는지 확인하고, 열려 있으면 사용자가 닫은 뒤 진행한다.
2. 원본과 작업 파일의 같은 페이지에서 모든 고유 텍스트를 목록화한다.
3. 겹친 레이어와 중복 오브젝트를 대조하고 병합 기준을 결정한다.
4. 2페이지의 색, 글꼴, 카드, 선, 번호 체계를 적용해 레이아웃을 재구성한다.
5. 원본 텍스트를 축약 없이 배치한다.
6. 도형 이름과 적절한 Z-order를 정리해 이후 수정을 쉽게 한다.
7. 대상 파일에 직접 저장한다.
8. 렌더링 이미지로 잘림, 겹침, 정렬, 대비를 검사한다.
9. 원본과 텍스트를 다시 대조해 고유 내용 누락이 없는지 확인한다.

## 완료 판정

- 3–27페이지가 2페이지와 같은 디자인 언어를 사용한다.
- 모든 텍스트 오브젝트의 글꼴이 `Noto Sans KR`로 저장되어 있다.
- 텍스트 겹침, 도형 밖 넘침, 잘림이 없다.
- 원본에 있던 고유 문장, 수치, 항목이 모두 남아 있다.
- 완전히 동일한 중복만 제거되었다.
- 주요 구성 요소가 편집 가능한 PowerPoint 오브젝트다.
- 작업 파일 이외의 새 PPT가 생성되지 않았다.

조건을 만족하지 못한 페이지가 하나라도 있으면 완료로 보고하지 말고 해당 페이지를 수정한 뒤 다시 검수한다.
