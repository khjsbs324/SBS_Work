## 사이트 입력용 피드백

1. 컨테이너 최대 폭

css
/* 학생 코드 */
.con {
  max-width: var(--containner);
}

css
/* 정답 코드 */
.con {
  max-width: var(--container);
}

피드백:
정의된 토큰은 --container인데 사용부에 --containner가 남아 있어 최대 폭이 무효입니다. 1920px 실측에서도 .con의 max-width가 none으로 계산되어 콘텐츠가 화면 전체로 퍼집니다. 사용 변수명을 선언부와 맞춰야 합니다.

2. 5열 Grid 문법과 Flex 우회

css
/* 학생 코드 */
.grid-5 {
  grid-template-columns: repeat(5 1fr);
}
.product-grid { display: flex; }

css
/* 정답 코드 */
.grid-5 {
  display: grid;
  grid-template-columns: repeat(5, 1fr);
}
.product-grid { margin-top: var(--num4); }

피드백:
repeat()의 쉼표가 빠져 Grid 선언이 무효이고 product-grid의 Flex가 display:grid를 덮어씁니다. 실제 화면에서도 데스크톱 columns가 none으로 계산됩니다. Grid 문법을 바로잡고 Flex 우회를 제거해야 5열·3열·2열 전환이 정상 작동합니다.

3. 모바일 가로 스크롤

css
/* 학생 코드 */
body {
  min-width: 1600px;
}

css
/* 정답 코드 */
body {
  word-break: keep-all;
}

피드백:
최종 normal.css에 min-width:1600px이 남아 있습니다. 그래서 1024px·768px·480px에서도 문서 폭이 1600px으로 고정되고 오른쪽 콘텐츠가 화면 밖으로 밀립니다. 이 선언을 제거해야 반응형 미디어쿼리가 의미를 갖습니다.
