# 평가 사이트 등록

문제 또는 점수의 등록·수정 요청이 있을 때 적용한다. 로컬 자료 작성만으로 사이트 쓰기를 시작하지 않는다. 이미 등록 요청이 명확하다면 같은 승인을 다시 받지 않는다.

## 문제 등록

1. 선택한 평가의 AGENTS.md·Exam.md·수행준거·학생 안내·제출 양식·강사용 채점표에서 입력 내용을 준비한다. 과정명·교과목·능력단위명·평가도구·회차를 현재 사이트와 대조한다. 대상이나 원문 대응이 불명확한 경우 해당 저장만 보류한다.
2. `능력단위평가 → 해당 평가내역 → 전체점수 옆 평가도구 탭 → 평가문제등록`으로 이동한다. 같은 문제가 있으면 기존 문제를 수정한다.
3. 위쪽 **평가기준**에서 모든 능력단위요소와 수행준거를 선택해 추가하고 Exam의 배점을 대응시킨다. 수행준거의 원문·순서·개수를 보존한다. 상세 루브릭으로 원문을 교체하지 않는다.
4. 아래쪽 **문제등록**의 문제·설명·정답·채점기준을 각각 작성한다. 문제에는 평가명, 설명에는 목표·순서·조건, 정답에는 제출 파일명·형식·필수 내용을 넣는다. 이 사이트 입력란의 `정답`을 학생 배포 파일의 강사용 모범답안 공개로 해석하지 않는다.
5. 학생 공개용 **채점기준**에는 자연어 항목 제목과 점수를 굵게 쓰고 최고점부터 최저점까지 4단계 구간을 작성한다. 총점 제목도 굵게 쓴다. 내부 DC·DM·SO 코드, `증빙:`, 강사용 메모와 자동화 과정은 제외한다. 같은 원인으로 중복 감점하지 않음을 안내한다.
6. 파일 제출이면 업로드를 사용한다. 별도 URL 제출이 있을 때만 링크 기능을 사용한다. 수행준거 수·배점 합계·입력란·기능 설정을 확인한 뒤 저장한다.
7. 저장된 상세정보를 다시 열어 제목·설명·정답·채점기준, 수행준거 원문·개수·순서·배점, 총점과 업로드·링크 설정을 대조한다. 총점 100점 평가에서는 `100 / 100`을 확인한다. 성공 메시지만으로 완료 처리하지 않는다.

`채점기준 수정`을 `평가기준 수정`으로 해석하지 않는다. 길이 오류가 나면 입력란부터 확인하며 원문을 축약하지 않는다. 저장 오류 뒤에는 현재 상세정보에서 기존 자료 보존 여부를 먼저 확인하고 잘못된 항목만 고친다. 같은 원인의 재시도는 1회로 제한하고 지속되는 오류와 현재 저장 상태를 보고한다.

## 점수 등록

로컬 채점 결과와 계산 검증이 완료된 학생만 처리한다. 학생명·식별자·능력단위·수행준거·기존 점수를 대조하고 각 문항 점수·총점·공개 피드백을 입력한다. 현재 권한이나 학생 매칭이 불명확하면 저장하지 않는다.

저장 후 상세 화면의 학생·문항별 점수·총점·피드백 전문을 로컬 자료와 다시 비교한다. 실제 확인한 시각과 결과를 학생 기록에 남긴다. 로컬 검증 스크립트의 통과를 사이트 등록 완료 증빙으로 사용하지 않는다.

완료 보고에는 대상 평가·문제 또는 학생, 문항 수·총점, 요청한 기능 설정, 원문 보존 여부와 실제 상세화면 재검증 결과를 포함한다.
