# 채점과 피드백

## 기준과 증빙

대상 평가의 AGENTS.md·Exam.md·수행준거, [공통 피드백 지침](../../../../능력단위평가/피드백.md)과 평가별 피드백.md를 읽는다. 저장소가 필요한 평가에서만 해당 평가 또는 공통 학생 저장소 목록을 확인한다. 목록이 실제로 없으면 누락을 보고하며 PDF 제출 평가에 GitHub 주소를 새로 요구하지 않는다.

- 학생명과 제출물 식별 정보를 대조한다. 저장소 평가라면 URL·기본 브랜치·채점 커밋·검토 환경을, 파일 평가라면 파일명·크기·SHA-256·수령일을 기록한다.
- 학생 코드와 제출물은 읽기 전용으로 검토한다. 문항마다 직접 증빙과 판단을 기록하고 동일한 원인으로 반복 감점하지 않는다.
- 미확인 동작이나 판독 실패는 통과 또는 임의 0점으로 만들지 않는다. 미확인 항목은 보류하고 점수 계산 전에 해소한다.
- 코드·화면 검토는 해당 평가가 요구할 때 수행한다. PDF 과제는 내용·정보 구조·가독성을 검토한다. 취향, 가상 클라이언트 사용, AI 이용 여부를 임의 감점 요건으로 추가하지 않는다.

## 계산 자동화

평가별 환산 예외가 없고 총점이 100점인 경우 공통 환산식은 `ROUND(60 + 원점수 × 0.4, 0)`이다. 문항별 `배점 × 0.6 + 원점수 × 0.4`를 내림하고, 부족한 점수를 소수 잔여가 큰 순으로 배분한다. 동률이면 문항 원래 순서를 따른다.

[harness.py](../../../../scripts/harness.py)의 `scores`는 이 계산만 수행하며 학생의 원점수를 결정하지 않는다. 입력 JSON은 `rows` 배열에 고유 `id`, 양의 정수 `max`, 0~max의 정수 `raw`를 둔다. 합계 배점은 100이다. `null`, 소수, 불리언과 미확인 점수는 거부한다. 기존 `문항별_채점.json`도 입력할 수 있다.

```powershell
# 국비 폴더 기준. 실제로 준비한 입력 경로를 지정한다.
python -B scripts/harness.py scores "입력.json"
python -B scripts/harness.py check --records
```

계산은 JSON으로 표준 출력에 반환하며 입력 파일·등록 상태·검증 시각을 수정하지 않는다. 사용자나 평가 전용 지침에서 다른 환산식을 지정한 경우 이 공통 계산을 적용하지 않는다. 제출물 검사의 줄바꿈 경고는 원본 ZIP 및 수록 파일 해시가 일치할 때만 허용되며, 사본의 바이트 일치까지 요구하면 `check --records --strict-hashes`로 확인한다.

## 기록과 공개문

결과가 완성되면 해당 평가의 `채점 완료/<학생명>.txt`에 교사용 근거와 학생 공개문을 구분해 저장한다. 구조화 기록을 작성한다면 `채점 자료/<학생명>/문항별_채점.json`에 학생명, 평가명, `rows`, `rawTotal`, `registeredTotal`을 기록한다. 각 행에는 `id/max/raw/registered/evidence/judgement`를 둔다.

피드백은 실제 제출 근거와 구체적인 다음 수정 방법을 중심으로 작성한다. `~습니다` 문체를 유지하며 내부 ID·원점수·환산식·순위·다른 학생 정보·강사용 정답을 공개하지 않는다. 상세 표현 원칙은 공통·평가별 피드백.md에만 유지한다.

완료 전에 학생 식별·문항 대응·점수·증빙·공개문·결과 파일 수를 대조한다. 사이트 등록은 요청된 경우 [등록 절차](registration.md)를 이어서 수행한다.
