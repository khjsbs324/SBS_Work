# 학생 면담 기록

[면담 지침](<../../../국비 시상식/면담 일지/AGENTS.md>)을 읽는다. 학생이 체크하거나 직접 작성한 응답을 우선한다. 이미지형 PDF는 모든 페이지의 선택 항목과 서술형 답변을 확인한다. 자료가 없거나 판독되지 않으면 기존 다른 학생의 일지를 대신 사용하지 않는다.

실제 응답에서 학습 적응, 자신감·부담·흥미, 문제 해결과 도움 요청 방식, 도구·디자인·코딩·AI 활용, 확인되는 진로 고민을 구분한다. 진술과 관찰, 강사의 계획을 섞지 않는다. 해결 결과가 확인되어야 `해결함`으로 기록하고 결과가 없으면 `해결을 시도함`으로 쓴다. 모순된 응답은 양쪽 차이를 보존한다.

최종 면담 문서는 아래 두 최상위 항목만 사용한다. 각 범주는 불릿이나 표 없이 자연스러운 문단으로 작성하며, 없는 정보는 `면담 내용에서 확인되지 않았음`으로 짧게 남긴다.

```markdown
## [학생명] 학생 심리상태 분석

[실제 학습 상황에서 확인된 심리상태]

## 일지

### 1. 학습 상태 및 수업 적응

[학생의 진술과 확인된 학습 상태]

### 2. 직무 수행 및 NCS 학습 상태

[도구·디자인·AI·코딩·NCS 수행과 확인된 어려움]

### 3. 진로 및 상담 확인 사항

[확인된 희망 직무·취업·포트폴리오 고민과 지원 요구]
```

학생명이 없으면 첫 제목에서 학생명만 생략한다. 최종 문서에 판독 과정·출처 목록·점수·진단·별도 종합 의견·추가 제안을 넣지 않는다. 학생의 직접 진술은 `~라고 함`, `~다고 답함`으로 쓰며, 추정한 감정·출결·취업 시기·직무·포트폴리오 계획을 추가하지 않는다. 같은 근거를 표현만 바꾸어 반복하지 않는다.

파일 작성 요청이면 지정 파일을 UTF-8로 저장한다. 문서 형식 제한은 면담 산출물에 적용하며 자동화 구조 점검 같은 다른 작업의 보고 형식으로 확대하지 않는다.
