# 훈련시간 편성

[타임테이블 지침](../../../타임테이블/AGENTS.md)을 읽고 현재 과정·기간·시간대·교사·선후 조건과 확정 편성시간을 원본에서 정리한다. 기존 TXT, 예시 XLSX와 과거 확정기준은 과정이 다를 수 있다. 서로 다른 기간의 수치를 합치지 않는다.

1. 최신 자료에서 주말·지정 휴일을 제외한 훈련일과 시간대별 가용시간을 확인한다. 공휴일을 기억으로 확정하지 않는다. 사용자가 공급한 확정 가용시간이 있다면 이를 사용한다.
2. 교과의 교육적 선후관계와 사용자 고정 조건을 판단해 시간대별 순서를 정한다. 특정 교과의 오전·오후 고정을 유지한다.
3. 국비 폴더에서 `python -B scripts/harness.py timetable "입력.json"`을 실행한다. 입력 계약은 [HARNESS.md](../../../HARNESS.md)의 시간표 예시를 따른다. 스크립트는 정해진 순서대로 셀을 채우고 남는 시간을 다음 셀로 이월하며, 교과별 총시간을 교차 검산한다.
4. 출력의 셀별 배정·공란·교과별 합계를 원본과 대조한다. 가용시간이 남으면 공란으로 유지한다. 교과의 총시간을 늘려 채우지 않는다.
5. 요청한 XLSX 또는 연결된 스프레드시트의 대상 범위만 수정하고 같은 범위를 다시 읽어 수식·합계·시간대·서식을 확인한다. 현재 시트 수동 수정값을 오래된 대화 값으로 덮어쓰지 않는다.

스크립트는 배정 순서의 교육적 타당성, 휴일의 정확성, 교사의 중복 배정이나 실제 Google Sheets 반영 여부를 판정하지 않는다. 이 항목은 현재 원본과 편집 결과로 검토한다. 상세 커리큘럼은 요청받았을 때만 작성한다.
