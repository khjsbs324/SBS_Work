# 학생 면담 자료 지침

이 폴더는 학생 면담 기록과 검토 이미지를 보관한다. 학생별 TXT와 `.pdf_review/` 이미지는 기존 기록·근거이며 임시 파일로 일괄 삭제하지 않는다.

- 학생이 작성·선택한 실제 응답만 근거로 사용한다. 다른 학생의 기록, NCS 교재 또는 일반적인 학습 특성으로 빈 내용을 채우지 않는다.
- 학습 상황에서 확인되는 감정·부담만 기술하고 의학적·임상적 진단이나 성격 유형을 부여하지 않는다.
- 학생 진술, 확인한 수행 결과, 강사의 지원 계획을 구별한다. 응답 사이의 모순과 확인되지 않은 사항을 보존한다.
- 일지 작성 절차와 산출물 형식은 [student-interview](../../.agents/skills/student-interview/SKILL.md)를 따른다.
