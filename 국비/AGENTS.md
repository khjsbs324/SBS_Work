# 국비 작업공간 에이전트 지침

## 목적

HTML, CSS, JavaScript, GitHub만 사용하는 수업을 위한 NCS 평가자료를 즉시 활용할 수 있는 형태로 제작한다. 강사용 정답과 학생용 안내를 분리하고, 원본 PDF 및 코드와의 추적성을 유지한다.

## 필수 스킬

이 폴더에서 PDF 분석, 시험 출제, 산출물 생성, 채점기준 작성, 등록 결과 검증을 수행할 때 `skills/ncs-exam-production/SKILL.md`를 사용한다.

## 작업 원칙

- 편집하기 전에 현재 파일 구조와 관련 원본 파일을 확인한다.
- `문제 코드`와 `정답`을 현재 코드의 기준으로 삼는다.
- 사용자가 명시적으로 요청하지 않는 한 백엔드, 데이터베이스, 서버, 프레임워크 또는 배포 요구사항을 추가하지 않는다.
- 최종 자료는 `최종 결과 산출물`에 간결하게 정리하며, 요청 없이 중복 산출물 폴더를 만들지 않는다.
- `문제 출제 예시.pdf`와 비슷한 상세 수준으로 수행준거별 4단계 채점기준을 작성한다.
- 관련 없는 파일은 보존하고 총점, 한글 인코딩, 경로, 링크, 학생용 자료와 정답의 분리 여부를 검증한다.
- 실제 사이트에 등록할 때는 허가된 항목만 수정하고 저장된 상세 화면을 확인한다.

## 서브에이전트 배정

- NCS 원문 및 추적성 분석: `.agents/ncs-source-analyst.md`
- 프론트엔드 문제와 정답 검토: `.agents/frontend-exam-reviewer.md`
- 산출물, 채점기준 및 등록 결과 검수: `.agents/assessment-qa-reviewer.md`

최종 판단은 주 에이전트가 담당하며, 서브에이전트의 결과를 사용자의 최신 요청과 대조하여 조정한다.
