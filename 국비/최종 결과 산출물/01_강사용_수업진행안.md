# 강사용 수업진행안

## 1. 수업 개요

| 항목 | 내용 |
|---|---|
| 과제명 | MALBON 반응형 페이지 CSS 분리·오류 수정 |
| 대상 기술 | HTML, CSS, Git, GitHub |
| JavaScript | 사용하지 않음 |
| 권장 시간 | 3~4시간 |
| 작업 형태 | 개인 또는 2인 1조 |
| 기준 화면 | `문제 코드/정답.png` |
| 정답 코드 | `정답/index.html`, `정답/css/*.css` |

## 2. 학습 목표

- 하나의 큰 CSS 파일을 책임에 따라 분리할 수 있다.
- CSS 사용자 정의 속성, Grid 함수, `min-width`로 인한 반응형 오류를 개발자 도구로 진단할 수 있다.
- CSS 파일 연결 순서와 캐스케이드의 관계를 설명할 수 있다.
- Git 커밋과 GitHub Pull Request로 수정 근거와 결과를 남길 수 있다.

## 3. 수업 전 준비

- [ ] 학생 배포본에 `정답` 폴더와 강사용 정답 문서가 포함되지 않았는지 확인한다.
- [ ] `문제 코드/index.html`이 `./css/style.css` 한 개만 연결하는지 확인한다.
- [ ] `문제 코드/css/style.css`에 결함 3건이 유지되어 있는지 확인한다.
- [ ] `정답.png`가 열리는지 확인한다.
- [ ] Chrome 또는 Edge 개발자 도구 사용이 가능한지 확인한다.
- [ ] GitHub 저장소 생성 방식과 제출 마감 시각을 공지한다.

## 4. 학생에게 전달할 안내

> 제공된 HTML 구조와 화면 콘텐츠는 변경하지 않습니다. `style.css`를 8개 파일로 분리하고, 기준 이미지와 다르게 보이게 하는 CSS 오류 3건을 찾아 수정하세요. 답을 추측하지 말고 개발자 도구에서 무효 처리된 속성, 계산된 값, Grid와 비율을 확인한 근거를 제출 보고서에 기록하세요.

## 5. 권장 진행 순서

### 도입: 20분

1. 문제 화면과 `정답.png`를 비교한다.
2. 개발자 도구의 Styles, Computed, Layout 패널을 소개한다.
3. CSS 파일을 분리할 때 연결 순서가 유지되어야 함을 설명한다.

### 실습 1: CSS 구조 분석·분리 60~80분

학생은 `style.css`의 규칙을 다음 책임으로 분류한다.

- 브라우저 초기화·폰트
- 원시 디자인 토큰
- 프로젝트용 의미 토큰
- 버튼·아이콘
- 텍스트·이미지·상품 항목
- 컨테이너·Grid·공통 배치
- 페이지 섹션
- 반응형 미디어 쿼리

분리 후 `index.html`에서 8개 파일을 올바른 순서로 연결하게 한다.

### 실습 2: 오류 진단·수정 60분

- 넓은 화면에서 컨테이너 중앙 정렬과 최대 폭 확인
- BEST PICKS 상품 목록의 Grid 계산값 확인
- 1600px 미만에서 페이지 전체에 가로 스크롤이 발생하는지 확인

### 실습 3: 반응형·회귀 테스트 30분

1920, 1600, 1024, 768, 480px에서 헤더, 상품 Grid, 컬렉션, 프로모션, 푸터를 확인한다. 특히 1600px 미만에서 `body`가 뷰포트 너비로 줄어드는지, 하단 가로 스크롤바가 생기지 않는지 확인한다. 수정한 부분뿐 아니라 전체 페이지가 유지되는지 점검한다.

### 제출: 20분

브랜치, 커밋, PR, 전후 화면, 단일 제출 보고서를 확인한다.

## 6. 단계별 힌트

정답을 직접 말하지 않고 다음 순서로 제공한다.

1. 1차 힌트: `Computed`에서 기대한 속성이 실제로 적용되는지 확인하세요.
2. 2차 힌트: 변수명 철자, 함수 인수 구분자, 뷰포트보다 큰 최소 너비가 지정되어 있는지 확인하세요.
3. 3차 힌트: `.con`, `.grid-5`, `body` 선택자를 확인하세요.

## 7. 제출 직전 구두 확인 질문

- `normal.css`와 `root.css`의 역할 차이는 무엇인가?
- `component.css`가 `root.css` 다음에 와야 하는 이유는 무엇인가?
- CSS 선언이 무효 처리되었음을 개발자 도구에서 어떻게 확인했는가?
- 1920px에서 BUG-01이 가장 잘 드러나는 이유는 무엇인가?
- 미디어 쿼리는 바뀌는데 모바일에서 화면 전체가 줄어들지 않는다면 어떤 상위 요소의 계산값을 확인해야 하는가?
- 파일 분리 후에도 캐스케이드가 유지되는지 어떻게 검증했는가?
