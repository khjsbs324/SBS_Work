1. 기본 역할부터 차근차근 복습하기

파일과 구성요소가 헷갈릴 때 선택해 사용할 수 있는 복습 자료입니다. 먼저 한 요소를 직접 열어 역할을 설명하고, 그다음 13개 전체로 넓혀 갑니다.

순서작은 실습완료 모습
1 · 10분초안·최종 파일 찾기같은 번호 두 파일이 열린다.
2 · 15분역할과 상태 구분하기요소가 전달하는 정보를 한 문장으로 말한다.
3 · 15분버튼 한 쌍 비교하기바뀐 점 또는 유지 이유를 적는다.
4 · 15분웹의 적용 위치 찾기가이드와 웹의 같은 요소를 짚는다.

실제 점수 등급을 나누는 자료가 아닙니다. 자신에게 필요한 부분을 복습한 뒤 B자료의 과정 기록이나 A자료의 최종 점검으로 이어가세요.

오늘의 목표: 자신의 7번 Button 초안·최종 한 쌍을 열고, 어떤 행동을 돕는지와 달라진 점을 설명합니다.

3. 같은 번호의 초안·최종 파일 찾기

제출용 복사본에서 파일 목록을 정리합니다. 번호를 바꾸기 전에 어떤 요소인지 먼저 열어서 확인하세요. 확장 요소를 추가했더라도 필수 13개가 사라지지 않도록 구분합니다.

파일 묶음찾을 내용
1~2표지 / Getting Started
3~6Colors / Typography / Spacing & Sizing / Radius & Effects
7~8Button / Badge
9~12Progress / Question Number / Quiz Option / Timer
13Card

예를 들어 스타일가이드_초안7.png와 스타일가이드_최종7.png를 함께 열면 두 파일 모두 Button이어야 합니다. “최종7”이라는 이름만 보고 판단하지 말고 실제 내용을 읽습니다.

실습 2: 13개 대응목록.csv에서 열린 파일과 아직 찾지 못한 파일을 구분하세요. 파일이 없거나 열리지 않으면 그 상태를 기록하고 먼저 보완합니다.

4. 버튼 하나의 의도와 변화 설명하기

자신의 버튼에서 누가, 어떤 행동을 해야 하는지 먼저 정합니다. 가상 전시 예약 예시에서는 “관람 시간을 고른 사람이 예약 단계로 이동하도록 돕는다”가 버튼의 목적입니다.

비교 질문작성 도움
어떤 행동인가요?버튼 문구를 읽고 다음 화면이나 상태를 말합니다.
무엇이 보이나요?배경색·문구·테두리·간격 중 실제 보이는 것을 적습니다.
어떻게 달라졌나요?초안과 최종의 차이를 같은 위치에서 찾습니다.
왜 바꾸거나 유지했나요?읽기·선택·브랜드 인상과 연결합니다.
웹에서도 같은가요?최종 HTML에서 같은 버튼을 찾아 상태를 확인합니다.

“색을 바꿨다”에서 멈추지 말고 “주요 예약 행동을 구분하려고 강조색을 적용했다”처럼 목적을 붙입니다. 실제 결과에서 구분이 안 된다면 문구·대비·주변 배치를 다시 살펴봅니다.

실습 3: 버튼 하나를 설명한 뒤 Badge 또는 Card로 반복하세요. 작은 비교가 익숙해지면 B자료를 이용해 전체 변경·유지 이유를 정리합니다.

5. 직접 열어 확인하고 다음 학습으로

  • 초안·최종 이미지가 각각 13장인지 목록과 실제 파일을 대조한다.
  • 두 HTML을 열어 스타일가이드 모음과 실제 웹 화면을 구분한다.
  • 가이드의 버튼·카드가 웹의 어느 위치에 적용됐는지 찾는다.
  • 파일명과 설명의 번호가 같은지 확인한다.
  • 찾지 못한 파일과 설명하기 어려운 요소를 질문으로 남긴다.
