1. 경험부터 최종 화면까지 대조하기

비교한 대안과 시각적 방향이 마련되어 있다면 이제 실제 경험, 소개 문장, 화면에서 보이는 정보가 같은 이야기를 하는지 확인합니다. 기존 썸네일 또는 커버와 소개 페이지를 펼쳐 놓고 중복 문구·이름·교육 상태·출처를 함께 점검하세요.

  1. 직접 판단하고 수정한 경험 한 장면을 고릅니다.
  2. 그 경험을 설명하는 브랜드 문장과 연결합니다.
  3. AI에 준 조건과 최종 서체·색·이미지 선택을 대조합니다.
  4. 두 화면의 정보와 읽는 순서를 동료에게 확인합니다.

이번 자료는 기존 두 화면과 기획·수정 기록을 다듬는 실습입니다. 프로젝트 개수나 새 웹사이트 제작을 늘리기보다 자신이 이미 한 작업을 정확하게 설명하는 데 집중하세요. 실제 AI 대화와 수정 전후 화면, 사용 자산의 출처를 준비합니다.

2. 경험을 브랜드 문장의 근거로 쓰기

가상 예로 버튼 이름과 실제 연결의 불일치를 찾아 바꾼 경험이 있다면 “사용자가 예상한 행동과 화면을 맞추는 디자이너”라는 문장으로 연결할 수 있습니다. 이 문장을 자신의 소개에 그대로 쓰기보다 실제로 한 행동과 판단이 드러나도록 바꾸세요.

연결 항목작성할 내용
상황어느 작업의 어떤 장면이었는가
판단과 행동무엇을 보고 어떤 선택·수정을 했는가
확인한 결과실제 화면 또는 기록에서 무엇을 확인했는가
브랜드 문장그 경험으로 설명할 수 있는 작업 태도는 무엇인가

확인하지 않은 성과 수치나 맡지 않은 역할은 넣지 않습니다. “문제 해결력이 좋다”에서 멈추지 말고 실제 수정 화면을 근거로 붙이세요. 작업물을 소개하는 순서도 핵심 문장을 가장 잘 뒷받침하는 사례가 먼저 오도록 검토합니다.

3. 대안 비교와 AI 조건을 다시 보기

초안 여러 개가 남아 있다면 최종안을 고른 기준을 같은 항목으로 비교합니다. 서체·색·질감·명암을 모두 바꾸었다면 어떤 문제가 있어서 각각을 조정했는지 기록하세요.

비교 기준초안에서 볼 것최종안에서 확인할 것
전달 내용경험과 무관한 장식이나 표현소개 문장의 핵심이 보이는가
가독성이름·본문이 배경에 묻히는 부분실제 표시 크기에서 읽히는가
일관성커버와 소개의 다른 시각 규칙제목·본문·강조 색 역할이 같은가

새 질문이 필요하다면 “내가 제공한 경험 안에서 소개문 두 가지를 제안하고 각 문장의 근거가 된 행동을 표시해 줘. 없는 경력은 추가하지 마”처럼 자료와 조건을 구체적으로 적어 보세요. 이것은 연습용 질문 예시이며 실제 사용 기록은 별도로 남깁니다.

이미지 질문도 대상·구도·분위기·문자를 놓을 여백처럼 화면에 필요한 조건을 씁니다. 기존 생성물을 검토하는 것만으로도 실습할 수 있으며 새 유료 생성은 필수 활동이 아닙니다.

4. 두 화면의 정보와 출처 정밀 점검

이름의 영문 표기, 교육 과정의 수료·수강 상태, 연락 정보 등은 본인이 확인한 기준 자료와 대조합니다. 초안에 있던 예시 문구가 실제 이력처럼 남아 있지 않은지도 확인하세요.

항목대조 방법
중복 문구커버는 핵심 메시지, 소개는 그 근거를 설명하는지 확인
이름·교육 상태두 화면을 나란히 두고 같은 표기와 현재 사실인지 확인
서체·컬러제목·본문·강조의 역할과 실제 적용 위치 대조
자산 출처폰트·이미지의 제공처, 이용 조건 확인 위치, 적용 화면 기록

출처가 확인되지 않은 자산은 확인할 항목으로 표시하고 교체 여부를 정합니다. Adobe Fonts 안내는 해당 서비스의 글꼴을 검토할 때 참고하며, 다른 제공처의 글꼴은 그 제공처의 안내를 확인하세요. 학습자료를 읽는 것은 무료이나 실제 도구·자산 이용 범위는 별도입니다.

화면 속 표기만 고친 뒤 끝내지 말고 원본과 내보낸 이미지 양쪽에서 같은 내용인지 다시 읽어 보세요.

5. 동료의 첫인상과 읽는 순서 확인

동료에게 커버와 소개 페이지를 먼저 보여 주고 “어떤 작업을 하는 사람으로 보이나요?”, “어느 문장을 먼저 읽었나요?”라고 물어보세요. 원하는 답을 먼저 알려 주지 말고 실제 답변을 짧게 기록합니다.

  1. 내가 전달하려는 핵심 문장을 별도로 적습니다.
  2. 동료가 처음 읽은 문장과 이해한 내용을 기록합니다.
  3. 의도와 다른 부분을 문구·배치·대비 중 어떤 문제인지 살펴봅니다.
  4. 수정 한 건을 반영하고 두 화면을 다시 확인합니다.

실습양식의 경험 대응표에는 작업 파일과 근거 위치를, 대안 비교표에는 실제 질문·초안·최종 선택을, 최종 점검표에는 사실·출처와 동료 확인 결과를 남깁니다. 대화 기록이 길면 해당 결정이 드러나는 부분을 표시하세요.

같은 동료에게 다시 확인했다면 이미 내용을 알고 있다는 점을 기록합니다. 작은 확인 결과를 전체 사용자의 반응으로 확대하지 않고 실제 답변과 수정한 내용을 설명하세요.

6. 완료 기준과 포트폴리오 연결

  • 소개 문장의 근거를 실제 경험과 파일에서 찾을 수 있습니다.
  • 대안의 선택·수정 이유가 최종 화면에 반영되어 있습니다.
  • 두 화면의 시각 규칙과 이름·교육 상태가 일치합니다.
  • 중복된 문구와 예시 정보가 정리되어 있습니다.
  • 사용한 자산의 출처와 확인할 이용 조건이 기록되어 있습니다.
  • 동료의 실제 답변과 수정한 내용이 연결됩니다.

교사에게 경험 한 장면, 이를 설명하는 소개 문장, 최종 화면을 순서대로 보여 주세요. 근거가 약한 문장은 표현을 줄이거나 다른 실제 경험으로 바꿉니다.

이후 포트폴리오에서는 핵심 소개문을 뒷받침하는 작업을 먼저 배치합니다. AI가 제시한 표현보다 본인이 선택하고 수정한 이유를 설명할 수 있도록 질문 기록과 수정 전후 자료를 함께 보관하세요.
