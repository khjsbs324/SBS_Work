1. 원본과 최종 내보내기 파일을 같은 화면에서 확인합니다.
2. 이름과 핵심 문장을 직접 읽어 봅니다.
3. 가장 먼저 고칠 한 항목을 교사와 정합니다.
4. 실제 질문·초안·수정본·선택 이유를 한 묶음으로 모읍니다.

를 기준으로 두 화면을 통일하세요. 교육·자격의 상태도 실제 내용과 맞는지 확인합니다.
점검 항목 확인 방법

본문과 배경 글자가 질감·사진·유사한 밝기에 묻히는지 확인

목을 바꾼 뒤 다시 내보내서 읽어 보세요. 편집 화면을 확대했을 때만 보이는 상태로 끝내지

3. 실제 질문부터 수정본까지 모으기
AI를 사용한 과정은 대화 화면과 파일에서 확인할 수 있어야 합니다. 대화가 길면 이번 결정에
관련된 질문과 답변을 찾아 위치를 적습니다. 초안과 수정본은 서로 구분되는 파일명이나 캡
처로 남기세요.

4. 콘셉트와 최종 선택의 이유 연결하기
콘셉트가 “차분함”이라면 자신의 어떤 작업 태도나 경험과 연결되는지 한 문장으로 적습니다.
근거를 찾기 어렵다면 표현을 줄이고 실제로 한 행동부터 정리하세요.
1. 실제로 한 작업 한 장면을 고릅니다.
2. 그때 직접 판단하거나 바꾼 내용을 적습니다.
3. 경험과 연결할 짧은 소개 문장을 씁니다.
4. 커버의 메시지와 소개 페이지가 그 문장을 설명하는지 봅니다.
5. 최종 서체와 색을 고른 이유를 해당 화면에서 확인합니다.
가상 예로 정보의 순서를 바꾸어 제목을 먼저 보이게 했다면 “읽는 순서를 정리했다”는 행동을
설명할 수 있습니다. 실제로 하지 않은 결과를 자신의 경험으로 사용하지 마세요.
서체는 후보 목록을 남기는 것에서 끝내지 말고 최종으로 사용한 이름과 제목·본문의 역할을
적습니다. 사용 자산의 제공처와 이용 조건 확인 링크도 기록합니다.

5. 수정 한 건을 반영하고 다시 확인하기
처음 정한 우선 항목을 수정한 다음 원본과 내보낸 두 화면을 다시 엽니다. 이름을 고쳤다면
모든 위치가 같은지, 대비를 고쳤다면 실제 표시 크기에서 읽히는지 확인하세요.
1. 수정 전 화면과 문제가 있는 위치를 남깁니다.
2. 한 항목을 수정하고 최종 파일을 구분해 저장합니다.
3. 동료에게 이름과 핵심 문장을 읽어 보게 합니다.
4. 실제 답변과 남은 문제를 기록합니다.
5. 질문·초안·수정본·선택 이유를 한 묶음으로 보여 줍니다.
실습양식 1은 본인 정보와 가독성, 2는 실제 AI 대화와 수정 과정, 3은 경험·콘셉트·최종 확인에
사용합니다. 빈칸에 예상 결과를 넣지 말고 파일과 화면에서 확인한 내용을 적으세요.
새로운 유료 생성은 필요하지 않습니다. 기존 대화와 화면만으로도 수정 이유를 정리할 수 있
습니다. 확인하지 못한 부분은 남은 질문으로 적고 교사와 함께 확인합니다.

6. 완료 기준과 이어서 할 일

핵심 문장과 본문을 실제 표시 크기에서 읽을 수 있습니다.
실제 질문·초안·수정본을 찾을 수 있거나 없는 기록이 구분됩니다.
고친 위치와 최종 선택 이유를 화면에서 설명합니다.
콘셉트가 실제 경험과 연결되고 최종 서체가 정해져 있습니다.
출처 확인과 남은 작업이 기록되어 있습니다.
교사에게 가장 먼저 고친 한 항목을 직접 보여 주세요. 수정 전후의 차이를 설명하고, 아직 확
인하지 못한 사항은 다음 순서로 정합니다. 모든 기록을 한 번에 완벽하게 꾸미기보다 실제 근
거를 찾을 수 있도록 정리하세요.
다음 포트폴리오 학습에서는 정확한 소개 화면을 바탕으로 자신이 한 작업과 수정 이유를 덧
붙입니다. AI 제안을 그대로 나열하기보다 본인이 고른 이유를 짧게 설명하는 연습을 이어 갑
