1. 선택 기초학습의 목표

이 자료는 필요할 때 선택하는 기초 연습입니다. 원본과 연습 사본을 구분하고 HTML·CSS 연결부터 화면 변화 한 건을 확인합니다. 특정 학습자가 반드시 이 단계부터 시작해야 한다는 뜻은 아닙니다.

순서할 일스스로 설명할 것
준비ZIP을 풀고 lab/index.html 열기어느 파일을 열었는가
연결styles.css와 link 경로 확인어디의 CSS를 읽는가
수정연습 CSS 한 값만 변경무엇을 왜 바꿨는가
확인저장·새로고침·전후 비교화면에서 무엇이 달라졌는가

독립 제작한 카드 예시는 2개 파일로 이루어집니다. MALBON 평가 정답이나 제출물 전체가 아니며, 연습을 마친 뒤 자신의 평가 파일에 같은 확인 습관을 적용합니다.

2. 파일에서 화면까지 이어지는 시각 예시

HTML은 내용의 구조, CSS는 표현 규칙을 담당합니다. 파일이 같은 폴더라면 ./styles.css처럼 현재 HTML에서 출발하는 경로를 사용합니다. 다른 폴더라면 실제 구조에 맞춰 경로가 달라집니다.

<link rel="stylesheet" href="./styles.css">
  • 편집기에서 styles.css를 열고 .card의 padding 값을 찾습니다.
  • 연습 사본에서 그 값 한 개만 바꿔 저장합니다.
  • 같은 lab/index.html 화면을 새로고침하고 전후를 비교합니다.
  • 바뀌지 않으면 다른 사본을 열었는지, 저장했는지, 경로가 맞는지부터 확인합니다.

초기화하거나 전체 코드를 지우기보다 연결 한 곳씩 확인합니다. DevTools의 임시 변경은 실제 파일 저장과 다르다는 점도 구분하세요.

3. 내 과제의 CSS 역할 지도 만들기

작은 연습 파일은 연결 원리를 익히기 위한 것입니다. 실제 평가는 다음 8개 CSS 파일을 역할별로 분리하고 연결하도록 되어 있습니다. 현재 자신의 파일명을 읽고 표 옆에 위치를 적어 보세요.

파일역할확인
normal.cssreset·기본 요소기존 의미 구조·포커스 보존
root.css공통 원시 변수선언 이름과 범위
component.css프로젝트 의미 변수주석·문법과 실제 적용
btn_cpn.css버튼·아이콘링크와 버튼 역할
item_cpn.css개별 항목·유틸리티공통 항목 책임
layout_cpn.css컨테이너·Grid너비와 배치
style.css페이지별 영역중복 연결·덮어쓰기
media.css화면 구간별 변경기본 규칙과 연결

처음에는 모든 규칙을 다시 나누지 말고 한 규칙이 어디에 있는지 찾습니다. 파일이 열리고 내용이 있으며 HTML에서 한 번 연결되는지 확인한 뒤 다음으로 넘어갑니다.

4. 작은 Grid와 좁은 화면 관찰

lab 예시의 카드 4개는 넓은 화면에서 2열, 좁은 화면에서 1열로 배치됩니다. 아래 코드는 연습 원리를 설명하며 평가 상품의 열 수 기준은 자신의 원문 요구사항을 확인해야 합니다.

.cards {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  gap: 16px;
}
@media (max-width: 600px) {
  .cards { grid-template-columns: 1fr; }
}

먼저 1024px와 480px에서 카드 열 수가 달라지는지 봅니다. 가로로 밀리면 body나 상위 요소에 최소 폭이 남았는지 확인합니다. 열 정의만 고쳐도 display가 다른 규칙에 의해 바뀌면 기대한 배치가 나오지 않을 수 있습니다.

변수는 선언 이름과 var() 사용 이름이 같아야 합니다. 한 글자 차이, 주석 기호 누락, 쉼표 누락은 화면을 바꿀 수 있습니다. 무작정 수치를 추가하기보다 Styles에서 문제 선언을 찾습니다.

양식직접 적을 것확인할 결과

02 작은 수정한 선택자·수정 전후값·이유같은 화면의 변화
03 검사와 질문너비·열 수·결과·남은 질문실제 수행한 범위
  • 연습 1: .card의 여백 한 값을 바꾼 뒤 전후 화면을 남깁니다.
  • 연습 2: 1024px와 480px에서 열 수와 글자 읽기 상태를 적습니다.
  • 연습 3: 키보드 Tab으로 예시 링크를 찾아 현재 위치 표시를 확인합니다.

익숙해지면 실제 평가의 1920·1600·1024·768·480px로 확인 범위를 확장하세요. 하지 않은 검사는 미확인으로 적습니다. 파일 요청이 성공해도 문법 때문에 실제 규칙이 적용되지 않을 수 있어 화면까지 함께 봅니다.
