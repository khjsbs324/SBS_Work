1. 파일을 열고 작은 목표 정하기

여러 기능을 한꺼번에 늘리기 전에 한 사람이 한 가지 일을 끝낼 수 있는 흐름을 만듭니다. 다이어리 선택 또는 생성, 상품 담기, 시간 설정 중 자신의 화면에 있는 과업 하나를 고르세요.

  1. Figma 원본을 열고 현재 작업 페이지와 화면을 확인합니다.
  2. 실행 링크를 열어 사용자가 처음 보는 화면을 확인합니다.
  3. 이번에 끝낼 일을 한 문장으로 씁니다.
  4. 시작·행동·결과·복귀 네 칸을 교사와 함께 채웁니다.

예를 들어 “오늘의 기록을 만들고 목록에서 다시 찾는다”는 완료 여부를 확인할 수 있습니다. “앱 전체를 완성한다”는 범위가 너무 넓으므로 이번 실습의 목표로 쓰지 않습니다.

원본을 복제하거나 수정 전 화면을 보관하세요. 다른 페이지에 있는 예전 시안으로 실행되지 않는지 먼저 확인합니다. 자신이 아직 만들지 않은 기능은 남은 항목으로 적고 핵심 흐름에 필요한 화면부터 준비합니다.

2. 네 칸으로 필요한 화면 찾기

네 칸가상 기록 예시자신의 화면에 적을 것
시작홈의 기록 메뉴처음 보이는 화면과 진입 버튼
행동오늘 기록 작성선택·입력·확인하는 화면
결과저장 완료 안내무엇이 끝났는지 보여 주는 상태
복귀목록에서 기록 확인돌아갈 화면과 확인할 항목

상품 담기라면 결과는 담긴 상품 안내이고 복귀는 상품 탐색을 이어갈 위치가 됩니다. 시간 설정이라면 설정 메뉴로 들어가 시간을 바꾸고 저장한 값을 다시 확인하는 흐름이 됩니다. 같은 네 칸을 사용하되 자신의 과업에 맞게 내용을 바꾸세요.

네 칸 중 빈 곳이 있으면 필요한 화면 또는 상태를 먼저 찾습니다. 빈 칸을 새 기능 목록으로 늘리지 않고 그 과업을 마치는 데 필요한 한 장면부터 보완합니다.

3. 올바른 시작점과 연결 만들기

시작점은 실행했을 때 과업이 출발하는 화면입니다. 편집 화면에서 원하는 장면을 보고 있었어도 실행 링크가 다른 흐름을 열 수 있으므로 링크를 다시 열어 확인해야 합니다.

  1. 시작 화면의 상위 프레임을 선택하고 프로토타입의 흐름 시작점을 확인합니다.
  2. 누를 버튼 또는 요소를 선택하고 목적지 프레임을 연결합니다.
  3. 어떤 행동에서 어느 화면으로 이동할지 확인합니다.
  4. 네 칸 순서대로 실행하고 막힌 연결을 수정합니다.
  5. 실행 링크를 새로 열어 같은 시작점에서 다시 시도합니다.

기상 시간을 바꾸는 기능이 엉뚱한 메뉴에서 열리면 메뉴 이름과 연결을 함께 살펴보세요. “설정”에서 예상하는 내용과 실제 화면이 맞는지 확인합니다. 메뉴와 화면 이름을 적어 놓으면 잘못된 목적지를 찾기 쉽습니다.

뒤로 가기와 팝업 닫기도 눌러 봅니다. 팝업을 닫은 뒤 원래 화면이 보이는지, 완료 후 막다른 화면에 남지 않는지 확인하세요.

4. 완료 안내와 저장한 내용 확인하기

버튼을 눌렀다는 사실과 일을 마쳤다는 사실은 다릅니다. 결과 화면에서 무엇이 완료되었는지 알 수 있어야 합니다. 실제 서비스 연동이 없는 시제품에서는 해당 상태를 화면으로 표현하고 그 범위를 설명합니다.

과업완료 상태의 예추가로 확인할 것
기록 만들기기록 제목과 저장 완료 문구목록에서 해당 기록을 찾을 수 있는가
상품 담기상품 이름과 담기 완료 안내담긴 항목을 확인하거나 탐색으로 돌아가는가
시간 설정선택한 시간과 저장 결과다시 열었을 때 설정한 값을 확인하는가
  1. 완료 안내 문구에 대상이 드러나는지 읽어 봅니다.
  2. 결과 뒤에 누를 버튼을 정하고 복귀 화면을 연결합니다.
  3. 수정한 값을 확인할 장면을 준비합니다.
  4. 직접 실행하며 네 칸 흐름표와 화면을 대조합니다.

화면만 바뀌고 완료 안내가 없다면 간단한 문구와 결과 확인 위치부터 보완하세요. 애니메이션이나 장식은 흐름이 끝까지 이어진 뒤 검토합니다.

5. 동료가 도움 없이 시연하도록 하기

교사와 함께 한 번 흐름을 확인한 다음 동료에게 목표만 말하고 실행해 보게 합니다. “오늘 기록을 만들고 다시 찾아보세요”처럼 안내하고 어떤 버튼을 눌러야 하는지는 먼저 설명하지 않습니다.

  1. 처음 화면을 열고 실행할 과업을 읽어 줍니다.
  2. 동료가 어디를 누르고 어디서 멈추는지 봅니다.
  3. 도움을 주었다면 어떤 말을 했는지 기록합니다.
  4. 완료와 복귀까지 이어졌는지 네 칸에 표시합니다.
  5. 막힌 지점 하나를 고친 뒤 같은 시작점에서 다시 확인합니다.

실습양식에는 실제로 확인한 결과만 적습니다. 아직 실행하지 않은 계획은 “다음 작업”에 적고 “완료”로 표시하지 않습니다. 한 번에 끝나지 않아도 멈춘 위치가 구체적이면 다음에 고칠 곳을 정할 수 있습니다.

완료 화면 캡처와 실행 링크를 함께 남기세요. 링크가 열리는지 동료와 확인하고, 교사에게 수정한 위치를 직접 보여 주며 설명합니다.

6. 한 과업을 마친 뒤 점검하기

  • 실행 링크가 정해 둔 시작 화면을 엽니다.
  • 메뉴와 버튼이 목적에 맞는 화면으로 이어집니다.
  • 한 과업의 결과와 완료 안내를 확인할 수 있습니다.
  • 완료 뒤 목록이나 원래 화면으로 돌아옵니다.
  • 도움 없이 수행한 결과와 막힌 위치가 구분되어 있습니다.
  • 반영한 수정과 다음에 할 일을 따로 적었습니다.

직접 시연하면서 시작·행동·결과·복귀를 순서대로 설명해 보세요. 동료가 같은 과업을 마칠 수 있다면 다음으로 필요한 작은 과업을 하나 정합니다. 아직 도움이 필요했다면 그 위치부터 다시 보완하세요.

다음 AI 기획 학습에서는 이번에 해결한 작은 문제를 실제 경험으로 정리할 수 있습니다. 처음부터 큰 성과를 적기보다 자신이 찾은 문제와 직접 수정한 화면을 근거로 설명하세요.
