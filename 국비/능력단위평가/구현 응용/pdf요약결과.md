## 원문 분리 기준

PDF는 각 학습 내용에 구현과 구현 응용의 목표를 함께 제시한다. 이 평가에서는 다음과 같이 `구현 응용` 문장만 분리했다.

- 학습 1: 전체 콘텐츠를 `구성하고 활용`, 시각적 흐름을 `제시하고 구현`, 기술개발을 `제안하고 활용`하는 문장 3개
- 학습 2: `표준화된 기준`, `효과적 구현`, 개발사항을 `구현하여 활용`하는 문장 3개
- 학습 3: 개발진과 `협업하고 활용`, 디자인 내용을 `정리, 문서화하여 전달`, 본래 의도에 최적화된 결과물을 `도출하고 정리`하는 문장 3개
- 위 응용 표현이 없는 기본 문장은 `0802010418_16v3`으로 보아 제외했다.

## 1. 콘텐츠 구성하기

1. 정보설계와 디자인 방향성을 기반으로 전체 콘텐츠를 구성하고 여러 화면·맥락에서 활용한다.
2. 콘텐츠 구조와 특성에 맞는 시각 흐름을 실제 화면·상호작용으로 구현한다.
3. 영역별 멀티미디어 기능을 기술 수준으로 제안하고 프로젝트 안에서 활용한다.

개인 브랜딩 포트폴리오에서는 홈·프로필·프로젝트 목록·상세·문의의 콘텐츠 모델과 공통 구성요소, 프로젝트 데이터, 내비게이션·읽기·행동 흐름을 실제 소스에 연결한다.

## 2. 기능 요소 활용하기

4. 웹 매체 특성을 이해하고 시맨틱 구조, 반응형, 접근성, 자산·코드 규칙 등 표준화된 기준에 맞게 콘텐츠를 구현한다.
5. 이미지·영상·애니메이션·필터·모달 등 필요한 디지털 미디어 기능을 효과적으로 제작한다.
6. 매체별 개발사항을 모듈·컴포넌트·유틸리티 등 재사용 가능한 방식으로 구현해 활용한다.

효과의 화려함보다 콘텐츠 목적, 성능, 키보드 조작, 대체 콘텐츠, 오류·빈 상태와 환경별 안정성을 함께 평가해야 한다.

## 3. 개발 요소 협업하기

7. 웹 매체와 기술 트렌드에 맞는 개발 이슈를 개발진 또는 제공된 협업 시나리오와 검토하고 실제 구현에 활용한다.
8. 디자인 토큰, 컴포넌트 상태, 반응형 규칙, 자산·파일 위치와 판정 기준을 정리·문서화해 전달한다.
9. 협의 결과를 반영해 본래 디자인 의도와 사용자 목적에 맞게 기능·성능·접근성을 최적화하고 결과를 정리한다.

협업 상대가 없는 개인평가에서는 강사 제공 이슈를 사용할 수 있다. 실제 응답을 창작하지 않고 요청·질문·결정·반영·재검증의 흐름을 증빙한다.

## 구현과 구현 응용의 차이

| 구분 | 구현 | 구현 응용 |
|---|---|---|
| 콘텐츠 | 전체 콘텐츠를 구성 | 구성한 콘텐츠를 구조적으로 활용 |
| 흐름 | 시각 흐름을 제시 | 시각 흐름을 실제 구현 |
| 기능 제안 | 기술개발 제안 | 제안한 기능을 실제 활용 |
| 기준 | 매체에 적합하게 구현 | 표준화된 기준에 맞게 구현 |
| 미디어 | 기능요소 제작 | 목적에 맞게 효과적으로 제작 |
| 개발 | 개발사항 구현 | 구현한 개발사항을 재사용·활용 |
| 협업 | 개발진과 협업 | 협업 결과를 구현에 활용 |
| 전달 | 디자인 정보 전달 | 정리·문서화하여 전달 |
| 최적화 | 최적화 결과 도출 | 본래 의도에 맞게 도출하고 정리 |

## 현재 평가 설계 반영

- 기존 개인 브랜딩 포트폴리오 구현 결과 또는 강사 제공 시작 소스를 입력 자료로 사용한다.
- 콘텐츠 모델·공통 컴포넌트·기능을 여러 화면과 반응형 환경에서 재사용한다.
- HTML 의미 구조, CSS 토큰·레이아웃·상태, JavaScript 모듈·예외 처리와 자산 규칙을 표준화한다.
- 실제 브라우저에서 데스크톱·태블릿·모바일, 키보드, 오류·빈 상태, Console·Network와 성능을 점검한다.
- 실제 검토 의견 또는 강사 제공 이슈를 문서화하고 수정 전후·재검증을 근거 ID로 연결한다.
- 외부 배포보다 로컬 실행과 직접 증빙을 우선한다.

## 평가 방법

- 개인 포트폴리오: 실행 가능한 응용 구현 소스 ZIP과 구현 응용 보고서 PDF
- 동작 확인: 제출 소스를 로컬에서 실행하고 화면·링크·상호작용·반응형·키보드·오류 대안을 직접 점검
- 과정 확인: 표준 기준, 기술 제안, 개발 전달, 협업 결정, 수정 전후와 재검증을 근거 ID로 추적
- 최적화 판단: 기능 수보다 본래 디자인 의도, 매체 특성, 재사용성, 안정성, 성능과 접근성에 맞는 선택을 평가
