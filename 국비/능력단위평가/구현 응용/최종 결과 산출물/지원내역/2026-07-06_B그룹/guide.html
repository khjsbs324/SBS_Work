3. 2차 안에 3차를 중첩하기

<li class="primary-item">
  <a href="#library">자료 살펴보기</a>
  <div class="sub-panel">
    <ul class="secondary-list">
      <li class="secondary-item">
        <a href="#design">디자인</a>
        <ul class="third-list">
          <li><a href="#type">타이포그래피</a></li>

3차 목록은 해당 2차 항목의 li 안에 들어갑니다. 3차 항목 하나를 먼저 만든 뒤 같은 구조를 반복하세요. 화면에서 나란히 보인다고 HTML에서도 올바른 자식이라는 뜻은 아닙니다.

실습: 선택한 2차 항목의 직접 자식을 표시하세요. 메뉴 제목 a와 3차 목록 ul이 같은 li 안에 있는지 확인하고 나머지 항목으로 확장합니다.

4. 클래스와 선택자가 실제로 만나는지 확인하기

스타일이 안 먹으면 값부터 크게 바꾸지 말고 선택자가 실제 요소를 찾는지 보세요. >는 바로 아래 자식이고, 공백은 더 깊은 후손도 포함합니다.

/* .third-list는 .secondary-item의 직접 자식 */
.secondary-item:hover > .third-list { display: flex; }
/* third-lsit 같은 오타는 다른 이름입니다. */

5. 기본 닫힘과 2·3차 열림 연결하기

.sub-panel { display: none; }
.primary-item:hover > .sub-panel { display: block; }

.third-list { display: none; }
.secondary-item:hover > .third-list { display: flex; }

기본 상태를 먼저 확인하고 1차 항목에 마우스를 올려 2차를 표시합니다. 그다음 2차 항목에 마우스를 올려 해당 3차만 나타나는지 확인하세요. 모든 하위 목록을 한꺼번에 보이게 하면 중첩 구조를 확인하기 어렵습니다.

순서목표
메뉴 밖2·3차가 보이지 않음
1차 진입2차 이미지와 목록 표시
2차 항목 진입그 항목의 3차 표시
다른 항목·메뉴 밖상태가 해당 위치에 맞게 바뀜

height:0만으로 내용이 숨겨지지 않을 수 있습니다. 예제는 display로 닫고 엽니다. 높이 전환 방식을 사용하는 자신의 코드는 overflow와 내부 초점도 함께 점검하세요.

실습: 기본·2차·3차 상태를 각각 확인하고, 안 바뀌는 상태는 조건과 대상 선택자를 따로 적으세요.

6. 위치 기준·고정 너비·여백 보완하기

absolute 자식의 기준 부모에는 position을 설정합니다. 필요 이상으로 큰 고정 너비나 hover 시 상단바 padding 변경은 화면을 밀거나 흔들리게 할 수 있습니다.

.study-nav { position: relative; }
.sub-panel { position: absolute; top: 100%; left: 0; right: 0; }
.header-row { max-width: 1120px; margin: auto; padding: 18px 24px; }

위 수치는 연습용 설계값입니다. 실제 평가 시안과 다른 값을 정답처럼 적용하지 마세요. padding:auto처럼 허용되지 않는 값을 먼저 고치고 실제 크기·위치를 확인합니다.

실습: 01_before의 고정 너비와 정상 예제의 max-width를 비교하세요. 1200·768·390px에서 어떤 항목이 잘리는지 보완학습으로 기록합니다.

7. 로고·링크·인라인 SVG 마무리하기

로고는 브랜드를 설명하는 alt와 실제 목적지 링크를 갖도록 확인합니다. 단순 텍스트로 보이는 전화번호와 tel: 링크는 다르며, 외부 SVG 이미지와 HTML 안의 SVG 코드도 구분해야 합니다.

<a class="icon-link" href="#classification">
  전체 분류
  <svg viewBox="0 0 24 24" aria-hidden="true" focusable="false">
    <circle cx="5" cy="12" r="1.8"></circle>
    <circle cx="12" cy="12" r="1.8"></circle>
    <circle cx="19" cy="12" r="1.8"></circle>
  </svg>
</a>

이 예제는 전체 분류로 이동하는 텍스트 링크에 장식 아이콘을 붙였습니다. 링크의 이름은 텍스트가 제공합니다. 색 반전 효과는 글자와 아이콘 모두 읽을 수 있는지 함께 확인하세요.

실습: 과제의 링크 목적지·전화 형식·SVG 직접 작성 조건을 대조하세요. 실제 통화를 했다고 기록하지 말고, 확인한 코드·이동 동작 범위만 적습니다.

8. 화면·키보드·수정 결과 확인하기

02_after는 CSS :focus-within으로 Tab 이동도 보완합니다. 마우스가 메뉴 밖에 있어도 초점이 안에 있으면 열림을 유지할 수 있으므로, 닫힘을 확인할 때는 초점 위치도 같이 보세요.

.primary-item:focus-within > .sub-panel { display: block; }
.secondary-item:focus-within > .third-list { display: flex; }
a:focus-visible { outline: 3px solid #b34c12; outline-offset: 3px; }

예제는 일반 링크 내비게이션이며 Escape·화살표 조작을 갖춘 별도 메뉴 위젯은 아닙니다. 터치에서는 본문의 직접 링크도 활용할 수 있습니다.

실습: Tab으로 1차 → 2차 → 3차 링크를 지나가고 초점이 보이는지 확인하세요. 증상·원인·수정·환경·결과를 첨부 양식에 남깁니다.
