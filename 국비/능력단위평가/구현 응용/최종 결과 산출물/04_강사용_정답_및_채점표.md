# 구현 응용 강사용 정답 및 채점표

## 정답 성격

이 과제는 하나의 프레임워크나 화면 효과를 복제하는 평가가 아니다. 학생의 기존 구현·브랜드·콘텐츠에 따라 결과는 달라질 수 있으며, 다음 추적 관계가 성립하고 제출 소스가 실제로 동작하면 적합한 정답으로 판단한다.

`입력 구현·본래 의도 → 콘텐츠·표준·기능 명세 → 재사용 응용 구현 → 협업 이슈·전달 문서 → 수정 전후 → 기능·성능·접근성 재검증`

## 등록용 정답 문구

정답: 정보설계·디자인 방향에 따른 재사용 가능한 콘텐츠와 시각 흐름, 멀티미디어 기술 제안·활용, 웹 표준·반응형·접근성 기준의 콘텐츠와 디지털 미디어 기능, 재사용 가능한 HTML·CSS·JavaScript 개발사항, 개발 협업 기록·디자인 전달 문서·수정 전후·최적화 결과가 포함된 실행 가능한 소스 ZIP 1개와 구현 응용 보고서 PDF 1개

## 필수 확인표

- [ ] ZIP과 PDF가 정상적으로 열리고 안내에 따라 로컬 실행된다.
- [ ] 입력 구현의 문제·응용 목표·본래 의도와 변경 범위가 있다.
- [ ] 콘텐츠 모델·공통 구성요소·데이터가 여러 화면에서 활용된다.
- [ ] 핵심 시각 흐름과 두 종류 이상의 미디어 기능이 실제 동작한다.
- [ ] 의미 구조·토큰·반응형·접근성·자산·파일 표준이 코드에 적용됐다.
- [ ] CSS·JavaScript·컴포넌트·유틸리티가 여러 화면과 환경에서 재사용된다.
- [ ] 실제 검토 또는 제공 이슈의 결정이 코드 변경에 연결된다.
- [ ] 디자인 전달 문서의 ID·수치·상태·자산·파일이 실제 소스와 일치한다.
- [ ] 세 화면 폭, 키보드, Console·Network, 성능·접근성의 수정 전후와 재검증이 있다.

## 판단 유의 사항

- 화면이 화려하거나 기능 수가 많다는 이유만으로 상위 구간을 부여하지 않는다.
- 특정 프레임워크를 사용하거나 배포했다는 사실만으로 가점하지 않는다.
- 보고서의 기능 설명과 실제 브라우저 동작이 다르면 직접 실행 결과를 기준으로 판단한다.
- 기존 구현에 이미 있던 기능은 응용 과정에서 구조화·표준화·활용·최적화한 증빙이 있을 때 평가한다.
- 하나의 결함이 여러 문항과 관련되어도 가장 직접적인 문항에서만 감점하고 다른 문항에는 참조한다.
- 외부 서비스 장애와 학생 소스 결함을 구분하고 확인하지 못한 기능은 정상으로 추정하지 않는다.

상세 점수 구간은 `../Exam.md`의 IA-01~IA-09를 사용한다.
