# 구현 응용 학생 공개용 채점기준

## 1. 콘텐츠 구성과 활용 — 32점

- 전체 콘텐츠를 공통 모델·구성요소·데이터로 구조화하고 여러 화면·상태에서 활용했는가
- 콘텐츠 구조와 특성에 맞는 시작·탐색·선택·완료·예외 흐름을 실제 화면과 상호작용으로 구현했는가
- 영역별 멀티미디어 기능을 기술 수준으로 제안하고 제약·대안을 고려해 실제 화면에서 활용했는가

## 2. 기능 요소 활용 — 34점

- 웹 매체 특성에 맞는 의미 구조·디자인 토큰·반응형·접근성·자산·파일 표준을 실제 콘텐츠에 적용했는가
- 목적이 다른 두 종류 이상의 디지털 미디어 기능을 상태·키보드·대체 콘텐츠·오류·성능과 함께 제작했는가
- HTML·CSS·JavaScript·컴포넌트·유틸리티를 여러 화면과 데스크톱·태블릿·모바일에서 재사용했는가

## 3. 개발 요소 협업 — 34점

- 실제 검토 의견 또는 강사 제공 이슈를 요청·질문·대안·결정·담당·상태로 추적하고 구현에 활용했는가
- 디자인 토큰·상태·반응형·접근성·자산·파일 위치와 수용 기준을 정리·문서화했는가
- 본래 디자인 의도를 유지하며 이슈를 수정하고 기능·성능·접근성의 수정 전후·재검증·잔여 과제를 정리했는가

## 제출 전 확인

- ZIP은 압축 해제 후 실행 안내에 따라 로컬에서 열려야 합니다.
- 보고서의 근거 ID는 실제 코드·화면·개발 문서와 대응해야 합니다.
- 마우스와 키보드로 핵심 흐름과 기능을 확인할 수 있어야 합니다.
- 데스크톱 1440px, 태블릿 768px, 모바일 390px 또는 선택한 대체 기준에서 테스트합니다.
- Console 오류, Network 404, 접근성·성능과 오류·대체 상태를 확인합니다.
- 완성 화면의 화려함보다 표준화·재사용·목적 적합성·협업 추적성과 최적화를 우선합니다.
