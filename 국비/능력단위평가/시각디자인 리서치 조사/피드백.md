# 시각디자인 리서치 조사 피드백 지침

학생 피드백은 `확인한 증빙 → 조사 질문과의 관련성 → 자료·추론의 한계 → 디자인 결정에 미치는 영향 → 다음 조사 행동` 순서로 작성한다.

- PDF 페이지·절·자료 ID·원자료 파일명을 근거로 사용한다.
- “자료가 부족하다”에서 끝내지 말고 어떤 질문에 어떤 출처·참여자·비교 기준이 더 필요한지 적는다.
- 최신 사례를 수집했다는 이유만으로 높은 평가를 하지 않고 발행 주체·시점·맥락과 프로젝트 적합성을 확인한다.
- 사실, 참여자 발언, 학생 해석과 미검증 가설이 섞였으면 분리 방법을 안내한다.
- 경쟁 사례의 외형 모방을 권하지 않고 관찰한 원리를 자신의 브랜드·콘텐츠·사용자에게 맞게 변형하도록 지도한다.
- 실제 참여자의 개인정보가 드러난 경우 점수 논의보다 먼저 비식별화와 자료 교체를 안내한다.

예: “PDF 8쪽의 포지셔닝 맵은 사례 네 곳을 배치했지만 ‘전문적–친근함’ 축의 위치를 뒷받침하는 화면·문구 ID가 없습니다. 각 사례에서 첫 화면 정보량, 어조, 시각 대비를 같은 기준으로 기록한 뒤 위치를 다시 정하면 VR-04의 추적성이 높아집니다.”
