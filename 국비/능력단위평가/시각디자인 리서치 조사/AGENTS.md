# 시각디자인 리서치 조사 평가 지침

## 평가 목적

이 폴더의 능력단위는 `시각디자인 리서치 조사(0802010112_20v4)`이다. 학생이 개인 브랜딩 포트폴리오 사이트 개발에 앞서 시장환경·디자인 트렌드·사용자를 조사하고, 출처가 확인되는 자료를 향후 디자인 방향의 근거로 정리하는 능력을 평가한다.

## 원문 범위

- 원본은 `시각디자인 리서치 조사`와 `시각디자인 리서치 분석`이 결합된 PDF다.
- 평가는 조사 코드 `0802010112_20v4`의 학습목표 13개만 사용한다.
- 분석 코드 `0802010113_20v4`의 대응 학습목표는 이 평가에서 제외한다.
- 조사 학습목표를 원문 순서대로 `VR-01`~`VR-13`에 연결한다. VR 번호는 내부 추적 ID이며 공식 NCS 수행준거 번호가 아니다.

## 평가 조건

- 개인평가, 240분, 포트폴리오 방식으로 진행한다.
- 조사 대상은 학생 자신의 개인 브랜딩 포트폴리오 사이트다.
- 필수 제출은 `이름_시각디자인리서치조사.pdf` 1개와 `이름_시각디자인리서치조사_자료.zip` 1개다.
- PDF에는 조사 목적·범위, 출처가 있는 시장·트렌드 자료, 경쟁 포지셔닝, 사용자 정의·조사 기록, 요구사항과 개발수준 예측이 판독 가능해야 한다.
- ZIP에는 원문 링크 목록, 캡처·메모·설문지·인터뷰 기록 등 조사 원자료를 포함한다.
- 실제 참여자를 조사할 때는 동의를 받고 이름·연락처 등 불필요한 개인정보를 제출하지 않는다.
- 참여자를 확보하지 못한 경우 강사가 제공한 익명 응답 자료를 사용할 수 있다. 제공 자료와 실제 조사 자료를 구분하며 응답을 임의로 창작하지 않는다.

## 판단 원칙

- 결과물의 화려함보다 `조사 질문 → 출처·원자료 → 관찰·비교 → 요구사항·예측 → 디자인 방향`의 추적성을 우선한다.
- 시장·트렌드의 최신성은 발행일·접속일·작성 주체를 통해 확인한다.
- 경쟁사·유사 사례는 단순 캡처 수보다 선정 기준, 비교 기준, 포지셔닝 근거를 본다.
- 조사와 분석의 경계를 지킨다. 이 능력단위에서는 자료 수집·분류·비교와 예비 방향 설정을 평가하며, 별도 분석 능력단위 수준의 확정적 결론을 요구하지 않는다.
- 사용자 조사 결과는 관찰 사실, 참여자 발언, 연구자의 해석과 아직 확인하지 않은 가설을 구분한다.
- 같은 원인의 문제를 여러 문항에서 중복 감점하지 않는다.

## 채점과 검증

- `Exam.md`의 `VR-01`~`VR-13`을 사용하며 총점은 100점이다.
- 모든 점수는 PDF 페이지·절·자료 ID 또는 ZIP 원자료 중 하나 이상의 직접 증빙에 연결한다.
- 원문 13문장, 수행준거 TXT 13개, Exam 13문항과 영역별 배점, 총 100점을 대조한다.
- 개인평가 240분, PDF 1개·자료 ZIP 1개 조건이 모든 문서에 일치하는지 확인한다.
