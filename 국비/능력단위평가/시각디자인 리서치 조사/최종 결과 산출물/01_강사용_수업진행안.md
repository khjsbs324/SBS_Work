# 시각디자인 리서치 조사 강사용 수업진행안

## 운영 조건

- 개인평가 240분
- 대상: 자신의 개인 브랜딩 포트폴리오 사이트
- 제출: 조사 보고서 PDF 1개, 출처·원자료 ZIP 1개
- 완성 시안·코드·배포는 필수가 아님

## 사전 준비

- 학생은 평가 전 개인 브랜딩 기본 정보와 포트폴리오에 넣을 프로젝트 목록을 준비한다.
- 인터넷 이용 범위, 출처 표기 방법과 AI 도구 사용 표시 규칙을 공지한다.
- 사용자 조사 참여자를 확보하기 어려운 학생을 위해 개인정보를 제거한 공통 응답 자료를 준비한다.
- 실제 참여자를 사용할 때 동의, 비식별화와 안전한 자료 보관 원칙을 안내한다.

## 시간 운영

1. 0~25분: 프로젝트 브리프, 조사 목적·질문·범위·키워드·자료 ID 설정
2. 25~75분: 시장 현황·전망·수요, 거시·미시 환경 자료 수집과 요구사항 정리
3. 75~115분: 직·간접 경쟁 디자인 비교, 포지셔닝 맵과 예비 전략
4. 115~160분: 국내외 디자인 트렌드·조형 자료 수집, 자원 보드와 아이디어·포지셔닝
5. 160~205분: 주·부 사용자 설정, 요구·행동 영향 요소, 사용자 조사 수행·기록
6. 205~225분: 조사 근거에 따른 필수·권장·후속 개발수준과 다음 검증 계획
7. 225~240분: PDF·ZIP 정리, 파일명·출처·자료 ID·개인정보·누락·열림 확인

## 운영 유의 사항

- 한 출처의 주장이나 이미지에 과도하게 의존하지 않고 작성 주체와 발행 시점을 대조하게 한다.
- 포지셔닝 맵의 축은 사례를 배치한 뒤 임의로 붙이지 말고 프로젝트 의사결정에 필요한 차이로 정의하게 한다.
- 트렌드는 단순 캡처가 아니라 반복 신호, 적용 가능성, 배제 이유를 기록하게 한다.
- 사용자 응답을 임의 생성하지 않는다. 실제 조사, 강사 제공 익명 자료와 수업용 모의 자료의 유형을 표시하게 한다.
- 생성형 AI로 키워드 정리·질문 초안을 만들었다면 사용 위치와 검토·수정 내용을 기록하게 한다. AI 출력은 시장·사용자 사실의 출처로 인정하지 않는다.

## 회수 순서

1. PDF·ZIP 파일명과 열림을 확인한다.
2. PDF의 자료 ID가 ZIP 원자료·출처 목록과 대응하는지 확인한다.
3. 시장 현황·전망·수요와 거시·미시 환경 자료를 확인한다.
4. 경쟁사 선정·비교 기준과 포지셔닝 근거를 확인한다.
5. 국내외·전반적·조형적 트렌드와 아이디어·포지셔닝 연결을 확인한다.
6. 주·부 사용자, 조사 도구·기록·자료 유형·비식별화를 확인한다.
7. 요구사항과 개발수준이 자료 근거 및 다음 검증 계획에 연결되는지 확인한다.
8. `Exam.md` VR-01~VR-13에 직접 증빙을 연결해 채점한다.
