시각디자인 리서치 조사
인터뷰 기반 브랜딩 수업 계획 및 자동화 프롬프트

강의는 ‘실제 인터뷰 정리 → 가설 페르소나 생성 → 가상 인터뷰 → 브랜딩 기획 보고서’ 순서로 구성한다. 학생들은 각 단계의 결과를 파일로 저장하고, 다음 단계에서 그 파일을 입력 자료로 사용한다.

수업의 핵심 기준
실제 학생 인터뷰는 조사 자료이고, AI 가상 인터뷰는 아이디어를 탐색하기 위한 시뮬레이션이다. 옆자리 학생 한 명의 의견을 전체 시장의 요구로 일반화하지 않고, AI가 보완한 내용을 실제 조사 결과처럼 사용하지 않는다.

운영 기준: 100분 수업 × 4차시
이 문서는 수업 운영 계획이며, 기존 능력단위평가의 시험 시간·제출 조건·채점 기준을 변경하지 않는다. 아래 배점은 수업 활동 평가 예시이다.


1. 수업 목표와 최종 결과물

학생들은 자신이 정한 브랜드 주제에 대해 인터뷰를 분석하고, 고객 가설과 브랜드 방향을 세운 뒤, 시각디자인으로 연결되는 기획 보고서를 완성한다.

① 구두 인터뷰 정리
- 배울 내용: 발화를 근거로 행동·불편·요구를 구분하기
- 결과물: 인터뷰 분석서

② 가상인물·인터뷰 설계
- 배울 내용: 조사 근거와 추정을 구분해 페르소나와 질문 만들기
- 결과물: 가설 페르소나 및 질문지

③ 가상인물 인터뷰 진행
- 배울 내용: 답변에 따라 후속 질문을 이어가며 가설 탐색하기
- 결과물: 가상 인터뷰 기록 및 가설 목록

④ 브랜딩 기획
- 배울 내용: 고객 문제를 브랜드 전략과 시각디자인 방향으로 연결하기
- 결과물: 브랜딩 기획 보고서

평가에서는 결과물의 화려함보다 ‘인터뷰 근거 → 해석 → 브랜드 결정’이 연결되는지 확인한다.


2. 수업 전 준비

학생마다 다음 내용을 담은 ‘브랜드_기초정보.md’를 작성한다.
- 브랜드 주제와 제공하려는 제품·서비스
- 브랜드가 해결하려는 문제
- 현재 예상하는 고객과 그 이유
- 이번 인터뷰에서 확인하고 싶은 질문 3개
- 이미 결정한 사항과 아직 정하지 않은 사항

예시
‘대학생을 위한 텀블러 브랜드’라면, ‘대학생은 친환경 제품을 좋아한다’에서 출발하기보다 ‘텀블러를 가지고 다니다가 사용하지 않게 되는 상황은 무엇인가?’를 조사 질문으로 잡는다.

녹음 자료는 수업과 AI 분석에 활용할 수 있는지 확인하고, 이름·연락처 등 분석에 필요 없는 정보는 지운다. 파일에는 ‘참여자_A’처럼 익명 표기를 사용한다.

음성을 직접 처리할 수 없는 AI 도구에서는 먼저 전사문을 준비한다. 전사문에는 가능하면 화자와 시간표시를 넣고, 불명확한 발화는 추측해서 채우지 않는다.


3. 차시별 운영 계획

[1차시: 구두 인터뷰 정리 / 100분]
- 설명: 15분
- 전사 확인: 20분
- AI 분석: 30분
- 원문 대조: 25분
- 저장: 10분
- 수업 활동: 녹음과 전사문을 대조하고 행동·불편·니즈를 분류한다.
- 교사 확인: AI가 원문에 없는 내용을 추가했는가?

[2차시: 가상인물과 질문 설계 / 100분]
- 피드백: 15분
- 페르소나 생성: 25분
- 질문 설계: 25분
- 상호 검토: 25분
- 저장: 10분
- 수업 활동: 핵심 페르소나 1명과 인터뷰 질문지를 작성한다.
- 교사 확인: 인물 설정의 근거와 추정이 구분되는가?

[3차시: 가상 인터뷰 진행 / 100분]
- 시범: 15분
- 학생 주도 인터뷰: 25분
- 자동 인터뷰: 20분
- 비교·분석: 30분
- 저장: 10분
- 수업 활동: 학생이 먼저 후속 질문을 해보고 AI 자동 진행 결과와 비교한다.
- 교사 확인: 새롭게 나온 내용이 실제 사실로 취급되지 않는가?

[4차시: 브랜딩 기획 보고서 / 100분]
- 근거 검토: 15분
- 전략 작성: 25분
- 시각 방향 작성: 25분
- 보고서 편집: 20분
- 발표: 15분
- 수업 활동: 포지셔닝·메시지·시각 방향·검증 계획을 정리한다.
- 교사 확인: 시각디자인 선택에 고객 근거가 있는가?

수업 첫 실행에서는 각 단계가 끝날 때 학생이 검토한 뒤 다음 단계로 넘어간다. 학생이 과정과 오류를 이해한 후에 네 단계를 연속 실행하는 자동화를 적용한다.


4. 구두 인터뷰 정리 방법

인터뷰는 단순 요약보다 다음 구조로 정리한다.

① 실제 발언
전사문에서 그대로 인용하고 발언 ID·시간표시를 기록한다.

② 상황·행동
언제, 어디에서, 무엇을 했는지 정리한다.

③ 불편·장벽
행동을 어렵게 만든 조건을 정리한다.

④ 명시적 요구
참여자가 직접 원한다고 말한 내용을 정리한다.

⑤ 잠재 니즈
분석자가 해석한 요구를 정리한다. 반드시 ‘해석’으로 표시한다.

⑥ 추가 확인 질문
현재 자료만으로 알 수 없는 내용을 정리한다.

[정리 예시]
참여자 발언: “텀블러는 있는데 씻기 귀찮아서 잘 안 들고 다녀요.”
- 실제 발언: 세척이 귀찮아 자주 가지고 다니지 않는다고 말함.
- 해석: 세척 부담이 반복 사용을 방해할 가능성이 있음.
- 브랜드 가설: 관리 편의성을 강조하는 제품과 안내가 도움이 될 수 있음.
- 추가 질문: 최근 언제 세척이 번거로웠고, 어떤 부분이 어려웠는가?

위 발언만으로 곧바로 ‘고객은 세척이 쉬운 텀블러를 구매한다’고 결론내리지 않는다.


5. 단계별 자동화 파일 구성

학생마다 아래 폴더 구조를 만들어 사용한다. Markdown 파일은 일반 텍스트로도 열 수 있고, 다음 AI 작업에 입력하기 쉽다.
아래 구조는 학생 실습용 구성 예시이며, 이 TXT 문서에 수록된 설계안이다.

브랜드리서치_프로젝트/
├─ 00_입력/
│  ├─ 브랜드_기초정보.md
│  └─ 인터뷰_전사문.txt
├─ 01_프롬프트/
│  ├─ 00_공통규칙.md
│  ├─ 01_인터뷰정리.md
│  ├─ 02_가상인물과질문생성.md
│  ├─ 03_가상인터뷰진행.md
│  └─ 04_브랜딩기획.md
└─ 02_결과/
   ├─ 01_인터뷰분석.md
   ├─ 02_가설페르소나_질문지.md
   ├─ 03_가상인터뷰_가설목록.md
   └─ 04_브랜딩기획보고서.md

자동화 흐름
기초정보·전사문 → 인터뷰 분석 → 페르소나·질문지 → 가상 인터뷰 → 기획 보고서

마지막 기획 단계에서는 가상 인터뷰만 읽지 않고 원래 인터뷰 분석서도 함께 읽게 한다. 단계가 진행되며 추정이 사실로 바뀌는 오류를 줄이기 위해서다.

아래 프롬프트는 각 파일에 복사해 사용할 수 있다.


5-1. 공통 규칙 — 00_공통규칙.md

[프롬프트 시작]
당신은 시각디자인 수업의 브랜드 리서치 보조 에이전트다.
모든 단계에서 다음 규칙을 적용하라.

1. 내용을 [실제 근거], [해석], [가설], [디자인 제안]으로 구분한다.
2. 실제 발언은 제공된 전사문에서만 인용한다.
3. 실제 근거에는 발언 ID와 가능한 경우 시간표시를 붙인다.
   시간표시가 없으면 만들지 않는다.
4. 자료에 없는 정보는 ‘확인되지 않음’으로 표시한다.
5. 가상인물과 가상 인터뷰는 시뮬레이션임을 명시한다.
6. 가상 답변을 실제 고객 발언이나 가설 검증 결과로 사용하지 않는다.
7. 참여자 수를 늘려 해석하거나 시장 전체로 일반화하지 않는다.
8. 시장 규모, 경쟁사 현황, 통계는 제공 자료가 없으면 만들지 않는다.
9. 서로 다른 의견과 반례를 지우지 않는다.
10. 각 결과물 끝에 학생이 검토할 항목을 작성한다.
[프롬프트 끝]


5-2. 인터뷰 정리 프롬프트 — 01_인터뷰정리.md

[프롬프트 시작]
공통 규칙을 적용하라.

[입력]
- 브랜드_기초정보.md
- 인터뷰_전사문.txt

[목표]
구두 인터뷰를 브랜딩 기획에 사용할 수 있는 근거 자료로 정리한다.

[작업]
1. 인터뷰 목적과 참여자 정보를 정리한다.
   참여자 정보는 자료에서 확인되는 범위만 사용한다.
2. 인터뷰를 요약하고, 핵심 발언에 E01, E02 형태의 ID를 부여한다.
3. 다음 열로 분석표를 작성한다.
   발언 ID / 실제 인용 / 상황·행동 / 불편·장벽 /
   명시적 요구 / 잠재 니즈 해석 / 추가 확인 질문
4. 주요 주제를 도출한다. 자료가 부족하면 주제 수를 억지로 늘리지 않는다.
5. 반복 언급과 여러 참여자 사이의 공통 의견을 구분한다.
6. 브랜드에 도움이 될 인사이트 후보를 작성하고 근거 ID를 연결한다.
7. 유도 질문, 모호한 답변, 상충하는 발언, 부족한 정보를 표시한다.
8. 실제 참여자에게 추가로 물어볼 질문 5개를 제안한다.

[출력]
01_인터뷰분석.md

마지막에 원문 대조가 필요한 항목과 학생 검토 목록을 작성한다.
[프롬프트 끝]


5-3. 가상인물·인터뷰 생성 프롬프트 — 02_가상인물과질문생성.md

이 단계에서는 가상인물과 질문지를 함께 만들되, 답변은 아직 생성하지 않는다.

[프롬프트 시작]
공통 규칙을 적용하라.

[입력]
- 브랜드_기초정보.md
- 01_인터뷰분석.md

[목표]
실제 인터뷰에서 발견한 행동과 문제를 탐색하기 위한
가설 페르소나 1명과 인터뷰 질문지를 만든다.

[작업]
1. 이 인물이 실제 참여자와 구별되는 가설 페르소나임을 명시한다.
2. 다음 항목으로 인물을 설정한다.
   가명 / 사용 상황 / 목표 / 현재 행동 / 불편 /
   선택 기준 / 제약 / 브랜드를 선택하지 않을 이유
3. 각 설정에 ‘근거 기반’ 또는 ‘추가 가정’을 표시한다.
   근거 기반 설정에는 발언 ID를 연결한다.
4. 나이, 성별, 직업, 소득 등을 자료 없이 임의로 채우지 않는다.
   역할 수행에 필요한 추가 설정은 가정으로 표시한다.
5. 인터뷰 질문 8~10개를 작성한다.
   최근 행동 → 구체적 경험 → 불편 → 현재 대안 →
   선택 기준 → 거절 이유 → 제안 반응 순서로 구성한다.
6. 질문마다 확인하려는 가설과 후속 질문 1개를 붙인다.
7. 구매 의향이나 브랜드에 대한 호감을 유도하는 질문을 수정한다.
8. 원래 가설과 다른 가능성을 살펴보는 질문을 2개 이상 포함한다.

[출력]
02_가설페르소나_질문지.md

이 단계에서는 가상인물의 답변을 생성하지 않는다.
[프롬프트 끝]


5-4. 가상인물 인터뷰 진행 프롬프트 — 03_가상인터뷰진행.md

첫 실습은 대화형, 두 번째 실습은 자동형으로 운영한다. 두 결과를 비교하면서 학생이 직접 던진 후속 질문의 가치를 확인하게 한다.

[프롬프트 시작]
공통 규칙을 적용하라.

[입력]
- 01_인터뷰분석.md
- 02_가설페르소나_질문지.md
- 진행 모드: 대화형 또는 자동형

[목표]
가설 페르소나와의 시뮬레이션으로 브랜드 가설을 탐색한다.

[진행 규칙]
1. 시작할 때 ‘이 대화는 AI 가상 인터뷰이며 실제 조사 결과가 아니다’라고 표시한다.
2. 인물의 설정과 제약을 일관되게 유지한다.
3. 모든 제안에 동의하지 말고, 설정에 맞는 조건·불편·거절 이유를 표현한다.
4. 새로 만든 경험과 상황에는 ‘시뮬레이션 설정’ 표시를 붙인다.

[대화형]
학생이 인터뷰어를 맡고 AI는 가상인물로 답한다.
한 번에 현재 질문에만 답하고 다음 질문을 기다린다.
학생이 ‘인터뷰 종료’라고 입력하면 분석 결과를 작성한다.

[자동형]
AI가 인터뷰어와 가상인물을 구분하여 진행한다.

[목표]
실제 인터뷰 근거와 탐색한 가설을 바탕으로
시각디자인 실행에 연결되는 브랜딩 기획 보고서를 작성한다.

[보고서 구성]
1. 프로젝트 개요
   브랜드 주제, 기획 목적, 조사 질문

2. 조사 방법과 한계
   실제 참여자 수와 방식, 가상 인터뷰 활용 범위,
   현재 자료만으로 판단할 수 없는 사항

3. 핵심 발견
   주요 발견과 실제 발언 근거 ID

4. 타깃 고객 가설
   핵심 상황, 목표, 행동, 불편, 아직 확인하지 못한 가정

5. 브랜드 기회
   해결할 고객 문제와 해결 방향
   경쟁 우위는 경쟁 자료가 없으면 검증 전 가설로 표시

6. 브랜드 전략
   포지셔닝 문장, 핵심 가치 3개, 브랜드 약속,
   핵심 메시지, 말투와 표현 방식

7. 시각디자인 방향 2안
   콘셉트명, 키워드, 색채 방향, 서체 성격,
   이미지 스타일, 레이아웃 원칙, 주요 적용 매체
   각 선택이 어떤 고객 문제나 전략과 연결되는지 설명

8. 우선 제안과 선택 이유
   두 방향의 장단점을 비교하고 우선안을 제안
   학생이 최종 결정해야 할 사항을 표시

9. 후속 검증 계획
   확인할 가설, 실제 조사 대상 조건, 질문 또는 테스트 방식,
   결과에 따라 유지하거나 수정할 브랜드 결정

6. 최종 보고서와 평가 방법

보고서는 본문 6~8쪽 내외로 구성하고, 인터뷰 원문과 가상 대화는 부록으로 넣는다.

[수업 활동 평가 예시 / 총 100점]

① 실제 인터뷰 분석: 30점
발언을 정확하게 인용하고 행동·요구·해석을 구분했는가?

② 페르소나·질문 설계: 20점
설정에 근거가 있고 질문이 답변을 유도하지 않는가?

③ 가상 인터뷰 활용: 20점
반례와 후속 질문을 탐색하고 실제 검증 과제를 만들었는가?

④ 브랜딩·시각 방향: 20점
고객 문제와 브랜드·디자인 선택이 연결되는가?

⑤ 보고서의 명료성: 10점
조사 근거, 가설, 한계, 다음 행동이 분명한가?

[학생 발표 질문]
1. 우리의 브랜드 방향에 가장 큰 영향을 준 실제 발언은 무엇인가?
2. AI의 제안 중 무엇을 수정하거나 제외했고, 그 이유는 무엇인가?
3. 다음 실제 인터뷰에서 무엇을 확인하면 브랜드 방향을 더 확실히 정할 수 있는가?

교사는 AI가 만든 문장을 얼마나 잘 다듬었는지보다, 학생이 근거를 확인하고 브랜드 방향을 스스로 선택했는지를 중심으로 피드백한다.
