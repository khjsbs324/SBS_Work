## 13. 최종 자기점검

### 콘셉트와 포지셔닝

- [ ] UX 전략과 디자인 키워드가 연결됩니다.
- [ ] 비교 근거와 축이 있는 포지셔닝을 작성했습니다.
- [ ] 업무 플로우별 화면 목적·콘텐츠·상태를 정의했습니다.
- [ ] 레퍼런스의 원리와 실제 적용 위치를 설명했습니다.

### 스타일 가이드

- [ ] 대상 OS·기기와 공식 지침 URL·확인일을 기록했습니다.
- [ ] 컬러·서체·간격·레이아웃·아이콘·컴포넌트·상태 규칙이 있습니다.
- [ ] 접근성 및 오류·빈·로딩·성공 상태를 검토했습니다.
- [ ] 스타일 가이드와 핵심 화면이 일치합니다.

### 화면·프로토타입·의견 반영

- [ ] 핵심 과업의 시작·진행·완료를 프로토타입으로 확인할 수 있습니다.
- [ ] 콘텐츠 위계와 주요 행동이 명확합니다.
- [ ] 관계자 의견의 출처·판단·수정 전후가 연결됩니다.
- [ ] 원본과 프로토타입 공유 권한을 확인했습니다.

### 제출

- [ ] PDF의 화면·표·글자가 잘리지 않고 읽힙니다.
- [ ] 외부 자료와 이미지의 출처를 표시했습니다.
- [ ] 실제로 확인하지 않은 사용자 반응을 만들지 않았습니다.
- [ ] 파일명과 학생 정보가 정확합니다.
