# 학생 공개용 채점기준

## 평가에서 보는 핵심

이 평가는 화면을 많이 만들거나 유행하는 스타일을 따라 하는 평가가 아닙니다. UX 전략과 콘텐츠·업무 플로우에서 디자인 콘셉트를 도출하고, 플랫폼에 적합한 스타일 가이드를 실제 화면과 프로토타입에 일관되게 적용한 뒤 관계자 의견에 따라 보완할 수 있는지를 봅니다.

## 1. 디자인 콘셉트 수립 — 32점

### 높은 성취

- 사용자·문제·가치·콘텐츠·핵심 과업이 디자인 키워드와 시각 방향으로 연결됩니다.
- 경쟁·유사 앱을 적절한 축으로 비교하여 포지셔닝과 차별 방향을 설명합니다.
- 업무 플로우 단계별 화면 목적·콘텐츠 위계·상태와 디자인 원칙이 명확합니다.
- 레퍼런스와 무드 보드에서 추출한 원리가 실제 화면 결정으로 이어집니다.

### 보완이 필요한 경우

- 콘셉트가 유행·취향 형용사에 머물고 사용자 과업과 연결되지 않습니다.
- 포지셔닝의 비교 축이나 경쟁 근거가 불분명합니다.
- 화면 목록은 있지만 플로우와 상태, 스타일 적용 위치를 찾기 어렵습니다.

## 2. 스타일 가이드 제작 — 32점

### 높은 성취

- 색·서체·간격·레이아웃·이미지·아이콘·컴포넌트·상태·접근성 규칙이 재사용 가능한 형태로 정리됩니다.
- 대상 OS·기기와 현재 공식 지침을 확인하고 적용·변형 이유를 설명합니다.
- 스타일 가이드와 주요 화면을 이용해 기획·개발·디자인 관점의 쟁점을 소통하고 결정합니다.

### 보완이 필요한 경우

- 색과 서체만 정리되어 실제 화면과 상태에 적용할 규칙이 부족합니다.
- 플랫폼 이름만 적고 공식 자료·확인일·적용 항목을 찾기 어렵습니다.
- 관계자 의견과 스타일 가이드의 구체적인 쟁점이 연결되지 않습니다.

## 3. 시안 디자인 제작·검토 — 36점

### 높은 성취

- 콘텐츠 위계·콘셉트·스타일 가이드가 핵심 화면과 상태에 일관되게 적용됩니다.
- 위계·균형·대비·가독성과 브랜드 분위기가 조화를 이루며 주요 행동을 방해하지 않습니다.
- 프로토타입에서 핵심 과업과 필요한 오류·빈·로딩·성공·회복 상태를 확인할 수 있습니다.
- 관계자 의견의 출처·판단·반영·보류와 수정 전후가 최종안까지 추적됩니다.

### 보완이 필요한 경우

- 화면마다 색·서체·컴포넌트·상태 표현이 달라 예측하기 어렵습니다.
- 시각적 장식이 콘텐츠 위계·가독성 또는 조작 명확성을 방해합니다.
- 프로토타입 연결이 끊기거나 조작 결과·오류 회복을 확인할 수 없습니다.
- 의견을 나열하거나 모두 수용했지만 판단 근거와 실제 수정이 연결되지 않습니다.

## 공통 확인사항

- 공식 플랫폼 자료의 URL과 확인일을 기록합니다.
- 외부 레퍼런스·이미지·폰트·아이콘의 출처와 사용 조건을 확인합니다.
- 편집 원본과 프로토타입 링크의 접근 권한을 점검합니다.
- 코드·앱 빌드·백엔드·스토어 배포는 필수 제출물이 아닙니다.
- 디자인 도구와 AI 사용 여부 자체는 점수에 영향을 주지 않습니다.
- 최종점수는 보고서, 편집 원본과 프로토타입에서 확인되는 직접 근거를 종합하여 산정합니다.
