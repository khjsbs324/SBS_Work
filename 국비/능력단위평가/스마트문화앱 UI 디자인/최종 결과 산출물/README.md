# 스마트문화앱 UI 디자인 평가자료

이 평가는 기존 UX 전략과 업무 플로우를 바탕으로 스마트 문화 앱의 디자인 콘셉트와 포지셔닝을 수립하고, 선택 플랫폼의 현재 공식 지침을 참조한 스타일 가이드·핵심 화면·프로토타입을 제작한 뒤 관계자 의견에 따라 보완하는 포트폴리오형 능력단위평가다.

## 파일 구성

| 파일 | 대상 | 용도 |
|---|---|---|
| `01_강사용_수업진행안.md` | 강사 | 평가 준비, 300분 진행, 관찰과 회수 방법 |
| `02_학생용_과제안내서.md` | 학생 | 과제 목표, 작업 순서와 제출 규칙 |
| `03_학생_제출_산출물.md` | 학생 | 보고서 작성 양식과 제출 확인 |
| `04_강사용_정답_및_채점표.md` | 강사 | 직접 증빙 확인법과 12문항 채점표 |
| `05_학생공개용_채점기준.md` | 학생 | 평가 영역과 성취 수준 안내 |

## 기준 자료

- 상위 폴더의 원본 NCS 학습모듈 PDF
- 상위 폴더의 `스마트문화앱 UI 디자인 수행준거.txt`
- 상위 폴더의 `Exam.md`
- 상위 폴더의 `AGENTS.md`와 `피드백.md`

## 배포 구분

학생에게 제공:

1. `02_학생용_과제안내서.md`
2. `03_학생_제출_산출물.md`
3. `05_학생공개용_채점기준.md`

강사만 사용:

1. `01_강사용_수업진행안.md`
2. `04_강사용_정답_및_채점표.md`
3. 상위 폴더의 `Exam.md`, `AGENTS.md`, `피드백.md`

학생은 보고서 PDF, 편집 가능한 디자인 원본 또는 공유 링크, 핵심 과업 프로토타입을 제출한다. 앱 코드·빌드·스토어 배포는 필수 제출물이 아니다.
