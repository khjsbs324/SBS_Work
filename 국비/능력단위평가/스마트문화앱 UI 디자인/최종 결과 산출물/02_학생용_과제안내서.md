# 스마트문화앱 UI 디자인 능력단위평가

## 과제 목표

기존 스마트 문화 앱의 UX 전략과 업무 플로우를 바탕으로 디자인 콘셉트와 포지셔닝을 수립합니다. 선택한 플랫폼의 현재 공식 디자인 지침을 확인해 스타일 가이드를 만들고, 핵심 과업의 화면 시안과 프로토타입을 제작합니다. 관계자 의견을 검토하여 최종 디자인까지 보완합니다.

## 평가 조건

- 개인평가
- 평가 시간: 300분
- 앱 코드·빌드·백엔드·스토어 배포: 필수 아님
- 디자인 도구: 프로젝트에 적합한 도구를 자유롭게 사용

## 필수 제출

1. `이름_스마트문화앱_UI디자인.pdf`
2. 편집 가능한 디자인 원본 또는 접근 가능한 공유 링크
3. 핵심 과업의 시작·진행·완료를 확인할 수 있는 프로토타입 링크 또는 파일

공유 링크를 제출한다면 평가자가 열 수 있도록 권한을 확인하세요. 프로토타입 링크는 보고서에도 적습니다.

## 작업 순서

1. 앱의 목표 사용자, 문제, 가치, 콘텐츠와 핵심 과업을 정리합니다.
2. 대상 OS와 기기 범위를 정하고 현재 공식 디자인 지침을 확인합니다.
3. UX 전략에서 디자인 키워드와 콘셉트를 도출합니다.
4. 경쟁·유사 앱을 비교해 포지셔닝과 차별 방향을 정합니다.
5. 핵심 업무 플로우를 단계별로 나누고 화면 목적·콘텐츠 위계·필요 상태를 정의합니다.
6. 레퍼런스와 무드 보드를 분석해 적용할 디자인 원리를 정합니다.
7. 컬러·서체·간격·레이아웃·이미지·아이콘·컴포넌트·상태·접근성 스타일 가이드를 제작합니다.
8. 핵심 과업의 화면과 필요한 오류·빈·로딩·성공 상태를 제작합니다.
9. 주요 화면을 프로토타입으로 연결하고 직접 조작해 확인합니다.
10. 기획·개발·디자인·사용자 관점의 의견을 검토합니다.
11. 의견을 반영·수정·보류하고 이유와 수정 전후를 기록합니다.

## 플랫폼 공식 자료

대상 플랫폼에 맞는 현재 공식 자료를 사용하고 확인일과 적용한 절을 기록합니다.

- Apple Human Interface Guidelines: <https://developer.apple.com/design/human-interface-guidelines/>
- Android UI Design: <https://developer.android.com/design/ui>
- Material Design 3: <https://m3.material.io/>

공식 컴포넌트를 그대로 복제해야 하는 것은 아닙니다. 브랜드와 사용자에게 맞게 변형했다면 일관성·사용성·접근성과 구현 가능성 측면에서 이유를 설명하세요.

## 화면과 프로토타입 범위

화면 수를 채우기보다 핵심 과업 한 건의 전체 흐름을 확인할 수 있어야 합니다.

- 과업을 시작하는 화면
- 탐색·선택·입력 등 진행 화면
- 완료 또는 성공 화면
- 프로젝트에 필요한 오류·빈·로딩·권한·확인 상태
- 뒤로 가기, 취소, 재시도 등 회복 경로

## 관계자 의견

실제 관계자 또는 수업 안에서 역할을 정한 모의 검토를 사용할 수 있습니다. 의견의 출처와 관점을 표시하고, 모두 반영하지 않아도 됩니다. 반영·수정·보류한 이유를 사용자·콘텐츠·개발 제약과 연결하세요.

## AI 활용

AI는 레퍼런스 정리, 누락 점검, 대안 발상과 문장 정리에 사용할 수 있습니다. AI가 만든 화면·수치·사용자 반응을 검증 없이 실제 결과로 제출하지 않습니다. 최종 선택과 판단은 본인의 UX 전략과 공식 플랫폼 자료로 설명해야 합니다.

- [ ] 포지셔닝과 레퍼런스 적용 이유가 기록되어 있습니다.
- [ ] 대상 OS·기기 범위, 공식 자료 URL·확인일·적용 항목이 있습니다.
- [ ] 스타일 가이드와 핵심 화면의 컬러·서체·간격·컴포넌트·상태가 일치합니다.
- [ ] 프로토타입에서 핵심 과업과 필요한 상태를 확인할 수 있습니다.
- [ ] 관계자 의견, 판단과 수정 전후가 연결됩니다.
- [ ] PDF의 글자·표·화면 이미지가 잘리지 않고 읽힙니다.
- [ ] 디자인 원본과 프로토타입 링크 권한을 확인했습니다.
