## 원본의 핵심 수행 흐름

1. 사용자·비즈니스·콘텐츠에 관한 UX 전략에서 디자인 콘셉트를 도출한다.
2. 경쟁·유사 앱과 타깃 사용자 관점으로 포지셔닝과 디자인 키워드를 정한다.
3. 업무 플로우 단계별 콘텐츠 위계, 화면 목적과 스타일 방향을 연결한다.
4. 레퍼런스와 무드 보드로 색·서체·레이아웃·이미지·아이콘 방향을 시각화한다.
5. 일관된 화면을 위한 시각·기능 디자인 요소와 상태를 정의한다.
6. 앱 개발 계획과 선택 플랫폼을 반영한 스타일 가이드를 제작한다.
7. 주요 화면 시안에 스타일 가이드를 적용해 기획자·개발자·디자이너와 검토한다.
8. 콘텐츠·콘셉트·가이드가 일치하는 핵심 화면을 제작한다.
9. 위계·균형·대비·가독성·사용성을 고려해 심미성을 부여한다.
10. 핵심 과업 프로토타입으로 사용자 환경과 상호작용을 점검한다.
11. 선호도·성능·UX 평가 등 목적에 맞는 방법으로 의견을 수렴한다.
12. 의견을 판단하여 반영·보류하고 수정 전후와 최종안을 기록한다.

## 현재 평가에 적용할 때의 유의사항

원본은 2019년 발행 자료이므로 당시 iOS·Android 화면 구성과 용어를 현재의 고정 규격으로 복제하지 않는다. 2026년 10월 확인 기준으로 Apple은 Human Interface Guidelines를, Android는 Android UI Design과 Material Design 3를 공식 디자인 자료로 제공한다. 학생은 선택한 플랫폼의 공식 지침 URL·확인일·적용 범위를 기록하고, 평가자는 해당 프로젝트의 기기·OS 범위와 일치하는지 확인한다.

- Apple Human Interface Guidelines: <https://developer.apple.com/design/human-interface-guidelines/>
- Android UI Design: <https://developer.android.com/design/ui>
- Material Design 3: <https://m3.material.io/>

앱 UI 디자인 평가이므로 코드 구현, 백엔드, 앱 패키징과 스토어 배포는 필수로 확대하지 않는다. 대신 편집 가능한 디자인 원본, 스타일 가이드 적용 상태와 핵심 과업 프로토타입을 직접 증빙으로 사용한다.
