# 시안 디자인 개발 심화 피드백 지침

## 기본 순서

학생 피드백은 `관찰 → 학생 의도 → 적합성 → 영향 → 구체적 보완 방법`으로 작성한다.

## 작성 원칙

- 학생이 실제로 제출한 PDF 페이지, 시안 ID, 소스 파일과 출력 점검 기록을 근거로 사용한다.
- 좋아 보인다·세련됐다와 같은 취향 표현 대신 콘셉, 정보 위계, 가독성, 매체 적합성과 제작 사양을 언급한다.
- 비주얼 모틴, 타이포그래피, 색채, 그리드 중 어느 요소가 어떤 매체에서 문제를 만드는지 특정한다.
- 모형 정답을 복제하라고 안내하지 않고 학생의 핵심 콘셉을 유지하면서 문제를 해결할 방법을 제시한다.
- 같은 원인을 여러 문항에서 반복하지 않고 가장 영향이 큰 문항에서 설명한다.

## 권장 표현

- “페이지 8의 정보그래픽은 5개 단계를 같은 크기로 표현해 우선순위를 구분하기 어렵습니다. 핵심 전환 단계의 크기·색 대비를 키우고 보조 정보를 하위 위계로 조정해 정보 흐름을 재확인하세요.”
- “인쇄용 시안에서도 RGB 원본과 같은 수치를 사용해 주조색이 탁하게 보일 가능성이 있습니다. CMYK 전환 후 프루프에서 브랜드 인지도를 유지하는 보정값을 비교하세요.”

## 피해야 할 표현

- “더 예쁘게 하세요.”
- “전문적으로 보이게 하세요.”
- “색을 다른 것으로 바꾸세요.”
- “정답 예시를 그대로 따라 하세요.”
