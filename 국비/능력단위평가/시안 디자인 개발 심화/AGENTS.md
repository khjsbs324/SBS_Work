# 시안 디자인 개발 심화 평가 지침

## 평가 목적

이 폴더의 능력단위는 `시안 디자인 개발 심화(0802010121_20v3)`이다. 학생이 기존 개인 브랜딩과 포트폴리오 콘텐츠를 기반으로 정보를 수집·분류하고, 콘셉에 맞는 정보그래픽·브랜드 아이덴티티·편집디자인 시안을 심화·확장하며, 매체별 베리에이션과 출력 점검·보완까지 수행하는 능력을 평가한다.

## 원문 범위

- 원본은 `시안디자인 개발 응용과 심화` 합본 학습모듈 PDF이다.
- 이 평가에서는 `0802010121_20v3` 심화 능력단위에 해당하는 학습목표 14개만 사용한다.
- 학습 3의 `BI 시안 베리에이션 제작`은 `0802010120_20v3` 응용 능력단위 요소이므로 평가 문항에서 제외한다.
- `SD-01`~`SD-14`는 로컬 평가 추적 ID이며 공식 NCS 수행준거 번호로 표현하지 않는다.

## 평가 조건

- 개인평가, 240분, 포트폴리오 방식으로 진행한다.
- 학생의 기존 개인 브랜딩, 웹사이트 기획, 와이어프레임 또는 강사가 제공한 브랜드 브리프 중 한 건을 입력 자료로 사용한다.
- 필수 제출은 `이름_시안디자인개발심화.pdf` 1개와 `이름_시안디자인개발심화_원본.zip` 1개다.
- PDF에는 기초 자료, 적합성 판단, 작업 계획, 발상과 중간 시안, 최종 시안, 매체별 베리에이션, 출력 점검과 보완 전후가 판독 가능해야 한다.
- ZIP에는 편집 가능한 최종 소스, 링크 자산, 출력용 파일과 폰트·라이선스 정보를 포함한다.
- 특정 프로그램을 강제하지 않으며 학생이 선택한 제작 도구를 인정한다.

## 판단 원칙

- 단순히 화려한 결과보다 수집 자료→콘셉→비주얼 모티프→시안→매체별 변형→점검·보완의 추적성을 우선한다.
- 정보그래픽은 데이터와 스토리의 구조, 정보 위계, 형태소와 텍스트의 인지 가능성을 본다.
- 브랜드 아이덴티티는 심벌·로고타입·색채·타이포그래피·비주얼 모티프의 통합성과 확장성을 본다.
- 매체별 베리에이션은 같은 콘셉을 유지하면서 레이아웃, 크기, 색상 모드, 재료와 출력 조건에 맞게 적응했는지 판단한다.
- 취향 차이만으로 감점하지 않고, 학생이 밝힌 디자인 의도와 실제 결과의 일치를 직접 증빙으로 판단한다.
- 3D 제작물의 실물 제작은 필수가 아니며, 적절한 목업과 제작 사양으로 예상 결과를 판단할 수 있으면 인정한다.
- 출력 검수는 실제 프린트 또는 PDF 출력 미리보기로 수행할 수 있다. 검수 방식 자체보다 문제 발견과 보완 추적성을 본다.

## 채점과 피드백

- `Exam.md`의 `SD-01`~`SD-14`를 사용하며 총점은 100점이다.
- 모든 점수는 제출 PDF 페이지·절·시안 ID, 편집 소스, 파일 속성 또는 출력 검수 기록 중 하나 이상의 직접 증빙에 연결한다.
- 같은 원인을 여러 문항에서 중복 감점하지 않는다. 파일 누락과 디자인 판단을 구분한다.
- 학생 공개용 피드백은 `관찰 → 의도 대조 → 적합성 → 영향 → 구체적 보완 방법`의 순서로 작성한다.

## 최종 검증

- 원문 학습목표 14개, 수행준거 TXT 14개, Exam 14문항의 문장·순서·개수를 대조한다.
- 영역별 배점 20·56·24점과 전체 100점, 4단계 점수 구간을 확인한다.
- 개인평가 240분, PDF 1개와 원본 ZIP 1개 제출 조건이 모든 문서에 일치하는지 확인한다.
- 학생용 자료에 강사용 점수 판단 예시나 모범 정답이 노출되지 않는지 확인한다.
