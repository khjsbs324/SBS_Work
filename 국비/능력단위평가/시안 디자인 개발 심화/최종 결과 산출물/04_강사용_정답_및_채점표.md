# 시안 디자인 개발 심화 강사용 정답 및 채점표

## 정답 성격

이 과제는 하나의 고정된 시각 정답을 요구하지 않는다. 적합한 정답은 학생이 설정한 브랜드 목적·대상·콘셉에 따라 다를 수 있다. 채점자는 외형 유사도보다 다음 추적 연결을 확인한다.

`R 자료 → S 스케치·시안 → 아이덴티티 규칙 → M 매체별 베리에이션 → O 출력 문제·보완`

## 필수 확인표

- [ ] PDF 1개와 원본 ZIP 1개가 열린다.
- [ ] 브랜드 목적·대상·핵심 메시지가 명시됐다.
- [ ] 기초 자료의 출처·분류·적합성 판단·작업 방법이 있다.
- [ ] 정보 구조·스토리보드·스케치·중간 시안·최종안이 연결된다.
- [ ] 심벌·로고타입·비주얼 모틴·타이포그래피·색채 체계를 확인할 수 있다.
- [ ] 인쇄·디지털·입체 적용을 포함한 매체별 시안이 3종 이상이다.
- [ ] 매체별 사양·레이아웃·색상 모드 차이가 표시됐다.
- [ ] 출력 문제, 원인, 보완 전후와 재확인 결과가 있다.
- [ ] ZIP에 편집 가능한 소스·링크 자산·출력용 파일이 정리됐다.

## 판단 유의 사항

- 포스터·패키지·웹 배너의 종류는 정답이 아니다. 학생이 선택한 매체가 목적과 대상에 적합한지 판단한다.
- 목업이 화려해도 실제 재료·크기·가공 조건이 없으면 SD-10의 상위 구간을 부여하지 않는다.
- 팔레트가 같다는 이유만으로 SD-09를 최고점 처리하지 않고 매체·재료별 재현 조정을 확인한다.
- 시안 수가 많다는 이유만으로 SD-14를 최고점 처리하지 않고 콘셉 유지와 심화된 변형을 확인한다.
- 파일 누락은 열림과 증빙 확인에 영향을 주는 문항에서만 반영하고 같은 이유로 중복 감점하지 않는다.

상세 점수 구간은 `../Exam.md`의 SD-01~SD-14를 사용한다.
