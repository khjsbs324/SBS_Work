# 시안 디자인 개발 심화 평가자료

이 평가는 개인 브랜딩을 기반으로 기초 자료를 선별하고, 정보그래픽·브랜드 아이덴티티·편집디자인 시안을 심화한 뒤 인쇄·디지털·입체 매체로 확장하고 출력 문제를 보완하는 과정을 평가한다.

- `01_강사용_수업진행안.md`: 240분 운영과 회수·검수 순서
- `02_학생용_과제안내서.md`: 학생 공개용 작업 범위와 제출 규칙
- `03_학생_제출_산출물.md`: PDF 포트폴리오 작성 양식
- `04_강사용_정답_및_채점표.md`: 직접 증빙과 채점 순서
- `05_학생공개용_채점기준.md`: 영역별 학생 공개용 기준

학생에게는 02번, 03번, 05번을 제공한다. `Exam.md`와 01번·04번은 강사용이다.
