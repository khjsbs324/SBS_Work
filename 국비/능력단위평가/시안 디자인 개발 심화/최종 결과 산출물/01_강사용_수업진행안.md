# 시안 디자인 개발 심화 강사용 수업진행안

## 운영 조건

- 개인평가 240분
- 입력 자료: 학생의 개인 브랜딩·포트폴리오 기획 또는 강사 제공 브랜드 브리프
- 필수 제출: PDF 1개, 원본 ZIP 1개
- 제작 도구: 학생이 선택한 편집·백터·레이아웃·3D 목업 도구

## 240분 진행

1. 0~30분: 브랜드 목적·대상·핵심 메시지 확정, 기초 자료 수집·분류
2. 30~55분: 자료 적합성 판단, 정보 구조·스토리보드·작업 방법 계획
3. 55~105분: 정보그래픽과 키 비주얼 스케치, 중간 시안 비교·선정
4. 105~160분: 심벌·로고타입·비주얼 모틴·타이포그래피·색채 체계 고도화
5. 160~205분: 인쇄·디지털·입체 매체 중 3종 이상으로 베리에이션
6. 205~225분: 출력 미리보기·프루프 점검, 문제 수정과 재확인
7. 225~240분: PDF·ZIP 정리, 파일명·열림·누락 확인과 제출

## 운영 유의 사항

- 입체 적용은 실물 제작을 강제하지 않고 목업과 제작 사양으로 예상 결과를 판단한다.
- 실제 프린터가 없으면 PDF 출력 미리보기와 색상 모드·도련·폰트·링크 점검으로 대체할 수 있다.
- 제작물 수보다 매체별 차이와 콘셉 유지 규칙을 평가한다.
- 시안의 시각적 화려함만으로 점수를 주지 않고 학생의 설명과 실제 결과를 대조한다.
- AI 이미지를 사용한 경우 생성 여부보다 선택·편집·보정·저작권 및 사용 조건 기록을 확인한다.

## 회수·검수 순서

1. PDF·ZIP 파일명, 열림, 파일 크기를 확인한다.
2. PDF의 제출 목록과 시안 ID를 ZIP의 소스와 대조한다.
3. 수집 자료에서 최종 시안까지의 선택·변환 흐름을 확인한다.
4. 정보그래픽, 아이덴티티 요소와 키 비주얼의 일관성을 확인한다.
5. 세 가지 이상 매체의 사양, 레이아웃 차이와 콘셉 유지를 확인한다.
6. 출력 문제 ID, 보완 전후와 재확인 결과를 확인한다.
7. `Exam.md` SD-01~SD-14에 PDF 페이지·시안 ID·소스 직접 증빙을 연결해 채점한다.
