## 전제와 범위

이 프로젝트는 백엔드 없이 브라우저에서 실행되는 정적 웹사이트를 개선하는 과제다. 실제 회원가입, 로그인, 데이터베이스 저장, 파일 전송은 구현하지 않는다. 폼 제출과 학습 진도는 JavaScript 데모 동작으로 표현하고, 필요하면 `localStorage`에 비민감한 예시 상태만 저장한다.

### 포함

- 시맨틱 HTML 구조와 접근 가능한 콘텐츠
- CSS 반응형 레이아웃, 디자인 토큰, 컴포넌트 상태
- JavaScript 메뉴, 탭, 아코디언, 모달, 폼 검증, 학습 진도 데모
- Git 브랜치·커밋·Pull Request 기반 협업
- GitHub Pages 정적 배포와 배포 URL 검증

### 제외

- 백엔드, DB, API, 실제 인증·권한, 실제 파일 업로드
- 개인정보 수집과 실제 이메일 전송
- 결제, 운영자 화면, 서버 배포

## 완료 조건

- 우선순위 `상` 결함 0건, 요구사항 테스트 통과율 100%
- 360px~1440px에서 핵심 콘텐츠 손실 없음
- 키보드만으로 메뉴·탭·모달·폼을 이용 가능
- 새로고침과 GitHub Pages 직접 URL 접근 시 오류 없음
- 커밋·PR·README·배포 주소로 변경 이력을 추적 가능
