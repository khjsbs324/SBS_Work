# 결함이 포함된 과제 설명서

## 목표

HTML·CSS·JavaScript 정적 사이트와 GitHub 저장소에 포함된 결함을 찾아 수정하고, GitHub Pages에서 재검증한다.

## 최소 수행

- 디자인/CSS 결함 5건 이상
- 콘텐츠/HTML 접근성 결함 5건 이상
- JavaScript 상호작용 결함 5건 이상
- Git/GitHub/Pages 관리 결함 3건 이상
- 각 영역의 우선순위 `상` 결함 1건 이상 수정
- 수정 전후, 커밋, PR, 배포 검증 증빙 제출

## 제공 파일

```text
project/
├─ index.html
├─ courses.html
├─ course-detail.html
├─ lesson.html
├─ contact.html
├─ css/style.css
├─ js/menu.js
├─ js/widgets.js
├─ js/form.js
├─ js/progress.js
├─ assets/images/
└─ README.md
```

## 제한

- 백엔드, DB, 실제 인증, 외부 API를 추가하지 않는다.
- 문의 폼은 실제 전송하지 않는 데모로 유지한다.
- 개인 저장소 비밀값, 개인정보, 실제 이메일을 예시 데이터로 사용하지 않는다.
- 수정은 기능 브랜치와 PR을 통해 기록한다.
