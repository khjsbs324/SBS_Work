# 리뷰 환경 및 시나리오

## 환경

| 구분 | 환경 | 확인 사항 |
|---|---|---|
| 로컬 | VS Code Live Server 또는 파일 실행 | HTML/CSS/JS 기본 동작 |
| 데스크톱 | Chrome, Edge, Firefox | 콘솔·키보드·레이아웃 |
| 모바일 | 360×800, 390×844 | 메뉴·터치·줄바꿈 |
| 접근성 | 키보드, 200% 확대, 화면낭독기 | 이름·역할·상태 |
| 저장소 | GitHub 이슈·브랜치·PR | 추적·리뷰 기록 |
| 배포 | GitHub Pages URL | 경로·링크·새로고침 |

## 시나리오

### S-01 모바일 메뉴

360px에서 버튼으로 메뉴를 열고 모든 링크를 순회한 뒤 Escape로 닫는다. 열림 상태, 포커스 이동·복귀, 배경 스크롤을 확인한다.

### S-02 탭과 아코디언

키보드로 각 탭과 아코디언을 조작한다. 보이는 패널과 ARIA 상태가 일치하고 JS 비활성 시 모든 핵심 내용을 읽을 수 있는지 확인한다.

### S-03 문의 폼

빈 값, 잘못된 이메일, 정상 예시 값을 차례로 입력한다. 오류가 필드와 연결되고, 정상 입력은 네트워크 요청 없이 성공 데모를 표시하는지 확인한다.

### S-04 진도와 저장소

진도를 체크하고 새로고침해 복원한 뒤 초기화한다. 저장소 차단 상황에서도 화면이 중단되지 않는지 확인한다.

### S-05 GitHub Pages

배포 URL의 모든 페이지, CSS, JS, 이미지, 자막, 내부 링크를 확인하고 콘솔 오류와 대소문자 경로 오류를 기록한다.
