# 웹 스타일 가이드

## 디자인 토큰

| 토큰 | 값 | 용도 |
|---|---|---|
| color-primary-700 | `#174EA6` | 주요 버튼, 링크 |
| color-primary-100 | `#E8F0FE` | 선택 배경 |
| color-text-900 | `#1F2937` | 본문·제목 |
| color-text-600 | `#4B5563` | 보조문구 |
| color-error-700 | `#B42318` | 오류 텍스트·테두리 |
| color-success-700 | `#067647` | 성공 텍스트 |
| color-surface | `#FFFFFF` | 기본 배경 |
| radius-sm/md/lg | `4px / 8px / 16px` | 입력창·카드·모달 |
| space-1~6 | `4, 8, 12, 16, 24, 32px` | 간격 체계 |

## 타이포그래피

| 스타일 | 크기/행간 | 굵기 | 사용처 |
|---|---|---|---|
| Display | 32/40px | 700 | 페이지 대표 제목 |
| Heading 1 | 24/32px | 700 | 주요 섹션 |
| Heading 2 | 20/28px | 600 | 하위 섹션 |
| Body | 16/24px | 400 | 본문 |
| Caption | 14/20px | 400 | 보조 정보 |

## 레이아웃

- 최대 콘텐츠 너비: 1200px
- 데스크톱: 12열, 거터 24px, 좌우 여백 32px
- 태블릿: 8열, 거터 20px, 좌우 여백 24px
- 모바일: 4열, 거터 16px, 좌우 여백 16px
- 카드 내부 여백: 최소 16px
- 터치 대상: 가급적 44×44px 이상

## 컴포넌트 상태

- 버튼: 기본, hover, active, focus-visible, disabled, loading 상태를 제공한다.
- 입력창: 레이블을 항상 표시하고 도움말과 오류 메시지를 입력창에 연결한다.
- 포커스: 2px 이상 외곽선과 충분한 대비를 사용하며 요소를 가리지 않는다.
- 오류: 색상, 아이콘, 오류 텍스트를 함께 사용한다.
- 모달: 열릴 때 모달로 포커스를 이동하고 닫힌 뒤 실행 버튼으로 복귀한다.

## 이미지·아이콘

- 기능 아이콘은 텍스트 레이블 또는 접근 가능한 이름을 갖는다.
- 장식 아이콘은 보조기술에서 제외한다.
- 비트맵 이미지는 표시 크기의 2배 해상도를 권장하되 용량을 최적화한다.
- 로고를 임의 변형·회전·왜곡하지 않는다.
