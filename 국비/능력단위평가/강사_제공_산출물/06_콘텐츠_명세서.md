# 콘텐츠 명세서

| ID | 화면 | 유형 | 내용 | 접근성 요구 | 출처 |
|---|---|---|---|---|---|
| CNT-001 | 홈 | 로고 | 한빛교육 | `alt="한빛교육"` | 가상 자산 |
| CNT-002 | 강좌 목록 | 썸네일 | UX 기초 강좌 | 목적에 맞는 alt | 가상 자산 |
| CNT-003 | 학습 | 동영상 | 사용자 조사 기초 | VTT 자막·대본 | 자체 제작 가정 |
| CNT-004 | 문의 | 안내 | 데모 폼·개인정보 금지 | 폼 앞에 텍스트 안내 | 자체 작성 |
| CNT-005 | 전체 | 상태 | 오류·성공·선택됨 | 텍스트·아이콘 병기 | 자체 작성 |

## 문구 예시

- 폼 안내: `교육용 데모입니다. 실제 개인정보를 입력하지 마세요.`
- 필수 오류: `이름을 입력해 주세요.`
- 형식 오류: `example@email.com 형식으로 입력해 주세요.`
- 성공 데모: `문의가 제출된 것으로 표시했습니다. 실제로 전송되지는 않았습니다.`
- 진도 초기화: `이 브라우저에 저장된 예시 진도를 초기화할까요?`

## 콘텐츠 검수

- 고유한 페이지 제목과 순차적 제목 구조
- 목적을 알 수 있는 링크·버튼 문구
- 정보성 이미지 alt, 장식 이미지 빈 alt
- 자막의 맞춤법·전문용어·동기화
- 색이나 위치만으로 의미를 전달하지 않음
