# 학생공개용 채점기준

## 평가에서 보는 흐름

이 평가는 작품 이미지를 많이 모으는 것만으로 끝나지 않습니다. 다음 과정이 직접 증빙으로 연결되는지를 봅니다.

`전체 프로젝트 확인 → 목적·타깃·본인 역할 분석 → 취업 목표·콘셉트 → 무드보드·스타일 가이드 → 정보구조·와이어프레임 → 주요 화면 시안 → ChatGPT 검토·편집 → QA·최종 제출`

## 평가 영역

### 1. 전체 프로젝트와 개인 역할

확인 내용:

- 강사가 지정한 모든 웹디자인 프로젝트를 제출했는가
- 프로젝트별 결과물 파일·링크와 포트폴리오 위치가 연결되는가
- 목적·타깃·문제·과정·결과를 설명했는가
- 팀 프로젝트에서 본인이 맡은 역할과 직접 제작 범위를 구분했는가

### 2. 취업 목표와 포트폴리오 콘셉트

확인 내용:

- 희망 직무와 강조할 역량을 정했는가
- 대표 프로젝트와 전체 프로젝트의 관계를 설명했는가
- 콘셉트·키워드·전달 인상과 편집 원칙이 일관되는가

### 3. 무드보드와 스타일 가이드

확인 내용:

- 참고자료의 출처와 적용·변형·제외 판단이 있는가
- 컬러·서체·그리드·이미지·아이콘·카드 규칙이 있는가
- 스타일 가이드가 실제 화면에 반복 적용되는가

### 4. 정보구조와 와이어프레임

확인 내용:

- 프로젝트를 취업 목표에 맞게 분류하고 우선순위를 정했는가
- 방문자가 필요한 정보를 빠르게 찾을 수 있는가
- 메인·프로필·목록·상세의 위계와 탐색 흐름이 연결되는가
- 실제 콘텐츠와 반응형 화면 조건을 고려했는가

### 5. 주요 화면 시안

확인 내용:

- 실제 프로젝트 이미지와 설명을 사용했는가
- 레이아웃·이미지·텍스트의 위계와 가독성이 적절한가
- 콘셉트·스타일 가이드·와이어프레임이 화면에 일관되게 반영됐는가

### 6. ChatGPT 활용

확인 내용:

- 아이디어·문구·콘텐츠 구조를 위한 사용 목적과 프롬프트가 있는가
- AI가 만든 경력·역할·성과를 실제 자료와 대조했는가
- 결과를 선택·제외·직접 수정하고 적용 위치를 기록했는가

### 7. 최종 검수와 제출 패키지

확인 내용:

- 디자인 일관성·가독성·오탈자·이미지 품질을 점검했는가
- 프로젝트 파일·링크·권한을 실제로 확인했는가
- 발견 문제와 수정 전후·재확인을 기록했는가
- PDF·원본·결과물·버전과 폴더 구조가 정리됐는가

## 공통 4수준 성취기준

| 수준 | 판단 기준 |
|---|---|
| 매우 충실 | 전체 프로젝트가 빠짐없이 확인되고, 프로젝트 분석·통합 콘셉트·스타일·구조·시안·AI 활용·QA가 취업 목표에 맞게 명확히 연결됩니다. |
| 충실 | 주요 프로젝트와 통합 결과는 확인되지만 일부 설명·가이드 적용·구조·시안·AI 기록·링크 또는 검수 정보가 부족합니다. |
| 부분 충실 | 여러 결과물은 있으나 전체 목록과의 대조, 본인 역할, 통합 디자인과 수정 근거가 약해 추가 설명이 많이 필요합니다. |
| 미충족 | 필수 프로젝트가 다수 누락되거나 결과물·개인 역할·통합 포트폴리오·최종 검수의 핵심 증빙을 확인하기 어렵습니다. |

## 작업할 때 기억할 점

- 대표 작품만이 아니라 강사가 지정한 전체 프로젝트를 먼저 확인하세요.
- 팀 결과보다 자신이 무엇을 판단하고 만들었는지 구체적으로 적으세요.
- 기존 화면을 나열하지 말고 취업 목표에 맞게 분류·요약·재구성하세요.
- 스타일 가이드는 표에서 끝내지 말고 모든 주요 화면에 적용하세요.
- AI 문구를 그대로 사용하지 말고 실제 역할·성과와 대조하세요.
- 제출 전에 모든 파일과 링크를 다른 환경에서도 열어 보세요.

신규 사이트 코딩과 배포는 이 평가의 필수 대상이 아닙니다.
