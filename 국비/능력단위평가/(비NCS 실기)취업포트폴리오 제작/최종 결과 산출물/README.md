# 취업포트폴리오 제작 비NCS 실기평가 자료

이 평가는 훈련과정에서 제작한 웹디자인 프로젝트 전체를 취업 목표에 맞게 분석·통합·보완하여 일관된 웹디자인 포트폴리오로 완성하는 기관 자체 비NCS 실기평가다.

## 파일 구성

| 파일 | 대상 | 용도 |
|---|---|---|
| `01_강사용_수업진행안.md` | 강사 | 전체 프로젝트 목록 확정, 300분 진행과 회수 |
| `02_학생용_과제안내서.md` | 학생 | 과제 목표, 전체 제출과 제작·검수 규칙 |
| `03_학생_제출_산출물.md` | 학생 | 인벤토리·기획·시안·QA·제출 양식 |
| `04_강사용_정답_및_채점표.md` | 강사 | 직접 증빙 확인법과 10문항 채점표 |
| `05_학생공개용_채점기준.md` | 학생 | 평가 영역과 4수준 성취기준 |
