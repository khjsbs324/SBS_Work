# 학생용 과제안내서

## 시험 문제

**웹디자인 과정에서 제작한 모든 프로젝트를 정리하여 취업용 포트폴리오를 제출해 주세요.**

## 과제 목표

수업 중 제작한 모든 웹디자인 프로젝트를 빠짐없이 정리하고 취업 목표에 맞는 하나의 포트폴리오로 통합합니다. 프로젝트별 목적·타깃·본인 역할·과정·결과를 설명하고, 스타일 가이드·무드보드·정보구조·와이어프레임을 바탕으로 주요 화면 시안을 제작합니다. ChatGPT는 아이디어·문구·콘텐츠 구조 보조에 활용할 수 있으며, 최종 내용은 반드시 실제 정보와 대조하고 직접 수정합니다.

## 평가 조건

- 평가 구분: 비NCS 실기평가·기관 자체 기준
- 평가 방식: 개인 실기 및 포트폴리오
- 평가 시간: 300분
- 제출 범위: 강사가 확정한 과정 중 웹디자인 프로젝트 전체

## 필수 제출물

1. `이름_취업포트폴리오.pdf`
2. 편집 가능한 디자인 원본 또는 평가자가 열 수 있는 공유 링크
3. 프로젝트별 결과물 파일 또는 열람 가능한 링크

결과물 링크가 외부 환경에서 열리지 않을 수 있으므로 핵심 화면과 결과는 PDF에도 포함합니다.

## 작업 순서

1. 강사가 확정한 프로젝트 목록과 자신의 파일·링크를 대조합니다.
2. 프로젝트별 목적·타깃·문제·본인 역할·도구·과정·결과를 정리합니다.
3. 희망 직무와 강조할 역량, 대표 프로젝트와 전체 프로젝트의 관계를 정합니다.
4. 포트폴리오 콘셉트·키워드·전달 인상과 편집 원칙을 설정합니다.
5. 참고자료를 출처와 함께 분석하고 무드보드로 시각 방향을 정합니다.
6. 컬러·서체·그리드·이미지·아이콘·카드 등의 스타일 가이드를 만듭니다.
7. 프로젝트 분류·순서·콘텐츠 우선순위와 사이트맵·목차를 정합니다.
8. 메인·프로필·프로젝트 목록·상세의 와이어프레임과 탐색 흐름을 설계합니다.
9. 실제 프로젝트 이미지와 설명을 사용해 주요 화면 시안을 제작합니다.
10. 필요한 경우 ChatGPT로 아이디어·문구·콘텐츠 구조를 보조하고 결과를 검증·수정합니다.
11. 일관성·가독성·오탈자·이미지 품질·링크·권한·파일명을 점검하고 수정합니다.
12. PDF·원본·프로젝트 결과물을 제출 목록과 버전에 맞게 정리합니다.

## 프로젝트별 최소 정보

- 프로젝트명과 유형
- 제작 기간과 사용 도구
- 목적과 타깃 사용자
- 해결하려던 문제와 제약
- 개인·팀 여부와 본인 역할
- 조사·기획·디자인·구현 과정 중 본인이 수행한 내용
- 주요 디자인 결정과 이유
- 핵심 화면과 최종 결과
- 결과물 링크 또는 파일
- 배운 점과 다음 개선 방향

## 주요 화면 최소 범위

- 포트폴리오 표지 또는 메인
- 프로필·역량 소개
- 전체 프로젝트 목록
- 대표 프로젝트 상세

## ChatGPT 활용 원칙

- 프롬프트의 목적과 입력한 맥락을 기록합니다.
- AI가 만든 경력·역할·성과·수치는 실제 자료와 대조합니다.
- AI 출력과 자신이 선택·수정한 내용을 구분합니다.
- 학생 또는 팀원의 개인정보와 비공개 프로젝트 자료를 입력하지 않습니다.
- ChatGPT를 사용하지 않은 항목은 사용하지 않았다고 기록하고 직접 작성 근거를 제시합니다.

## 제출 전 확인

- [ ] 강사가 확정한 모든 프로젝트가 인벤토리에 있습니다.
- [ ] 모든 프로젝트의 파일·링크와 PDF 위치를 확인했습니다.
- [ ] 팀 프로젝트의 본인 역할을 구분했습니다.
- [ ] 취업 목표·콘셉트·대표 프로젝트의 연결이 명확합니다.
- [ ] 스타일 가이드가 주요 화면에 일관되게 적용됐습니다.
- [ ] 정보구조·와이어프레임·시안의 흐름이 일치합니다.
- [ ] ChatGPT 문구를 사실에 맞게 직접 검토·수정했습니다.
- [ ] 오탈자·이미지·링크·권한·파일명과 버전을 점검했습니다.
- [ ] PDF·원본·프로젝트 결과물을 모두 열어 보았습니다.

신규 사이트 코딩과 배포는 필수가 아닙니다.
