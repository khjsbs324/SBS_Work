# 취업포트폴리오 제작 비NCS 실기평가 검증 결과

- 검증일: 2026-10-01
- 평가 구분: 비NCS 실기평가·기관 자체 기준
- 교과목: 취업포트폴리오 제작

## 1. 기준자료 확인

- 작업 전 대상 폴더에는 PDF, 평가계획서 파일과 기존 평가 문서가 없었다.
- 사용자가 제공한 평가계획 5개 문장과 “웹디자인 과정에서 제작한 모든 포트폴리오 제출” 조건을 원문 근거로 기록했다.
- NCS 능력단위 코드·수행준거·학습모듈이 있는 것으로 추정하거나 작성하지 않았다.
- `PF-01`~`PF-10`은 공정한 채점을 위해 평가계획과 과제 조건을 구체화한 기관 자체 평가요소다.

## 2. 평가계획 반영 확인

| 사용자 제공 조건 | 반영 위치 |
|---|---|
| 프로젝트 목적·타깃 분석과 일관된 디자인 방향 | 프로젝트 분석, 취업 목표·콘셉트 |
| 콘셉트·컬러·타이포그래피 등 스타일 가이드 | 스타일 가이드 평가와 제출 양식 |
| 레이아웃·이미지·콘텐츠 배치 시안 | 주요 화면 시안 평가 |
| 무드보드·와이어프레임·전체 흐름·UX | 시각 방향, 정보구조와 와이어프레임 평가 |
| ChatGPT 아이디어·문구·콘텐츠 구조 보조 | 프롬프트·사실 확인·학생 편집 평가 |
| 일관성·가독성·완성도·오류 수정 | QA 체크리스트, 수정 전후와 최종 패키지 |
| 과정 중 모든 웹디자인 프로젝트 제출 | 강사 확정 목록·학생 인벤토리 대조 |

## 3. 문항과 배점

| 평가 영역 | 문항 | 배점 |
|---|---|---:|
| 전체 프로젝트·분석·콘셉트 | PF-01~PF-03 | 30점 |
| 스타일·구조·UX·시안 | PF-04~PF-08 | 50점 |
| ChatGPT 활용·최종 QA | PF-09~PF-10 | 20점 |
| 합계 | 10문항 | 100점 |

- 기관 자체 평가요소 한 개당 문항 한 개로 연결했다.
- 모든 문항은 직접 증빙과 4수준 점수 구간을 포함한다.
- 각 10점 문항의 구간은 9~10점, 6~8점, 3~5점, 0~2점이다.

## 4. 전체 프로젝트 제출 검증 방식

- 프로젝트 개수와 명칭은 임의로 정하지 않았다.
- 강사는 평가 전에 과정 중 필수 제출 대상 프로젝트 목록을 확정해야 한다.
- 학생은 프로젝트 인벤토리에 전체 목록, 개인·팀 구분, 결과물 파일·URL, PDF·원본 위치와 접근 상태를 기록한다.
- 팀 프로젝트는 본인 역할과 직접 제작 범위를 구분한다.
- 외부 링크 장애와 프로젝트 미제출을 구분하고, 가능한 경우 로컬 파일·캡처·원본으로 결과를 확인한다.

## 5. 운영 조건과 제출물

- `Exam.md`, 강사용 수업진행안과 학생용 과제안내서의 평가 시간은 모두 300분이다.
- 시험 문제 제목은 “웹디자인 과정에서 제작한 모든 프로젝트를 정리하여 취업용 포트폴리오를 제출해 주세요.”로 일치한다.
- 필수 제출물은 통합 포트폴리오 PDF, 편집 가능한 디자인 원본 또는 접근 가능한 공유 링크, 프로젝트별 결과물 파일 또는 열람 가능한 링크로 일치한다.
- 기존 프로젝트는 평가 전에 준비하고, 평가시간에는 통합·선별·재구성·보완·QA·패키징에 집중한다.
- 신규 HTML·CSS·JavaScript 구현과 새로운 배포는 필수 범위에서 제외했다.

## 6. 직접 증빙과 공개 범위

- 프로젝트 목록·설명·콘셉트·무드보드·스타일 가이드·정보구조·와이어프레임·시안·ChatGPT 기록·QA를 직접 증빙으로 연결했다.
- 학생용 과제안내서, 제출 템플릿과 공개용 채점기준에는 내부 문항 ID와 원점수·환산 절차가 없다.
- 강사용 문서에는 내부 ID, 전체 프로젝트 대조 순서, 경계 사례와 중복 감점 방지 원칙을 포함했다.
- 등록용 정답 문구는 강사용 문서와 `Exam.md`에 별도 표시했다.

## 8. 한계와 후속 조치

- 기관의 실제 평가계획서 원본 파일과 필수 프로젝트 목록은 확인하지 못했다.

- 추후 원본 평가계획서 또는 과정 프로젝트 목록이 확보되면 시간·배점·프로젝트 수·제출 형식을 우선하여 재대조해야 한다.
- 실제 학생 프로젝트·링크 검수, 배포용 PDF 변환, 신규 사이트 배포, 외부 평가 사이트 등록, 채점과 Git 커밋은 수행하지 않았다.
