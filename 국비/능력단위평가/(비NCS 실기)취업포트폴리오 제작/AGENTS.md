# 취업포트폴리오 제작 비NCS 실기평가 작업 지침

상위 `국비/AGENTS.md`와 `능력단위평가/AGENTS.md`의 자료 보존·학생/강사 문서 분리·직접 증빙·검증 원칙을 따르되, 이 평가는 NCS 능력단위평가가 아니다.

## 평가 성격과 기준

- 평가 구분: 비NCS 실기평가·기관 자체 기준
- 교과목: 취업포트폴리오 제작
- 제출 범위: 훈련과정에서 제작한 웹디자인 프로젝트 전체
- 기준 원문: 사용자가 제공한 평가계획 5개 항목과 전체 프로젝트 제출 조건
- `PF-01`~`PF-10`은 내부 추적 ID이며 NCS 공식 수행준거나 능력단위 코드가 아니다.

강사는 평가 전에 과정 중 제출 대상 프로젝트 목록을 확정한다. 프로젝트 개수·명칭을 임의로 추정하지 않으며, 학생의 프로젝트 인벤토리와 확정 목록을 대조한다.

## 평가 조건

- 별도 지시가 없으면 개인 실기·포트폴리오형 평가, 300분, 총점 100점으로 운영한다.
- 기존 웹디자인 결과물을 입력자료로 사용하고, 평가시간에는 누락 확인·취업용 재구성·스타일 통일·설명 보완·오류 수정·최종 패키징을 수행한다.
- 필수 결과는 취업용 통합 포트폴리오 PDF, 편집 가능한 디자인 원본 또는 접근 가능한 공유 링크, 프로젝트별 결과물 파일 또는 열람 가능한 링크다.
- 프로젝트마다 목적·타깃·본인 역할·제작 과정·주요 결정·결과를 확인할 수 있어야 한다.
- 신규 HTML·CSS·JavaScript 구현, 기존 프로젝트의 전면 재개발과 새로운 배포는 필수로 요구하지 않는다.

## 판단 원칙

- 제출 개수만 보지 않고 강사가 확정한 대상 목록의 완전성, 파일·링크 접근성과 프로젝트별 설명을 함께 확인한다.
- 모든 프로젝트를 동일한 비중으로 보여 주기보다 취업 목표와 역량에 맞는 우선순위·분류·편집 근거를 본다. 단, 필수 제출 대상은 누락하지 않는다.
- 스타일 가이드는 포트폴리오 전체의 콘셉트·컬러·타이포그래피·그리드·이미지·컴포넌트 규칙으로 실제 화면에 적용되어야 한다.
- 무드보드·와이어프레임·시안은 결과 장식이 아니라 디자인 방향과 사용자 흐름의 근거로 평가한다.
- ChatGPT는 아이디어·문구·콘텐츠 구조를 보조할 수 있으나 사실 확인과 최종 편집 책임은 학생에게 있다.
- 동일 원인으로 여러 항목을 반복 감점하지 않으며, 확인하지 못한 파일·링크를 추측하여 인정하거나 자동 0점 처리하지 않는다.

## 문서 분리와 검증

- 학생용 문서에는 내부 문항 ID, 문항별 점수 계산과 강사용 판단 예시를 노출하지 않는다.
- 강사용 문서는 프로젝트 목록, PDF 페이지, 원본 프레임, 결과물 URL, ChatGPT 기록과 수정 이력에 연결해 판단할 수 있도록 작성한다.
- 변경 후 `국비` 폴더에서 `python -B scripts/harness.py check --records`를 실행한다.
- 실제 배포용 PDF 변환, 포트폴리오 사이트 배포, 외부 평가 사이트 등록과 학생별 채점은 사용자가 별도로 요청할 때만 수행한다.
