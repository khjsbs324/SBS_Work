# 취업포트폴리오 제작 평가 기준자료 정리

## 1. 자료 현황

- NCS 학습모듈 PDF: 없음
- 별도 평가계획서 파일: 폴더에 없음
- 사용자 확정 제출 범위: 웹디자인 과정에서 제작한 모든 포트폴리오 제출
- 사용자 제공 평가계획 문장: 5개

이 평가는 NCS 원문을 추정하여 채우지 않고, 제공된 평가계획 문장과 전체 프로젝트 제출 조건을 근거로 한 기관 자체 비NCS 실기평가로 설계한다.

## 2. 평가계획 원문

1. 프로젝트 목적과 타깃을 분석하여 스타일 가이드의 콘셉트, 컬러, 타이포그래피 등 핵심 요소를 기획하고 일관된 디자인 방향을 설정한다.
2. 스타일 가이드에 기반하여 포트폴리오 시안을 구성하고 레이아웃, 이미지, 콘텐츠 배치를 시각적으로 설계한다.
3. 디자인 툴을 활용하여 무드보드, 와이어프레임, 시안 화면 등을 제작하고 전체 흐름과 사용자 경험을 구체화한다.
4. ChatGPT를 활용하여 아이디어 발상, 문구 작성, 콘텐츠 구조 정리 등 기획 및 제작 과정을 보조한다.
5. 최종 결과물을 검토하여 디자인 일관성, 가독성, 완성도를 점검하고 오류 및 미흡한 부분을 수정·보완하여 완성도를 높인다.

## 3. 기관 자체 평가요소 구체화

평가계획의 5개 문장과 전체 제출 조건을 다음 10개 증빙 영역으로 구체화했다.

1. 전체 프로젝트 인벤토리와 제출 완전성
2. 프로젝트별 목적·타깃·본인 역할·문제 분석
3. 취업 목표 기반 포트폴리오 콘셉트
4. 컬러·타이포그래피·그리드·이미지·공통 요소 스타일 가이드
5. 무드보드·참고자료와 시각 방향
6. 프로젝트 분류·순서·콘텐츠 정보구조
7. 와이어프레임·탐색 흐름·사용자 경험
8. 레이아웃·이미지·콘텐츠가 적용된 주요 화면 시안
9. ChatGPT 프롬프트·결과·학생 선택·수정 기록
10. 일관성·가독성·완성도·파일·링크 QA와 수정·패키징

## 4. 전체 프로젝트 제출 원칙

- 강사는 평가 전에 과정 중 필수 제출 프로젝트의 목록과 명칭을 확정한다.
- 학생은 프로젝트 인벤토리에 확정 목록 전체를 작성하고 결과물 파일 또는 열람 가능한 링크를 연결한다.
- 포함·제외 여부, 접근 상태와 포트폴리오 안의 위치를 기록한다.
- 취업 목표에 따라 대표 프로젝트의 노출 비중을 조절할 수 있지만 필수 프로젝트 자체를 누락하지 않는다.
- 팀 프로젝트는 본인 역할, 직접 제작 범위와 팀 결과를 구분한다.
- 결과물 링크가 열리지 않으면 접근 장애와 제출 누락을 구분한다.

## 5. 평가 운영 가정

- 개인 실기·포트폴리오형 300분
- 10개 기관 자체 평가요소, 각 10점, 총점 100점
- 필수 제출: 통합 포트폴리오 PDF, 편집 원본 또는 공유 링크, 프로젝트별 결과물 파일 또는 링크
- 기존 프로젝트는 평가 전에 준비하고, 평가시간에는 통합·편집·보완·검수·패키징에 집중
- 신규 사이트 코딩·배포는 후속 취업 포트폴리오 구현 단계로 보고 필수에서 제외
- 실제 평가계획서 원본에 시간·배점·제출 방법이 추가로 확인되면 원본을 우선하여 수정
