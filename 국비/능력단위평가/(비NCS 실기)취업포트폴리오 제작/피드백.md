# 취업포트폴리오 제작 비NCS 실기평가 피드백 지침

상위 공통 피드백 원칙을 따르며, 이 평가에서는 전체 프로젝트 제출 완전성, 채용 관점의 정보 전달과 통합 디자인의 일관성을 중심으로 작성한다.

## 학생 공개 피드백 구성

1. 잘된 점: 프로젝트·스타일·구조·시안에서 직접 확인한 강점 1~2개
2. 보완할 점: 취업 담당자의 이해나 결과물 신뢰도에 가장 큰 영향을 주는 문제 1~2개
3. 다음 행동: 지원 전에 바로 실행할 구체적인 수정 1~2개

PDF 페이지·프로젝트명·프레임·URL·QA 항목을 근거로 적는다. 내부 문항 ID, 문항별 원점수 계산과 강사용 판단 메모는 학생 공개 피드백에 쓰지 않는다.

## 권장 표현

- “프로젝트 인벤토리와 PDF 목차가 일치해 전체 결과물을 빠르게 확인할 수 있습니다.”
- “팀 프로젝트의 본인 역할을 화면·기능 단위로 구분하면 기여 범위가 더 명확해집니다.”
- “스타일 가이드의 제목 위계가 상세 페이지마다 달라 프로젝트 간 일관성이 약해집니다.”
- “ChatGPT가 만든 소개 문장을 실제 역할과 성과에 맞게 수치 없이 다시 검증하세요.”

피할 표현:

- “작품이 별로다”, “취업하기 어렵다”처럼 취향이나 가능성을 단정하는 표현
- 제출 개수만 보고 포트폴리오 완성도를 판단하는 표현
- 팀 결과 전체를 학생 개인 성과로 간주하는 표현
- 열어 보지 못한 링크나 실행하지 않은 결과물을 정상이라고 단정하는 표현

## 중점 피드백

### 전체 프로젝트와 설명

- 강사 확정 목록과 인벤토리·PDF·원본·링크를 대조한다.
- 프로젝트 목적·타깃·본인 역할·문제·과정·결과가 빠르게 이해되는지 본다.
- 팀 결과와 학생의 직접 기여를 구분했는지 본다.

### 통합 디자인과 UX

- 포트폴리오 콘셉트와 스타일 규칙이 프로젝트마다 일관되는지 본다.
- 대표 프로젝트와 전체 프로젝트의 우선순위가 취업 목표에 맞는지 본다.
- 와이어프레임과 최종 시안의 정보 위계·탐색 흐름이 연결되는지 본다.

### ChatGPT와 최종 QA

- AI 문구·구조가 실제 정보와 일치하고 학생이 직접 선택·수정했는지 본다.
- 오탈자, 이미지 품질, 링크, 권한, 파일명, 버전과 폴더 구조를 확인한다.
- 수정 전후와 최종 제출 목록이 연결되는지 본다.

## 점수와 피드백 일치

- 높은 성취: 실제 지원 직무에 맞춘 프로젝트 순서·요약·면접 연결 지점을 제시한다.
- 중간 성취: 이미 확보된 강점과 가장 큰 전달·일관성 공백을 함께 적는다.
- 낮은 성취: 누락 프로젝트 정리, 대표 프로젝트 1건 설명, 스타일 가이드 적용처럼 먼저 완성할 최소 단위를 제시한다.
- 미확인 자료: 링크 접근 불가·파일 누락·역할 불명확 범위와 재제출 조건을 구체적으로 기록한다.
