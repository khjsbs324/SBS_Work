# 취업포트폴리오 제작 비NCS 실기평가 기준

## 평가 개요

- 평가 구분: 비NCS 실기평가·기관 자체 기준
- 교과목: 취업포트폴리오 제작
- 시험 문제 제목: 웹디자인 과정에서 제작한 모든 프로젝트를 정리하여 취업용 포트폴리오를 제출해 주세요.
- 평가 형식: 개인 실기 및 포트폴리오 평가
- 시험 시간: 300분
- 필수 제출: `이름_취업포트폴리오.pdf`, 편집 가능한 디자인 원본 또는 접근 가능한 공유 링크, 프로젝트별 결과물 파일 또는 열람 가능한 링크
- 문항 수: 10개
- 총점: 100점

## 과제 개요

훈련과정에서 제작한 모든 웹디자인 프로젝트를 누락 없이 정리한다. 프로젝트별 목적·타깃·본인 역할·문제·과정·결과를 분석하고 취업 목표에 맞는 포트폴리오 콘셉트와 스타일 가이드를 수립한다. 무드보드, 정보구조와 와이어프레임을 거쳐 레이아웃·이미지·콘텐츠가 적용된 주요 화면 시안을 제작한다. ChatGPT는 아이디어·문구·콘텐츠 구조 정리에 활용할 수 있으며, 모든 결과는 학생이 사실을 확인하고 직접 선택·수정한다. 최종적으로 일관성·가독성·완성도와 파일·링크를 점검하여 통합 제출 패키지로 완성한다.

## 정답란 표준 문구

프로젝트별 목적·타깃·담당 역할과 제작 과정을 정리하고, 브랜드 콘셉트·컬러·타이포그래피·레이아웃이 포함된 스타일 가이드, 무드보드, 와이어프레임, 주요 화면 시안, 최종 결과물 링크 또는 파일, ChatGPT 활용 기록 및 디자인 검토·수정 결과를 일관된 형식으로 구성한 취업용 웹디자인 포트폴리오.

## 공통 판단 원칙

1. 강사가 확정한 제출 대상 목록과 학생 인벤토리를 먼저 대조한다.
2. PDF 페이지·절, 원본 프레임, 프로젝트 파일·URL, ChatGPT 기록과 수정 이력에 직접 연결해 채점한다.
3. 프로젝트 수만으로 평가하지 않고 목적·타깃·역할·과정·결과 설명과 취업 목표에 따른 편집을 본다.
4. 팀 프로젝트는 팀 결과와 학생의 직접 역할·기여 범위를 구분한다.
5. 스타일 가이드·무드보드·와이어프레임은 주요 화면 시안과 실제로 연결되어야 한다.
6. ChatGPT 출력은 학생의 실제 경력·역할·프로젝트와 대조하고, 학생이 선택·수정한 부분을 확인한다.
7. 같은 자료를 여러 문항의 증빙으로 사용할 수 있으나 같은 원인에 대한 감점은 주된 문항에서만 처리한다.
8. 신규 코드 구현과 새로운 배포는 평가하지 않는다.

## 기관 자체 평가요소별 채점기준

### PF-01. 전체 프로젝트 제출 완전성 — 10점

- 원문: 훈련과정에서 제작한 모든 웹디자인 프로젝트를 확인 가능한 결과물과 함께 누락 없이 정리할 수 있다.
- 증빙: 강사 확정 목록, 학생 프로젝트 인벤토리, 결과물 파일·URL, PDF·원본 내 위치, 접근 확인.
- 9~10점: 확정된 전체 프로젝트를 빠짐없이 인벤토리에 기록하고 각 결과물·설명·포트폴리오 위치·열람 경로를 정확히 연결했다.
- 6~8점: 대부분 제출되어 있으나 일부 위치, 파일명, 링크 권한, 결과물 형식 또는 설명 연결이 부족하다.
- 3~5점: 여러 프로젝트가 있으나 확정 목록과 대조하기 어렵거나 일부 필수 프로젝트·결과물이 누락됐다.
- 0~2점: 전체 제출 범위를 확인할 인벤토리가 없고 다수의 필수 프로젝트를 확인할 수 없다.

### PF-02. 프로젝트 목적·타깃·역할·문제 분석 — 10점

- 원문: 각 프로젝트의 목적, 타깃, 본인 역할과 주요 문제를 분석하여 취업 포트폴리오에 필요한 설명을 작성할 수 있다.
- 증빙: 프로젝트별 배경·목적·타깃·문제·제약·본인 역할·도구·과정·결과·배운 점.
- 9~10점: 모든 프로젝트의 목적·타깃·문제와 본인 역할을 구체적 제작 결정·결과에 연결해 채용 관점에서 이해하기 쉽게 작성했다.
- 6~8점: 주요 프로젝트 설명은 명확하지만 일부 프로젝트의 역할, 문제, 과정·결과 또는 근거가 부족하다.
- 3~5점: 프로젝트명·도구·결과만 나열하거나 팀 결과와 본인 기여를 구분하기 어렵다.
- 0~2점: 프로젝트별 목적·타깃·역할과 문제 분석을 확인할 수 없다.

### PF-03. 취업 목표 기반 포트폴리오 콘셉트 — 10점

- 원문: 취업 목표와 프로젝트 분석을 바탕으로 포트폴리오의 콘셉트와 일관된 디자인 방향을 설정할 수 있다.
- 증빙: 희망 직무·채용 대상, 핵심 역량, 대표 프로젝트, 콘셉트·키워드, 전달 인상, 편집 원칙.
- 9~10점: 취업 목표·핵심 역량·프로젝트 특성을 분석해 차별화된 콘셉트와 일관된 편집·디자인 원칙을 설정했다.
- 6~8점: 목표와 콘셉트는 타당하지만 일부 프로젝트 연결, 차별성, 전달 인상 또는 편집 원칙이 부족하다.
- 3~5점: 감성 키워드 중심으로 방향을 정해 취업 목표와 프로젝트 구성에 활용하기 어렵다.
- 0~2점: 포트폴리오 콘셉트와 디자인 방향을 확인할 수 없다.

### PF-04. 스타일 가이드 핵심 요소 — 10점

- 원문: 포트폴리오 콘셉트에 맞는 컬러, 타이포그래피, 그리드, 이미지와 공통 구성요소를 스타일 가이드로 기획할 수 있다.
- 증빙: 컬러, 제목·본문 서체, 그리드·여백, 이미지 비율·톤, 아이콘, 버튼·카드, 상태·사용·금지 규칙.
- 9~10점: 콘셉트와 매체에 맞는 핵심 요소를 재사용 가능한 규칙·상태·사용·금지 예로 정리하고 실제 시안에 일관되게 적용했다.
- 6~8점: 주요 스타일 규칙과 적용은 적절하지만 일부 그리드, 이미지, 상태, 사용 조건 또는 적용 일관성이 부족하다.
- 3~5점: 컬러·서체 목록은 있으나 포트폴리오 전체에 반복 적용할 규칙과 콘셉트 연결이 약하다.
- 0~2점: 평가 가능한 스타일 가이드가 없거나 시안과 서로 충돌한다.

### PF-05. 무드보드와 시각 방향 — 10점

- 원문: 디자인 툴을 활용하여 무드보드와 참고자료를 제작하고 포트폴리오의 시각 방향을 구체화할 수 있다.
- 증빙: 참고자료 출처, 무드보드, 추출 원리, 적용·변형·제외 판단, 시각 방향 키워드.
- 9~10점: 다양한 참고자료를 출처와 함께 분석하고 공통 원리·차이를 추출하여 콘셉트에 맞는 독자적 시각 방향과 적용 판단으로 구체화했다.
- 6~8점: 무드보드와 방향은 명확하지만 일부 출처, 분석 기준, 적용·제외 이유 또는 차별화가 부족하다.
- 3~5점: 이미지 모음은 있으나 포트폴리오 시안으로 이어지는 원리와 판단이 약하다.
- 0~2점: 무드보드·참고자료 또는 시각 방향을 확인할 수 없다.

### PF-06. 정보구조와 콘텐츠 우선순위 — 10점

- 원문: 프로젝트의 분류, 순서와 콘텐츠 우선순위를 정하고 포트폴리오의 정보구조와 전체 흐름을 설계할 수 있다.
- 증빙: 사이트맵·목차, 프로젝트 분류·순서, 대표/전체 구분, 섹션별 콘텐츠, 채용 담당자 핵심 행동.
- 9~10점: 취업 목표와 방문자 행동에 맞춰 전체 프로젝트를 분류·우선순위화하고 탐색하기 쉬운 정보구조와 콘텐츠 흐름을 설계했다.
- 6~8점: 주요 구조와 프로젝트 순서는 타당하지만 일부 분류, 대표/전체 구분, 콘텐츠 위계 또는 행동 연결이 부족하다.
- 3~5점: 프로젝트를 시간순으로 나열하거나 목차만 있어 취업 목표와 탐색 흐름을 판단하기 어렵다.
- 0~2점: 포트폴리오 정보구조와 콘텐츠 우선순위를 확인할 수 없다.

### PF-07. 와이어프레임과 사용자 경험 — 10점

- 원문: 와이어프레임을 통해 주요 화면의 레이아웃, 탐색 흐름과 사용자 경험을 구체화할 수 있다.
- 증빙: 주요 화면 와이어프레임, 내비게이션, 콘텐츠 위계, 프로젝트 탐색·상세 이동, 반응형 고려와 주석.
- 9~10점: 주요 화면의 정보 위계·탐색·프로젝트 상세 흐름을 와이어프레임과 주석으로 구체화하고 다양한 화면 조건을 고려했다.
- 6~8점: 주요 흐름과 레이아웃은 이해되지만 일부 연결, 콘텐츠 위계, 주석 또는 반응형 고려가 부족하다.
- 3~5점: 화면 틀은 있으나 프로젝트 탐색과 상세 흐름이 끊기거나 실제 콘텐츠 배치를 판단하기 어렵다.
- 0~2점: 평가 가능한 와이어프레임과 사용자 흐름이 없다.

### PF-08. 취업 포트폴리오 주요 화면 시안 — 10점

- 원문: 스타일 가이드와 와이어프레임에 따라 레이아웃, 이미지와 콘텐츠를 배치한 취업 포트폴리오 시안을 제작할 수 있다.
- 증빙: 표지 또는 메인, 프로필, 프로젝트 목록, 프로젝트 상세 시안, 실제 콘텐츠, 가이드 적용표.
- 9~10점: 주요 화면에 실제 프로젝트 콘텐츠를 가독성 있게 배치하고 스타일 가이드·와이어프레임·콘셉트를 일관되게 적용했다.
- 6~8점: 주요 시안과 콘텐츠는 완성됐지만 일부 화면의 위계, 이미지 품질, 정렬, 가이드 적용 또는 상세 구성에 부족함이 있다.
- 3~5점: 화면은 있으나 자리표시자·장식 중심이거나 실제 프로젝트 설명과 스타일 규칙의 연결이 약하다.
- 0~2점: 취업 포트폴리오의 주요 화면 시안을 확인할 수 없다.

### PF-09. ChatGPT 활용과 결과 편집 — 10점

- 원문: ChatGPT를 활용하여 아이디어 발상, 문구 작성과 콘텐츠 구조 정리를 보조하고 결과를 사실에 맞게 선택·수정할 수 있다.
- 증빙: 사용 목적, 프롬프트, 응답 요약, 사실 확인, 선택·제외·수정 내용과 최종 적용 위치.
- 9~10점: 구체적 맥락·제약·출력 형식으로 아이디어·문구·구조를 탐색하고 모든 결과를 실제 프로젝트와 대조해 선택·수정·적용했다.
- 6~8점: ChatGPT 활용과 학생 편집은 확인되지만 일부 프롬프트 맥락, 사실 검토, 선택 근거 또는 적용 위치가 부족하다.
- 3~5점: 일반적인 프롬프트와 결과 캡처만 있거나 AI 문구를 거의 그대로 사용했다.
- 0~2점: ChatGPT 활용 과정 또는 학생의 사실 확인·수정을 확인할 수 없다.

### PF-10. 최종 QA·수정·제출 패키지 — 10점

- 원문: 최종 결과물의 디자인 일관성, 가독성, 완성도, 링크와 파일 오류를 점검하고 수정·보완하여 제출 패키지로 정리할 수 있다.
- 증빙: QA 체크리스트, 발견 문제, 수정 전후, 전체 프로젝트 링크 확인, 파일명·버전·폴더 구조와 최종 제출 목록.
- 9~10점: 일관성·가독성·콘텐츠·이미지·링크·파일·권한을 체계적으로 점검하고 수정 전후와 버전을 남겨 완전한 제출 패키지로 정리했다.
- 6~8점: 주요 점검과 수정·패키징은 적절하지만 일부 링크, 오탈자, 이미지 품질, 버전 또는 파일 구조가 부족하다.
- 3~5점: 최종 결과는 있으나 점검 기록과 수정 전후가 약하고 파일·링크·버전 관리에 오류가 남아 있다.
- 0~2점: 최종 검토·수정 기록이 없고 제출 패키지의 주요 파일·링크를 확인할 수 없다.
