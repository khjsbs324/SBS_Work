# 서비스ㆍ경험디자인 관찰조사 체크리스트

> 이 문서는 완성된 시험문제나 채점표가 아닌 기존 브랜딩 프로젝트를 바탕으로 가상의 서비스를 점검하고, 부족한 부분을 AI와 상의하여 보완하기 위한 학생용 작성 양식입니다.

## 0. 작성 안내

### 작업 목표

내가 기획한 서비스를 처음 보는 사람도 이해할 수 있도록 자세히 설명하고, 다음 과정을 한 문서 안에 기록합니다.

1. 서비스 초안과 브랜딩 자료를 확인합니다.
2. 사용자 유형과 요구를 구체화합니다.
3. 사용자 여정과 관찰조사 계획을 점검합니다.
4. 서비스의 부족한 부분을 찾아 우선순위를 정합니다.
5. AI와 상의하되 최종 판단은 직접 내립니다.
6. 수정 전·후와 재확인 결과를 기록합니다.
7. 작성이 끝난 체크리스트를 PDF로 변환하여 제출합니다.

### 판정 및 근거 표시

- 체크 항목이 충족되면 `[x]`, 미확인 또는 보완이 필요하면 `[ ]`로 표시합니다.
- 확인된 내용과 가상의 내용을 아래와 같이 구분합니다.
  - `[프로젝트]`: 기존 브랜딩 문서나 결과물에서 확인한 내용
  - `[조사]`: 출처가 있는 데스크 리서치·경쟁 서비스 조사 내용

- AI의 답변은 조사 근거가 아닙니다. 출처가 필요한 사실은 별도로 확인합니다.
- 이름, 연락처, 얼굴, 계정 등 실제 개인정보를 입력하거나 AI에 전달하지 않습니다.
- 짧게 `있음`, `좋음`이라고만 쓰지 말고 대상·상황·이유·기대 효과가 드러나게 작성합니다.

| 핵심 제공 내용 | 사용자가 오늘의 피부 컨디션, 외출 상황, 원하는 피부 표현을 선택하면 조건에 맞는 제품 조합을 추천하고, 제품별 사용 순서와 사용량, 바르는 방법을 함께 안내한다. |

| 서비스 제공 방식 | 브랜드가 자체 앱에서 선택형 인터페이스와 제품·사용법 콘텐츠를 제공한다. 사용자가 입력한 피부 컨디션, 상황, 피부 표현 정보를 기준으로 적합한 제품 조합을 매칭하고, 결과 화면에서 사용 순서와 방법을 단계별로 안내한다. |

| 포함 범위 | 피부 컨디션·외출 상황·원하는 피부 표현 선택, 조건별 제품 조합 추천, 제품 사용 순서, 사용량과 바르는 방법 안내, 최종 추천 결과 화면까지를 기획 범위에 포함한다. |
| 제외·제약 조건 | 카메라를 활용한 피부 진단, 피부 질환 판단, 의료적 상담, 정밀 피부 분석은 포함하지 않는다. 추천 결과는 사용자가 직접 선택한 정보와 브랜드가 보유한 제품 범위에 기반하므로 실제 피부 상태나 개인차를 완전히 반영하는 데 한계가 있다. |

### 6-1. 관찰 목적과 질문

## 9. 서비스 개념과 실행 방향 정리

### 9-1. 핵심 가치 제안

| 항목 | 작성 내용 |

| 혜택 | 화장 고민 시간 단축, 들뜸·밀림 실패 방지, 기존 보유 화장품의 시너지 극대화로 하루 종일 편안하고 완성도 높은 피부 표현 |

| 차별점 | 고가의 맞춤 제조나 카메라 촬영 강요 없이, 보유 제품 기반의 '실전 도구 테크닉과 꿀팁'을 30초 내 즉각 안내 |
| 사용자의 부담 | 30초 내외의 간편 터치 3회 외에 추가적인 사진 촬영, 개인정보 입력, 긴 설문 등의 부담이 일절 없음 |

### 9-2. 서비스 원칙

1. 원칙 1: **30초 컷의 원칙 (Speed & Simplicity)**
   - 필요한 이유: 출근 직전 촉박한 아침 시간에 사용되므로 복잡하거나 긴 절차는 무조건 이탈로 이어짐.
   - 적용 예시: 질문은 3개 이내로 제한하고, 카메라 촬영 등 불필요한 단계를 과감히 배제하여 30초 내 결과 도출.
2. 원칙 2: **실전 도구 중심 가이드 (Actionable Technique)**
   - 필요한 이유: 같은 화장품도 어떤 도구(스펀지/브러시/손)로 어떻게 바르느냐에 따라 밀착력과 결과가 완전히 달라짐.
   - 적용 예시: 제품명 나열에 그치지 않고 "물먹인 스펀지로 톡톡 두드리기", "콩알 반쪽 양으로 얇게 펴 바르기" 등 구체적 행동 지침 제공.
3. 원칙 3: **핸즈프리 노-스크롤 뷰 (Hands-free Usability)**
   - 필요한 이유: 화장 중 손에 제품이 묻어 스마트폰 화면을 다시 터치하거나 스크롤하기 어려움.
   - 적용 예시: 가이드 진입 시 화면 꺼짐 방지(Always-On) 기본 적용 및 스크롤 없이 한 화면에 1-2-3단계 요약 노출.

## 11. AI와 상의하기

### 11-1. AI에 전달할 내용

- 서비스 설명: 오늘의 피부 컨디션, 외출 상황, 원하는 피부 표현을 선택하면 최적 제품 조합과 실전 도구·바르는 법을 추천하는 맞춤형 뷰티 가이드
- 주요 사용자와 상황: 아침 15분 내 화장을 마쳐야 하는 2030 여성 직장인 (이소연 페르소나, 화장대 앞 모바일 이용)
- 확인된 근거: 2030 소비자의 74% 피부 컨디션 변화 체감(오픈서베이), 긴 문진 시 60% 이탈(뷰티테크 분석)
- 아직 검증하지 않은 가설: 화장 중 화면 꺼짐 마찰, 텍스트 과다로 인한 도구 팁 미인지, 자사 제품 미보유 시 이탈 우려
- 점검할 `OBS-` 문제 ID: `OBS-01`(화면 꺼짐), `OBS-02`(텍스트 과다 및 스크롤), `OBS-03`(추천 제품 미보유 시 이탈)
- 반드시 유지할 브랜드·서비스 원칙: 30초 컷의 원칙, 실전 도구 중심 가이드, 핸즈프리 노-스크롤 뷰
- AI에게 묻고 싶은 내용: 화장품이 묻은 손으로 조작하기 어려운 문제를 해결할 인터랙션과, 제품 미보유 사용자를 포용하는 UI 구성안

## 14. 최종 정리

- 내 서비스의 가장 분명한 강점: 복잡한 카메라 촬영이나 긴 설문 없이, 30초 안에 그날의 피부·외출 상황에 맞는 최적 제품 조합과 핸즈프리 도구 팁을 제공해 화장 들뜸·밀림 실패를 방지한다는 점.
- 점검 전 가장 부족했던 부분: 화장 중 손에 화장품이 묻어 스마트폰 화면을 다시 터치하기 어렵고, 텍스트 설명이 길어 바쁜 아침에 직관적으로 인지하기 어려웠던 물리적/시각적 사용성 마찰.
- AI와 상의한 뒤 내가 선택한 핵심 개선: 결과 화면 진입 시 스마트폰 '화면 켜짐 유지(Always-On)' 및 '3-Step 도구 픽토그램 카드(노-스크롤 단일 뷰)' 적용, 자사 제품 미보유자를 위한 '대체 제형 팁' 추가.
- 개선으로 달라진 사용자 경험: 화장대 앞에서 스마트폰을 전혀 만지지 않고 거울과 화면만 보며 3분 안에 메이크업을 안정적으로 완성할 수 있게 됨.
