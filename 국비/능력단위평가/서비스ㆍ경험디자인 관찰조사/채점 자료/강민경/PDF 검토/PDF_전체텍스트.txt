                          설명 항목                                                    작성 내용

 기획 배경                                                    일정은 캘린더 앱, 필기는 Goodnotes, 간단한 생각은 메모장, 사진과 추억은 사진 앱처럼 개인의 기록이 여러 서비스에 분
                                                         산되어 있어 하나의 하루와 경험이 서로 끊겨 저장되는 불편이 있음. 또한 기존 디지털 다이어리 앱은 사용 방법은 쉽지만
                                                         레이아웃 자유도가 부족하거나, 자유도가 높은 필기 앱은 기능이 많아 초보 사용자가 복잡하게 느낄 수 있음. DAMORI의
                                                         기존 브랜드 방향인 ‘기록을 내 방식대로, 삶을 나답게’라는 가치와 연결하여, 쉽고 직관적으로 시작하면서도 사용자가 자
                                                         신의 방식대로 기록 구조를 구성할 수 있는 통합 기록 서비스를 기획함.

 해결할 핵심 문제                                                사용자는 일상, 학교, 학원, 직장, 이동 중 등 다양한 상황에서 일정·할 일·필기·메모·사진·감정 기록을 남기지만 기록 도구가
                                                         서로 달라 정보를 다시 찾거나 연결하기 어려움. 또한 정해진 속지와 레이아웃만 사용할 경우 자신에게 맞는 기록 방식을
                                                         만들기 어렵고, 파일을 가져오거나 다른 기기에서 이어서 확인하는 과정에도 불편이 발생함. 따라서 여러 종류의 기록을
                                                         하나의 기록책과 날짜 흐름 안에서 연결하고, 기록·확인·수정·회고 과정의 복잡성을 줄이는 것이 핵심 문제임.

 주요 사용자                                                   일정 관리와 필기, 일기, 사진 기록을 함께 사용하는 10대 후반~30대 사용자를 주요 대상으로 함. 특히 대학생·취업준비생
                                                         처럼 학습·일정·취향 기록을 병행하는 사용자, 직장인처럼 일정관리·자기관리·라이프로그를 함께 기록하는 사용자, 기록 습
                                                         관을 만들고 싶지만 복잡한 기록 방식에 부담을 느끼는 사용자에게 적합함. 이 사용자층은 모바일과 태블릿을 함께 사용하
                                                         는 경우가 많고, 기록 방식의 자유도와 접근 편의성을 동시에 필요로 한다는 점에서 선정함.

 핵심 제공 내용                                                 사용자가 직접 구성한 다이어리·노트 묶음을 메인에서 확인하고, 기록책을 선택한 뒤 Monthly·Weekly·Daily·Free Note 등
                                                         기본 속지를 추가하여 바로 기록 가능하도록 제공함. 손글씨, 텍스트, 이미지, 사진, 스티커, 문서, PDF 등의 기록 기능을 제
                                                                       공하며, 선택한 속지의 일정 영역·메모 영역·사진 영역·체크리스트 등을 이동·추가·삭제·크기 조절할 수 있는 자유 레이아웃
                                                         편집 기능을 제공함. 캘린더에서는 일정과 해당 날짜에 작성한 필기·사진·메모를 함께 확인하며, Google Calendar·Naver
                                                                                                                  Calendar 등 외부 일정 서비스 연동과 PDF·이미지·문서·클라우드 파일 가져오기 기능을 고려함. 모바일·태블릿·웹 간 기록
                                                                       동기화, 기록책 잠금, 생체인증, 표지·스티커·템플릿 꾸미기 기능도 포함함.

                          설명 항목                                                    작성 내용

 이용 과정                                                    사용자는 DAMORI 앱을 처음 실행한 뒤 스플래시와 온보딩에서 ‘흩어진 기록을 하나로 연결한다’는 서비스 가치를 확인함.
                                                         로그인 후 기기 동기화를 시작하고, 메인 화면에서 자신이 만든 기록책 목록과 최근 기록을 확인함. 새 기록책을 만들거나
                                                         기존 기록책을 선택한 뒤 기본 속지를 선택하고, 필요에 따라 레이아웃을 수정함. 이후 손글씨·텍스트·사진·문서 등을 기록
                                                                             하고, 작성된 내용은 기록책·날짜·주제 기준으로 축적됨. 사용자는 모바일에서 빠르게 확인하거나 메모하고, 태블릿에서 자
                                                         세히 작성·편집하며, 웹에서는 기록을 검색·관리·정리할 수 있음. 이후 캘린더와 Archive를 통해 과거 기록을 다시 확인하고
                                                                       회고함.

 핵심 혜택                                                    여러 앱을 오가며 기록해야 하는 시간을 줄이고, 일정·필기·메모·사진을 하나의 서비스 안에서 관리할 수 있어 기록 과정의
                                                         편의성이 높아짐. 기본 템플릿을 제공하면서도 사용자가 직접 레이아웃을 수정할 수 있어 기록 시작의 부담은 낮추고 표현
                                                         의 자유도는 높일 수 있음. 기록이 날짜와 기록책 단위로 자연스럽게 축적되어 다시 찾기 쉬워지고, 여러 기기에서 이어서
                                                         확인할 수 있어 기록 단절을 줄일 수 있음. 사용자가 직접 만든 표지·속지·레이아웃과 기록이 지속적으로 쌓이면서 개인 기
                                                         록물에 대한 애착과 성취감을 형성할 수 있음.

 서비스 제공 방식                                                                     DAMORI가 모바일 앱·태블릿 앱·웹 서비스를 제공하고, 사용자는 개인 계정으로 로그인하여 자신의 기록 데이터를 관리함.
                                                         서비스 내부에서는 기록책 생성, 속지 선택, 자유 레이아웃 편집, 필기 도구, 이미지·문서 가져오기, 캘린더, Archive, 템플릿·
                                                         꾸미기 콘텐츠 등을 제공함. 모바일은 빠른 확인과 간단한 기록 중심, 태블릿은 손글씨·문서 필기·레이아웃 편집 중심, 웹은
                                                                                               검색·관리·Archive 중심으로 역할을 구분함. 외부 캘린더와 클라우드 서비스는 API 연동을 통해 연결하는 방향으로 기획함.

 브랜드와의 연결                                                                     DAMORI는 ‘담다 + Memory’라는 네이밍과 ‘기록을 내 방식대로, 삶을 나답게’라는 브랜드 가치를 가진 기록·아카이브 브
                                                                       랜드임. 앱에서도 기록을 단순히 작성하는 기능보다 하루·생각·감정·사진·일정을 하나의 기록 흐름으로 담고 축적하는 경험
                                                         을 중심으로 설계함. 기존 DAMORI의 기록책·아카이브·페이지·인덱스 개념을 디지털 환경으로 확장하여, 메인 화면을 파일
                                                         목록보다 사용자의 기록책이 모인 ‘기록 책장’처럼 구성함. 기본 구조는 제공하지만 사용자가 자신의 방식대로 편집할 수
                                                         있도록 하여 브랜드의 ‘자유로운 기록’과 ‘개인 아카이브’ 가치를 서비스 경험으로 연결함.

 포함 범위                                                    이번 기획에서는 DAMORI 앱의 핵심 서비스 구조와 모바일 대표 화면 6장까지 우선적으로 다룸. 모바일 6장은 Splash,
                                                                                                               Onboarding, 회원가입·로그인, Home·나의 기록책, Page Builder, Record 화면으로 구성함. 또한 서비스 구조상 필요한 캘
                                                                             린더, Archive, 파일 가져오기, 동기화, 보안, 꾸미기, 템플릿 스토어, 커뮤니티, 마이페이지 기능의 역할과 연결 구조를 정의
                                                                                             함. 이후 파생 화면으로 태블릿의 Record Workspace와 웹의 Archive·관리 화면을 추가 제작하는 방향을 포함함.

 제외·제약 조건                                                 현재 단계에서는 실제 앱 개발, 서버 구축, 데이터베이스 설계, 결제 시스템, 앱스토어·플레이스토어 실제 등록, 외부 API 연
                                                         동 구현, 클라우드 저장 용량 정책, 개인정보 처리 정책, 보안 기술 구현 등은 다루지 않음. Google Calendar·Naver
                                                                                                                  Calendar·Google Drive·iCloud·OneDrive 연동은 필요 기능으로 기획했으나 실제 API 제공 범위와 기술적 구현 가능성은 아
                                                         직 검증하지 않은 상태임. 템플릿 스토어·커뮤니티·사용자 간 공유·템플릿 판매 기능도 확장 기능으로 정의하였으며 이번
                                                         모바일 6장 핵심 화면에서는 별도 상세 화면을 제작하지 않음.
