# 서비스ㆍ경험디자인 관찰조사 강사용 수업진행안

## 평가 개요

| 항목 | 내용 |
|---|---|
| 과제 | 브랜딩 기반 가상 서비스 관찰조사 설계 및 개선 |
| 능력단위 | 서비스ㆍ경험디자인 관찰조사 / 0802010613_17v3 |
| 형태 | 개인 모의 사례 연구 및 작성 결과물 평가 |
| 시간 | 180분 |
| 대상 | 기존 브랜딩 프로젝트를 기반으로 구상한 가상 서비스 한 건 |
| 도구 | 문서 편집 도구, 기존 프로젝트 자료, 출처 조사, AI 상의 |
| 제출 | 이름_서비스경험디자인_관찰조사.pdf 한 개 |
| 평가 | 원본 학습목표 12개 대응, 100점 |

이번 평가는 관찰조사의 설계·분석·개선 논리를 모의 사례에서 확인한다. 가상 이용기록을 실제 사용자 관찰 결과로 인정하지 않는다. 실제 현장 수행 확인 여부는 성적과 별도로 기록한다. 원본의 30명 표본, 현장조사, 팀별 발표 등 활동 예시는 필수 조건이 아니다.

## 평가 전 준비

- 학생에게 기존 브랜딩 자료와 가상 서비스 초안, 실제로 확인 가능한 참고 자료를 준비하도록 안내한다. 새로 브랜드 전체를 제작하게 하지 않는다.
- 시험 시작 전에 기존 자료가 열리는지와 재사용할 조사 출처를 확인하고, 과제안내서의 사용자 여정·잠재 요구·카노 모델 등 기초 용어를 간단히 설명한다. 사전 준비 없이 180분 안에 이론 학습과 프로젝트 기획을 모두 새로 끝내도록 요구하지 않는다.
- 학생용 과제안내서·제출 안내·체크리스트·학생 공개용 채점기준을 제공한다. 강사용 채점표와 Exam은 배포하지 않는다.
- 체크리스트의 서비스 설명·핵심 용어·작성 예시용 문구를 먼저 읽게 하고, 작성 칸에는 자기 서비스 내용을 쓰도록 안내한다.
- 문서 편집, AI 접속, PDF 내보내기가 되는지 확인한다. 특정 유료 모델이나 디자인 도구를 필수화하지 않는다.
- 조사 출처는 기존에 확인한 프로젝트 자료와 실제 외부 자료를 함께 활용할 수 있다. 가상 사용자 발언·숫자를 생성해 조사 결과로 제출하게 하지 않는다.
- 과제 조건과 원본 학습목표의 구분, 출처·가설·AI 제안의 표기, 최종 PDF 한 개 제출을 안내한다.

## 180분 진행

| 시간 | 학생 작업 | 강사 확인 |
|---|---|---|
| 0~20분 | 기본 정보와 상세 서비스 설명 | 대상·문제·이용 과정·혜택·브랜드 연결을 이해할 수 있는가 |
| 20~40분 | 선행조사·경쟁 서비스와 개발 방향 | 출처의 확인 내용과 학생 해석이 구분되는가 |
| 40~60분 | 사용자 특성·유형과 경험 전략 | 라이프스타일·인구학·소비심리와 분류 이유가 있는가 |
| 60~85분 | 관찰 목적·질문·과업·방법 설계 | 무엇을 어떻게 기록하고 판단할지 구체적인가 |
| 85~110분 | 전·중·후 가상 이용기록, 요구·이론 해석 | 행동 가설과 잠재 요구, 이론 적용 이유가 연결되는가 |
| 110~130분 | 디자인 요소 점검과 문제 선정 | 사용자의 요구에서 실제 접점·정보·절차의 문제로 이어지는가 |
| 130~150분 | AI 상의와 학생 판단 | 제안의 반영·수정·보류 이유를 학생이 설명하는가 |
| 150~170분 | 수정 전후와 재확인 | 문제·요구·변경·확인 결과를 추적할 수 있는가 |
| 170~180분 | PDF 출력과 제출 | 이름·본문·출처·표·글자가 읽히고 파일이 열리는가 |

시간표는 운영 권장안이다. 각 학생이 특정 단계에 쓴 시간이나 작성 속도를 점수화하지 않는다. AI 응답이 늦으면 먼저 자신의 보완안을 기록하고, 이용 가능한 시점에 제안을 비교하게 한다. 도구 장애가 평가에 영향을 주면 사실과 운영 조치를 기록하고 AI 모델 성능을 학생 능력으로 평가하지 않는다.

## 진행 중 질문

- “이 요구를 예상하게 된 이용 상황과 자료는 무엇인가요?”
- “관찰할 행동과 인터뷰로 확인할 생각을 어떻게 구분했나요?”
- “그 행동에는 다른 이유도 있을까요?”
- “AI 제안 중 선택하지 않은 것은 무엇이고 이유는 무엇인가요?”
- “수정한 문서에서 무엇을 다시 확인했고, 실제 사용자에게 확인할 것은 무엇인가요?”

질문은 학생의 제출물 이해와 증빙 위치 확인을 위한 것이다. 강사가 정답을 대신 작성하거나 학생에게 보이지 않은 기준을 추가하지 않는다. 별도의 발표자료·현장 관찰·실제 제3자 인터뷰를 즉석에서 필수화하지 않는다.

## 회수와 채점

1. 학생명·파일명·수령일·파일 크기·SHA-256을 기록한다. 열리지 않으면 보류하고 재제출 또는 환경 확인 경위를 남긴다.
2. PDF 전체를 읽고 페이지·절·자료 ID를 기준으로 증빙을 찾는다. 서식과 다르게 편집했어도 같은 수행이 확인되면 인정한다.
3. `04_강사용_정답_및_채점표.md`와 상위 `Exam.md`의 12문항으로 원점수를 채점한다.
4. 동일 누락·같은 출처 오류는 주된 문항에서 처리하고 다른 문항에서 반복 감점하지 않는다. 독립된 수행 누락은 구별해 기록한다.
5. 사용자 요구·전략·개선의 연결과 PDF 표현을 구분하여 피드백을 쓴다.
6. 등록 요청이 있는 경우 공통 환산식 및 문항별 최대잔여법을 적용하고 합계와 학생 매칭을 검증한다.

## 공식 등록 전 확인 사항

PDF는 NCS 학습모듈이며 별도 번호가 붙은 공식 수행준거 공시표는 제공하지 않는다. 현재 12문항은 PDF 평가 준거의 학습목표 원문에 대응한다. 사이트 등록 요청 때 공식 요소·수행준거 문장·순서·개수를 대조하고, 대응이 다르면 기준을 갱신한 후 등록한다. 이 문서 작성만으로 사이트 등록이나 공식 대조가 끝났다고 기록하지 않는다.
