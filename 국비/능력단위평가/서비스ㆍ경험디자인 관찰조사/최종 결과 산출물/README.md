## 운영 범위

원본 학습모듈에는 공식 수행준거 번호표가 없어 현재 평가 준거의 12개 학습목표에 대응하여 구성했다. 공식 사이트의 수행준거 대조와 문제 등록은 이후 등록 요청 단계에서 진행한다. 학생 제출물이 아직 없어 학생별 채점·성적 등록도 진행하지 않았다.

가상 시나리오의 설계·해석·개선 판단을 평가하며 실제 현장조사 수행·사용자 효과 검증을 완료했다는 의미가 아니다. 원본 `AGTENS.md`와 기존 체크리스트 사본은 초기 요청·자료 보존용이고 현재 운영 기준은 [AGENTS.md](../AGENTS.md)다. `.검증`은 분석·출력 확인용 내부 자료이며 학생 배포 대상이 아니다.
