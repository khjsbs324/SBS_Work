## 학생·강사용 자료 일관성

- 기존 브랜딩 기반 가상 서비스 한 건, 개인평가, 180분 조건을 통일했다.
- 필수 제출은 `이름_서비스경험디자인_관찰조사.pdf` 한 개다. 편집 원본·코드·GitHub·ZIP·실제 사용자 모집을 추가 필수로 요구하지 않는다.
- 학생 체크리스트는 2열 표와 핵심 기록으로 정리했다. 필수·선택 분량과 앞 절의 동등한 증빙을 참조하는 방법을 안내했다.
- 출처 2건(경쟁·유사 서비스 포함), 사용자 유형 2개, 이용 전·중·후 3단계, 명시·잠재 요구, 디자인 요소·문제·AI 판단·수정·재확인 각 2건을 작업 최소 안내로 제시했다. 수량 자체에 별도 점수를 주지 않는다.
- 라이프스타일·인구학·소비심리 특성은 실제 확인 자료에 연결하고, 가상 사용자에게 적용한 해석과 구분하도록 명시했다.
- 수정 중 최소 1건은 잠재 요구에 따른 서비스 환경 개선으로 연결하도록 보완했다.
- 가설·프로젝트 확인 내용·출처 조사·AI 제안을 구분했다. 가상 시나리오와 문서 재확인을 실제 사용자 관찰·효과 측정으로 표현하지 않았다.
- 사전 자료 준비와 기초 용어 설명을 강사용 진행안에 포함했다. 이 준비를 전제로 한 180분 권장안이며 실제 수업 시간 실측은 하지 않았다.
- 문항별 판단 범위를 구분하여 같은 원인의 반복 감점을 방지했다.
- 학생 배포용 4종 Markdown에서 내부 SO·DM 번호, 원점수·환산식·등록총점·강사용 `증빙:` 표기 비노출을 확인했다.

## PDF와 파일 검증

- 로컬 숨김 Chrome으로 학생 체크리스트, 과제안내서, 제출안내, 공개용 채점기준을 PDF로 출력했다. 온라인 페이지 접근이나 자료 업로드는 하지 않았다.
- 배포용 [06_학생용_체크리스트.pdf](최종%20결과%20산출물/06_학생용_체크리스트.pdf)는 작성 전 읽기·출력용 양식이다. 학생이 작성한 최종 제출본은 별도로 내보낸다.
- PDF의 한글 텍스트 추출, 대체문자, 페이지 밖 텍스트, HTML 가로 넘침을 자동 확인했다. 결과는 `.검증/검증_수치.json`에 기록했다.
- 출력한 각 문서의 전체 페이지 렌더 이미지를 시각 확인했다. 글자·표의 잘림과 겹침은 없었으며, 공개용 채점기준의 쪽 끝 제목 분리를 수정했다.
- 학생 체크리스트는 A4 세로, 본문 10.5pt 기준 9쪽이다. 긴 표는 다음 쪽에 머리글을 반복하고 행 중간을 자르지 않도록 출력했다.
- 학생이 긴 답변·이미지를 추가한 상태까지 검증한 것은 아니다. 학생 제출 안내에 최종 작성 후 모든 PDF 페이지를 다시 확인하도록 명시했다.
- Markdown은 UTF-8이며 내부 상대 링크와 참조 파일의 존재를 확인했다. 기준·출력 재생성 스크립트는 `.검증/build_and_validate.py`에 보관했다.
