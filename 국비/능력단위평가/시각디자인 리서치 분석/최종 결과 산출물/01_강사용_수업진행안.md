# 시각디자인 리서치 분석 강사용 수업진행안

## 운영 조건

- 개인평가 240분
- 대상: 자신의 개인 브랜딩 포트폴리오 사이트
- 입력: 이전 리서치 조사 결과 또는 강사 제공 익명 데이터 세트
- 제출: 분석 보고서 PDF 1개, 정리 데이터·분석 근거 ZIP 1개
- 완성 시안·코드·배포는 필수가 아님

## 사전 준비

- 학생별 리서치 조사 결과의 파일 열림, 출처·자료 ID와 개인정보 제거 여부를 확인한다.
- 조사 결과가 없는 학생을 위해 시장·경쟁·트렌드·사용자 항목이 포함된 공통 익명 데이터 세트를 준비한다.
- 분석과 요약의 차이, 상관과 인과, 사실·해석·예측의 구분을 공지한다.
- AI 도구를 사용할 경우 분류·요약 초안 보조로만 사용하고 원자료 대조와 최종 판단은 학생이 수행하게 한다.

## 시간 운영

1. 0~25분: 입력 자료 점검, 분석 목적·질문·범위·기준·근거 ID 설정
2. 25~75분: 시장 현황·전망·수요 교차분석, 디자인 이론과 거시·미시 환경 기반 요구사항
3. 75~115분: 직·간접 경쟁 디자인 비교, 포지셔닝·공백·차별화와 콘셉트 분석전략
4. 115~160분: 디자인 환경·국내외·조형적 트렌드 분석, 자원·아이디어·목표 포지셔닝
5. 160~205분: 사용자 요구 가설, 행동 영향 요소, 사용자 특성·세분화 분석
6. 205~225분: 디자인 전략, 필수·권장·후속 개발수준과 다음 검증 계획
7. 225~240분: PDF·ZIP 정리, 근거 ID·개인정보·누락·열림·파일명 확인

## 운영 유의 사항

- 단순한 출처·발언 요약을 분석으로 인정하지 않고 비교 기준, 패턴·차이·예외와 해석을 확인한다.
- PEST, SWOT, 3C, 어피니티 다이어그램 등 특정 도구를 의무화하지 않는다. 프로젝트 질문에 맞는 도구와 기준을 선택하게 한다.
- 포지셔닝 축과 세분화 기준은 결론을 만들기 위해 임의로 고르지 않고 원자료의 차이를 설명할 수 있어야 한다.
- AI가 만든 가상 통계·가상 사용자 응답을 분석 근거로 사용하지 않는다. AI 활용 위치와 사람이 재검토한 내용을 표시하게 한다.
- 표본·출처의 한계를 명시했다고 무조건 감점하지 않는다. 그 한계를 고려한 결론 수준과 다음 검증 계획을 평가한다.

## 회수 순서

1. PDF·ZIP 파일명과 열림을 확인한다.
2. 입력 조사자료와 PDF의 근거 ID·분석표가 대응하는지 확인한다.
3. 시장 현황·전망·수요의 비교·교차검증과 디자인 이론 적용을 확인한다.
4. 거시·미시 환경에서 디자인 요구사항으로 이어지는 분석을 확인한다.
5. 경쟁 포지셔닝·장단점에서 콘셉트 분석전략으로 이어지는지 확인한다.
6. 국내외·조형적 트렌드에서 자원·아이디어·목표 포지셔닝으로 이어지는지 확인한다.
7. 사용자 요구·행동·특성·세분화에서 디자인 전략과 개발수준으로 이어지는지 확인한다.
8. `Exam.md` VA-01~VA-13에 직접 증빙을 연결해 채점한다.
