# 시각디자인 리서치 분석 포트폴리오 평가

## 시험 문제

개인 브랜딩 포트폴리오 개발을 위한 시장환경·디자인 트렌드·사용자 리서치 분석 결과를 제출해 주세요.

## 과제 목표

이전에 조사한 시장환경, 경쟁 디자인, 국내외 트렌드와 사용자 자료를 비교·해석합니다. 자료의 패턴·차이·예외·한계를 시각화하고, 결과를 나의 포트폴리오 사이트에 필요한 디자인 요구사항, 차별화 방향, 사용자 전략과 개발수준으로 연결합니다.

## 입력 자료

- 자신의 `시각디자인 리서치 조사` 결과와 원자료 또는
- 강사가 제공한 익명 조사 데이터 세트

입력 자료의 출처·자료 유형·범위와 부족한 점을 먼저 기록합니다. 응답이나 통계를 임의로 만들어서는 안 됩니다.

## 작업 순서

1. 입력 자료를 점검하고 분석 목적·질문·범위·기준을 정합니다.
2. 시장 현황·전망·수요 자료를 비교하고 일치·차이·불확실성을 분석합니다.
3. 관련 디자인 이론·원칙과 거시·미시 환경을 이용해 요구사항을 구체화합니다.
4. 직·간접 경쟁 디자인을 같은 기준으로 비교해 포지셔닝과 차별화 기회를 분석합니다.
5. 국내외 디자인 환경과 조형적 트렌드의 반복 원리·차이를 분석해 자원과 아이디어로 전환합니다.
6. 사전 사용자 요구 가설을 조사자료로 확인·수정·기각합니다.
7. 경험·행동 영향 요소와 생활양식·인구학적 경향·소비심리 특성을 분석합니다.
8. 사용자를 의미 있는 기준으로 구분하고 디자인 전략과 필수·권장·후속 개발수준을 정합니다.

## 분석 작성 규칙

- 모든 분석 결과는 원자료 ID와 연결합니다.
- 사실, 참여자 발언, 나의 해석과 앞으로 검증할 예측을 구분합니다.
- 비교 기준은 분석 도중 유리하게 바꾸지 않습니다. 변경했다면 이유를 기록합니다.
- 소수 응답이나 단일 사례를 전체 시장·사용자의 특성으로 단정하지 않습니다.
- 실제 참여자의 이름·연락처·얼굴 등 불필요한 개인정보는 제출하지 않습니다.
- AI를 사용했다면 사용 목적·입력·출력 중 채택·수정·폐기한 내용을 표시합니다. AI 출력은 새로운 시장 통계나 사용자 응답이 아닙니다.

## 제출물

```text
이름_시각디자인리서치분석.pdf
이름_시각디자인리서치분석_근거.zip
```

PDF에는 분석 과정과 결과를 판독 가능한 크기로 정리합니다. ZIP에는 정리된 데이터 표, 분석 메모, 다이어그램 편집 원본과 사용한 조사 원자료를 넣습니다.

## 평가에서 중요한 내용

- 원자료에서 분석 결과와 디자인 결정까지 이어지는 추적성
- 시장 현황·전망·수요의 비교·교차검증과 예측의 조건
- 디자인 이론과 거시·미시 환경을 적용한 구체적 요구사항
- 경쟁 디자인의 포지셔닝·공백·과밀·차별화 분석
- 국내외·조형적 트렌드의 원리와 프로젝트 맞춤형 자원·아이디어
- 사용자 가설의 확인·수정, 행동 영향 요소, 특성·세분화 분석
- 세그먼트별 요구와 현실적인 프로젝트 개발수준
