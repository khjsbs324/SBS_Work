# 시각디자인 리서치 분석 피드백 지침

학생 피드백은 `확인한 원자료·분석 결과 → 적용한 기준 → 해석의 적합성·한계 → 디자인 결정에 미치는 영향 → 구체적 재분석 방법` 순서로 작성한다.

- PDF 페이지·표·다이어그램·근거 ID와 ZIP 원자료를 근거로 사용한다.
- “분석이 부족하다”에서 끝내지 말고 비교할 변수, 다시 분류할 기준, 확인할 예외와 필요한 시각화를 적는다.
- 분석 도구 이름이나 표의 개수보다 원자료에서 결론까지 추적되는지 확인한다.
- 상관관계를 인과관계로 단정하거나 소수 응답을 전체 사용자 특성으로 일반화하면 한계와 다음 검증 방법을 안내한다.
- 경쟁·트렌드 분석에서는 외형 복제가 아니라 반복 원리·맥락·차별화 조건을 자신의 프로젝트에 맞게 변환하도록 지도한다.
- 실제 참여자의 개인정보가 드러난 경우 점수 논의보다 먼저 비식별화와 자료 교체를 안내한다.

예: “PDF 9쪽의 ‘채용 담당자는 강한 모션을 선호하지 않는다’는 결론은 U-02 한 명의 발언만 근거로 연결되어 전체 사용자 특성으로 일반화하기 어렵습니다. 이를 현재 표본의 발견점으로 낮추고, 세그먼트별 과업 시간·기기·콘텐츠 탐색 행동을 추가 비교한 뒤 모션 사용 조건을 정해 보세요.”
