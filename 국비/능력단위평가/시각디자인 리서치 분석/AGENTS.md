# 시각디자인 리서치 분석 평가 지침

## 평가 목적

이 폴더의 능력단위는 `시각디자인 리서치 분석(0802010113_20v4)`이다. 학생이 개인 브랜딩 포트폴리오 사이트를 위해 조사한 시장환경·디자인 트렌드·사용자 자료를 분류·비교·해석하고, 추적 가능한 디자인 요구사항과 개발방향으로 전환하는 능력을 평가한다.

## 원문 범위

- 원본은 `시각디자인 리서치 조사`와 `시각디자인 리서치 분석`이 결합된 PDF다.
- 평가는 분석 코드 `0802010113_20v4`의 수행준거 13개만 사용한다.
- 조사 코드 `0802010112_20v4`의 대응 수행준거는 이 평가에서 제외한다.
- 분석 수행준거를 원문 순서대로 `VA-01`~`VA-13`에 연결한다. VA 번호는 내부 추적 ID이며 공식 NCS 수행준거 번호가 아니다.

## 평가 조건

- 개인평가, 240분, 포트폴리오 방식으로 진행한다.
- 분석 대상은 학생 자신의 개인 브랜딩 포트폴리오 사이트다.
- 입력 자료는 이전 `시각디자인 리서치 조사` 결과 또는 강사가 제공한 익명 조사 데이터 세트다.
- 필수 제출은 `이름_시각디자인리서치분석.pdf` 1개와 `이름_시각디자인리서치분석_근거.zip` 1개다.
- PDF에는 분석 목적·방법, 시장·경쟁·트렌드·사용자 분석, 시각화, 요구사항·디자인 방향·개발수준과 근거 ID가 판독 가능해야 한다.
- ZIP에는 정리된 데이터 표, 분석 메모, 다이어그램 원본과 사용한 조사 원자료를 포함한다.
- 실제 참여자 자료는 비식별화하고, 제공·모의 데이터는 자료 유형을 명시한다. 사용자 응답·통계·근거를 임의로 창작하지 않는다.

## 판단 원칙

- 자료의 양이나 결과물의 화려함보다 `원자료 → 정리·비교 → 패턴·차이 → 해석·한계 → 요구사항·의사결정`의 추적성을 우선한다.
- 시장 전망과 사용자 특성은 확정 사실, 분석 해석과 아직 검증되지 않은 예측을 구분한다.
- 한 가지 분석 틀을 기계적으로 채웠는지보다 프로젝트 질문에 적합한 기준을 선택하고 자료에 일관되게 적용했는지 본다.
- 상관관계를 인과관계로 단정하거나 소수 응답을 전체 사용자 특성으로 일반화하지 않는다.
- 경쟁·트렌드의 외형을 모방하기보다 반복되는 원리, 맥락, 차별화 가능성과 적용 조건을 분석한다.
- 같은 원인의 문제를 여러 문항에서 중복 감점하지 않는다.

## 채점과 검증

- `Exam.md`의 `VA-01`~`VA-13`을 사용하며 총점은 100점이다.
- 모든 점수는 PDF 페이지·절·표·근거 ID 또는 ZIP 원자료 중 하나 이상의 직접 증빙에 연결한다.
- 원문 13문장, 수행준거 TXT 13개, Exam 13문항과 영역별 배점, 총 100점을 대조한다.
- 개인평가 240분, PDF 1개·근거 ZIP 1개 조건이 모든 문서에 일치하는지 확인한다.
