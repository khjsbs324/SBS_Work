# 프로토타입 제작 및 사용성 테스트 평가자료

이 평가는 이전 단계의 스토리보드·스케치·저충실도 시안을 바탕으로 핵심 과업의 작동 프로토타입을 제작하고, 목표 사용자 조건과 가까운 참여자를 대상으로 사용성·선호도 테스트를 실시한 뒤 분석·수정·재확인하는 개인 포트폴리오형 능력단위평가다.

## 파일 구성

| 파일 | 대상 | 용도 |
|---|---|---|
| `01_강사용_수업진행안.md` | 강사 | 평가 준비, 300분 운영, 테스트 통제와 회수 |
| `02_학생용_과제안내서.md` | 학생 | 과제 목표, 작업 순서와 제출 규칙 |
| `03_학생_제출_산출물.md` | 학생 | 보고서·테스트 기록·수정 관리 양식 |
| `04_강사용_정답_및_채점표.md` | 강사 | 직접 증빙 확인법과 10문항 채점표 |
| `05_학생공개용_채점기준.md` | 학생 | 평가 영역과 4수준 성취기준 |

## 기준 자료

- 상위 폴더 통합 NCS 학습모듈의 PDF 45~90쪽
- 상위 폴더의 `프로토타입 제작 및 사용성 테스트 수행준거.txt`
- 상위 폴더의 `Exam.md`
- 상위 폴더의 `AGENTS.md`와 `피드백.md`
