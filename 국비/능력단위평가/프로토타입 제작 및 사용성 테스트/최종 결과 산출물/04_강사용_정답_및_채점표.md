# 강사용 정답 및 채점표

## 1. 정답의 성격

이 과제에는 하나의 고정된 화면 정답이 없다. 다음 연결이 직접 증빙으로 성립해야 한다.

`입력자료 → 제작·비교 → 작동 프로토타입 → 분석 방향·참여자 → 표준화된 테스트 → 원자료·분석 → 적용 화면 → 범위·우선순위 → 수정 전후·재확인 → 관리 지침`

고충실도 화면 자체보다 핵심 과업의 동작, 테스트의 신뢰도와 수정 판단의 추적 가능성을 평가한다.

## 2. 접수 확인

- [ ] 보고서 PDF의 글·표·이미지를 식별할 수 있다.
- [ ] 디자인 원본 또는 공유 링크를 열 수 있다.
- [ ] 지정된 시작점에서 프로토타입 핵심 과업을 수행할 수 있다.
- [ ] 테스트 전 기준 버전과 수정 후 버전이 구분된다.
- [ ] 참여자별 원자료와 결과 집계가 있다.
- [ ] 문제·우선순위·수정 전후·재확인이 같은 ID로 연결된다.

## 3. 직접 증빙 확인 순서

1. 입력자료와 테스트 전 기준 버전을 확인한다.
2. 제작 자료의 출처·가공·적용 화면을 대조한다.
3. 원본에서 요소·아이콘·서체·애니메이션의 대안과 구조를 확인한다.
4. 프로토타입의 핵심 과업과 필요한 상태·피드백을 직접 조작한다.
5. 목표·참여자 프로파일·선정 기준을 확인한다.
6. 과업·성공 조건·대본·관찰표와 참여자별 원자료를 대조한다.
7. 원자료와 성공·시간·오류·경로·선호 집계를 재계산한다.
8. 문제와 적용 화면·UX, 수정 범위·우선순위를 확인한다.
9. 수정 전후, 반영·보류, 재확인, 버전과 관리 지침을 확인한다.

## 5. 문항 간 구분

- PT-01은 제작 자료와 화면의 적합성·추적을 본다.
- PT-02는 요소·애니메이션의 제작 구조와 대안 비교를 본다.
- PT-03은 핵심 과업의 실제 동작과 상태·피드백을 본다.
- PT-04는 분석 목표에 맞는 참여자 선정 근거를 본다.
- PT-05는 방법론·진행 절차·원자료의 일관성을 본다.
- PT-06은 원자료에서 인사이트와 개선 방향을 도출한 분석을 본다.
- PT-07은 결과를 적용할 구체적 화면·UX의 선정 판단을 본다.
- PT-08은 기간·자원·공수를 고려한 반영 범위를 본다.
- PT-09는 중요도 기준과 실제 적용 순서를 본다.
- PT-10은 수정 추적·재확인·향후 관리의 완결성을 본다.

## 6. 경계 사례

- 시각 완성도가 높아도 핵심 과업이 끊기면 작동 프로토타입의 높은 수준으로 보지 않는다.
- 사운드가 불필요한 서비스는 기능적 애니메이션·상태 피드백과 미사용 근거가 있으면 불이익을 주지 않는다.
- 영상 기록이 없어도 표준화된 관찰지와 원자료가 충분하면 테스트 실행으로 인정한다.
- 참여자 2명이 같은 의견을 냈다고 전체 사용자의 요구로 일반화하면 분석 한계로 기록한다.
- 참여자가 도움을 받은 성공은 완전 성공으로 계산하지 않는다. 학생이 정한 부분 성공 기준과 실제 도움 기록을 대조한다.
- 선호가 낮아도 과업 성공에 영향이 없다면 사용성 결함과 분리한다.
- 모든 문제를 수정하지 않아도 기간·중요도·공수에 따른 보류 근거가 타당하면 감점하지 않는다.
- 실제 코드나 배포 결과가 있어도 테스트·수정 증빙이 없는 문항의 점수를 자동으로 높이지 않는다.

## 7. 중복 감점 방지

- 하나의 링크 접근 장애로 여러 문항을 확인하지 못하면 접근 문제와 영향 범위를 별도로 기록하고 같은 사유를 반복 기재하지 않는다.
- 단일 경로 오류가 테스트 실패와 수정 필요를 동시에 만든 경우 동작 문항을 중심으로 감점하고 분석·수정 문항은 해당 오류를 올바르게 다뤘는지 평가한다.
- 참여자 부적합은 선정 문항에서 처리하며 같은 원자료라는 이유만으로 이후 분석 문항을 자동 감점하지 않는다.
- 보고서 미관은 평가하지 않는다. 가독성 때문에 직접 증빙을 확인할 수 없는 범위만 기록한다.

## 8. 최종 확인

- [ ] 10개 문항 모두 PDF·원본·프로토타입·원자료의 직접 증빙 위치가 있다.
- [ ] 프로토타입 핵심 경로를 직접 실행했다.
- [ ] 원자료와 집계값을 대조했다.
- [ ] 각 문항에 하나의 점수와 판단 메모가 있다.
- [ ] 같은 원인을 반복 감점하지 않았다.
- [ ] 학생 공개 피드백에 내부 ID와 점수 계산을 노출하지 않았다.
