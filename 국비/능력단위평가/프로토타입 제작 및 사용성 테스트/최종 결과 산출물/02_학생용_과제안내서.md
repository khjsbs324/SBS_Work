# 학생용 과제안내서

## 과제 목표

이전 단계의 스토리보드와 시안을 핵심 과업이 작동하는 프로토타입으로 제작합니다. 목표 사용자 조건과 가까운 참여자에게 같은 과업을 수행하게 하여 사용성·선호도 자료를 수집합니다. 결과를 분석해 개선할 화면과 UX를 고르고, 평가 시간 안에 반영할 범위와 순서를 정해 수정한 뒤 전후와 재확인 결과를 정리합니다.

## 평가 조건

- 평가 방식: 개인 포트폴리오
- 평가 시간: 300분
- 입력자료: 이전 단계 결과물 또는 강사 제공 자료
- 테스트 참여자: 목표 사용자 조건과 가까운 교실 내 참여자 2명 이상

참여자가 적으므로 결과를 모든 사용자의 의견으로 일반화하지 않습니다. 관찰된 과업과 참여자 범위에서만 결론을 냅니다.

## 필수 제출물

1. `이름_프로토타입_사용성테스트.pdf`
2. 편집 가능한 디자인 원본 또는 평가자가 열 수 있는 공유 링크
3. 작동 프로토타입 링크 또는 파일

보고서에는 입력자료와 제작 내역, 요소 비교, 프로토타입 경로·상태, 테스트 계획·참여자별 원자료·분석, 개선 대상, 수정 범위·우선순위, 수정 전후와 재확인, 향후 관리 지침을 포함합니다.

## 작업 순서

1. 이전 결과물의 핵심 과업과 기준 버전을 정합니다.
2. 화면별로 필요한 이미지·영상·텍스트·사운드 등의 자료를 준비하고 출처·이용 조건을 기록합니다.
3. 화면 요소·아이콘·서체·애니메이션 대안을 비교해 선택합니다.
4. 핵심 과업의 시작·진행·완료와 필요한 상태를 프로토타입으로 연결합니다.
5. 테스트 전에 링크, 시작점, 모든 연결과 문구를 직접 점검해 기준 버전을 고정합니다.
6. 사용성과 선호도에서 확인할 질문을 구분하고 참여자 선정 기준을 만듭니다.
7. 과업, 성공 조건, 진행 대본, 관찰표와 사후 질문을 준비합니다.
8. 참여자마다 같은 조건으로 테스트하고 행동·시간·오류·도움·발언을 기록합니다.
9. 성공 결과와 관찰 패턴·예외를 분석해 인사이트와 개선 방향을 정합니다.
10. 결과를 적용할 화면과 UX를 고르고 사용성 문제와 선호 의견을 구분합니다.
11. 영향도·빈도·시급성·공수와 남은 시간을 기준으로 수정 범위와 순서를 정합니다.
12. 수정 후 핵심 과업을 다시 확인하고 전후·버전·향후 지침을 정리합니다.

## 프로토타입 최소 범위

- 핵심 과업 1개 이상의 시작·진행·완료
- 주요 내비게이션과 입력·선택·확인 동작
- 정상·오류·빈·로딩·성공 중 과업에 필요한 상태
- 조작 결과를 알려 주는 시각적 피드백
- 필요한 경우 기능적 애니메이션 또는 사운드
- 테스트 시작점을 지정한 공유 링크 또는 파일

## 테스트 기록 최소 범위

- 분석 목표와 목표 사용자 조건
- 참여자 프로파일과 선정·제외 이유
- 과업 문장과 성공·부분 성공·실패 조건
- 참여자별 행동, 시간, 오류, 이동 경로, 도움과 발언
- 사후 만족도·선호 질문
- 집계, 패턴·예외, 문제·인사이트·개선 방향

## 개인정보·진행 주의사항

- 참여자 실명·연락처·계정정보는 수집하지 말고 `P01`, `P02` 같은 코드를 사용합니다.
- 화면 녹화·음성 녹음은 필수가 아닙니다. 필요하다면 먼저 동의를 받고 평가에 필요한 범위만 수집합니다.
- 참여자에게 조작 위치나 정답 경로를 알려 주지 않습니다.
- 도움을 주었다면 시점과 내용을 반드시 기록합니다.
- 참여자 능력을 평가하는 말이나 결과를 공개하지 않습니다.
- 모든 1차 테스트가 끝날 때까지 기준 프로토타입을 수정하지 않습니다.

## 평가 제외 범위

실제 서비스 코드, 백엔드, 운영 데이터 연동, 앱스토어·서버 배포는 필수가 아닙니다. 별도로 제작했더라도 테스트와 수정 근거가 없는 문항을 대신할 수 없습니다.

## 제출 전 확인

- [ ] 프로토타입에서 핵심 과업을 처음부터 끝까지 수행할 수 있습니다.
- [ ] 필요한 상태와 피드백 모션 또는 사운드를 확인했습니다.
- [ ] 참여자 선정 이유와 테스트 방법을 설명할 수 있습니다.
- [ ] 참여자별 원자료와 결과 집계가 일치합니다.
- [ ] 관찰 사실·문제·인사이트·해결안을 구분했습니다.
- [ ] 수정 범위와 순서를 기간·중요도·공수로 설명했습니다.
- [ ] 수정 전후와 재확인 결과를 같은 문제 번호로 연결했습니다.
- [ ] 보고서·원본·프로토타입 링크와 권한을 확인했습니다.
