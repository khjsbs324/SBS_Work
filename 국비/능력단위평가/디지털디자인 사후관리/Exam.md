# 디지털디자인 사후관리 평가 기준

## 평가 개요

- 능력단위: 디지털디자인 사후관리
- 능력단위 코드: 0802010408_13v1
- 평가 과제: 완료된 디지털디자인 프로젝트 사후관리
- 평가 형식: 포트폴리오 및 작업 결과물 평가
- 수행준거 수: 16개
- 총점: 100점
- 필수 자료: 학생 제출 서식 10종, 수정 전후 결과물, 편집 가능한 최종 소스, 산출물 인덱스, 백업 및 버전 기록

## 공통 채점 원칙

1. 수행준거 원문, 순서와 개수를 유지한다.
2. 결과물의 미적 취향보다 오류 발견, 판단, 조율, 수정, 재검증과 관리 과정을 평가한다.
3. 요청을 반영하지 않았더라도 계약 범위, 일정, 비용, 사용자 영향에 따른 근거가 타당하면 인정한다.
4. 모든 점수는 학생 제출물의 직접 증빙과 연결한다.
5. 같은 원인을 여러 문항에서 반복 감점하지 않는다.
6. 웹 프로젝트가 아닌 학생에게 코드 또는 브라우저 증빙을 요구하지 않는다.

- 증빙: 01_모니터링_체크리스트.md, 점검 화면 또는 파일

- 4~5점: 주요 영역을 점검했으나 일부 항목의 위치, 주기 또는 판정 근거가 부족하다.
- 2~3점: 단순 감상이나 육안 확인에 머물며 확인 항목과 결과의 연결이 약하다.
- 0~1점: 모니터링 기록이 없거나 프로젝트를 체계적으로 점검하지 않았다.

- 9~10점: 오류별 현상·위치·재현 조건·원인을 구분하고 원본 의도를 보존하는 수정 또는 최적화를 완료했다.
- 6~8점: 주요 오류를 수정했으나 일부 원인 분석 또는 최적화 근거가 부족하다.
- 3~5점: 결과는 일부 달라졌지만 원인과 조치의 연결이 약하거나 임시 보정에 머문다.
- 0~2점: 원인 분석 없이 임의 수정했거나 핵심 오류가 남아 있다.

- 4~5점: 주요 수정 결과는 확인했으나 연관 영역 또는 실패 항목 기록이 부족하다.

- 4~5점: 핵심 요청은 파악했으나 배경, 우선순위 또는 확인 내용이 일부 부족하다.
- 2~3점: 요청 문장을 옮겼으나 의도와 완료 조건을 구체화하지 못했다.

- 4~5점: 범위와 일정은 구분했으나 비용, 영향 또는 승인 기록이 일부 부족하다.
