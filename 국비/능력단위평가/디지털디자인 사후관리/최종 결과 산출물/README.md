# 디지털디자인 사후관리 평가자료

이 평가는 학생이 완료한 디지털디자인 프로젝트를 대상으로 오류 모니터링, 수정·최적화, 클라이언트 요청 및 피드백 반영, 재검증, 내부 리뷰, 소스 데이터 백업과 버전 관리를 수행하는 포트폴리오형 능력단위평가이다.

## 파일 구성

| 파일 | 대상 | 용도 |
|---|---|---|
| 01_강사용_수업진행안.md | 강사 | 평가 준비, 진행 순서, 관찰과 회수 방법 |
| 02_학생용_과제안내서.md | 학생 | 과제 목표, 작업 순서, 제출 규칙 |
| 03_학생_제출_산출물.md | 학생 | 제출 폴더 구성, 서식 10종과 증빙 안내 |
| 04_강사용_정답_및_채점표.md | 강사 | 직접 증빙 확인법, 16문항 채점표 |

## 기준 자료

- 상위 폴더의 디지털디자인 사후관리.pdf
- 상위 폴더의 디지털디자인 사후관리 수행준거.txt
- 상위 폴더의 Exam.md
- 상위 폴더의 학생_제출_산출물 서식 10종

## 배포 구분

학생에게 제공:

1. 02_학생용_과제안내서.md
2. 03_학생_제출_산출물.md
3. 학생_제출_산출물 폴더의 서식 10종

강사만 사용:

1. 01_강사용_수업진행안.md
2. 04_강사용_정답_및_채점표.md
3. 상위 폴더의 Exam.md와 피드백.md

이 평가에는 모든 학생이 복제해야 하는 하나의 시각적 정답이 없다. 학생이 선택한 프로젝트에 맞는 사후관리 절차와 증빙의 정확성을 평가한다.
