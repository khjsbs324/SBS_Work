# 강사용 기준 및 채점표

평가 종료 전 학생에게 공개하지 않습니다.

## 1. 강사용 판단 기준

이 평가에는 학생이 그대로 복제해야 하는 하나의 시각적 정답이 없다. 학생별 프로젝트가 다르므로 다음 연결 관계가 모범 수행의 기준이다.

    모니터링 결과
    → 오류 수정 요구
    → 원인 분석과 수정 계획
    → 클라이언트 요구와 범위 조율
    → 수정·피드백 반영
    → 수정 전후 재검증
    → 프로젝트 사후리뷰
    → 산출물 인덱스
    → 버전별 백업과 실제 복구

각 단계의 ID, 파일, 화면과 판단이 다음 단계까지 추적되어야 한다.

## 2. 모범 수행 확인표

- [ ] 프로젝트 특성에 맞는 모니터링 영역과 주기를 정했다.
- [ ] 오류의 실제 현상, 재현 조건과 기대 결과를 구분했다.
- [ ] 표면 증상과 직접·근본 원인을 구분했다.
- [ ] 수정으로 다른 산출물에 미치는 영향을 검토했다.
- [ ] 클라이언트 요청의 배경, 목적과 완료 조건을 확인했다.
- [ ] 계약 범위, 일정, 비용과 영향에 따라 요청을 조율했다.
- [ ] 사용자와 클라이언트 피드백을 구분하여 분석했다.
- [ ] 반영·보류·제외 결정에 근거가 있다.
- [ ] 수정 항목과 연관 영역을 재검증했다.
- [ ] 프로젝트 장단점에서 실행 가능한 보완책을 도출했다.
- [ ] 원본·작업본·최종본과 편집 가능한 소스를 구분했다.
- [ ] 산출물 인덱스와 실제 파일이 일치한다.
- [ ] 버전 규칙과 변경 이력이 일관된다.
- [ ] 백업 파일을 실제로 열고 지정 버전을 복구했다.

## 4. 능력단위요소별 빠른 검수

### 오류 수정하기 — 24점

01~04번 서식, 오류별 수정 전후 결과와 재검증을 확인한다. 디자인이 달라졌다는 사실만으로 통과시키지 않고 오류 원인과 조치가 연결되는지 본다.

### 클라이언트 요청사항 반영하기 — 36점

05~07번 서식과 수정 결과를 확인한다. 요청을 모두 수용했는지보다 요구 파악과 범위 결정이 합리적인지 평가한다.

### 프로젝트 내부 공유 및 리뷰하기 — 20점

08번 서식과 공유 자료를 확인한다. 개인 감상이 아니라 프로젝트 단계별 근거와 차후 적용할 보완책이 있어야 한다.

### 데이터베이스 관리하기 — 20점

09~10번 서식, 실제 폴더, 편집 소스, 백업과 복구 결과를 대조한다. 백엔드 데이터베이스의 존재 여부는 평가하지 않는다.

## 5. 직접 증빙 예시

| 평가 내용 | 인정 가능한 직접 증빙 |
|---|---|
| 오류와 수정 | 같은 조건의 전후 화면, 아트보드, 파일 속성, 타임코드, 작업 이력 |
| 요구사항 | 인터뷰 기록, 이메일·메신저 요약, 회의록, 승인 기록 |
| 피드백 | 설문·인터뷰·관찰 기록, 출처가 있는 클라이언트 의견 |
| 재검증 | 테스트 조건, 통과·실패 결과, 비교 이미지와 추가조치 |
| 내부 공유 | 회고 문서, 공유 링크·위치, 발표 자료, 받은 의견 |
| 산출물 관리 | 실제 폴더, 파일명, 인덱스, 연결 파일과 라이선스 |
| 백업·복구 | 백업 일시·위치, 파일 크기, 복구 과정과 열린 결과물 |

## 6. 감점 및 보류 원칙

- 확인하지 않은 항목을 정상으로 추정하지 않는다.
- 미적 취향 차이만으로 감점하지 않는다.
- 반영하지 않은 요청의 근거가 타당하면 감점하지 않는다.
- 동일한 결함을 여러 문항에서 반복 감점하지 않는다.
- 최종 출력만 있고 편집 소스가 없으면 DM-13·15에서 반영한다.
- 백업 파일은 있으나 열거나 복구하지 못하면 DM-14 만점으로 평가하지 않는다.
- 학생 프로젝트의 특성상 적용할 수 없는 증빙은 동등한 다른 증빙으로 대체할 수 있다.
- 자료 누락과 평가 환경 문제를 구분하고 확인 불가 사유를 기록한다.

## 7. 피드백 작성

피드백은 다음 순서로 작성한다.

1. 학생 제출물에서 확인한 관찰 사실
2. 수행준거와 기대한 상태
3. 적합한 점 또는 부족한 점
4. 품질·일정·사용자·클라이언트·재사용성에 미치는 영향
5. 다음 사후관리에서 적용할 개선 방법

학생 공개용 피드백에는 내부 코드 DM-01~DM-16, 강사용 모범답안 전체 또는 내부 점수 산식을 넣지 않는다.

## 8. 최종 검증

- [ ] 16문항 점수를 모두 입력했다.
- [ ] 배점 합계가 100점이다.
- [ ] 모든 점수에 직접 증빙 또는 미확인 사유가 있다.
- [ ] 학생용과 강사용 자료가 분리되어 있다.
- [ ] 동일 결함을 설명 없이 중복 감점하지 않았다.
- [ ] 서식 10종과 실제 결과물이 일치한다.
- [ ] 산출물 인덱스, 버전, 백업과 복구 결과를 확인했다.
