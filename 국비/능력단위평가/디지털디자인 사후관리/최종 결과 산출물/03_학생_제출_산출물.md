## 4. 결과물 제출 확인

- [ ] 수정 전 원본을 보존했다.
- [ ] 수정 전과 수정 후 결과물을 구분했다.
- [ ] 편집 가능한 최종 소스가 있다.
- [ ] 링크 이미지·영상·폰트가 누락되지 않았다.
- [ ] 최종 출력 파일이 정상적으로 열린다.
- [ ] 외부 자료의 출처와 라이선스를 기록했다.

## 5. 증빙 제출 확인

- [ ] 모니터링 위치와 실제 상태를 확인할 수 있다.
- [ ] 오류별 수정 전후를 같은 조건으로 비교할 수 있다.
- [ ] 클라이언트 요청과 작업 범위 결정 기록이 있다.
- [ ] 사용자·클라이언트 피드백의 출처가 있다.
- [ ] 재검증 결과와 실패·추가조치가 기록되어 있다.
- [ ] 산출물 인덱스와 실제 파일이 일치한다.
- [ ] 지정 버전을 복구한 결과가 있다.
