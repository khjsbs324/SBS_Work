## 오류별 상세 기록

### ERR-01

- **발견 과정**: P-01이 청포도·피스타치오를 선택하려는 경로와 HTML 요소 타입을 대조했다.
- **영향 대상**: P-01, P-03, P-04 / `웹디자인_수정본.html`
- **반복 발생**: 모든 18개 옵션에서 반복
- **임시 대응 필요 여부**: 필요. 수정 전까지 해당 영역이 실제 선택 기능이 아닌 구성 예시임을 명확히 안내
- **수정 완료 조건**: 클릭·키보드로 선택되며 상품군별 1개만 활성

### ERR-02

- **발견 과정**: 선택 시도 후 요약 DOM이 갱신되는지 코드와 화면을 확인했다.
- **영향 대상**: P-01, P-02 / 구성 요약
- **반복 발생**: 모든 조합에서 반복
- **임시 대응 필요 여부**: 필요. 고정 요약이 실제 사용자 선택 결과로 오인되지 않도록 예시 상태임을 안내
- **수정 완료 조건**: 세 요소 명칭과 완성 상태가 실시간 갱신

### ERR-03

- **발견 과정**: P-04가 체크 모양을 실제 선택으로 오해하는 경로를 확인했다.
- **영향 대상**: P-03, P-04 / 모바일·태블릿
- **반복 발생**: 첫 방문과 모든 선택 변경 시
- **임시 대응 필요 여부**: 필요. 선택 상태와 예시 상태의 의미를 별도 안내
- **수정 완료 조건**: 단계 표시·`aria-pressed`·완성 안내 동기화

### ERR-04

- **발견 과정**: P-05가 7AM 팩에서 아몬드만 변경하려는 경로를 추적했다.
- **영향 대상**: P-02, P-05 / 추천 조합 4개
- **반복 발생**: 모든 추천 조합에서 반복
- **임시 대응 필요 여부**: 낮음. 수정 전에는 추천 조합을 정보 제공용 카드로만 유지
- **수정 완료 조건**: 예정된 구성값 적용 후 개별 옵션 변경 가능

### ERR-05

- **발견 과정**: P-03의 최종 행동에서 구매나 구매 준비 CTA를 찾았다.
- **영향 대상**: P-01~P-05 / 구성 요약
- **반복 발생**: 모든 조합 완성 시
- **임시 대응 필요 여부**: 필요. 실제 구매가 불가능하며 판매 정책 확인 전임을 명확히 안내
- **수정 완료 조건**: CTA가 작동하고 선택한 구성과 현재 판매 제약을 안내
