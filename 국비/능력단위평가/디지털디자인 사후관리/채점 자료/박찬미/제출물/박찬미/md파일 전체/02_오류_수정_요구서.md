## 오류별 상세 기록

### ERR-01

- 발견 과정: 메인페이지 최초 화면을 확인하는 과정에서 Hero 이미지가 차지하는 시각적 비중과 텍스트 대비가 약해 첫 화면의 임팩트가 부족한 점을 확인함.
- 영향을 받는 사용자·화면·파일: 메인페이지 방문자, Hero 화면, `웹디자인 수정본.html`.
- 반복 발생 여부: 페이지를 열 때마다 동일하게 확인됨.
- 임시 대응 필요 여부: 있음. 최종 이미지 확정 전까지 확대된 Hero 이미지 영역을 자리 표시자로 유지함.
- 수정 완료 조건: 첫 화면에서 이미지 영역과 핵심 문장이 강한 위계로 보이고, 현재 단계에서는 Hero의 넓은 이미지 비율과 문구·버튼 배치를 유지한 채 중앙에 `이미지 칸`이 표시됨.

### ERR-02

- 발견 과정: #01과 #02 대표 상품의 탐색 흐름과 버튼 연결 상태를 비교하는 과정에서 정보가 별도 구간으로 분리된 점을 확인함.
- 영향을 받는 사용자·화면·파일: 대표 제품을 비교하는 사용자, HALO SIGNATURE GEAR 구간, `웹디자인 수정본.html`.
- 반복 발생 여부: 대표 기어 구간 진입 시 항상 발생.
- 임시 대응 필요 여부: 없음. 단, 수정 전에는 제품별 상세·비교·알림 대상을 사용자가 다시 확인해야 함.
- 수정 완료 조건: 기본 선택은 #01이며, #01·#02 텍스트 버튼을 선택할 때 대표 이미지 자리 문구, 보조 이미지 자리 4개, 제품명, 설명, 제형·용량·자외선 차단 지수·사용 단계, 상세 보기, 비교함과 출시 알림 대상이 동일 제품 기준으로 함께 변경됨. 모바일에서는 선택 버튼, 대표 이미지, 보조 이미지 2×2, 설명과 행동 순서로 표시되고 가로 넘침이 없어야 함.

### ERR-03

- 발견 과정: 4단계 제작 과정의 STEP 01과 STEP 02 경계 및 상단 라벨 배치를 확인하는 과정에서 카드 사이 여백과 외곽선, 패딩 제거 후 라벨 밀착 문제를 확인함.
- 영향을 받는 사용자·화면·파일: 제작 과정을 탐색하는 사용자, BEYOND SUNCARE 구간, `웹디자인 수정본.html`.
- 반복 발생 여부: 데스크톱과 모바일의 제작 과정 카드 표시 시 반복.
- 임시 대응 필요 여부: 없음.
- 수정 완료 조건: 원본 가로 카드 레이아웃, 카드 크기, 단계 순서, 문장, 수치 요약, 이전·다음 조작과 반응형 동작은 유지함. 카드 자체 패딩과 카드 사이 간격은 `0`이고 검정 외곽선은 표시되지 않으며, STEP 번호와 단계 분류명에는 별도의 내부 여백이 적용되어 인접 카드와 붙어 보이지 않아야 함.

### ERR-04

- 발견 과정: 제작 과정에서 Pre/In/Post 루틴으로 이동하는 흐름을 검토하면서 #01의 사용 전·후 차이를 설명하는 중간 화면이 없는 점을 확인함.
- 영향을 받는 사용자·화면·파일: #01 사용 구조를 이해하려는 사용자, 제작 과정 다음 비교 구간, `웹디자인 수정본.html`.
- 반복 발생 여부: 해당 콘텐츠가 없어 항상 발생.
- 임시 대응 필요 여부: 없음.
- 수정 완료 조건: 제작 과정 다음, 루틴 이전에 `WITHOUT HALO / WITH HALO` 섹션이 표시됨. 실제 이미지는 사용하지 않고 동일 인물의 미사용·사용 장면 자리 표시자를 사용함. 비교 손잡이는 50%에서 시작하며 포인터, 터치와 방향키로 프레임 안에서 이동하고 현재 비율을 보조기기에 전달함. 피부 개선이나 임상 효과로 오인될 문구는 없어야 하며 루틴 이동 버튼은 `#routine`으로 연결됨.
