| ERR-04 | #01 사용 전·후의 운동 흐름 차이를 직접 비교할 수 없음 | 제작 과정과 루틴 사이에 대표 사용 경험을 설명하는 비교 화면이 없음 | 제품 기능과 연구 과정 중심으로 정보 구조를 설계하여 실제 사용 방식의 변화가 별도 사용자 시나리오로 연결되지 않음 | 사용 전·후 비교, `#before-after` | #01 사용 구조 이해, 제작 과정에서 루틴으로 이어지는 콘텐츠 흐름 | `#haloComparisonRange`, `updateHaloComparison()` |

## 위험 및 영향 검토

| 검토 항목 | 예상 영향 | 예방 방법 | 확인 방법 |
|---|---|---|---|
| 다른 화면·파일에 미치는 영향 | 메인페이지 선택 상태와 공용 비교함·모달 함수 연결이 달라질 수 있으나 카테고리 페이지와 원본 파일에는 직접 변경 없음 | 수정 대상을 `웹디자인 수정본.html`로 한정하고 원본 `메인페이지_최종.html`은 보존. 기존 상품 ID 1·2와 공용 함수 사용 | 원본 파일 변경 여부 확인, 상세 모달·비교함·출시 알림 대상 교차 확인 |
| 일정에 미치는 영향 | 반응형 재배치와 상호작용 검수 시간이 추가됨 | 와이어프레임 단계에서는 실제 이미지 제작을 제외하고 자리 표시자로 범위를 제한 | 데스크톱, 390px와 360px 기준으로 필수 화면과 조작을 우선 검수 |
| 품질에 미치는 영향 | 숨겨진 기존 대표 섹션과 신규 상태 관리가 중복되어 유지보수 복잡도가 증가할 수 있음 | 신규 대표 기어 데이터와 전환 함수를 단일 진입점으로 사용하고 표시 영역의 ID를 고유하게 유지 | 스크립트 구문 검사, 중복 ID 확인, 제품 전환 후 텍스트·버튼 대상 확인 |
| 원본·라이선스에 미치는 영향 | 외부 레퍼런스의 이미지·브랜드 요소를 직접 복제할 위험 | 레퍼런스에서는 정보 구조와 화면 위계만 참고하고 숲소리 상품 이미지·문구·색상은 사용하지 않음. 현재 실제 제품 이미지 생성·삽입 제외 | 로컬 자산 참조와 화면 문구 확인, 외부 브랜드명·상품명 미노출 확인 |
