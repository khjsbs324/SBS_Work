## 오류별 상세 기록

### ERR-01

- 발견 과정: 클라이언트 요구사항(`REQ-01`) 검토 및 첫 방문자 시선 추적(Eye-tracking 시뮬레이션) 과정에서, 100% 무료 반품 정책이 11번째 섹션(`SEC-010-11`)에만 배치되어 상단 체류 중 이탈하는 고객의 혜택 인지율이 15% 미만으로 측정됨.
- 영향을 받는 사용자·화면·파일: 신규 방문 고객 및 3-Step 세트 구매 고려 고객 / 메인 헤더, 히어로 스테이지, 루틴 세트 카드 / `메인페이지_웹디자인_초안.html`, `가상클라이언트_웹디자인.md`
- 반복 발생 여부: 상시 발생 (모든 해상도 및 접속 환경에서 상단 띠배너 부재)
- 임시 대응 필요 여부: 불필요 (마크업 및 CSS 추가로 영구 수정 가능)
- 수정 완료 조건: 상단 헤더 바로 아래에 `[첫 구매 미니 샘플 0원 증정 · 100% 무료 반품 안심 보장]` 띠배너가 고정(Sticky) 렌더링되고, 3-Step 시그니처 세트 카드 옆에 안심 앰블럼이 정상 노출될 것.

### ERR-02

- 발견 과정: 모바일 반응형 QA 테스트(`viewport width: 375px ~ 430px`) 과정에서 `SEC-010-10` 카테고리 탭 기본값이 `ALL (15)`로 렌더링되어, 2열 8개 행으로 스크롤 높이가 1,850px에 달해 타깃 사용자가 다음 섹션으로 이동하기 전 스크롤 피로도로 이탈하는 현상 확인(`REQ-02`).
- 영향을 받는 사용자·화면·파일: 모바일 디바이스 접속 고객 (전체 트래픽의 약 70%) / `SEC-010-10` 카테고리 제품 그리드 / `메인페이지_웹디자인_초안.html`
- 반복 발생 여부: 모바일 환경 접속 시 100% 발생
- 임시 대응 필요 여부: 불필요
- 수정 완료 조건: 모바일 뷰포트에서 기본 탭을 `SET (3)`으로 지정하거나, `ALL` 선택 시 상위 6개 상품만 노출 후 [15개 전 제품 펼쳐보기 ↓] 토글 버튼을 통해 전체 확장이 정상 작동할 것.

### ERR-03

- 발견 과정: UI 컴포넌트 사용성 평가 과정에서 `.card-btn-row` 클래스가 `grid-template-columns: 1fr 1fr`로 지정되어 있어, Secondary Action인 [Quick Spec]과 Primary CTA인 [담기] 버튼의 시각적 가중치가 50:50으로 동일하여 즉각적인 장바구니 담기 클릭률이 저하되는 구조 확인(`REQ-03`).
- 영향을 받는 사용자·화면·파일: 전체 쇼핑몰 방문 고객 / 15종 제품 카드 컴포넌트 (`modern-product-card`) / `메인페이지_웹디자인_초안.html`
- 반복 발생 여부: 상시 발생
- 임시 대응 필요 여부: 불필요
- 수정 완료 조건: [장바구니 담기] 버튼을 가로 100% 풀 와이드 또는 브랜드 포인트 컬러(`--point-terracotta`)로 강조하고, [Quick Spec]은 텍스트/아이콘 링크로 슬림하게 분리하여 시각적 위계가 명확해질 것.

### ERR-04

- 발견 과정: 장바구니 및 결제 플로우 테스트 중, 상품 카드에서 [담기] 클릭 시 하단 `toast-popup`만 2.5초 노출 후 소멸되고 장바구니 드로어가 반응하지 않아, 사용자가 상단 헤더의 작은 장바구니 아이콘을 다시 찾아 클릭해야만 결제창으로 이동할 수 있는 동선 마찰 확인(`REQ-04`).
- 영향을 받는 사용자·화면·파일: 상품 구매 의향 고객 / `addToCart()` 스크립트, 토스트 알림, Quick Cart 드로어 (`SCR-061`) / `메인페이지_웹디자인_초안.html`
- 반복 발생 여부: [담기] 버튼 클릭 시마다 상시 발생
- 임시 대응 필요 여부: 불필요
- 수정 완료 조건: [담기] 클릭 시 토스트 내에 [장바구니 확인 & 빠른 결제 ➔] 버튼이 함께 렌더링되거나, 첫 상품 담기 시 Quick Cart 드로어가 우측에서 자동으로 슬라이드인(Slide-in)되어 즉시 결제 유도가 이루어질 것.
