## 🔍 2. 결함별 상세 기술 명세 (Defect Specifications)

### 📌 [ERR-01] 장바구니 담기 시 무조건 강제 드로어 오픈으로 인한 탐색 흐름 차단
* **오류 ID**: `ERR-01`
* **발견 위치**: `웹디자인 수정본.html` 내 `<script>` 영역 `addAndOpenCart(id, name, price)` 함수 (Line 1320~)
* **발생 조건**: 사용자가 카탈로그나 시그니처 영역에서 상품 '담기' 버튼을 클릭할 때
* **실제 현상**: 상품이 카트에 담기자마자 `openDrawer('d2c')`가 강제로 실행되어 화면 전체를 덮는 460px 서랍창이 열림. 고객이 다른 상품을 보려면 매번 닫기(✕)를 눌러야 함.
* **기대 결과**: '담기' 클릭 시 드로어가 열리지 않고, 화면 우측 상단에 1.5초간 노출 후 사라지는 토스트 팝업(`div.toast-alert`)이 뜨며 상단 카트 뱃지 숫자만 `+1` 카운트업 처리됨.
* **중요도**: 🚨 **상 (Critical)**
* **수정 완료 조건**: 
  - [ ] `addAndOpenCart()` 내 `openDrawer()` 호출 제거 및 토스트 알림 함수 연동
  - [ ] 상품 담기 후에도 스크롤 위치와 화면이 유지되어 연속 탐색이 가능할 것

---

### 📌 [ERR-02] 상품 카드 소셜 프루프(평점/후기) 부재 및 선물포장/수량 옵션 선택 불가 결함
* **오류 ID**: `ERR-02`
* **발견 위치**: `renderCatalogGrid()` 카탈로그 카드 템플릿 생성부 (Line 1196~) 및 장바구니 아이템 렌더부
* **발생 조건**: 고객이 상품의 신뢰도를 검증하거나 선물용 포장 옵션을 선택하려 할 때
* **실제 현상**: 카드에 평점(★4.9) 및 리뷰 수가 전무하여 구매 망설임 발생. 선물용 쇼핑백 추가(+1,000원)나 10포/30포 세트 옵션 선택 필드가 없어 단일 규격으로만 주문됨.
* **기대 결과**: 카드 상단에 평점 뱃지 노출, 클릭 시 키워드 리뷰 모달 탭 호출, 장바구니 및 상세 영역에 '선물포장 추가' 체크박스 및 세트 선택 드롭다운 렌더링.
* **중요도**: 🚨 **상 (Critical)**
* **수정 완료 조건**:
  - [ ] 32종 카드마다 평점 뱃지(★4.9) 및 클릭 시 리뷰 모달 창 연결
  - [ ] 선물포장 옵션 선택 시 장바구니 합산 금액에 1,000원이 정상 반영될 것

---

### 📌 [ERR-03] GNB 실시간 키워드 검색창 부재 및 위시리스트(찜) 기능 누락 결함
* **오류 ID**: `ERR-03`
* **발견 위치**: `header.header-inner` 네비게이션 영역 (Line 179~) 및 `product-card` (Line 1196~)
* **발생 조건**: 32종 상품 중 특정 키워드(라벤더, GABA)를 찾거나 상품을 찜해두려 할 때
* **실제 현상**: GNB에 검색창이 없어 원하는 상품을 1초 만에 찾을 수 없고, 카드에 찜(♡) 버튼이 없으며 헤더에 찜 목록 모아보기 기능이 없음.
* **기대 결과**: GNB에 실시간 키워드 검색바(`oninput="searchCatalog(this.value)"`) 탑재, 카드 우측 상단 찜 하트 토글(♡ ➔ ♥), 헤더에 `♡ 찜 (0)` 뱃지 연동.
* **중요도**: 🚨 **상 (Critical)**
* **수정 완료 조건**:
  - [ ] 검색창 타이핑 즉시 32종 카드가 0.1초 내 필터링 렌더링될 것
  - [ ] 찜 버튼 클릭 시 하트 상태가 변경되고 찜한 상품만 모아보는 필터가 작동할 것

---

### 📌 [ERR-04] 1,400줄 긴 원페이지 수직 스크롤 피로 및 Top 플로팅 버튼 부재 결함
* **오류 ID**: `ERR-04`
* **발견 위치**: `body` 전역 및 CSS 스크롤 제어부 (Line 60~ 및 HTML 구조)
* **발생 조건**: 고객이 300px 이상 스크롤 다운하여 하단 카탈로그/쇼룸을 탐색할 때
* **실제 현상**: 9개 섹션 전체가 1,400줄에 걸쳐 수직 나열되어 있어, 최하단에서 다시 상단 메뉴나 장바구니로 가려면 수천 픽셀을 손으로 직접 올려야 함.
* **기대 결과**: 스크롤 다운 시 화면 우측 하단에 `Top(위로 가기)` 플로팅 버튼이 부드럽게 나타나고, 클릭 시 최상단으로 부드러운 스무스 스크롤 복귀.
* **중요도**: ⚠️ **중 (Major)**
* **수정 완료 조건**:
  - [ ] 스크롤 300px 이상 시 플로팅 버튼 노출 및 클릭 시 `window.scrollTo({top:0, behavior:'smooth'})` 정상 작동할 것

---

### 📌 [ERR-05] 5-in-1 감각 스튜디오 탭 화면 전환 미구현 및 시스템 alert() 남발 결함
* **오류 ID**: `ERR-05`
* **발견 위치**: `setStudioTab(idx)` 함수 (Line 1289~) 및 전역 `alert()` 호출 구문
* **발생 조건**: 스튜디오 5개 탭 클릭 및 상품 스펙/예약/결제 버튼 클릭 시
* **실제 현상**: 스튜디오 탭(조색, 3D각인, 사운드, B2B계산, 감정처방)을 클릭해도 버튼 스타일만 바뀌고 화면은 TDS 패널로 고정됨. 스펙 확인 시 90년대 시스템 경고창(`alert`)이 뜸.
* **기대 결과**: 5개 탭 클릭 시 각 독립 워크스테이션 컨테이너가 페이드 트랜지션으로 교체 렌더링되고, 모든 `alert()`가 세련된 UI 모달 창으로 교체됨.
* **중요도**: 🚨 **상 (Critical)**
* **수정 완료 조건**:
  - [ ] 5개 탭별 전용 워크스테이션 패널이 누락 없이 실제 전환될 것
  - [ ] 사이트 전체에서 브라우저 기본 alert() 호출이 0건일 것

---

### 📌 [ERR-06] 3-in-1 스마트 드로어 B2B 세금계산서 폼 및 1588 전화상담 폼 미분기 결함
* **오류 ID**: `ERR-06`
* **발견 위치**: `switchDrawerMode(mode)` 함수 (Line 1365~) 및 `drawerDynamicBody` 영역
* **발생 조건**: 스마트 드로어에서 'B2B 기업', '☎️ 1588 전화' 탭 클릭 시
* **실제 현상**: 탭 버튼 active 클래스만 바뀌고 본문은 D2C 일반 장바구니 리스트만 그대로 유지되어 기업 고객 및 시니어 고객이 결제/상담 폼을 이용할 수 없음.
* **기대 결과**: B2B 탭 클릭 시 법인 사업자번호/이메일 입력 폼 렌더링, 전화 탭 클릭 시 전화상담 예약 폼(이름/연락처/시간) 렌더링.
* **중요도**: 🚨 **상 (Critical)**
* **수정 완료 조건**:
  - [ ] 3개 탭 전환 시 장바구니 영역이 각 목적에 맞는 전용 폼으로 100% 교체 렌더링될 것

### 📌 [ERR-07] 기획 전문용어 대면 노출 및 모바일 11px 폰트 가독성 결함
* **오류 ID**: `ERR-07`
* **발견 위치**: HTML 전역 텍스트 및 모바일 반응형 미디어 쿼리 (`@media (max-width: 768px)`)
* **발생 조건**: 일반 고객 탐색 시 및 모바일 기기(375px~480px) 접속 시
* **실제 현상**: 'TDS 140ppm', '9:16 Tall Lookbook', '서사 앵커' 등 난해한 용어 노출, 모바일에서 스펙 폰트 11px로 줄바꿈 뭉침, 하단 고정 구매 바 부재.
* **기대 결과**: 직관적 감성 카피로 순화, 모바일 최소 폰트 `13px` 보장, 엄지손가락으로 1초 만에 주문 가능한 모바일 하단 고정 구매 바(`div.mobile-sticky-bar`) 제공.
* **중요도**: ⚠️ **중 (Major)**
* **수정 완료 조건**:
  - [ ] 기획 용어 100% 감성 카피로 교체 완료
  - [ ] 모바일 뷰포트에서 13px 가독성 보장 및 하단 고정 구매 바 정상 작동할 것
