## 1. 서비스 흐름 개요

본 서비스 흐름도는 잦은 해외 출장과 워케이션 환경에서 숙소 공용 수건의 위생 불안, 테리 타월의 캐리어 부피 낭비, 호텔 룸 건조 지연 문제를 해결하려는 김노마드(장서진) 페르소나의 인지·탐색·캐리어 부피 계산·글로벌 자수 커스텀·당일 특급 결제 전 과정을 최적화한 사용자 여정(User Journey) 설계서입니다.

사용자가 플랫폼에 진입하여 **'여권 크기 롤업 패킹'**, **'호텔 룸 3시간 완건조 성능'**, **'캐리어 부피 계산기'**, **'글로벌 IATA 자수 아틀리에'**를 거쳐 출국 전 당일 특급 발송 또는 간편결제를 완료하기까지의 모든 정상 경로와 분기/예외 경로를 상세히 다룹니다.

## 2. 사용자 유형과 시작 조건

### 2.1 사용자 유형 (User Personas)
1. **긴급 출장 비즈니스 트래블러 (Primary)**: 출국을 2~3일 앞두고 캐리어 공간 절감과 호텔 실내 속건 타월을 당일 특급으로 수령하려는 해외 출장러.
2. **워케이션 디지털 노마드 (Secondary)**: 1달 이상 장기 체류하며 호텔/에어비앤비 세면대에서 간편 손빨래 후 밤사이 말려 쓸 초경량 2종 키트를 찾는 원격 근무자.
3. **글로벌 여행 매니아 (Tertiary)**: 본인 영문 이름과 출국 공항 IATA 코드(ICN, SFO 등)가 각인된 감성 트래블 스트랩을 커스텀하려는 여행자.
4. **원단 경량성 체험자 (Quaternary)**: 3,000원에 85g 초경량 소창 원단 감촉을 테스트해 보려는 입문 트래블러.

### 2.2 시작 조건 (Entry Triggers)
* **진입점 A**: 메인페이지(`SCR-01`) 상단 히어로 배너 [여권 크기로 줄어드는 노마드 2종 키트] 클릭
* **진입점 B**: 상단 공지 띠배너 [✈️ 출국 전 긴급 발송: 평일 15시 이전 당일 특급 출고] 클릭
* **진입점 C**: 검색창(`SCR-12`)에서 노마드 핵심 키워드("여행용 수건", "호텔 속건 타월", "캐리어 수납", "여행용 파우치") 검색
* **진입점 D**: 1장 체험팩 플로팅 배너 [1장 3,000원 체험 후 본품 구매 시 100% 환급] 클릭

## 3. 핵심 정상 흐름 (Primary Happy Path)

주요 서비스 흐름은 `탐색 ➔ 선택 ➔ 상세 확인/검증 ➔ 핵심 행동 ➔ 결과 확인`의 5단계 표준 여정을 따릅니다.

```
[탐색: SCR-01 / SCR-12]
   │
   ▼
[선택: SCR-02 (트래블 2종 키트) / SCR-03 (항균 방수 파우치)]
   │
   ▼
[상세 확인 & 검증: SCR-05 (캐리어 계산기) / SCR-06 (3시간 속건실) / MODAL-01 (롤업 3D)]
   │
   ▼
[핵심 행동: SCR-04 (글로벌 자수 커스텀) ➔ SCR-08 (장바구니) ➔ SCR-09 (특급 결제)]
   │
   ▼
[결과 확인: SCR-10 (주문 완료) + 출장 D-Day 송장 번호 & 패킹 체크리스트 PDF]
```

### 3.1 단계별 상세 흐름
1. **탐색 (Explore)**: 사용자가 메인(`SCR-01`)에 진입하여 '여권 크기 롤업' 비주얼과 '호텔 3시간 완건조 vs 테리 수건' 비교 데이터를 확인.
2. **선택 (Select)**: 베스트 1위 `[비즈니스 트래블 2종 스타터 키트]`를 클릭하여 상품 상세(`SCR-02`)로 진입하거나, `[항균 방수 파우치(SCR-03)]` 선택.
3. **상세 확인 & 검증 (Inspect & Validate)**:
   - `캐리어 패킹 계산기(SCR-05)`에서 20인치 캐리어 내부 부피 70% 절감 시뮬레이션 및 85g 무게 확인.
   - `MODAL-01(3D 롤업 뷰어)`를 열어 여권 크기로 말리는 패킹 방식 확인.
   - `랩 & 검증실(SCR-06)`에서 호텔 룸 3시간 완건조 타임랩스 및 KATRI 시험성적서 확인.
4. **핵심 행동 (Action)**:
   - `글로벌 자수 아틀리에(SCR-04)`로 이동하여 영문 이니셜, IATA 공항 코드, 비행기 심볼을 실시간 스트랩에 렌더링하고 시안 확정.
   - 장바구니(`SCR-08`)에서 출국 D-Day를 확인하고, 주문서(`SCR-09`)에서 [당일 특급 출고] 선택 후 N-Pay 1초 결제.
5. **결과 확인 (Confirm)**:
   - 주문 완료(`SCR-10`) 화면에서 당일 출고 송장 번호, 자수 스트랩 확인증, 노마드 패킹 체크리스트 PDF 다운로드.

## 4. 분기, 오류, 이탈 및 재진입 흐름 (Branches & Exceptions)

| 구분 | 발생 조건 | 사용자 인터랙션 및 시스템 처리 | 이동/복구 화면 |
| :--- | :--- | :--- | :--- |
| **분기 A**<br>(단품 vs 2종 키트) | 단품 타월 선택 시 | 롱 바스타월 + 페이셜 와입스 15% 번들 할인 팝업 노출 및 2종 키트 전환 유도 | SCR-02 (키트 옵션) |
| **분기 B**<br>(자수 스트랩 유무) | 트래블 키트 구매 시 자수 선택 여부 | [자수 추가] 선택 시 자수 아틀리에(`SCR-04`) 호출, [미선택] 시 기본 스트랩 장바구니 담기 | SCR-02 ➔ SCR-04 또는 SCR-08 |
| **분기 C**<br>(일반 vs 당일 특급) | 결제 단계에서 배송 옵션 선택 시 | 출국 일정이 3일 이내일 경우 [당일 특급 출고(오후 3시 전 주문)] 자동 추천 | SCR-09 (배송 옵션 선택) |
| **오류 1**<br>(자수 글자수/코드 오류) | 영문 10자 초과 또는 미지원 특수문자 입력 시 | 입력창 붉은색 테두리 경고 및 "영문 대문자 및 IATA 3자리 코드로 입력해 주세요" 토스트 | SCR-04 (인라인 유지) |
| **오류 2**<br>(출국일 D-Day 촉박) | 출국일이 당일 또는 익일 오전인 경우 | "일반 택배로는 출국 전 수령이 어렵습니다. [인천공항 수령 서비스]로 전환하시겠습니까?" 모달 | SCR-09 (공항 수령 모달) |
| **오류 3**<br>(결제 실패/취소) | 잔액 부족 또는 간편결제 인증 취소 | 주문서 작성(`SCR-09`)으로 복귀 및 "선택하신 트래블 키트와 자수 시안이 안전하게 저장되었습니다" 토스트 | SCR-09 (재시도) |
| **이탈/재진입** | 장바구니 담기 후 창 이탈 | 24시간 내 재방문 시 상단 알림: "담아두신 노마드 트래블 키트가 안전하게 보관 중입니다" | SCR-01 ➔ SCR-08 |

## 5. 단계별 사용자 행동-시스템 처리 매트릭스

| 단계 | 사용자 행동 (User Action) | 시스템 처리 (System Process) | 출력 화면 | 다음 분기/조건 |
| :---: | :--- | :--- | :---: | :--- |
| **1. 탐색** | 메인 진입 후 트래블 키트 카드 클릭 | 키트 상세 스펙, 모던 컬러 스와치, 행잉 스트랩 로드 | **SCR-01 ➔ SCR-02** | 단품 구매 or 키트 선택 |
| **2. 패킹 계산** | [캐리어 부피 계산기] 클릭 | 20인치/24인치 캐리어 부피 70% 절감 시뮬레이션 실행 | **SCR-05** | 수건 개수별 용량 확인 |
| **3. 롤업 확인** | [여권 크기 3D 롤업 보기] 클릭 | 35x90cm ➔ 여권 크기 압축 3D 인터랙션 애니메이션 재생 | **MODAL-01** | 확인 후 옵션 추가 |
| **4. 자수 커스텀** | [글로벌 자수 만들기] 클릭 | 실시간 Canvas 자수 렌더러 초기화 및 IATA 공항 코드 로드 | **SCR-04** | 이니셜/비행기 입력 |
| **5. 장바구니** | 장바구니 담기 클릭 | 자수 스트랩 이미지 썸네일 생성 및 장바구니 세션 저장 | **SCR-08** | [주문하기] 클릭 |
| **6. 배송 선택** | 출국 일정 입력 및 당일 특급 선택 | 평일 15시 이전 기준 당일 출고 확약 및 배송비 계산 | **SCR-09** | 결제 수단 선택 |
| **7. 결제** | 간편결제 선택 및 [결제하기] 클릭 | PG사 승인 처리 및 물류센터 당일 패킹 큐 자동 등록 | **SCR-09** | 결제 성공 ➔ 완료 화면 |
| **8. 완료** | 주문 완료 확인 및 체크리스트 다운로드 | 주문 번호 채번, 당일 송장 번호 발급, 카카오 알림톡 발송 | **SCR-10** | D-Day 패킹 트래킹 |

## 6. Mermaid 전체 서비스 흐름도

```mermaid
flowchart TD
  START(["진입: SCR-01 (메인) / SCR-12 (검색)"]) --> STEP1["SCR-01 메인 탐색"]

  %% 탐색 및 선택 분기
  STEP1 -->|트래블 2종 키트 클릭| STEP2["SCR-02 트래블 2종 키트 상세"]
  STEP1 -->|항균 방수 파우치 클릭| STEP3["SCR-03 항균 방수 파우치 상세"]
  STEP1 -->|캐리어 계산기 클릭| STEP5["SCR-05 캐리어 패킹 계산기"]
  STEP1 -->|1장 체험팩 클릭| STEP7["SCR-07 1장 안심 체험팩"]

  %% 상세 확인 및 검증 인터랙션
  STEP2 -->|3D 롤업 확인| MODAL1["MODAL-01 롤업 패킹 3D 뷰어"]
  MODAL1 -->|확인 완료| STEP2
  STEP2 -->|3시간 속건 검증| STEP6["SCR-06 랩 & 검증실"]
  STEP6 -->|구매 복귀| STEP2
  STEP5 -->|최적 키트 담기| STEP2

  %% 자수 커스텀 분기
  STEP2 -->|글로벌 자수 선택| STEP4["SCR-04 글로벌 자수 아틀리에"]
  STEP4 -->|영문/IATA 코드 입력| VALID_JASU{"자수 유효성 검사"}
  VALID_JASU -- 글자수 초과 --> ERROR_JASU["오류: 영문 10자 이내 경고"] --> STEP4
  VALID_JASU -- 유효성 통과 --> APPLY_JASU["자수 스트랩 확정 & 장바구니 저장"] --> STEP8["SCR-08 장바구니"]

  STEP2 -->|기본 스트랩으로 구매| STEP8
  STEP3 -->|장바구니 담기| STEP8
  STEP7 -->|3,000원 체험 신청| STEP9["SCR-09 주문 및 결제"]

  %% 주문 및 특급 배송 분기
  STEP8 -->|주문하기 클릭| STEP9
  STEP9 --> CHECK_DDAY{"출국 D-Day 일정 검사"}
  CHECK_DDAY -- 3일 이내 긴급 -- 당일특급["평일 15시 당일 특급 출고 선택"] --> PAY_EXEC["결제 수단 선택 (N-Pay/카드)"]
  CHECK_DDAY -- 여유 일정 -- 일반배송["일반 안심 택배 선택"] --> PAY_EXEC

  %% 결제 처리
  PAY_EXEC --> PAY_PROCESS{"결제 승인 처리"}
  PAY_PROCESS -- 실패/취소 --> RETRY_PAY["오류: 결제 재시도 안내"] --> STEP9
  PAY_PROCESS -- 성공 --> STEP10["SCR-10 주문 완료"]

  %% 주문 완료 후속 처리
  STEP10 --> POST1["당일 출고 송장 번호 발급"]
  STEP10 --> POST2["자수 스트랩 확인증 발급"]
  STEP10 --> POST3["노마드 패킹 체크리스트 PDF"]
  STEP10 --> END_NODE(["종료: 출국 전 뽀송한 트래블 기어 수령"])
```
