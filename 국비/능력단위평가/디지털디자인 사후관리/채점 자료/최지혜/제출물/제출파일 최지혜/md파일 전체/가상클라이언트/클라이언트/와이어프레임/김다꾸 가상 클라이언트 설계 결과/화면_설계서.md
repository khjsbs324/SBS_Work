# 📐 플로뜰리에(Flottelier) - 김다꾸 맞춤형 화면 설계서 (Screen Specification)

> **프로젝트**: 프리미엄 감성 소창 욕실용품 & 커스텀 선물 전문 커머스  
> **기반 페르소나**: 김다꾸 (28세, 감성 인테리어 / 커스텀 수집가)  
> **입력 파일**: `가상 클라이언트 설계 결과/사이트맵.md`, `가상 클라이언트 설계 결과/서비스_흐름도.md`  
> **저장 위치**: `가상 클라이언트 설계 결과/화면_설계서.md`  
> **인코딩**: UTF-8

## 1. 프로젝트 및 설계 범위

본 화면 설계서는 '김다꾸' 페르소나의 니즈(4차 정련 완료 보증, 겹수별 용도 가이드, 세탁 전후 수축 1:1 비교, 실시간 자수 프리뷰, 고급 선물 포장 옵션)를 반영하여 **총 12개 주요 화면(P-01~P-12)**과 **3개 모달 레이어(M-01~M-03)**, **2개 예외 화면(EX-01~02)**에 대한 UI/UX 구조 및 인터랙션 정책을 정의합니다.

## 3. 핵심 화면 상세 명세 (P-01, P-05, P-11, M-03)

### 3.1 [P-01] 메인페이지 (Main Page)
- **목적**: 감성 욕실 톤앤매너 전달 및 4차 정련 완료 100% 보증을 통한 신뢰 구축
- **진입 조건**: URL 직접 진입, 랜딩 광고 클릭
- **종료 조건**: P-04(상품 카탈로그) 또는 P-05(상세 페이지)로 이동
- **화면 구성 영역**:
  - GNB 띠배너: `[받아서 바로 사용하는 4차 정련 완료 100% 보장] | [KC 성적서 보기]`
  - Hero Area: 파스텔 수채화 Canvas 배경 + 메인 브랜드 카피
  - Quick Filter: `[#4차정련완료] [#2겹세안] [#4겹샤워] [#자수가능] [#선물용포장]`
  - Editorial Grid: SHIROITO 80% 여백 비대칭 에디토리얼 연출 컷
- **표시 데이터**: 4차 정련 뱃지, 실시간 잔여 팝업 타임슬롯, 맘리뷰 평점 (4.9 ⭐)

### 3.2 [P-05] 상품 상세 페이지 (Product Detail Page)
- **목적**: 겹수/용도 선택 가이드 및 실시간 자수 프리뷰를 통해 구매 포기 요소 원천 차단
- **진입 조건**: P-01 또는 P-04에서 상품 클릭
- **화면 구성 영역**:
  - Top Section: 욕실 연출 컷, 4차 정련 완료 고정 뱃지, 컬러 스와치 (크림/베이지/연두/브라운)
  - Interactive Module: 세탁 전후 크기 1:1 슬라이더 (`세탁 전 40x80cm ➔ 세탁 후 36x72cm`)
  - Custom Module: 자수 텍스트 입력 폼 ➔ `[실시간 자수 프리뷰 (M-03)]` 버튼
  - Sticky Bottom Bar: 총 금액, 자수 제작(D+2) 포함 도착 예정일 자동 연산, `[1초 결제]` 버튼
- **인터랙션**:
  - 자수 문구 입력 시 M-03 모달 활성화
  - 겹수 가이드 툴팁 클릭 시 2겹 vs 3겹 vs 4겹 흡수력/건조속도 비교 팝업 노출

### 3.3 [M-03] 실시간 자수 프리뷰 모달 (Custom Embroidery Preview Modal)
- **목적**: 자수 결과물에 대한 불안감을 해소하여 즉시 결제 유도
- **진입 조건**: P-05 또는 P-07에서 `[실시간 자수 프리뷰]` 클릭
- **화면 구성 영역**:
  - Left Canvas Area: 타월 패브릭 질감 위 자수 실시간 렌더링
  - Right Controls: 텍스트 입력(최대 8자), 폰트 선택 4종(감성명조, 한즈선, 영문스크립트, 둥근고딕), 실 색상 5종(세이지, 테라코타, 베이지, 차콜, 골드), 위치(수건 하단/중앙)
- **유효성 검사**: 8자 초과 시 `"자수 문구는 최대 8자까지만 입력 가능합니다."` 실시간 경고 출력

## 5. 반응형 화면 기준 (Responsive Breakpoints)

- **데스크톱 (Desktop: 1400px 이상)**:
  - 3열 그리드 배치, 좌측 고화질 갤러리 + 우측 스티키 구매 옵션 2열 레이아웃.
- **태블릿 (Tablet: 768px ~ 1023px)**:
  - 2열 그리드 배치, GNB 햄버거 메뉴 전환, 자수 프리뷰 모달 상하 분할.
- **모바일 (Mobile: 767px 이하)**:
  - 1열 수직 렌더링, 하단 고정 Purchase Sticky Bar (총 금액 & 1초 결제 버튼), 탭 터치 최적화.

---

## 6. 웹 접근성 요구사항 (WCAG 2.1 AA Standard)

1. **포커스 링**: 모든 버튼 및 링크 요소 `:focus-visible` 최소 3px 고대비 테두리 제공.
2. **스킵 내비게이션**: 최상단 `.skip-nav` 본문 바로가기 제공.
3. **WAI-ARIA**: 모달 `role="dialog"`, `aria-modal="true"`, 탭 `role="tablist"`, `aria-selected="true"`.
4. **대체 텍스트**: 모든 제품 샷, 수축 슬라이더, 인증서 이미지에 정밀한 `alt` 속성 부여.

## 7. 미확정 정책 및 가정 (Assumptions)

- **가정 1**: 소창 전용 케어템(세제, 대야)은 묶음 구매 시 10% 자동 할인 적용됨을 `가정`함.
- **가정 2**: 팝업스토어 노쇼 방지를 위해 예약 변경은 방문 1일 전까지 가능함을 `가정`함.
- **가정 3**: 자수 커스텀 주문 건은 개별 제작 공정(D+2)으로 인해 단순 변심 반품이 제한됨을 주문 결제 전 안내함을 `가정`함.
