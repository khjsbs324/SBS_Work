## 1. 프로젝트 및 설계 범위

본 화면 설계서는 해외 출장과 워케이션 시 숙소 공용 수건의 위생 불신, 테리 타월의 캐리어 부피 낭비, 실내 건조 지연 문제를 해결하려는 김노마드(장서진) 페르소나를 위한 반응형 웹 플랫폼 화면 정의서입니다.
캐리어 70% 공간을 절감하는 **여권 크기 초슬림 압축**, 호텔 룸 **3시간 오버나이트 퀵드라이**, **초경량 항균 방수 파우치**, **글로벌 IATA 자수 아틀리에**, **당일 특급 출고**를 12개 화면과 1개 모달로 체계화하였습니다.

## 3. 화면별 상세 설계 명세

### [SCR-01] 메인페이지 (Main Portal)
* **목적**: 노마드 트래블 패브릭의 핵심 가치(여권 크기 압축, 호텔 3시간 속건)를 시각적으로 전달하고 최적 키트 구매 유도.
* **진입 조건**: 루트 URL 접속, GNB 로고 클릭.
* **종료 조건**: 트래블 2종 키트 상세(`SCR-02`), 캐리어 계산기(`SCR-05`), 자수 아틀리에(`SCR-04`) 이동.
* **화면 구성 영역**:
  1. **상단 띠배너**: [✈️ 출국 전 긴급 발송: 평일 15시 이전 당일 특급 출고]
  2. **GNB 헤더**: 로고, 메뉴 5종(TRAVEL GEAR, LAB, ATELIER, SIMULATOR, TRIAL), 검색창, 장바구니.
  3. **히어로 섹션**: "호텔 룸에서 밤에 빨아 널면 아침에 뽀송! 여권 크기로 줄어드는 노마드 소창 타월" + CTA [2종 키트 바로담기] / [캐리어 계산기].
  4. **속건 비교 섹션**: 3시간 완건조 소창 vs 12시간 눅눅한 테리 타월 타임랩스 그래프.
  5. **베스트 기어 그리드**: 2종 스타터 키트, 항균 방수 파우치, 수분 진정 와입스.
  6. **글로벌 리뷰 피드**: 디지털 노마드/해외 출장러 실사용 인스타그램 포토 피드.
* **표시 데이터**: 3시간 완건조 수치, 무게 85g, 부피 절감율 70%, 런칭 15% 할인가.
* **사용자 행동 및 인터랙션**:
  - [2종 키트 카드] 클릭 시 `SCR-02` 이동.
  - [캐리어 패킹 계산기] 클릭 시 `SCR-05` 이동.
  - [3D 롤업 가이드] 클릭 시 `MODAL-01` 팝업 호출.
* **상태 정의**:
  - `Default`: 히어로 롤업 애니메이션 및 베스트 상품 그리드 노출.
  - `Loading`: 스켈레톤 UI 노출 (0.2초 이내).

### [SCR-02] 트래블 2종 키트 상세 (Travel Kit Detail)
* **목적**: 롱 바스타월(35x90cm) + 페이셜 와입스(25x25cm) 구성의 스펙과 컬러, 행잉 스트랩 옵션을 선택하여 구매.
* **진입 조건**: 메인페이지(`SCR-01`) 키트 카드 클릭, GNB 메뉴 클릭.
* **종료 조건**: 자수 아틀리에(`SCR-04`) 이동, 장바구니(`SCR-08`), 즉시 결제(`SCR-09`).
* **화면 구성 영역**:
  1. **대표 갤러리**: 캐리어 패킹 컷, 호텔 룸 건조 컷, 바스타월 착용 컷.
  2. **모던 컬러 셀렉터**: 샌드베이지 / 슬레이트그레이 / 올리브 (3색 스와치).
  3. **행잉 스트랩 옵션**: 스냅 단추형 트래블 행잉 스트랩 포함 여부 체크박스 (+0원 기본 포함).
  4. **글로벌 자수 커스텀 배너**: [나만의 영문 네임 & IATA 공항 코드 각인하기 (+3,000원)].
  5. **하단 스티키 결제 바**: 수량 선택, 장당 단가, [장바구니 담기], [N-Pay 1초 구매].
* **표시 데이터**: 규격(35x90cm / 25x25cm), 무게(85g / 20g), 세탁 후 건조 시간(3시간).
* **사용자 행동 및 인터랙션**:
  - 컬러 스와치 클릭 시 대표 이미지 실시간 전환.
  - [글로벌 자수 각인하기] 클릭 시 `SCR-04`로 이동하여 시안 제작.
* **상태 정의**:
  - `Option Selected`: 컬러 및 자수 선택에 따른 최종 결제 금액 실시간 갱신.

### [SCR-03] 초경량 항균 방수 트래블 파우치 상세 (Waterproof Pouch Detail)
* **목적**: 이동 중 젖은 타월을 냄새/습기 없이 담는 멤브레인 방수 파우치 단품 및 세트 결합 구매.
* **진입 조건**: 메인페이지(`SCR-01`) 파우치 카드 클릭, GNB GEAR 메뉴 클릭.
* **종료 조건**: 장바구니(`SCR-08`), 주문서 작성(`SCR-09`).
* **화면 구성 영역**:
  1. **방수/통기 시연 컷**: 수분은 가두고 공기는 통하는 멤브레인 원단 확대 컷.
  2. **캐리어 결착 가이드**: 알루미늄 카라비너를 캐리어 외측 핸들에 결착한 모습.
  3. **번들 할인 셀렉터**: 단품(14,900원) vs 2종 키트 결합 구매 시(9,900원 특가).
* **표시 데이터**: 규격(18x22cm), 무게(28g), 방수 등급(IPX4), 항균 99.9% 인증.

---

### [SCR-04] 글로벌 노마드 자수 아틀리에 (Nomad Custom Atelier)
* **목적**: 영문 네임, IATA 공항 코드, 비행기 심볼을 실시간 Canvas 스트랩에 렌더링하여 나만의 트래블 기어 완성.
* **진입 조건**: 상품 상세(`SCR-02`) 자수 버튼 클릭, GNB ATELIER 메뉴 클릭.
* **종료 조건**: 시안 확정 후 장바구니(`SCR-08`) 또는 상품 상세(`SCR-02`) 복귀.
* **화면 구성 영역**:
  1. **실시간 Canvas 스트랩 렌더러**: 스냅 단추형 패브릭 스트랩 위에 실시간 자수 합성 뷰어.
  2. **텍스트 입력 필드**: 골퍼/노마드 영문 이니셜 (최대 10자, 대문자 자동 변환).
  3. **IATA 공항 코드 셀렉터**: ICN(서울), SFO(샌프란시스코), NRT(도쿄), CDG(파리), LHR(런던) 등 20개 프리셋 버튼 + 직접 입력.
  4. **트래블 심볼 6종 그리드**: 1. 비행기 2. 나침반 3. 여권 4. 지구본 5. 캐리어 6. 산.
  5. **자수 실 색상 셀렉터**: 골드 / 딥네이비 / 퓨어화이트 / 오렌지.
  6. **하단 액션 바**: [시안 확정하고 장바구니 담기] / [미리보기 이미지 저장].
* **표시 데이터**: 실시간 렌더링 이미지, 글자수 카운터 (0/10자), 추가금(+3,000원).
* **유효성 검사**:
  - 영문 10자 초과 시 입력 제한 및 붉은색 경고 테두리.
  - 특수문자 입력 시 "영문 대문자, 숫자, IATA 코드만 지원합니다" 안내.

### [SCR-05] 캐리어 패킹 계산기 (Packing Simulator)
* **목적**: 20인치/24인치 캐리어 내부에서 일반 수건 대비 70% 부피가 절감되는 효과를 인터랙티브하게 시뮬레이션.
* **진입 조건**: 메인페이지(`SCR-01`) 배너 클릭, GNB SIMULATOR 메뉴 클릭.
* **종료 조건**: 상품 상세(`SCR-02`) 이동, 3D 롤업 모달(`MODAL-01`) 호출.
* **화면 구성 영역**:
  1. **캐리어 규격 선택기**: 20인치 기내용 캐리어 vs 24인치 수하물 캐리어 탭.
  2. **출장 일정 슬라이더**: 2박 3일 (타월 2장) ~ 1주일 (타월 4장) 선택 슬라이더.
  3. **3D 캐리어 내부 시각화**: 일반 수건 차지 공간(30%) vs 노마드 소창 차지 공간(8%) 비교.
  4. **절감 수치 대시보드**: 절감 부피(2,400㎤), 절감 무게(780g), 여권 크기 비교 인포그래픽.
  5. **추천 키트 CTA**: [출장 맞춤 2종 키트 바로 담기].

### [SCR-06] 랩 & 속건 검증실 (Lab & Proofs)
* **목적**: 호텔 룸 실내 환경(온도 22℃, 습도 45%)에서 3시간 완건조되는 타임랩스 데이터와 KATRI 공인 성적서 제공.
* **진입 조건**: 메인페이지(`SCR-01`) 랩 섹션 클릭, GNB LAB 메뉴 클릭.
* **종료 조건**: 트래블 키트 상세(`SCR-02`), 1장 체험팩(`SCR-07`).
* **화면 구성 영역**:
  1. **호텔 룸 3시간 건조 타임랩스**: 1시간(50% 증발), 2시간(85% 증발), 3시간(100% 완건조) 그래프.
  2. **KATRI 시험성적서 원본 뷰어**: KOTITI/KATRI 속건성, 100회 손빨래 인장강도, 4無 안전성.
  3. **호텔 세면대 1분 손빨래 매뉴얼**: 미온수 헹굼 ➔ 비틀어 짜기 ➔ 옷걸이 거치 3단계 가이드.

### [SCR-07] 트래블 1장 체험팩 (Trial Pack)
* **목적**: 3,000원에 페이셜 와입스 1장을 먼저 체험해보고, 본품 구매 시 3,000원 전액 환급 쿠폰 발급.
* **진입 조건**: 메인페이지(`SCR-01`) 체험팩 배너, 플로팅 퀵 버튼.
* **종료 조건**: 주문서 작성(`SCR-09`).
* **화면 구성 영역**: 3,000원 안심 결제 안내, 100% 페이백 쿠폰 발급 조건, 노마드 실사용 포토 리뷰.

### [SCR-08] 장바구니 (Cart)
* **목적**: 선택한 트래블 기어, 자수 스트랩 시안, 수량, 출국 D-Day 특급 배송비 최종 검토.
* **진입 조건**: 헤더 장바구니 아이콘 클릭, 상세 페이지 담기 액션.
* **종료 조건**: 주문서 작성(`SCR-09`), 계속 쇼핑하기(`SCR-01`).
* **화면 구성 영역**: 상품 목록, 자수 시안 썸네일, 수량 변경기, 출국 D-Day 알림 바, 총 결제 금액 계산기.

### [SCR-09] 주문 및 결제 (Checkout)
* **목적**: 당일 특급 출고 옵션(평일 15시 이전) 또는 일반 택배를 선택하고 1초 간편결제 수행.
* **진입 조건**: 장바구니(`SCR-08`) [주문하기] 클릭, 상품 상세 [바로구매] 클릭.
* **종료 조건**: 주문 완료(`SCR-10`).

  3. **출국 일정 메모**: "출국일: 2026-08-25" 기재란.
  4. **간편결제 모듈**: 네이버페이 / 카카오페이 / 토스페이 / 해외 신용카드(Visa/Master).

### [SCR-10] 주문 완료 (Order Complete)
* **목적**: 주문 번호 및 당일 출고 송장 번호 안내, 최종 자수 스트랩 확인증 발급, 패킹 체크리스트 PDF 제공.

### [SCR-11] 기내 수분 진정 팁 (In-Flight Care Guide)

* **진입 조건**: 헤더 검색창 입력 후 엔터.
* **화면 구성 영역**: 검색어 입력창, 퀵 필터(키트/파우치/자수/와입스), 상품 결과 그리드.

## 5. 웹 접근성 (WCAG 2.1 AA) 및 안전성 요구사항

1. **시각 접근성**: 모든 텍스트 명도 대비 4.5:1 이상(주요 텍스트 `#1E293B` on `#FFFFFF` 12.6:1), 돋보기 확대 모드 지원.
2. **조작 접근성**: 키보드 Tab 키 포커스 링(`2px solid #2563EB`) 명확화, Skip Navigation(본문 바로가기) 제공.
3. **인지 접근성**: 이미지 대체 텍스트(`alt`) 100% 기술, 자수 글자수 초과 시 `aria-live="assertive"` 실시간 음성 지원.
