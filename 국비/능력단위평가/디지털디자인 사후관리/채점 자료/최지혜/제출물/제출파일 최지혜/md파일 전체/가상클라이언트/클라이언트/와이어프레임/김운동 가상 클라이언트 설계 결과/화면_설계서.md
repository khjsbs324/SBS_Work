## 1. 프로젝트 및 설계 범위

본 화면 설계서는 애슬레저 유저 **김운동(김오하운)**의 핵심 요구사항인 **1초 땀 흡수**, **땀 냄새 억제(99.8%)**, **40% 경량(95g)**, **30x90cm 슬림 롱타월 및 스냅 단추 스트랩**, **러닝 슬로건 Canvas 실시간 자수**, **1장 안심 체험팩(100% 환급)**, **러닝 크루 단체 발주** 기능을 구현하기 위한 16개 핵심 화면, 5개 레이어드 모달 및 2개 예외 화면의 UI/UX 상세 스펙을 정의합니다.

## 2. 화면 ID 규칙 및 전체 화면 목록

- `SCR-01 ~ SCR-15`: 주요 메인 및 서브 화면 (Depth 2~3)

## 3. 화면별 상세 설계 규격

### [SCR-01] 스포츠 메인 홈
* **화면 목적**: 스포츠 유저 대상 첫인상 확립, 1초 땀 흡수 성능 각인, 핵심 상품 빠른 접근 유도
* **진입 조건**: 메인 URL 접속 또는 GNB 'SPORT' 클릭
* **종료 조건**: 카탈로그(`SCR-02`), 스타터 팩(`SCR-03`), 1장 체험팩(`SCR-13`) 클릭
* **화면 구성 영역 및 UI 요소**:
  - `Header`: 로고, GNB(SPORT 활성), 상단 띠배너: `[가방 속 땀 냄새 제로 - 3배 빠른 건조 소창 스포츠 타월]`, 검색창, 장바구니 아이콘
  - `Hero Visual`: 땀 흘리는 러너 영상 썸네일, 카피: *"땀 흘리는 순간에도 뽀송하게, 1초 땀 흡수 소창 롱타월"*, CTA 버튼 `[1장 3,000원에 먼저 써보기]`
  - `Quick Persona Bar`: 13인 중 [김운동: 땀 흡수 1초 & 초경량 롱타월] 탭 활성화
  - `Feature Grid (3대 스펙)`: ① 1초 초고속 땀 흡수, ② 가방 속 땀 냄새 99.8% 억제, ③ 일반 수건 대비 40% 경량(95g)
  - `Best Products`: 오하운 스타터 팩(롱타월+와입스+파우치), 4겹 슬림 롱타월 단품
  - `Floating CTA`: `[1장 안심 체험팩 신청 (MOD-03)]`
* **상태별 정의**:
  - `기본 상태`: 히어로 비주얼 및 베스트 상품 그리드 정상 노출
  - `로딩 상태`: 비주얼 스켈레톤 UI 노출
* **반응형 기준**:
  - `PC`: 3단 상품 그리드 / 2열 피처 카드
  - `Mobile`: 1열 스택 / 하단 스티키 CTA 바 노출

---

### [SCR-03] 오하운 스타터 팩 상세
* **화면 목적**: 러너 및 헬스 매니아를 위한 올인원 패키지(롱타월+와입스3장+메쉬파우치) 원스톱 발주
* **진입 조건**: `SCR-01`, `SCR-02`에서 스타터 팩 카드 클릭
* **화면 구성 및 인터랙션**:
  - `Visual Gallery`: 롱타월 착용 컷, 메쉬 파우치 수납 컷, 360도 회전 뷰어
  - `Bundle Spec Box`:
    - 4겹 슬림 롱타월 1장 (30x90cm)
    - 2겹 포켓 와입스 3장 (25x25cm)
    - 오가닉 순면 통풍 메쉬 파우치 1개
    - *세트 할인가 38,000원 (정가 대비 15% 할인)*
  - `Option Selectors`:
    - 타월 컬러 (딥 차콜 / 올리브 세이지 / 오트밀 베이지)
    - 스냅 단추형 스트랩 추가 여부 (체크박스, +1,500원)
    - 슬로건 자수 추가 여부 (클릭 시 `MOD-01` Canvas 자수기 호출)
  - `Action Buttons`: `[장바구니 담기]`, `[N Pay 1초 구매]`, `[1장 체험팩 먼저 받기]`

---

### [SCR-04] 스포츠 슬림 롱타월 단품 상세
* **화면 목적**: 30x90cm 목 거치 전용 슬림 규격 및 스냅 스트랩 3D 확인 후 1:1 커스텀 발주
* **진입 조건**: `SCR-02` 카탈로그 또는 `SCR-01`에서 롱타월 단품 클릭
* **화면 구성 및 인터랙션**:
  - `500% HD Magnifier`: 봉제선 및 무라벨(Label-free) 마감 확대 렌더링
  - `Snap Strap 3D Viewer`: 기구 및 락커룸 거치 핏 3D 인터랙션 모달 연동 (`MOD-02`)
  - `Quantity & Tier Calculator`: 수량 변경 시 장당 단가 실시간 자동 계산 (1장 16,000원 / 3장 이상 장당 14,000원)
  - `Review Filter`: 세탁 50회 이상 운동 유저 포토 리뷰 탭 연동

---

### [SCR-08] 슬로건 Canvas 실시간 자수 스튜디오
* **화면 목적**: 나만의 러닝 슬로건이나 크루명을 0.05초 실시간 패브릭 위에 합성하여 확인
* **진입 조건**: 상세 화면(`SCR-03`, `SCR-04`)에서 [자수 커스텀] 클릭 또는 GNB 'CUSTOM' 진입
* **표시 데이터 & 입력 폼**:
  - `Text Input`: 슬로건 문구 입력 (예: 'RUN FREE', 'NEVER STOP') - 영문 최대 12자 / 한글 최대 8자
  - `Font Selection`: 애슬레저 폰트 8종 (고딕 볼드, 슬림 산세리프, 레트로 볼드, 필기체 등)
  - `Thread Color`: 7종 실 컬러 (딥 골드, 세이지 그린, 차콜 블랙, 오렌지 네온, 실버 화이트 등)
  - `Placement`: 스트랩 위치 / 타월 우측 하단 모서리
  - `Live Canvas Preview`: 0.05초 실시간 패브릭 텍스처 합성 프리뷰
* **유효성 검사 및 오류 메시지**:
  - 영문 12자 초과 입력 시: 붉은색 테두리 + `[영문 최대 12자(한글 8자)까지 입력 가능합니다]` 툴팁 표시
  - 특수문자 입력 시: `[영문, 한글, 숫자, 하이픈(-)만 입력 가능합니다]` 경고 표시

### [SCR-13] 1장 3,000원 스포츠 안심 체험팩
* **화면 목적**: 초기 구매 망설임을 해소하고 땀 흡수력을 먼저 체감하도록 유도
* **진입 조건**: 플로팅 CTA 배너 또는 메인/랩 페이지 내 [1장 체험팩] 클릭
* **화면 구성**:
  - `Benefit Summary`: *"3,000원에 먼저 써보세요. 본품 구매 시 3,000원 100% 환급 쿠폰을 즉시 돌려드립니다."*
  - `Quick Order Form`: 수령인 이름, 휴대폰 번호, 배송지 주소 (다음 우편번호 API 연동)
  - `1-Click Payment`: 카카오페이 / 네이버페이 / 신용카드 3,000원 원클릭 결제
  - `Coupon Automation`: 결제 완료 즉시 알림톡 발송 및 계정에 100% 페이백 쿠폰 등록

---

### [SCR-14] 장바구니 & 1초 결제
* **화면 목적**: 옵션 및 자수 시안 최종 확인 후 1초 간편 결제 완료
* **화면 구성**:
  - `Cart Items`: 상품명, 선택 컬러, 스냅 스트랩 여부, 자수 문구 썸네일 미리보기
  - `Add-on Checkbox`: `[+4,000원] 오가닉 순면 통풍 메쉬 파우치 추가`
  - `Eco Option`: `[선택] 100% 무비닐 제로웨이스트 포장으로 받기 (무료)`
  - `Price Summary`: 상품금액 + 배송비(3만원 이상 무료) - 100% 환급 쿠폰(-3,000원) = 최종 결제금액
  - `Payment Bar`: [N Pay 구매하기] / [카카오페이 구매하기]

## 4. 5대 레이어드 모달 시스템 규격 (MOD-01 ~ MOD-05)

* **`MOD-01` [Canvas 슬로건 자수 모달]**: 상세 페이지 내에서 이탈 없이 문구, 폰트, 실 컬러를 선택하고 실시간 프리뷰를 확인한 뒤 장바구니로 넘겨주는 레이어드 팝업.
* **`MOD-02` [스냅 단추 스트랩 3D 뷰어 모달]**: 목에 걸쳤을 때와 헬스 기구/락커룸에 체결했을 때의 모습을 360도 회전하며 확인할 수 있는 3D 뷰어.
* **`MOD-03` [1장 안심 체험팩 신청 모달]**: 1초 간편 입력 및 3,000원 결제 후 100% 환급 쿠폰을 자동 발급하는 퀵 오더 모달.
* **`MOD-04` [러닝 크루 직인 견적서 PDF 1초 출력 모달]**: 크루 단체 주문 수량(20~100장) 선택 시 직인이 날인된 공식 견적서 PDF를 브라우저에서 즉시 다운로드.
* **`MOD-05` [KATRI 땀 냄새 99.8% 억제 공인 성적서 확대 모달]**: 모락셀라균 탈취율 99.8% 국가 공인 시험성적서 원본을 200% 고화질로 확대 줌.

## 5. 반응형 뷰포트 레이아웃 기준

| 구분 | 데스크톱 (Desktop, ≥ 1024px) | 태블릿 (Tablet, 768px ~ 1023px) | 모바일 (Mobile, ≤ 767px) |
| :--- | :--- | :--- | :--- |
| **GNB** | 상단 풀 메뉴 + 유틸리티 아이콘 | 햄버거 메뉴 + 주요 3개 퀵 탭 | 상단 미니 로고 + 햄버거 드로어 |
| **상품 그리드** | 3~4열 그리드 배치 | 2열 반응형 그리드 | 1열 스택 + 수평 스크롤 스와이프 |
| **자수 시뮬레이터** | 좌측 프리뷰 / 우측 옵션 컨트롤 | 상하 분할 배치 | 상단 고정 프리뷰 / 하단 아코디언 |

## 6. 웹 접근성(WCAG 2.1 AA) 및 입력 유효성 정책

1. **명도 대비**: 모든 텍스트는 배경 대비 4.5:1 이상의 명도 대비를 유지 (본문 #0F172A, 배경 #FAFDFD).
2. **키보드 접근성**: 모든 탭, 버튼, 입력창, 모달 닫기 버튼은 `Tab` 키 및 `Enter/Space`로 완전 조작 가능하며 `focus-visible` 아웃라인 제공.
3. **스크린 리더(ARIA)**: Canvas 실시간 자수 프리뷰 영역에 `aria-live="polite"` 및 대체 텍스트(`aria-label="선택된 자수 문구: RUN FREE, 색상: 딥 골드"`) 제공.
4. **이미지 대체 텍스트**: 모든 제품 및 실험 데이터 이미지 영역은 상세한 `alt` 속성 및 플레이스홀더 텍스트 포함.
