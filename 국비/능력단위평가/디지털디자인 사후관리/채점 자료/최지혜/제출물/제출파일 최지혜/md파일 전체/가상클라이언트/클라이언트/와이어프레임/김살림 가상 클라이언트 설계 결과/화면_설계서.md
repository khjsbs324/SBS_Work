## 1. 프로젝트 및 설계 범위

* **프로젝트명**: 플로뜰리에 (Flottelier) 스마트 살림 & 번들 플랫폼
* **설계 범위**:
  - 총 12개 화면 (`SCR-01` ~ `SCR-10`, 예외 화면 `SCR-EX01`, `SCR-EX02`)
  - 3개 핵심 레이어드 모달 (`MODAL-01` ~ `MODAL-03`)
  - 데스크톱(1440px), 태블릿(768px), 모바일(375px) 반응형 레이아웃 및 뷰포트 스위칭 인터랙션
* **UI/UX 디자인 원칙**:
  1. **실용 정보 우선 (Utility First)**: 감성 문구보다 장당 단가(9,900원), 건조 시간(1시간), 수납 부피(68% 절감) 등 실질적 수치를 최우선 노출.
  2. **관리 피로도 제로화 (Zero-Fatigue)**: 삶기 불필요 4차 정련 완료 뱃지와 세탁기 울/표준코스 O/X 인포그래픽을 전진 배치.
  3. **터치 친화적 인터랙션 (Touch-Friendly)**: 슬라이더 조작, 1초 N-Pay/카카오페이 간편결제 및 뷰포트 전환 지원.

### 3.1 [SCR-01] 메인페이지 (Smart Living Hero & Bundle Preview)

* **화면 목적**: 젖은 수건 쉰내와 수납 고민을 가진 김살림 페르소나에게 소창의 3배 건조/1/3 수납 강점을 전달하고 10장 번들 팩으로 신속히 유입시킴.
* **진입 조건**: 서비스 루트 URL (`/`) 접속 또는 GNB 브랜드 로고 클릭.
* **종료 조건**: 10장 번들 카드 클릭 시 `SCR-02` 이동, 건조실험 배너 클릭 시 `SCR-03` 이동, 1장 체험팩 배너 클릭 시 `SCR-06` 이동.
* **화면 구성 영역 및 UI 요소**:
  1. **상단 공지 띠배너**: `[받아서 바로 쓰는 4차 정련 완료 100% 보장]` + `[1장 3,000원 체험 후 100% 환급]`
  2. **글로벌 헤더**: 로고, GNB(10장교체팩, 건조·수납실험실, 세탁기가이드, 정기구독), 검색창, 장바구니 [0]
  3. **메인 히어로 배너**: 
     - 카피: *"장마철에도 뽀송하게 쉰내 제로. 3배 빠른 건조 소창 수건 10장 올 체인지 팩"*
     - CTA 버튼: `[우리 집 수건 전면 교체 10장 특가 보기 (장당 9,900원)]`
     - 인증 뱃지: `[4차 정련 완제품 - 삶지 않고 바로 사용]`
  4. **3대 살림 혜택 인포그래픽 카드 3종**:
     - 카드 1: `3배 빠른 자연 건조` (1시간 건조 vs 일반 타월 4시간)
     - 카드 2: `1/3 슬림 수납` (욕실 상부장 수납공간 3배 확장)
     - 카드 3: `세탁기 울/표준코스 간편 관리` (삶기 불필요)
  5. **베스트 번들 라인업 그리드**:
     - `10장 올체인지 데일리 팩` (장당 9,900원 / 26,000원 절감 뱃지)
     - `20장 패밀리 풀하우스 팩` (35% 할인)
     - `살림 풀세트` (페이스 10장 + 와입스 5장 + 바스 2장)
  6. **1장 안심 체험팩 플로팅 CTA**: 하단 고정 플로팅 배너.
* **화면 상태 (States)**:
  - `기본 상태`: 히어로 비주얼 및 번들 카드 정상 렌더링.
  - `로딩 상태`: 스켈레톤 UI 카드 3개 노출.

### 3.2 [SCR-02] 10장 수건 전체 교체 번들 상세 (All-Change Bundle Detail)

* **화면 목적**: 10장 수건 전면 교체의 실질적 가격 혜택(장당 9,900원)과 고리 옵션을 제시하여 즉시 구매 또는 정기구독으로 전환.
* **진입 조건**: `SCR-01` 10장 카드 클릭, `SCR-10` 검색 결과 선택.
* **종료 조건**: [장바구니 담기]/[1초 결제] 클릭 시 `SCR-07` 이동, [정기구독] 선택 시 `SCR-05` 이동.
* **화면 구성 영역 및 UI 요소**:
  1. **상품 갤러리 영역**:
     - 상부장에 가지런히 정돈된 10장 롤접기 대표 이미지 (플레이스홀더)
     - 500% HD 확대 뷰어 썸네일 (무라벨 마감 및 봉제선 확인)
  2. **가격 및 단가 표시 영역**:
     - 정가 125,000원 ➔ **할인가 99,000원 (21% 할인)**
     - 강조 뱃지: **[10장 구매 시 장당 9,900원 / 총 26,000원 절감]**
     - `[실시간 단가 계산기 열기 (MODAL-01)]` 버튼
  3. **옵션 선택 영역**:
     - 색상 선택: `내추럴 아이보리(기본)` / `오가닉 세이지` / `오트밀 베이지`
     - 순면 루프(고리) 유무 선택 라디오 버튼: `[고리형 (건조봉 걸기 편함, +0원)]` vs `[일반형]`
     - 구매 형태 선택: `[1회 일반 구매]` vs `[6개월 정기배송 (10% 추가할인)]`
  4. **스티키 LNB 탭**: `[3배 건조 & 1/3 수납 데이터]`, `[세탁기/건조기 O/X 표]`, `[살림 실사용 포토후기]`
  5. **하단 스티키 결제 바**: 총 금액 99,000원 (장당 9,900원) + `[N-Pay 1초 결제]` / `[장바구니 담기]` 버튼.
* **유효성 검사**: 고리 옵션 미선택 시 경고 툴팁 및 자동 스크롤.

### 3.3 [SCR-03] 3배 빠른 건조 & 1/3 슬림 수납 실험실 (Proofs Lab)

* **화면 목적**: 소창 타월의 3배 건조 속도와 상부장 1/3 수납 부피 절약 효과를 데이터와 인터랙션으로 실증.
* **진입 조건**: GNB '건조·수납 실험실' 클릭, `SCR-02` LNB 탭 클릭.
* **화면 구성 영역 및 UI 요소**:
  1. **초고속 자연 건조 비교 섹션**:
     - 건조 시간 비교 차트 (플로뜰리에 소창 1시간 vs 일반 테리 타월 4시간)
     - 모락셀라 쉰내균 99.9% 억제 KATRI 공인 시험성적서 원본 보기 버튼
     - 통기성 격자 직조 구조 원리 인포그래픽
  2. **욕실 상부장 1/3 슬림 수납 인터랙티브 슬라이더**:
     - 좌우 드래그 슬라이더: `[일반 수건 10장 수납장 가득 참]` ➔ `[소창 수건 10장 수납장 1/3만 차지]`
     - 공간 절약 수치: **수납 부피 68% 감소 (여유 공간 3배 확보)**
  3. **세탁 타임라인 엠보싱 텍스처 버튼**: `[1회~50회 세탁 타임라인 보기 (MODAL-02)]`
  4. **CTA 배너**: `[3배 건조 & 1/3 수납 10장 세트 바로 구매하기]` ➔ `SCR-02` 이동.

### 3.4 [SCR-04] 삶기 없는 세탁기 & 건조기 간편 가이드 (Laundry O/X Guide)

* **화면 목적**: "소창은 삶아야 한다"는 편견을 깨고 세탁기 울/표준코스로 편리하게 관리할 수 있음을 입증.
* **화면 구성 영역 및 UI 요소**:
  1. **4차 정련 완제품 인증 선언**: *"공장에서 4번 삶고 말려 보내드립니다. 받자마자 세탁기로 바로 쓰세요."*
  2. **세탁기 & 건조기 관리 O/X 인포그래픽 표**:
     - 세탁기 표준코스 / 울코스: **O (가능)**
     - 건조기 저온 코스: **O (가능, 저온 권장 및 수축 안정화)**
     - 냄비에 삶기: **X (불필요, 정련 완료)**
     - 섬유유연제 사용: **X (흡수력 유지를 위해 무첨가 권장)**
  3. **호텔식 소창 수건 3단 롤 접기 가이드**: 3단계 일러스트 및 수납 연출 팁.
  4. **3년 후 살림 업사이클링 팁**: 낡은 수건을 주방 행주 및 청소용 걸레로 활용하는 친환경 가이드.
  5. **다운로드 버튼**: `[한눈에 보는 세탁기 관리 지침서 PDF 즉시 다운로드]`

* **화면 구성 영역 및 UI 요소**:
  1. **정기구독 플랜 선택기**:
     - `6개월 주기 플랜 (추천)`: 수건 위생 최적 주기, 10% 추가할인 (장당 8,910원)
     - `12개월 주기 플랜`: 1년 단위 전체 교체, 10% 추가할인
  2. **카카오 알림톡 교체 리마인더 설정기 (`MODAL-03`)**:

  3. **구독 신청 폼**: 수령인, 배송지, 알림톡 수신 휴대폰 번호, 정기결제 카드 정보.
  4. **신청 버튼**: `[정기배송 신청하고 첫 회차 10% 할인받기]` ➔ `SCR-08` 이동.

## 5. 설계 가정 (Assumptions) 모음

1. **[가정 1 - 10장 번들 단가]**: 10장 올체인지 데일리 팩의 정상가는 125,000원이며, 21% 할인 적용 시 장당 9,900원(총 99,000원)으로 설정함.
2. **[가정 2 - 1장 체험팩 환급 정책]**: 1장 체험팩(3,000원) 구매 후 카카오 알림톡으로 발급되는 환급 쿠폰은 30일 이내 10장 번들 팩 구매 시 3,000원 즉시 할인 형태로 전액 환급됨.
3. **[가정 3 - 정기배송 주기]**: 정기배송 주기는 6개월(위생 권장 주기) 및 12개월(연간 교체) 2가지 옵션으로 제공되며 10% 추가 할인이 적용됨.
4. **[가정 4 - 예외 처리]**: 검색 결과가 없거나 잘못된 경로 접근 시 사용자가 10장 번들 팩으로 신속히 복귀할 수 있도록 `SCR-EX01`, `SCR-EX02` 화면을 정의함.
