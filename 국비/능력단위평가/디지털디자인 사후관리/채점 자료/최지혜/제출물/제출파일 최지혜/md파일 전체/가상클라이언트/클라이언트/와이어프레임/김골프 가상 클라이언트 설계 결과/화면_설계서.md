## 1. 프로젝트 및 설계 범위

### 1.1 프로젝트 개요
* **서비스명**: 플로뜰리에 (Flottelier) 프리미엄 골프 기어 & 필드 라운딩 패브릭 커머스 플랫폼
* **핵심 타깃**: 18홀 라운딩 중 땀 흡수와 클럽 케어를 원하고, 품격 있는 홀인원/이글 답례품을 준비하려는 3050 골퍼('김골프 / 배진혁')
* **설계 범위**:
  - 메인페이지(`SCR-01`)부터 마그네틱 타월 상세(`SCR-02`), 클럽/볼 와입스(`SCR-03`), 자수 아틀리에(`SCR-04`), 홀인원 답례품(`SCR-05`), 필드 검증실(`SCR-06`), 1장 체험팩(`SCR-07`), 주문/결제(`SCR-08~11`), 검색(`SCR-12`), 마그네틱 3D 모달(`MODAL-01`)까지 총 13개 화면 전체.

### 1.2 화면 ID 규칙
* **SCR-XX**: 독립적인 웹 페이지 화면 (Screen)
* **MODAL-XX**: 특정 화면 위에 오버레이되는 팝업/모달 (Modal Dialog)

### [SCR-01] 메인페이지 (Main Page)
* **목적**: 18홀 땀흡수 및 마그네틱 원터치 탈부착 골프 소창 타월의 차별화된 가치 전달 및 퀵 구매 유도
* **진입 조건**: 루트 URL 접속, GNB 로고 클릭
* **종료 조건**: 상세 화면(`SCR-02/03/05/07`) 또는 자수 아틀리에(`SCR-04`)로 이동
* **화면 구성 영역 및 UI 요소**:
  1. `상단 공지 띠배너`: "18홀 내내 뽀송! 마그네틱 골프 타월 런칭 특가 & 홀인원 10세트 이상 무료 각인"
  2. `글로벌 헤더 (GNB)`: 로고, GOLF GEAR, 자수 아틀리에, 홀인원 답례품, 필드 검증실, 체험팩, 검색/장바구니
  3. `히어로 비주얼`: 캐디백에 찰칵 결착된 포레스트 그린 골프 타월 고해상도 연출 컷 + [필드 올인원 기어팩 담기] CTA
  4. `1초 땀흡수 비교 섹션`: 합성 극세사(끈적임) vs 플로뜰리에 순면 소창(1초 즉각 흡수) 타임랩스 비교
  5. `베스트 골프 기어 그리드`: 마그네틱 롱타월, 클럽/볼 와입스, 홀인원 답례 세트 카드
  6. `플로팅 퀵 액션`: [실시간 자수 시뮬레이터], [홀인원 단체 견적기], [3,000원 체험팩]
* **상태 정의**: 기본(default), 로딩(skeleton), 장바구니 뱃지 갱신

### [SCR-02] 마그네틱 골프 타월 상세 (Magnetic Towel Detail)
* **목적**: 25x100cm 롱 슬림 타월의 규격과 마그네틱 자석 클립 옵션을 확인하고 구매 또는 자수 커스텀으로 연결
* **진입 조건**: 메인페이지 상품 카드 클릭, GNB GOLF GEAR 메뉴 클릭
* **화면 구성 영역 및 UI 요소**:
  1. `대표 이미지 갤러리`: 캐디백 거치 컷, 목에 두른 필드 착용 컷, 500% HD 확대 텍스처 썸네일
  2. `마그네틱 3D 뷰어 호출 버튼`: [자석 클립 원터치 탈부착 원리 3D 확인 ➔ MODAL-01]
  3. `컬러 스와치 선택기`: 포레스트 딥그린, 클래식 네이비, 샌드 아이보리
  4. `자수 커스텀 연동 버튼`: [+ 나만의 골퍼 이니셜/엠블럼 자수 추가하기 (무료 프로모션) ➔ SCR-04]
  5. `하단 스티키 결제 바`: 수량 증감 버튼, 총 결제 금액, [N-Pay 1초 결제], [장바구니 담기]

### [SCR-03] 클럽 & 볼 케어 와입스 상세 (Club & Ball Wipes Detail)
* **목적**: 20x20cm 순면 포켓 와입스의 스크래치 제로 클럽 페이스 케어 성능 확인 및 3장 번들 구매
* **화면 구성 영역 및 UI 요소**:
  1. `클럽 페이스 케어 컷`: 드라이버/아이언 페이스를 흠집 없이 닦아내는 고밀도 순면 직조 확대 컷
  2. `포켓 수납 컷`: 골프 바지 뒷주머니에 쏙 들어가는 20x20cm 컴팩트 사이즈 안내
  3. `3장 번들 세트 할인 옵션`: 1장(9,900원) vs 3장 세트(24,900원, 16% 할인) 선택 셀렉터

### [SCR-04] 골프 자수 아틀리에 (Custom Atelier)
* **목적**: 영문 이니셜, 핸디캡, 골프 엠블럼 6종을 실시간 Canvas에 조합하여 나만의 골프 타월 시안 완성
* **진입 조건**: 상품 상세(`SCR-02`), 홀인원 답례품(`SCR-05`), GNB 자수 메뉴 클릭
* **화면 구성 영역 및 UI 요소**:
  1. `실시간 Canvas 렌더링 뷰어`: 타월 컬러(그린/네이비/아이보리) 위에 자수 실(골드/실버/화이트) 실시간 렌더링
  2. `폰트 선택기`: 클래식 로만 세리프, 모던 고딕 산세리프, 스포티 이탤릭, 정갈한 한글 명조
  3. `텍스트 입력 필드`: 영문 최대 12자 / 한글 최대 6자 (글자수 카운터 표시)
  4. `핸디캡/백넘버 입력`: 싱글, 이븐, 백넘버 (예: HDCP 7, No. 18)
  5. `골프 엠블럼 6종 그리드`: 드라이버, 퍼터, 핀플래그, 플라잉 이글, 트로피, 골프볼
  6. `시안 확정 버튼`: [이 시안으로 적용하고 장바구니 담기 ➔ SCR-08]
* **유효성 검사**: 글자수 초과 시 인라인 붉은색 경고 및 렌더링 제한

---

### [SCR-05] 홀인원/이글 답례품 (Hole-in-One Gift)
* **목적**: 홀인원/이글 기념 동반자 감사 선물 10~50세트 단체 할인 계산 및 공식 직인 PDF 견적서 즉시 출력
* **진입 조건**: 메인페이지 답례품 배너 클릭, GNB 홀인원 메뉴 클릭
* **화면 구성 영역 및 UI 요소**:
  1. `패키지 갤러리`: 고급 한지 지함 박스, 오가닉 순면 소창 보자기 포장, 기념 엠블럼 스티커
  2. `실시간 단체 견적 계산기`:
     - 수량 슬라이더: 10세트(10% 할인), 20세트(15% 할인), 30세트(20% 할인), 50세트(30% 할인)
     - 장당 단가 및 총 절감액 실시간 표시
  3. `동반자 감사 메시지 카드 대필 입력란`: 기념일자, 골프장명, 동반자 이름, 감사 문구 템플릿 선택
  4. `PDF 직인 견적서 다운로드 버튼`: 사업자/법인 제출용 실시간 견적서 PDF 다운로드
  5. `동호회 로고 AI 업로드`: 단체 로고 일괄 각인 파일 드래그앤드롭 업로더
  6. `단체 발주 CTA`: [단체 주문서 작성하기 ➔ SCR-09/11]

### [SCR-06] 필드 케어 & 검증실 (Care & Proofs Lab)
* **목적**: 1초 땀흡수 타임랩스, 자석 인장력 성적서, 천연 잔디 얼룩 세척법을 실증하여 신뢰도 극대화
* **화면 구성 영역 및 UI 요소**:
  1. `1초 땀흡수 실험실`: 일반 극세사(흡수 지연) vs 4차 정련 소창(1초 즉시 침투) 비교 영상
  2. `마그네틱 자석 인장력 테스트`: 카트 주행 시 흔들림에도 떨어지지 않는 3.5kgf 자력 검증 성적서
  3. `잔디/흙먼지 얼룩 천연 세척 가이드`: 과탄산소다 1스푼으로 잔디 물 완벽 제거하는 인포그래픽
  4. `KC 공인 안전성 및 100회 세탁 보증서`: KATRI 유해물질 불검출 성적서 다운로드

### [SCR-07] 1장 안심 체험팩 (Trial Pack)
* **목적**: 첫 구매 골퍼가 3,000원에 원단 감촉과 땀 흡수력을 먼저 경험하고 본품 구매로 전환되도록 지원
* **화면 구성 영역 및 UI 요소**:
  1. `3,000원 1장 체험팩 신청 카드`: 배송비 무료 3,000원 결제
  2. `100% 환급 보증 안내`: 결제 완료 즉시 본품 구매 시 사용 가능한 3,000원 할인 쿠폰 자동 지급
  3. `체험단 솔직 후기`: "라운딩 나가서 써보고 바로 10장 세트 질렀습니다" 포토 리뷰

## 4. 반응형 레이아웃 기준 (Responsive Breakpoints)

* **Desktop (1200px 이상)**: 
  - 좌측 500% HD 확대 갤러리 + 우측 스티키 자수/주문 옵션 2열 배치
  - 실시간 Canvas 자수 시뮬레이터와 단체 견적 계산기 풀 레이아웃
* **Tablet (768px ~ 1199px)**:
  - 1열 반응형 카드 그리드 전환, 스티키 하단 액션 바 활성화
* **Mobile (767px 이하)**:
  - 1열 풀 위드 레이아웃, 터치 스와이프 이미지 갤러리, 하단 고정 스티키 구매 버튼 (`N-Pay / 주문하기`)
  - 한 손 터치 자수 입력 폼 및 바텀시트 모달

## 5. 웹 접근성 요구사항 (Accessibility - WCAG 2.1 AA)

1. **명도 대비 (Contrast Ratio)**: 모든 텍스트와 UI 아이콘은 배경 대비 최소 **4.5:1** 이상의 명도 대비 유지.
2. **대체 텍스트 (Alt Text)**: 모든 골프 기어 컷, 자수 엠블럼, 성적서 이미지에 의미 있는 대체 텍스트 부여.
3. **키보드 접근성 (Keyboard Navigable)**: 모든 버튼, 슬라이더, 탭 메뉴는 `Tab` 키와 `Enter/Space`로 접근 및 조작 가능.
4. **스크린 리더 지원 (ARIA Attributes)**: 실시간 자수 렌더러와 견적 계산기에 `aria-live="polite"`를 적용하여 변경 사항 실시간 음성 안내.
