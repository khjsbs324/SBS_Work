> **기반 페르소나**: 김기업 / 송민재 (42세, 중견기업 인사·총무팀 총괄 팀장 / B2B 대량 특판 구매 결정권자)  
> **입력 파일**: `김기업 가상클라이언트 설계 결과/사이트맵.md`, `김기업 가상클라이언트 설계 결과/서비스_흐름도.md`

## 1. 프로젝트 및 설계 범위

본 화면 설계서는 기업 인사·총무팀장 '김기업(송민재)'의 B2B 대량 구매 프로세스를 완벽하게 지원하기 위해 정의된 **12개 핵심 화면(P-01 ~ P-12)**, **4개 레이어드 모달(M-01 ~ M-04)**, **3개 예외 화면(EX-01 ~ EX-03)**의 영역 구성, UI 요소, 데이터 명세, 상태 정의, 유효성 검사 규칙 및 반응형 레이아웃 가이드를 상세히 기술한 명세서입니다.

## 3. 화면별 상세 UI 및 인터랙션 설계

### 3.1 P-01. B2B 기업 메인페이지
- **영역 구성**:
  1. `상단 띠배너`: `[B2B 사업자 세금계산서 즉시 발행] | [엑셀 1초 일괄 업로드] | [ESG 탄소 리포트 동봉]`
  2. `히어로 섹션`: "기업의 품격과 ESG 경영 가치를 전하는 4차 정련 소창 기프트" 비주얼 & 퀵 탭
  3. `예산별 퀵 견적 카드 (3종)`: 3만원대(실속), 5만원대(프리미엄 BEST), 10만원대(VIP)
  4. `B2B 3대 핵심 편의 배너`: 엑셀 1초 일괄 배송 / Canvas 로고 자수기 / 직인 견적서 PDF
  5. `경영진 보고용 무료 샘플 키트 신청 배너`: "사업자등록증 확인 후 24시간 내 긴급 발송"
- **표시 데이터**: 세트별 정가, 대량 할인율(25~40%), 장당 단가, 플라스틱 절감량(120g)
- **사용자 행동**: 기프트 팩 클릭 (`P-02~04`), 직인 견적서 출력 (`M-04`), 무료 샘플 신청 (`P-12`)

### 3.2 P-03. 5만원대 프리미엄 팩 상세 (창립기념일/명절 베스트 1위)
- **영역 구성**:
  1. `상단 갤러리`: 세안 3장 + 바스 1장 + 맞춤 슬리브 연출 컷
  2. `수량별 대량 할인 계산기`: 슬라이더 조작 시 50개(25%), 100개(30%), 200개(35%), 500개(40%) 단가 실시간 반응
  3. `4차 정련 완제품 스펙`: 받자마자 바로 쓰는 뽀송한 사용성 & 100회 세탁 보증
  4. `하단 CTA 바`: `[기업 로고 자수 커스텀 (P-05)]`, `[직인 견적서 PDF 출력 (M-04)]`, `[엑셀 일괄 배송 (P-07)]`
- **인터랙션**: 수량 입력 시 공급가액, 부가세, 할인액이 0.05초 만에 애니메이션 연산.

### 3.3 P-05. 기업 로고 자수 센터 (Canvas 실시간 렌더링)
- **영역 구성**:
  1. `로고 업로더`: AI, SVG, PNG 파일 드래그앤드롭 영역
  2. `자수 실 스와치`: 샴페인 골드(인기 1위), 플래티넘 실버, 앤티크 차콜 3종
  3. `Canvas 뷰어`: 소창 원단 질감 위에 로고 자수가 실사 합성되어 0.05초 만에 렌더링
- **상태 정의**:
  - `기본(Empty)`: 플로뜰리에 심볼 자수 렌더링
  - `성공(Success)`: 기업 로고 정밀 자수 렌더링 완료 및 시안 이미지 다운로드 활성화
  - `오류(Error)`: 비지원 파일 포맷 시 `EX-01` 안내 팝업

### 3.4 P-07. 엑셀 일괄 배송 센터 & M-01 엑셀 파서 모달
- **영역 구성**:
  1. `엑셀 템플릿 다운로더`: `[플로뜰리에_B2B_주소록_표준양식.xlsx]` 다운로드 버튼
  2. `드래그앤드롭 업로드 영역`: 파일 업로드 시 1초 만에 200명 주소록 자동 파싱
  3. `주소록 검증 테이블`: 수령인명, 연락처, 주소, 배송메시지 인라인 편집 그리드
- **유효성 검사**:
  - 연락처: `010-XXXX-XXXX` 정규식 검증
  - 우편번호: 5자리 숫자 검증
  - 오류 행은 붉은색 하이라이트 및 인라인 수정 지원 (`EX-01`)

### 3.5 P-10. 실시간 견적 & 세금계산서 센터 & M-04 견적 모달
- **영역 구성**:
  1. `B2B 공식 견적서 뷰어`: 공급자 플로뜰리에 법인 직인 날인, 품목명, 수량, 공급가액, 부가세, 총액
  2. `견적서 PDF 1초 출력 버튼`: 브라우저 인쇄/PDF 저장 라이브러리 연동
  3. `사업자 세금계산서 신청 폼`: 사업자등록번호 입력 시 국세청 실시간 휴폐업 검증
  4. `결제 모듈`: 법인카드 분할 결제 / 가상계좌(세금계산서 즉시 예약)

## 4. 반응형 레이아웃 및 접근성 가이드

### 4.1 디바이스별 반응형 분기
- **Desktop (1200px 이상)**: 3열 카드 그리드, 대형 Canvas 자수 뷰어, 엑셀 10열 테이블 전체 노출.
- **Tablet (768px ~ 1199px)**: 2열 카드 그리드, 축소형 Canvas 뷰어, 엑셀 테이블 가로 스크롤.
- **Mobile (375px ~ 767px)**: 1열 카드 레이아웃, 스티키 하단 견적서 PDF 다운로드 바, 실시간 배송 트래킹 최적화.

### 4.2 웹 접근성 (Accessibility)
- 모든 버튼 및 입력 필드에 명확한 `aria-label` 및 `id` 부여.
- 고대비 텍스트 색상(WCAG AA 기준 명도비 4.5:1 이상 충족).
- 키보드 Tab 키 탐색 및 ESC 키 모달 닫기 완벽 지원.

## 5. 입력 파일 외 미정의 정책 및 가정 사항 `[가정]`

1. **`[가정 1]` EX-01 엑셀 형식 오류 인라인 수정**: 엑셀 주소록 업로드 시 오류가 발생한 행은 재업로드 없이 화면 상의 표에서 즉시 수정하여 발주를 완료할 수 있도록 지원함.
2. **`[가정 2]` EX-02 1,000세트 이상 생산 라인 조율**: 1,000세트 초과 초대형 발주 시 시스템 에러 대신 1:1 B2B 전담 매니저 핫라인 통화 및 분할 순차 배송 확약 화면으로 자연스럽게 유도함.
3. **`[가정 3]` D-Day 납품 확약서 지연 보상**: 행사 D-Day 지정 후 물류 지연 발생 시 결제 금액의 100%를 보상하는 확약서를 PDF로 발급함.
