# 📱 플로뜰리에(Flottelier) - 김스테이 B2B 화면 설계서 (UI/UX Specification)

> **프로젝트**: 프리미엄 독채 스테이 & 한옥 감성 숙소 맞춤 B2B 어메니티 & 실시간 견적 플랫폼  
> **기반 페르소나**: 김스테이 / 정우진 (38세, 프리미엄 감성 독채 스테이 & 웰니스 숙소 호스트)  
> **입력 파일**: `김스테이_가상클라이언트_분석결과.md`, `김스테이.md`  
> **저장 폴더**: `클라이언트/와이어프레임/김스테이 가상 클라이언트 설계 결과/`  
> **인코딩**: UTF-8

---

## 1. 프로젝트 및 설계 범위

본 화면 설계서는 프리미엄 감성 스테이 호스트 '김스테이(정우진)'의 핵심 요구사항을 구현하기 위해 정의된 **11개 핵심 화면(P-01 ~ P-11)**, **3개 레이어드 모달(M-02 ~ M-04)**, **3개 예외 화면(EX-01 ~ EX-03)**의 영역 구성, UI 컴포넌트, 인터랙션, 표시 데이터, 유효성 검사 규칙 및 반응형 가이드를 기술한 상세 명세서입니다.

---

## 2. 전체 화면 목록표

| 화면 ID | 화면명 | Depth | 주요 목적 | 진입 조건 | 종료/이동 조건 |
| :---: | :--- | :---: | :--- | :--- | :--- |
| **P-01** | B2B 메인페이지 | 1차 | 스테이 전용 혜택 제안 및 퀵 견적 유도 | 루트 URL 접속 | 번들 선택, 샘플 신청, 견적서 출력 |
| **P-02** | 스테이 번들 카탈로그 | 2차 | 20/50/100장 객실 규모별 팩 탐색 | GNB/메인 배너 클릭 | 번들 카드 클릭 (P-03) |
| **P-03** | 번들 상품 상세 페이지 | 2차 | 스펙, 건조 데이터, 고리 옵션 선택 | P-02 번들 클릭 | 자수 센터(P-05), 견적서(P-07) |
| **P-04** | 객실 풀 어메니티 패키지 | 2차 | 바스타월~티코스터 풀 라인업 셋업 | P-02 탭 클릭 | 일괄 담기 후 결제(P-10) |
| **P-05** | 숙소 로고 자수 센터 | 1차 | 로고 업로드 및 실시간 Canvas 자수 프리뷰 | P-03 자수 버튼 클릭 | 자수 확정 후 P-06 또는 P-07 이동 |
| **P-06** | 국/영문 리추얼 카드관 | 2차 | 투숙객 감동 리추얼 카드 무료 동봉 확인 | P-05 자수 확정 후 | 견적서 출력(P-07), 결제(P-10) |
| **P-07** | 실시간 견적 & 세금계산서 | 1차 | 공식 견적서 PDF 1초 출력 및 세무 처리 | GNB/상세 CTA 클릭 | 견적서 PDF(M-04), 발주(P-10) |
| **P-08** | 100회 세탁 내구성관 | 2차 | 고온 세탁 안정성 및 KC 4無 인증 증명 | 상세 탭/푸터 링크 | 성적서 확대(M-02) |
| **P-09** | 호스트 샘플 키트 신청 | 1차 | 3종 샘플 키트 신청 (100% 환급 쿠폰) | 메인/상세 배너 클릭 | 15,000원 결제 후 환급 쿠폰 발급 |
| **P-10** | B2B 장바구니 & 결제 | 1차 | 사업자 세금계산서 신청 및 법인 발주 | 견적/상세 발주 클릭 | 결제 완료 ➔ P-11 이동 |
| **P-11** | 정기납품 & 엠블럼관 | 2차 | 3~6개월 정기구독 및 파트너 엠블럼 | 발주 완료/마이페이지 | 구독 설정 완료, 엠블럼 다운로드 |
| **M-02** | KC 4無 성적서 확대 모달 | Modal | 무형광·무표백 시험성적서 200% HD 뷰 | P-08 성적서 클릭 | 모달 닫기 |
| **M-03** | Canvas 실시간 자수기 모달 | Modal | 폰트/실 색상/위치 실시간 렌더링 | P-03/P-05 자수 클릭 | 자수 옵션 저장 |
| **M-04** | 실시간 견적서 PDF 출력 모달 | Modal | 직인 날인 견적서 1초 PDF 다운로드 | P-01/P-07 클릭 | PDF 저장 |
| **EX-01** | 로고 파일 오류 안내 | Exception | 저화질/비지원 포맷 업로드 대응 | P-05 파일 유효성 실패 | 파일 재업로드 또는 1:1 상담 |
| **EX-02** | 대량 납기 조율 안내 | Exception | 300장 이상 대량 발주 재고 대응 | P-07 수량 300개 초과 | 긴급 납기 핫라인 상담 |
| **EX-03** | 404 Not Found | Exception | 잘못된 경로 접근 시 복구 | 잘못된 URL | B2B 메인 홈 이동 |
