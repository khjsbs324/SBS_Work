> **프로젝트명**: 플로뜰리에 (Flottelier) - 4차 정련 순면 소창 기프트 큐레이션 & 친환경 커스텀 패키징 플랫폼

## 1. 프로젝트 및 설계 범위

### 1.1 설계 목적
본 화면 설계서는 선물 구매자('김선물 / 박서윤')가 겪는 **소창 생소함 및 겹수 선택 혼란**, **포장 상태 불확실성**, **직배송 시 가격 노출 불안감**을 완전히 해소하고, 2분 이내에 직관적이고 감동적인 선물을 발주할 수 있도록 7개 핵심 화면(`P-GF-01` ~ `P-GF-07`)과 4개 전역 모달(`M-GF-01` ~ `M-GF-04`), 2개 예외 플로우(`EX-GF-01` ~ `EX-GF-02`)의 UI/UX 스펙을 상세히 정의합니다.

### 1.2 화면 ID 명명 규칙
- **`P-GF-XX` (Page - Gift)**: 메인 및 상세 웹 페이지 (총 7종)
- **`M-GF-XX` (Modal - Gift)**: 전역 레이어드 인터랙티브 모달 시스템 (총 4종)
- **`EX-GF-XX` (Exception - Gift)**: 예외 처리 및 유효성 오류 알림 (총 2종)

- **화면 구성 영역**:
  1. **상단 안심 띠배너**: `[선물 직배송 시 가격표/영수증 100% 미동봉 안심 배송 보증]`
  2. **GNB**: 로고, GIFT(하이라이트), COLLECTION, GUIDE, 장바구니, 1-Click 재구매
  3. **히어로 섹션**: "소중한 분에게 전하는 4차 정련의 따스한 온기", [호불호 0% 시그니처 바로가기] CTA
  4. **상황별 5대 탭 셀렉터**: `[🏠 집들이]`, `[👶 출산축하]`, `[🎂 생일선물]`, `[💍 웨딩/신혼]`, `[🌿 감사선물]`
  5. **예산별 4대 필터**: `[전체 예산]`, `[3만원대 실속]`, `[5만원대 시그니처]`, `[7만원대 프리미엄]`

  7. **소창 선물 가치 30초 인포그래픽**: 4차 정련 완제품, 먼지 제로, 3배 빠른 건조, 3년 수명

## 4. 화면 상태 정의 (State Definitions)

| 화면 상태 | 상태 설명 | UI 처리 및 피드백 |
| :--- | :--- | :--- |
| **기본 상태 (Default)** | 모든 데이터와 컴포넌트가 정상 로딩된 상태 | 표준 컬러, 활성화된 인터랙션 버튼 정상 노출 |
| **로딩 상태 (Loading)** | 필터링 및 자수 Canvas 렌더링 중 | 스켈레톤 UI 노출 및 0.2초 스피너 표시 |
| **빈 상태 (Empty)** | 예산 필터 조건에 부합하는 상품이 없을 때 | "조건에 맞는 상품이 없습니다. BEST 1위 세트를 추천해 드립니다." (`EX-03`) |
| **오류 상태 (Error)** | 자수 문구 누락 또는 주소지 형식 오류 | 붉은색 테두리 하이라이트 및 안내 문구 노출 (`EX-GF-01/02`) |
| **완료 상태 (Success)** | 자수 적용, 메시지 카드 저장, 결제 완료 | 녹색 체크 뱃지 및 토스트 팝업 1.5초 노출 후 다음 단계 전환 |

## 7. 웹 접근성 (WCAG 2.1 AA) 및 가정(Assumption) 정책

### 7.1 웹 접근성 요구사항
1. **명도 대비**: 모든 텍스트는 배경 대비 4.5:1 이상의 높은 명도 대비 유지.
2. **스크린 리더(ARIA)**: 자수 Canvas 프리뷰 및 3D 뷰어에 `aria-live="polite"` 및 대체 텍스트(`alt`) 제공.
3. **키보드 탐색**: 모든 탭, 라디오 버튼, 모달 닫기 버튼은 `Tab` 및 `Enter` 키로 100% 접근 가능.

### 7.2 [가정] 정책 모음
- **`[가정 1]`**: 단체 답례품(10세트 이상) 구매 시 자동 15% 대량 할인 및 1:1 전담 컨시어지 상담창구가 연결됩니다.
- **`[가정 2]`**: 선물 직배송 주문 시 결제 완료 후 10분 이내에는 메시지 카드 문구를 무료로 수정할 수 있습니다.
- **`[가정 3]`**: 카카오톡 선물하기 API를 통해 수령인이 직접 배송지를 입력할 경우 결제일로부터 7일간 배송지 입력 유효기간이 부여됩니다.
