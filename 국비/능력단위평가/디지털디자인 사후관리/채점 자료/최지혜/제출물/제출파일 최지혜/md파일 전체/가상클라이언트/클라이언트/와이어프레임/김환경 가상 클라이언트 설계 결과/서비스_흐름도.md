# 🔄 플로뜰리에(Flottelier) - 김환경 맞춤형 서비스 흐름도 (Service Flowchart)

> **프로젝트**: 그린워싱 Zero & 국가 공인 인증 100% 투명 검증 에코 소창수건 커머스  
> **기반 페르소나**: 김환경 (그린워싱 Zero / 공인 인증서 원본 조회 / 전 과정 친환경 검증가)  
> **입력 파일**: `가상 클라이언트 설계 결과/사이트맵.md`, `김환경_가상클라이언트_분석결과.md`  
> **저장 위치**: `가상 클라이언트 설계 결과/서비스_흐름도.md`  
> **인코딩**: UTF-8

---

## 1. 서비스 흐름 개요

본 서비스 흐름도는 '김환경' 고객이 사이트에 진입하여 **국가 공인 환경표지 인증서 원본을 1초 공식 조회(M-02)**하고, **FSC 인증 적용 범위(포장재 전용)** 및 **친환경 정보표(Eco Specs Sheet)**를 검증한 뒤, **무비닐 0% 포장 & 합배송(P-11)** 또는 **자원 회수 프로그램 신청(M-03)**에 도달하기까지의 전체 사용자 여정(User Journey)을 정의합니다.

그린워싱 우려를 완전히 차단하는 인증 검증, 친환경 정보표 비교, 무비닐 합배송, 자원 회수 수거 등 모든 정상 및 예외 흐름을 명확히 포함합니다.

---

## 2. 사용자 유형 및 시작 조건

### 2.1 사용자 유형 (User Types)
1. **타입 A: 공인 환경 인증 검증자 (그린워싱 Zero 탐색가)**
   - 막연한 '에코' 홍보 문구를 배제하고 국가 공인 인증서 원본 조회(M-02)와 FSC 적용 범위를 검증하는 실천가.
2. **타입 B: 무비닐 제로웨이스트 실천가 (에코 배송 선호형)**
   - 100% 무비닐 종이 포장 옵션과 탄소 배출을 줄이는 묶음 합배송을 선택하여 주문하려는 고객.
3. **타입 C: 자원 순환 재구매자 (리사이클 참여형)**
   - 수명이 다한 소창 수건과 포장재를 무상 수거 신청(M-03)하고 수건 교체 주기에 맞춰 재주문(P-12)하려는 고객.

### 2.2 시작 조건 (Trigger Conditions)
- **진입 채널**: 환경 인증번호 검색, 제로웨이스트 블로그, 성수 팝업스토어 QR 코드
- **최초 착륙 페이지 (Landing Page)**: 메인페이지 (P-01) 또는 친환경 정보표 한눈 비교 (P-06)

## 3. 핵심 정상 흐름 (Happy Path)

```text
[1. 탐색 (Search & Explore)]
 메인 (P-01) / 전체 에코 카탈로그 (P-04) 진입 ➔ 국가 공인 환경표지 상단 뱃지 확인

[2. 인증 검증 (Cert Verification)]
 상품 상세 (P-05) 이동 ➔ 국가 공인 인증서 원문 모달 (M-02) 200% HD 확대 ➔ 공식 조회 링크 클릭

[3. 환경 데이터 확인 (Eco Data & Packing)]
 친환경 정보표 (Eco Specs Sheet) 탄소/물 절감률 확인 ➔ FSC 범주(포장재 전용) 확인 ➔ 무비닐 포장 체크

[4. 핵심 행동 (Checkout / Action)]
 묶음 합배송 선택 ➔ 🟢 N Pay / 카카오 1초 원클릭 결제 (P-11)

[5. 결과 확인 & 자원 순환 (Completion)]
 주문 완료 & 알림톡 수신 ➔ 마이페이지 (P-12) 수명 다한 수건/포장재 자원 회수 수거 신청 (M-03)
```

---

## 4. 분기, 오류, 이탈, 재진입 흐름 (Branching & Exception Flows)

1. **공인 인증서 공식 조회 링크 분기 (M-02)**:
   - 상세페이지(P-05)에서 인증번호 클릭 시 M-02 모달이 활성화되며, 200% HD 확대 및 공인 인증기관 공식 조회 외부 웹으로 1초 이동.
2. **친환경 정보표 한눈 비교 분기 (P-06)**:
   - 상품간 환경 지표 비교 클릭 시 P-06(Eco Specs Sheet)으로 이동하여 탄소/물 절감률, 3년 수명, 무비닐 여부를 동일 기준 비교.
3. **자원 회수 수거 신청 분기 (M-03)**:
   - 사용 완료한 포장재 및 수명이 다한 수건을 택배 무료 수거 접수(M-03)하여 리사이클 캠페인 참여.
4. **결제 실패/취소 재진입 분기**:
   - N Pay 결제 창 취소 시 장바구니(P-11)로 안전 재진입되며 선택했던 무비닐 포장 및 묶음 합배송 옵션 유지.

  START(["🚀 사이트 진입 (환경 인증 검색 / QR)"]) :::startEnd

  DEC_CERT{"국가 공인 인증서<br>원본을 조회하는가?"} :::decision

  DEC_INFO{"친환경 정보표로<br>환경지표를 비교하는가?"} :::decision
  P06["P-06: 친환경 정보표 한눈 비교<br>(탄소/물 절감 데이터 비교)"] :::action

  P11["P-11: 장바구니 & 결제<br>(🟢 N Pay / 무비닐0% / 합배송)"] :::action

  P08["P-08: 성수 팝업스토어"] :::action
  M01_POP["M-01: 팝업 사전예약 모달"] :::action
  END_POP(["🎟️ 팝업 예약 완료 알림톡"]) :::startEnd

  %% 흐름 연결
  START --> P01
  P01 --> P04
  P04 --> P05
  P05 --> DEC_CERT

  DEC_CERT -- "예" --> M02
  M02 --> DEC_INFO

  DEC_INFO -- "예" --> P06
  P06 --> P11
