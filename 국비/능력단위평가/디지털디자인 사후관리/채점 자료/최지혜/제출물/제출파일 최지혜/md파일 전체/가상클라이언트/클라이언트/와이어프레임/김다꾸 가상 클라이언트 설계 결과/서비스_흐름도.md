> **프로젝트**: 프리미엄 감성 소창 욕실용품 & 커스텀 선물 전문 커머스  
> **기반 페르소나**: 김다꾸 (28세, 감성 인테리어 / 다이어리 꾸미기 / 커스텀 수집가)  
> **입력 파일**: `가상 클라이언트 설계 결과/사이트맵.md`, `김다꾸_가상클라이언트_분석결과.md`  
> **저장 위치**: `가상 클라이언트 설계 결과/서비스_흐름도.md`  
> **인코딩**: UTF-8

## 1. 서비스 흐름 개요

본 서비스 흐름도는 '김다꾸' 고객이 사이트에 진입하여 **4차 정련 여부를 확인**하고, **2/3/4겹 용도 맞춤 큐레이션**을 거쳐 **실시간 자수 프리뷰(M-03)** 및 **선물 포장 패키지(M-01)**를 설정한 뒤 **1초 N Pay 결제** 또는 **성수 팝업스토어 사전예약(M-01)**에 도달하기까지의 전체 사용자 여정(User Journey)을 다룹니다.

핵심 정상 흐름뿐만 아니라 로그인 여부 분기, 자수 입력 오류, 세탁 전후 수축 팝업 확인, 결제 실패/재진입, 팝업 예약 마감 등 모든 예외 및 대안 흐름을 명확히 정의합니다.

---

## 2. 사용자 유형 및 시작 조건

### 2.1 사용자 유형 (User Types)
1. **타입 A: 신규 감성 탐색자 (비회원/초보자)**
   - 소창 수건을 처음 구매하며 정련 수축 불확실성 해소 및 1장 체험팩(P-06)을 먼저 신청하려는 사용자.
2. **타입 B: 커스텀 선물 구매자 (회원/비회원)**
   - 돌잔치/친구 선물을 위해 자수 폰트/실 색상을 실시간 렌더링(M-03)하고 고급 포장을 지정하려는 사용자.
3. **타입 C: 기존 단골 재구매자 (로그인 회원)**
   - 교체 주기에 맞춰 1초 재주문(P-12)을 진행하고 소창 케어템을 cross-selling 구매하려는 사용자.

### 2.2 시작 조건 (Trigger Conditions)
- **진입 채널**: 인스타그램 룩북 광고, 성수 팝업스토어 QR 코드, 네이버 검색 (`소창 4차정련 수건`)
- **최초 착륙 페이지 (Landing Page)**: 메인페이지 (P-01) 또는 1장 체험팩 (P-06)

## 3. 핵심 정상 흐름 (Happy Path)

```text
[1. 탐색 (Search & Explore)]
 메인 (P-01) / 상품 카탈로그 (P-04) 진입 ➔ 4차 정련 완료 뱃지 & 겹수 필터 (2겹/3겹/4겹) 확인

[2. 선택 (Select Option)]
 상품 상세 (P-05) 이동 ➔ 감성 컬러 (크림/베이지/연두/브라운) 및 고리/푸프 선택 ➔ 세탁 전후 수축 Slide 확인

[3. 상세 확인 (Preview & Custom)]
 실시간 자수 프리뷰 모달 (M-03) 호출 ➔ 텍스트 입력 및 폰트/실색상 렌더링 확인 ➔ 선물 포장 옵션 체크

[4. 핵심 행동 (Checkout / Action)]
 자수 제작 배송 예정일(D+2) 확인 ➔ 1초 N Pay / 카카오페이 결제 진행 (P-11)

[5. 결과 확인 (Completion)]
 주문 완료 페이지 & 카카오 알림톡 수신 ➔ 마이페이지 (P-12) 교체 주기 알림 자동 등록
```

---

## 4. 분기, 오류, 이탈, 재진입 흐름 (Branching & Exception Flows)

1. **로그인 상태 분기**:
   - 결제 단계(P-11) 진입 시 비회원은 N Pay / 카카오 1초 간편 결제로 인증 없이 즉시 구매 가능.
   - 마이페이지 1초 재주문(P-12) 진입 시 미인증 사용자는 소셜 간편 로그인 페이지로 리다이렉트.
2. **자수 텍스트 입력 오류 분기**:
   - 자수 문구 8자 초과 또는 금지 특수문자 입력 시, M-03 모달 내 실시간 경고 텍스트 출력 (`"최대 8자 이내 한글/영문만 가능합니다."`).
3. **옵션 품절 및 결과 없음 분기 (EX-01 [가정])**:
   - 특정 컬러/겹수 옵션 품절 시, `[재입고 알림 신청]` 버튼으로 전환되며 유사 추천 컬러 상품을 노출.
4. **결제 실패/취소 재진입 분기**:
   - N Pay 결제 창 취소 시 장바구니(P-11)로 안전 재진입되며 선택했던 자수 옵션 및 쿠폰 100% 자동 유지.
5. **성수 팝업 타임슬롯 마감 분기 (M-01)**:
   - 14:00 타임슬롯 마감 시 disabled 처리되며 16:00 (8석 남음) 대안 타임슬롯을 자동 추천.

| **ST-07** | 장바구니 & 결제 | N Pay 1초 간편 결제 클릭 | N Pay API 호출, 무비닐 eco 배송 포장 옵션 적용 | **P-11 (장바구니 & 결제)** | 결제 승인 완료 |
| **ST-08** | 주문 완료 & 케어 | 주문 완료 내역 확인 | 주문 정보 DB 저장, 카카오 알림톡 발송, 교체주기 등록 | **P-12 (마이페이지/완료)** | 케어 가이드 PDF 소장 |

## 6. Mermaid flowchart 전체 서비스 흐름도

```mermaid
flowchart TD
  classDef startEnd fill:#232527,color:#FFFFFF,stroke:#232527,stroke-width:2px;
  classDef action fill:#FAF7F2,color:#232527,stroke:#C47A5A,stroke-width:2px;
  classDef system fill:#F4F8F5,color:#232527,stroke:#7E8D7F,stroke-width:2px;
  classDef decision fill:#FFF9F5,color:#C47A5A,stroke:#C47A5A,stroke-width:2px;

  START(["🚀 사이트 진입 (광고 / 검색 / QR)"]) :::startEnd

  P01["P-01: 메인페이지 진입<br>(4차 정련 뱃지 & 수채화 Canvas)"] :::action
  P04["P-04: 전체 상품 카탈로그<br>(2/3/4겹 용도 필터링)"] :::action
  P05["P-05: 상품 상세 페이지<br>(수축 Slider & 컬러 스와치)"] :::action

  DEC_CUSTOM{"자수 커스텀<br>옵션을 추가하는가?"} :::decision
  M03["M-03: 실시간 자수 프리뷰 모달<br>(Canvas 폰트/실색상 렌더링)"] :::action
  CHK_TEXT{"자수 입력 유효성<br>(8자 이내 / 특수문자)"} :::decision
  ERR_TEXT["⚠️ 경고 메시지 출력<br>('8자 이내 한글/영문만 가능')"] :::system

  DEC_GIFT{"선물 포장 옵션을<br>선택하는가?"} :::decision
  M01_GIFT["M-01: 선물 포장 미리보기 모달<br>(박스/쇼핑백/메시지카드)"] :::action

  CALC_DATE["⚙️ 자수 제작(D+2) 반영<br>배송 예정일 자동 연산"] :::system

  P11["P-11: 장바구니 & 결제<br>(N Pay / 카카오 1초 결제)"] :::action
  DEC_AUTH{"로그인 유무 확인"} :::decision
  NPAY_EXEC["N Pay 1초 간편 결제 승인"] :::system

  P12["P-12: 마이페이지 & 주문완료<br>(교체주기 알림 자동등록)"] :::action
  END_BUY(["🎉 주문 완료 (카카오 알림톡 발송)"]) :::startEnd

  %% 팝업 대안 흐름
  P08["P-08: 성수 팝업스토어"] :::action
  M01_POP["M-01: 팝업 사전예약 모달"] :::action
  CHK_SLOT{"14:00 타임슬롯<br>잔여석 존재 여부"} :::decision
  SLOT_FULL["⚠️ 14:00 마감 (disabled)<br>16:00 타임슬롯 추천"] :::system
  END_POP(["🎟️ 팝업 예약 완료 알림톡"]) :::startEnd

  %% 흐름 연결
  START --> P01
  P01 --> P04
  P04 --> P05
  P05 --> DEC_CUSTOM

  DEC_CUSTOM -- "예" --> M03
  DEC_CUSTOM -- "아니오" --> DEC_GIFT

  M03 --> CHK_TEXT
  CHK_TEXT -- "오류" --> ERR_TEXT
  ERR_TEXT --> M03
  CHK_TEXT -- "정상" --> DEC_GIFT

  DEC_GIFT -- "예" --> M01_GIFT
  DEC_GIFT -- "아니오" --> CALC_DATE
  M01_GIFT --> CALC_DATE

  CALC_DATE --> P11
  P11 --> DEC_AUTH
  DEC_AUTH -- "회원/비회원" --> NPAY_EXEC
  NPAY_EXEC --> P12
  P12 --> END_BUY

  %% 팝업 흐름
  P01 --> P08
  P08 --> M01_POP
  M01_POP --> CHK_SLOT
  CHK_SLOT -- "마감" --> SLOT_FULL
  SLOT_FULL --> M01_POP
  CHK_SLOT -- "여유" --> END_POP
```
