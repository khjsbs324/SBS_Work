## 1. 프로젝트 및 설계 범위

본 화면 설계서는 샴푸 후 터번 풀림, 목덜미 누수, 드라이 시간 지연 및 잦은 고온 세탁에 따른 타월 손상을 겪는 프리미엄 헤어 살롱 대표 원장 '김헤어(백승현)'를 타깃으로 하는 **플로뜰리에 HAIR (Flottelier Hair)** 웹 B2B 커머스 플랫폼의 전체 12개 메인 화면 및 2개 공통 인터랙티브 모달의 UI/UX 구조와 인터랙션, 반응형 레이아웃 및 접근성 가이드를 정의합니다.

### [SCR-01] 플로뜰리에 HAIR 메인

* **화면 목적**: 드라이 시간 70% 단축과 샴푸 후 터번 흘러내림 제로의 가치를 살롱 원장에게 각인시키고 B2B 도매 발주 유도.
* **진입 조건**: 루트 URL 접속, GNB 로고 클릭.
* **종료 조건**: 상품 상세 이동(`SCR-02`, `SCR-03`), B2B 도매 센터 이동(`SCR-05`), 체험팩 신청(`SCR-08`).
* **주요 구성 영역 & UI 요소**:
  1. **상단 세무 띠배너**: [살롱 B2B 20장 이상 발주 시 살롱 로고 무료 자수 & 세금계산서 100% 즉시 발행] / [3,000원 체험팩 신청 &rarr;]
  2. **GNB 헤더**: 브랜드 로고, GNB 메뉴(5개), 도매 견적기 바로가기, 견적함/장바구니 뱃지, 사업자 마이페이지.
  3. **메인 히어로**: 프리미엄 헤어 살롱 시술 컷 비주얼 + "흘러내림 제로! 샴푸 후 드라이 시간을 70% 단축하는 프리미엄 살롱 헤어 랩" 슬로건 + `[살롱 B2B 도매 발주 센터]` CTA 버튼.
  4. **인터랙티브 퀵 계산기**: 살롱 의자 수(N석) 입력 시 월간 단축 드라이 시간 및 전기세 절감액 연산 위젯.
  5. **살롱 3대 기어 큐레이션**:
     - 카드 1: 루프 단추 헤어 터번 (40x100cm, 롱헤어 감싸기)
     - 카드 2: 샴푸 넥 가드 수분 타월 (목덜미 누수 차단)
     - 카드 3: 살롱 로고 톤온톤 자수 커스텀 에디션
  6. **살롱 다크 컬렉션 스와치**: 딥차콜, 나이트네이비, 모카브라운 3종 내오염성 시연.
  7. **글로벌 푸터**: B2B 전담 상담 센터, 더마테스트 성적서 PDF 다운로드, 세금계산서 발행 안내.
* **상태별 대응**:
  - `Default`: 추천 살롱 패브릭 및 B2B 프로모션 정상 로드.
  - `Loading`: 스켈레톤 UI 노출.

### [SCR-02] 루프 단추 헤어 터번 상세 (40x100cm)

* **화면 목적**: 긴 머리도 흔들림 없이 고정되는 루프 단추형 터번 스펙 및 다크 3종 컬러 옵션 선택 유도.
* **진입 조건**: 메인 상품 카드 클릭, GNB SALON GEAR 메뉴 클릭.
* **종료 조건**: 장바구니 담기(`SCR-09`), B2B 대량 도매 이동(`SCR-05`), 자수 아틀리에(`SCR-04`).
* **주요 구성 영역 & UI 요소**:
  1. **착용 갤러리**: 40x100cm 롱헤어 감싸기 컷, 신축 루프 결착 컷, 500% HD 텍스처 줌.
  2. **인터랙션 버튼**: `[🎬 3초 터번 착용법 인터랙티브 가이드 (MODAL-01)]`
  3. **살롱 다크 3종 컬러 선택기**: 다크 딥차콜, 나이트 네이비, 모카 브라운.
  4. **옵션 선택기**: 단품 (24,000원) / 5장 디자이너 세트 (98,000원) / B2B 20장 번들 (SCR-05 연동).
  5. **살롱 로고 자수 체크박스**: `[+ 살롱 로고/디자이너명 자수 추가 (SCR-04)]`

### [SCR-03] 샴푸 넥 가드 수분 타월 상세

* **화면 목적**: 샴푸대에서 목덜미로 물이 흘러 고객 옷을 적시는 사고를 0%로 차단하는 U자형 타월 스펙 안내.
* **진입 조건**: 메인 상품 카드 클릭, GNB 상품 메뉴 클릭.
* **종료 조건**: 장바구니 담기(`SCR-09`), 도매 센터 이동(`SCR-05`).
* **주요 구성 영역 & UI 요소**:
  1. **샴푸대 핏 갤러리**: 고객 목덜미 밀착 컷, U자형 입체 패턴 안내.
  2. **흡수 스펙**: 4차 정련 소창 4겹 순간 흡수, 초고속 자연 건조.
  3. **번들 옵션**: 10장 살롱 번들 (85,000원) / 20장 도매 번들 (150,000원).

### [SCR-04] 살롱 로고 자수 아틀리에 (Canvas 실시간 렌더링)

* **화면 목적**: 살롱 BI 로고 및 디자이너명을 Canvas 실시간 렌더링으로 합성하여 고급스러운 톤온톤 자수 시안 완성.
* **진입 조건**: 상품 상세 자수 옵션 클릭, GNB ATELIER 메뉴 클릭, 도매 센터 자수 버튼 클릭.
* **종료 조건**: 시안 확정 모달(`MODAL-02`) 확인 후 도매 발주 센터(`SCR-05`) 또는 장바구니(`SCR-09`) 이동.
* **주요 구성 영역 & UI 요소**:
  1. **실시간 Canvas 프리뷰 창**: 다크 소창 원단 위에 샴페인골드/실버 자수 합성 시뮬레이션.
  2. **살롱 로고 파일 업로드기**: AI / PNG 로고 파일 드래그앤드롭 및 해상도 자동 체크.
  3. **살롱명 텍스트 입력창**: 한글 최대 8자, 영문 최대 12자 입력 및 글자수 카운터.
  4. **자수 실 색상 선택기**: 샴페인 골드, 모던 실버, 톤온톤 차콜, 딥 네이비.
  5. **CTA 버튼**: `[살롱 자수 시안 확정 & B2B 견적함 담기 (MODAL-02 호출)]`.

### [SCR-05] 살롱 B2B 도매 발주 센터

* **화면 목적**: 20장/50장/100장 수량별 최대 38% 도매 할인율 확인 및 공식 직인 견적서 PDF 1초 자동 생성.
* **진입 조건**: 메인 B2B CTA 클릭, GNB B2B WHOLESALE 메뉴 클릭.
* **종료 조건**: 견적서 PDF 다운로드, B2B 결제 이동(`SCR-10`).
* **주요 구성 영역 & UI 요소**:
  1. **대량 수량 선택 슬라이더**: 20장(25% 할인), 50장(32% 할인), 100장(38% 할인).
  2. **실시간 도매 단가표**: 장당 정상가 24,000원 &rarr; 도매가 14,880원 (100장 기준).
  3. **견적서 1초 출력 버튼**: `[📄 법인 직인 날인 공식 견적서 PDF 다운로드]`.
  4. **B2B 혜택 안내**: 살롱 로고 무료 자수 + 전자세금계산서 즉시 발행 + D-Day 안심 배송.
  5. **CTA 버튼**: `[B2B 도매 발주서 작성하기 (SCR-10)]`.

* **화면 목적**: 타월 드라이 70% 흡수력, 더마테스트 엑설런트 두피 무자극, 200회 세탁 품질 보증 성적서 원본 제공.
* **진입 조건**: 상품 상세 성적서 링크, GNB SCIENCE & LAB 클릭.
* **종료 조건**: B2B 도매 이동(`SCR-05`), 체험팩 신청(`SCR-08`).
* **주요 구성 영역 & UI 요소**:
  1. **타월 드라이 수분 70% 흡수 차트**: 일반 타월 대비 3배 빠른 모세관 흡수 메커니즘.
  2. **독일 더마테스트 엑설런트 인증서 원본 뷰어**: 민감 두피 자극 0.00 인증.

  4. **시험성적서 원본 PDF 다운로드 버튼**.

### [SCR-07] 프로 살롱 타월 드라이 가이드

### [SCR-09] 살롱 B2B 장바구니

* **화면 목적**: 대량 도매 수량, 자수 시안 메타데이터 최종 확인 및 공식 견적서 출력/결제 이동.
* **진입 조건**: GNB 장바구니 아이콘 클릭, 상품 상세 담기 완료.
* **종료 조건**: B2B 결제 이동(`SCR-10`), 견적서 다운로드.

## 5. 반응형 뷰포트 기준 및 접근성(A11y) 규격

### 5.1 반응형 브레이크포인트
* **PC (Desktop)**: `1200px 이상` (2컬럼 B2B 도매 견적 계산기, Canvas 자수 좌우 분할 뷰어)
* **태블릿 (Tablet)**: `768px ~ 1199px` (유동적 그리드, GNB 모바일 토글 지원)
* **모바일 (Mobile)**: `390px ~ 767px` (1컬럼 스택, 하단 고정 B2B 견적 바, 터치 최적화 48px 터치 타깃)

### 5.2 웹 접근성 (Accessibility) 지침
* **대체 텍스트 (Alt Text)**: 모든 살롱 터번 이미지 및 자수 렌더링에 명확한 대체 텍스트 제공 (`alt="루프 단추형 헤어 터번 40x100cm 다크 딥차콜 착용 컷"`).
* **키보드 접근성**: 모든 탭, 폼 인풋, 모달 닫기 버튼에 `tabindex="0"` 및 Focus ring 시각적 표시.
* **명도 대비 (Contrast)**: 본문 텍스트 최소 `4.5:1`, 핵심 버튼 텍스트 최소 `7:1` 대비율 준수 (WCAG AAA 규격).
