## 1. 서비스 흐름 개요

본 서비스 흐름도는 스페셜티 카페 및 감성 티룸을 운영하는 오너 바이어 '김티타임(고은서)'이 플랫폼에 접속하여 **Zero-Lint 무보풀 성능 확인 ➔ 글라스 티 타월 & 스팀완드 와입스 선택 ➔ 톤다운 컬러(오트밀/말차/모카) 선택 ➔ 카페 로고 실시간 자수 합성 ➔ B2B 도매 번들팩(20/50장) 수량별 최대 35% 할인 확인 ➔ 직인 견적서 PDF 출력 또는 사업자 세금계산서 신청 결제 ➔ 발주 완료 및 D-Day 납품 확약서 & 과탄산 세척 매뉴얼 수령**에 이르는 전 과정을 체계적으로 설계한 서비스 플로우 문서입니다.

와인잔/찻잔 보풀 및 물자국, 100℃ 고온 머신 스팀 노즐 관리, 차/커피 착색 얼룩 등 카페 현장의 고질적 문제를 완벽히 해결하는 구매 여정을 구축합니다.

| 사용자 유형 | 진입 경로 (Entry Point) | 시작 조건 및 심리 상태 | 목표 (Goal) |
| :--- | :--- | :--- | :--- |
| **카페/티룸 대표 오너 (고은서)** | 메인 홈 (`SCR-01`) 또는 커피 B2B 포털 검색 | "찻잔을 닦을 때 먼지가 남지 않고, 100℃ 머신 스팀 노즐을 위생적으로 관리할 수 있는 소창 린넨을 도매가로 발주하고 세금계산서를 받고 싶다." | B2B 도매 센터(`SCR-05`)에서 50장 번들 선택, 카페 로고 자수(`SCR-04`) 확인, 세금계산서 신청 후 발주 |
| **바리스타 / 매장 매니저** | GNB 린넨 샵 또는 SNS 광고 | "와인잔과 유리 티팟을 투명하게 닦을 수 있는 무먼지 티 타월과 스팀 와입스가 필요하다." | 글라스 티 타월 단품(`SCR-02`) + 스팀완드 와입스(`SCR-03`) 확인 후 장바구니 담기 |
| **안심 사전 체험자** | 상단 띠배너 3,000원 체험팩 배너 (`SCR-08`) | "우리 매장 와인잔과 머신에서 진짜 보풀이 안 남고 흡수가 빠른지 3,000원에 먼저 써보고 싶다." | 3,000원 바리스타 체험팩 신청 ➔ 100% 환급 쿠폰 수령 ➔ B2B 본품 재진입 |

## 4. 분기, 오류, 이탈 및 재진입 흐름 (Branching & Exception Flows)

1. **글라스웨어 광택 비교 인터랙티브 가이드 분기 (`MODAL-01`)**:
   - 상품 상세(`SCR-02`)에서 광택 비교 클릭 ➔ 일반 행주 vs 소창 타월 분할 슬라이더 모달 팝업 ➔ 무먼지 투명 광택 확인 ➔ 구매 옵션 복귀.
2. **카페 로고 파일 및 자수 유효성 검사 분기 (`VALID_LOGO`)**:
   - 로고 AI/PNG 파일 해상도 저하 또는 텍스트 12자 초과 시 ➔ 에러 안내 및 1:1 무료 벡터 보정 가이드 노출 ➔ 정상 파일 시 Canvas 실시간 3D 자수 렌더링 후 `MODAL-02` 확정.
3. **B2B 공식 견적서 PDF 출력 후 사내 품의 이탈/재진입 (`SCR-05 ➔ SCR-10`)**:
   - 도매 센터(`SCR-05`)에서 직인 날인 견적서 PDF 다운로드 후 사이트 이탈 ➔ 매장 품의 승인 후 알림톡 링크 또는 견적서 번호 입력으로 결제창(`SCR-10`) 즉시 재진입.
4. **국세청 사업자등록번호 유효성 검증 분기 (`SYS_TAX_AUTH`)**:
   - 사업자등록번호 10자리 입력 시 실시간 API 검증 ➔ 휴/폐업 또는 번호 오류 시 인라인 피드백 ➔ 정상 사업자 확인 시 세금계산서 100% 자동 발행 예약.
5. **바리스타 체험팩 신청 후 B2B 도매 재진입 (`SCR-08 ➔ SCR-05`)**:
   - 3,000원 체험팩 수령 후 동봉된 100% 환급 쿠폰 번호를 도매 주문서(`SCR-10`)에 입력하여 전액 할인 적용.

## 5. 단계별 서비스 상세 흐름표 (Step-by-Step Matrix)

| 단계 | 사용자 행동 (User Action) | 시스템 처리 (System Action) | 표시 화면 (Screen) | 다음 조건 (Next Condition) |
| :---: | :--- | :--- | :--- | :--- |
| **01. 진입** | 메인 홈 접속 및 글라스 광택 비교 퀵 뷰어 확인 | 세금계산서 즉시 발행 띠배너 및 카페 베스트 린넨 라인업 로드 | `SCR-01 메인 홈` | 글라스 타월 클릭 시 02단계 이동 |
| **02. 탐색** | Zero-Lint 글라스 티 타월(40x60cm) 또는 스팀 와입스 클릭 | 톤다운 3종 컬러 스와치 및 와인잔 래핑 실사 컷 로드 | `SCR-02 타월 상세` / `SCR-03 와입스` | `[광택 비교 뷰어]` 클릭 시 모달 분기 |
| **03. 검증** | `[광택 비교 뷰어]` 클릭 또는 식품 위생 시험성적서 확인 | 모달 팝업 호출 및 분할 슬라이더/KTR 식품위생 성적서 렌더링 | `MODAL-01 뷰어` / `SCR-06 검증실` | 확인 완료 후 `[B2B 도매 발주]` 클릭 |
| **04. 커스텀** | 카페 BI 로고 업로드 또는 카페명 입력 & 자수 실 색상 선택 | Canvas 엔진이 0.05초 만에 린넨 원단 위 톤온톤 자수 그래픽 합성 | `SCR-04 자수 아틀리에` / `MODAL-02` | 유효성 통과 시 `[도매 발주 센터]` 이동 |
| **05. 도매/견적** | 발주 수량(20장/50장/100장) 선택 및 실시간 도매 단가 확인 | 수량별 할인율(최대 35%) 연산 및 직인 견적서 PDF 1초 생성 | `SCR-05 도매 센터` / `SCR-09 장바구니` | 품의 승인 후 `[결제하기]` 클릭 |
| **06. 결제/세무** | 사업자등록번호 입력 및 세금계산서 신청 체크 후 법인 결제 | 국세청 사업자 실시간 API 검증, 세금계산서 자동 발행 예약 | `SCR-10 B2B 결제` | 결제 승인 완료 시 07단계 이동 |
| **07. 완료** | 발주 완료 확인, D-Day 납품 확약서 및 과탄산 세척 매뉴얼 확인 | D-Day 확약서 PDF 다운로드 링크 생성 및 전자세금계산서 전송 | `SCR-11 발주 완료` | 배송 트래킹 및 발주 종료 |
