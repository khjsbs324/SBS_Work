## 협의 준비

- 기존 프로젝트의 목적: DAMORI가 기록을 시작하기 어렵거나 중단된 사용자가 자신의 속도에 맞춰 기록을 다시 이어가도록 돕는 HOME 웹페이지를 구축한다. 첫 화면의 브랜드 약속에서 기록 관점, 기록 흐름, 기록 방식, 상품 탐색으로 이어지는 이해 가능한 경험을 제공한다.
- 주요 사용자: 기록을 시작하고 싶지만 부담을 느끼는 사용자, 멈춘 기록을 다시 이어가려는 사용자, 아날로그와 디지털 기록 방식 중 자신에게 맞는 방법을 비교하려는 사용자. 모바일 우선 탐색 사용자도 포함한다.
- 현재 납품·완료 범위: HOME 메인페이지 초안 HTML과 관련 스토리보드·화면설계 기준. PRODUCTS·BRAND 페이지와 구매·결제 기능은 이번 HOME 검토 범위에 포함하지 않는다.
- 유지보수 계약 범위: 미확정. 실제 계약 조건은 클라이언트 확인 후 작성한다.
- 협의 전 확인한 자료: `메인페이지_웹디자인_수정본.html`, DAMORI HOME 최신 스토리보드, HOME 화면설계서, 레퍼런스 장점분석 자료.

## 협의 요약

- 클라이언트가 가장 중요하게 생각한 내용: HOME에서 브랜드 약속→기록 관점→4단계 흐름→투트랙 선택→상품 탐색이 자연스럽게 이어지고, 대표 3개·보조 12개의 정보 위계가 유지되는 것.
- 기존 요청과 달라진 내용: 상품 이미지·가격·거래 기능은 확정 전 상태로 제한하고, 원본 수정 대신 별도 최종본을 사용하며, 접근성·CSS 구조·검증 추적성 기준을 명시적으로 추가함.
- 추가 확인이 필요한 내용: 실제 상품 이미지와 라이선스 Source, 가격·거래 문구, 브라우저별 렌더링·키보드 입력·대비·reduced-motion, 잔여 CSS 가상요소의 미사용 여부.
- 다음 협의 일정: 브라우저 연결 및 자산 Source 확보 즉시 재검증 후 최종 승인 협의.
