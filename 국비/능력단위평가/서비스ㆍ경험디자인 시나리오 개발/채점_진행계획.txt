1단계 — 평가와 제출 현황 대조

- 학생명과 사이트 식별자를 대조하고 제출 완료·미제출·열람 불가를 구분한다.
- 기존 점수나 피드백이 있다면 먼저 보존하고 현재 상태를 기록한다.
- 대상이나 기준이 다르면 차이를 정리하고 해당 항목을 임의로 저장하지 않는다.

2단계 — 학생별 제출물 수령과 보존
- 제출된 PDF와 선택 원본을 학생별로 정리한다.
- 파일명·크기·SHA-256·수령 시각·학생 식별자를 기록하고 원본을 보존한다.
- 여러 버전이면 사이트 제출 기록을 기준으로 최종본을 구분한다.
- 기존 관찰조사 자료는 시나리오의 입력 근거를 확인할 때만 사용한다.
- 이전 평가의 점수·결함·등록 상태를 이번 채점에 그대로 적용하지 않는다.

3단계 — PDF 전체 검토 및 증빙 지도 작성
- PDF 전체를 읽어 서비스 가치, 이해관계자, 페르소나, 상황·접점, 단계, 시나리오 표현, 문제 분석, 평가, 수정 결과를 파악한다.
- 각 항목의 근거를 PDF 페이지·절·표·장면·기록 ID로 연결한다.
- 표·흐름도·스토리보드는 실제 화면으로 확대해 관계와 가독성을 확인한다.
- 텍스트 추출만으로 읽히지 않는 스캔·작은 도표는 이미지로 판독한다.
- 정해진 칸이 비어 있어도 다른 절에 동등한 증빙이 있는지 먼저 확인한다.
- 열리지 않거나 판독할 수 없는 자료는 임의 0점 대신 확인 불가 범위와 필요한 자료를 기록한다.

- 글·표·흐름도·스토리보드 중 선택한 방식으로 판단할 수 있으면 인정한다. 특정 표현 도구를 새로 강제하지 않는다.

- 모의 자료·가설·AI 제안·실제 반응을 구분하고, 실제 성과로 확대 해석했는지를 확인한다.

- SC-07은 잠재 문제 분석, SC-09는 평가 결과와 개선 계획의 연결, SC-10은 최종 반영·문서화로 판단 대상을 구분한다.
- 평가 증빙의 동일한 공백을 여러 문항에서 반복 감점하지 않는다.

6단계 — 점수 계산과 학생별 피드백 작성

- 글자수·문단수를 고정하지 않고 학생의 실제 내용과 문제의 복잡성에 맞춘다.
