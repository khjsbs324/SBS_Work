[P01-L1667] 1. 서비스명
[P01-L1668] MY ROUTINE
[P01-L1669] 사용자의 현재 필요에 맞는 NUNID 제품을 조합해 하나의 간결한 뷰티 루틴으로 추천하는 개인 맞춤형 서비스.
[P01-L1670] 2. 서비스 개요
[P01-L1671] 사용자가 원하는 루틴 방식, 가장 신경 쓰이는 피부 고민, 필요한 컬러 기능을 선택하면 조건에 적합한 NUNID 제품을 조합해 추천한다.
[P01-L1672] 추천 제품은 최대 4개로 제한하며, 제품 조합뿐 아니라 실제 사용 순서와 간단한 사용 방법까지 함께 안내한다.
[P01-L1673] 추천 결과에서는 제품을 개별 또는 한 번에 구매할 수 있으며, 추천 조합과 기존 SET 상품이 일치하는 경우 세트 구매 옵션도 함께 제공한다.

[P01-L1699] 4. 추천 결과 및 주요 기능
[P01-L1700] 선택한 조건을 바탕으로 사용자에게 필요한 제품을 최대 4개까지 추천한다.
[P01-L1701] 추천 결과는 실제 사용 순서에 따라
[P01-L1702] STEP 01 → STEP 02 → STEP 03 → STEP 04
[P01-L1703] 형태로 보여주며, 각 제품의 추천 이유와 간단한 사용 방법을 함께 안내한다.
[P01-L1704] 불필요하게 많은 제품이나 역할이 겹치는 제품은 함께 추천하지 않는다.
[P01-L1705] 주요 기능
[P01-L1706] 제품 상세 보기 — 추천 제품의 상세 정보 확인
[P01-L1707] 개별 구매 / 전체 담기 — 원하는 제품만 구매하거나 추천 제품을 한 번에 장바구니에 추가
[P01-L1708] SET 상품 제안 — 추천 조합과 동일한 세트가 있을 경우 해당 SET 상품 안내
[P01-L1709] 루틴 저장 — 마음에 드는 추천 결과 저장
[P01-L1710] 이전 루틴 확인 — 과거에 추천받은 루틴 다시 확인
[P01-L1711] 루틴 공유 — 추천 결과의 핵심 정보를 이미지 형태로 저장하거나 공유
[P01-L1712] 5. 서비스 목적
[P01-L1713] 사용자가 여러 제품을 직접 비교하지 않아도 자신의 필요에 맞는 제품과 사용 순서를 빠르게 찾을 수 있도록 한다.
[P01-L1714] 이를 통해 제품 선택에 대한 부담을 줄이고, NUNID가 추구하는 필요한 기능 중심의 제품 선택과 간결한 뷰티 루틴을 디지털 서비스 경험으로 확장한다.
[P01-L1715] 또한 개인화된 추천 결과를 제품 상세 및 구매와 자연스럽게 연결해 브랜드 제품에 대한 이해와 구매 경험을 함께 높이는 것을 목표로 한다.
