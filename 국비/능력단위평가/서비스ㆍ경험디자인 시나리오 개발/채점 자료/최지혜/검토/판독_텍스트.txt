[P01-L0001] 서비스 기획 내용
[P01-L0002] 서 비스 개요
[P01-L0003] 플로뜰리에는 소창 타월을 중심으로 단순히 제품을 판매하는 쇼핑몰을 넘어, 사용자가 자신의 생활 방식과 취향에 맞는 욕실 경험을 만들어갈 수 있도록 기획한 라이프스타일 기반 타월 브랜드 서비스입니다.
[P01-L0004] 서비스는 제품 탐색과 구매뿐만 아니라 개인의 취향을 반영한 큐레이션, 소창 사용 기록, 제품 관리 및 리사이클링 등 구매 전후의 경험을 하나의 흐름으로 연결하는 것을 목표로 합니다.
[P01-L0005] 이를 통해 사용자가 타월을 단순한 일회성 소비재가 아니라, 자신의 생활 속에서 지속적으로 사용하고 관리하는 물건으로 경험할 수 있도록 합니다.
[P01-L0006] 서비스 기획 목적
[P01-L0007] 기존 타월 쇼핑몰은 대부분 상품의 크기, 색상, 가격, 소재 등의 정보를 중심으로 제품을 판매합니다.
[P01-L0008] 플로뜰리에는 이러한 상품 중심의 구조에서 확장하여 사용자의 취향, 생활 방식, 피부 상태, 사용 습관 등을 서비스에 반영하고자 합니다.
[P01-L0009] 주요 목적은 다음과 같습니다.
[P01-L0010] 사용자의 욕실 취향에 맞는 공간 분위기와 제품을 제안합니다.
[P01-L0011] 사용자의 피부 상태 및 사용 방식에 적합한 타월을 찾을 수 있도록 돕습니다.
[P01-L0012] 구매 이후에도 소창 사용 과정을 기록하고 관리할 수 있도록 합니다.
[P01-L0013] 손상되거나 오래 사용한 제품을 수선 및 리사이클링 서비스와 연결합니다.
[P01-L0014] 사용자의 기록과 취향 데이터를 지속적으로 축적하여 브랜드 재방문을 유도합니다.
[P01-L0015] 즉, 제품 탐색 → 개인화 → 구매 → 사용 → 기록 → 관리 → 재사용으로 이어지는 장기적인 브랜드 경험을 만드는 것이 서비스의 핵심입니다.
[P01-L0016] 전체 IA 구조
[P01-L0017] 현재 IA는 크게 HOME, MY, 기록, 리사이클링, 큐레이션의 다섯 영역으로 구성되어 있습니다.
[P01-L0018] HOME
[P01-L0019] HOME은 사용자가 브랜드와 제품을 처음 탐색하는 영역입니다.
[P01-L0020] 메인 배너를 통해 브랜드 콘텐츠와 주요 상품을 노출하고, 검색 기능을 통해 원하는 제품을 직접 찾을 수 있도록 구성합니다.
[P01-L0021] 또한 BEST 상품과 FAVE 상품 등을 제공하여 처음 방문한 사용자도 쉽게 제품을 탐색할 수 있도록 합니다.
[P01-L0022] 주요 기능은 다음과 같습니다.
[P01-L0023] 메인 배너
[P01-L0024] 상품 검색
[P01-L0025] BEST 상품
[P01-L0026] FAVE 상품
[P01-L0027] 상품 상세 확인
[P01-L0028] 상품 구매 연결
[P01-L0029] HOME은 플로뜰리에의 브랜드와 커머스를 처음 경험하는 진입점 역할을 합니다.
[P01-L0030] MY
[P01-L0031] MY는 사용자의 쇼핑 및 서비스 이용 정보를 관리하는 개인 영역입니다.
[P01-L0032] 단순한 회원정보 관리 페이지가 아니라 주문, 혜택, 리뷰, 문의 등 사용자가 브랜드와 관계를 유지하기 위해 필요한 기능을 통합합니다.
[P01-L0033] 주요 기능은 다음과 같습니다.
[P01-L0034] 쿠폰 및 혜택
[P01-L0035] 포인트
[P01-L0036] 포인트 적립 내역
[P01-L0037] 리뷰 관리
[P01-L0038] 자주 묻는 질문
[P01-L0039] 문의하기
[P01-L0040] 나의 문의
[P01-L0041] 주문 내역
[P01-L0042] 주문 취소 및 관리
[P01-L0043] 회원정보 관리
[P01-L0044] 기본 배송지 관리
[P01-L0045] 배송지 변경
[P01-L0046] 로그인
[P01-L0047] 회원가입 및 계정 관련 기능
[P01-L0048] 사용자가 상품을 구매한 이후 발생하는 대부분의 활동을 MY 영역에서 관리할 수 있도록 구성합니다.
[P01-L0049] 기록 서비스
[P01-L0050] 플로뜰리에의 차별화 기능 중 하나는 소창을 사용한 경험을 기록할 수 있는 기능입니다.
[P01-L0051] 소창은 세탁과 사용을 반복하면서 질감과 사용감이 변화하는 소재이기 때문에, 이러한 변화를 하나의 사용 경험으로 기록할 수 있도록 기획합니다.
[P01-L0052] 현재 IA에서는 이를 30일 소창 기록 형태로 제공합니다.
[P01-L0053] 주요 기능은 다음과 같습니다.
[P01-L0054] 30일 소창 기록
[P01-L0055] 달력 형태의 기록 확인
[P01-L0056] 리스트 형태의 기록 확인
[P01-L0057] 기록 작성
[P01-L0058] 사용자는 자신이 사용하고 있는 소창의 상태나 변화 과정을 일정 기간 동안 기록할 수 있습니다.
[P01-L0059] 이를 통해 구매 이후에도 사용자가 지속적으로 브랜드 서비스에 방문할 수 있도록 유도할 수 있습니다.
[P01-L0060] 이 기능은 플로뜰리에가 제품을 판매하고 관계가 끝나는 브랜드가 아니라, 제품을 사용하는 과정까지 함께하는 브랜드라는 이미지를 형성하는 데 목적이 있습니다.
[P01-L0061] 리사이클링 서비스
[P01-L0062] 리사이클링은 사용하던 제품이 손상되었을 때 이를 바로 버리는 대신, 상태를 확인하고 다시 활용할 수 있도록 연결하는 서비스입니다.
[P01-L0063] 사용자가 제품의 손상 상태를 입력하면 해당 정보를 바탕으로 수선 또는 리사이클링 가능 여부를 확인할 수 있도록 구성합니다.
[P01-L0064] 기본 이용 흐름은 다음과 같습니다.
[P01-L0065] 손상 정보 입력 → 수선 가능 여부 확인 → 정보 확인 → 리사이클링 또는 후속 서비스 연결
[P01-L0066] 사용자는 제품의 상태를 직접 입력하고, 입력한 내용을 확인한 뒤 적절한 방법을 선택하게 됩니다.
[P01-L0067] 이 서비스는 단순히 친환경 메시지를 전달하는 것이 아니라, 실제로 제품의 사용 수명을 연장하는 행동을 서비스 안에서 지원한다는 점에 의미가 있습니다.
[P01-L0068] 큐레이션 서비스
[P01-L0069] 큐레이션은 사용자의 취향 또는 상태를 파악하여 적합한 공간 분위기와 제품을 제안하는 개인화 영역입니다.
[P01-L0070] 현재 기획에서는 크게 두 가지 개인화 방향으로 구분할 수 있습니다.
[P01-L0071] 8-1. 욕실 취향 기반 큐레이션
[P01-L0072] 사용자가 좋아하는 욕실 분위기, 색상, 소재, 가구 및 이미지 등을 선택하면 취향을 분석하여 적합한 욕실 분위기를 제안하는 기능입니다.
[P01-L0073] 사용자가 상품을 먼저 선택하는 것이 아니라, 자신이 원하는 공간의 분위기를 먼저 발견하고 그 결과를 상품과 연결하는 방식입니다.
[P01-L0074] MY BATHROOM MOOD 서비스가 이 영역에 해당합니다.
[P01-L0075] 사용자가 선택하는 주요 항목은 다음과 같습니다.
[P01-L0076] 선호하는 욕실 이미지
[P01-L0077] 컬러
[P01-L0078] 소재
[P01-L0079] 가구 및 수납 방식
[P01-L0080] 욕실 분위기
[P01-L0081] 원하는 공간 이미지
[P01-L0082] 이러한 응답을 종합하여 사용자의 욕실 무드를 도출하고 결과 페이지를 제공합니다.
[P01-L0083] 8-2. 피부 및 사용 습관 기반 큐레이션
[P01-L0084] 사용자의 피부 상태와 타월 사용 방식을 바탕으로 적합한 소창 타월을 추천하는 기능입니다.
[P01-L0085] 사용자의 피부 상태뿐만 아니라 실제 사용 방법까지 함께 고려합니다.
[P01-L0086] 주요 질문 항목은 다음과 같습니다.
[P01-L0087] 세안 및 샤워 후 피부 당김
[P01-L0088] 피부 붉어짐 및 자극 정도
[P01-L0089] 피부 건조 및 각질
[P01-L0090] 피부 유분 및 땀
[P01-L0091] 트러블 발생 정도
[P01-L0092] 피부 민감도
[P01-L0093] 수건 사용 부위
[P01-L0094] 선호하는 수건 촉감
[P01-L0095] 흡수력 및 건조 속도 선호
[P01-L0096] 수건 사용 방법
[P01-L0097] 수건 세탁 주기
[P01-L0098] 이 데이터를 바탕으로 단순히 인기 상품을 보여주는 방식이 아니라, 사용자의 실제 사용 환경에 적합한 타월을 안내하는 개인화 서비스를 제공합니다.
[P01-L0099] 기본 커머스 User Flow
[P01-L0100] 사용자가 상품을 구매하는 기본 흐름은 일반적인 쇼핑 과정과 연결됩니다.
[P01-L0101] 대표 흐름은 다음과 같습니다.
[P01-L0102] 사이트 접속 → HOME → 상품 탐색
[P01-L0103] 이후 사용자는 검색이나 상품 콘텐츠를 통해 제품을 찾습니다.
[P01-L0104] 검색 / BEST / FAVE → 상품 확인 → 상품 상세
[P01-L0105] 상품 상세 페이지에서 제품의 정보와 옵션을 확인한 뒤 구매 행동으로 이동합니다.
[P01-L0106] 상품 선택 → 장바구니 → 상품 확인 → 주문 → 배송정보 → 결제 → 주문 완료
[P01-L0107] 회원 여부에 따라 로그인 또는 회원가입 과정이 구매 과정과 연결됩니다.
[P01-L0108] 구매 완료 후에는 MY 영역을 통해 주문 정보를 확인할 수 있습니다.
[P01-L0109] 개인화 서비스 User Flow
[P01-L0110] 커머스와 별도로 큐레이션을 통한 제품 탐색 경로를 제공합니다.
[P01-L0111] 기본 구조는 다음과 같습니다.
[P01-L0112] 큐레이션 진입 → 질문 응답 → 사용자 취향 또는 상태 분석 → 결과 확인 → 적합한 제품 확인 → 상품 상세 → 장바구니 및 구매
[P01-L0113] 이 과정의 특징은 사용자가 처음부터 상품을 찾는 것이 아니라, 자신에 대한 질문에 답하는 것에서 쇼핑이 시작된다는 점입니다.
[P01-L0114] 따라서 사용자는 제품명을 정확히 알지 못하더라도 자신의 취향이나 피부 상태만으로 적합한 제품을 발견할 수 있습니다.
[P01-L0115] 구매 이후 User Flow
[P01-L0116] 플로뜰리에의 서비스는 구매 완료 이후에도 지속됩니다.
[P01-L0117] 대표적인 흐름은 다음과 같습니다.
[P01-L0118] 사용 기록
[P01-L0119] 제품 구매 → 사용 시작 → 30일 소창 기록 → 달력 또는 리스트 확인 → 지속 기록
[P01-L0120] 제품 관리
[P01-L0121] 제품 사용 → 제품 손상 발생 → 리사이클링 서비스 → 손상 상태 입력 → 수선 또는 재활용 여부 확인
[P01-L0122] 사용자 관계 유지
[P01-L0123] 구매 → MY → 리뷰 작성 / 포인트 확인 / 주문 관리 / 문의
[P01-L0124] 따라서 플로뜰리에의 User Flow는 구매 완료를 서비스 종료 지점으로 설정하지 않고, 사용과 관리 과정까지 하나의 사용자 여정으로 연결합니다.
[P01-L0125] 서비스 구조의 핵심 특징
[P01-L0126] 현재 IA와 User Flow를 종합하면 플로뜰리에의 서비스는 크게 네 가지 경험으로 정리할 수 있습니다.
[P01-L0127] SHOP
[P01-L0128] 제품을 발견하고 구매하는 경험입니다.
[P01-L0129] CURATION
[P01-L0130] 자신의 취향과 상태를 발견하고 적합한 제품을 찾는 경험입니다.
[P01-L0131] RECORD
[P01-L0132] 구매한 제품을 실제 생활 속에서 사용하고 그 변화를 기록하는 경험입니다.
[P01-L0133] RECYCLING
[P01-L0134] 사용한 제품을 관리하고 다시 활용하는 경험입니다.
[P01-L0135] 이를 하나의 사용자 여정으로 표현하면 다음과 같습니다.
[P01-L0136] Discover → Curate → Purchase → Use → Record → Care → Reuse
[P01-L0137] 즉,
[P01-L0138] 발견 → 개인화 → 구매 → 사용 → 기록 → 관리 → 재사용
[P01-L0139] 으로 이어지는 순환 구조입니다.
[P01-L0140] 서비스 핵심 가치
[P01-L0141] 플로뜰리에 서비스에서 중요한 것은 각각의 기능을 개별적으로 제공하는 것이 아니라, 사용자의 생활 경험을 중심으로 기능들이 서로 연결된다는 점입니다.
[P01-L0142] 일반적인 쇼핑몰이 상품 탐색 → 구매에서 사용자 경험이 종료된다면, 플로뜰리에는 그 이후의 사용 경험까지 확장합니다.
[P01-L0143] 나의 취향 발견 → 나에게 맞는 제품 선택 → 구매 → 사용 → 기록 → 관리 → 다시 사용하는 경험
[P01-L0144] 이러한 흐름을 통해 플로뜰리에는 단순한 소창 타월 쇼핑몰이 아니라, 개인의 욕실 취향과 생활 습관을 발견하고 제품의 선택부터 사용과 관리까지 함께하는 욕실 라이프스타일 서비스로 확장하고자 합니다.
[P01-L0145] 한 문장 요약
