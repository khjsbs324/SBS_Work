# 서비스ㆍ경험디자인 시나리오 개발 평가자료

이 평가는 기존 서비스 기획과 사용자 자료를 바탕으로 페르소나 중심의 서비스 시나리오를 기획·구조화·제작하고, 대내외 관점의 타당성 평가 결과에 따라 문제점을 보완하는 포트폴리오형 능력단위평가다.

## 파일 구성

| 파일 | 대상 | 용도 |
|---|---|---|
| `01_강사용_수업진행안.md` | 강사 | 평가 준비, 240분 진행, 관찰과 회수 방법 |
| `02_학생용_과제안내서.md` | 학생 | 과제 목표, 작업 순서와 제출 규칙 |
| `03_학생_제출_산출물.md` | 학생 | 작성 양식과 최종 제출 확인 |
| `04_강사용_정답_및_채점표.md` | 강사 | 직접 증빙 확인법과 10문항 채점표 |
| `05_학생공개용_채점기준.md` | 학생 | 평가 영역과 성취 수준 안내 |

## 기준 자료

- 상위 폴더의 원본 NCS 학습모듈 PDF
- 상위 폴더의 `서비스ㆍ경험디자인 시나리오 개발 수행준거.txt`
- 상위 폴더의 `Exam.md`
- 상위 폴더의 `AGENTS.md`와 `피드백.md`

## 배포 구분

2. `03_학생_제출_산출물.md`
