# 능력단위평가 공통 에이전트 지침

## 목적과 폴더 원칙

이 폴더는 NCS 능력단위평가의 문제 제작, 채점, 피드백 및 결과 관리를 위한 공통 작업공간이다.

- 루트에는 모든 평가에 공통인 지침, 스킬, 출제 예시, 학생 저장소 목록과 피드백 기준만 둔다.
- 평가별 하위 폴더에는 해당 평가의 NCS 원본, 수행준거, 문제·정답 코드, `Exam.md`, 시험지, 산출물과 채점 결과를 둔다.
- 서로 다른 평가의 원본, 코드, 정답과 채점 결과를 섞지 않는다.
- 평가별 지침이 필요하면 공통 문서를 해당 평가 폴더로 복제한 뒤 그 복제본만 구체화한다.

## 적용 우선순위

1. 사용자의 최신 지시
2. 선택한 평가 폴더의 `AGENTS.md`, `CLAUDE.md`, `피드백.md`
3. 선택한 평가의 NCS 원본과 수행준거
4. 선택한 평가의 문제 코드와 정답
5. 루트 공통 지침과 `skills/ncs-exam-production/`
6. `문제 출제 예시.pdf` 등 참고 자료

충돌이 있으면 상위 항목을 우선하고 판단을 결과에 기록한다.

## 작업 시작 절차

1. 사용자가 지정한 능력단위명과 일치하는 하위 폴더를 확정한다.
2. 이름이 모호하거나 후보가 여러 개면 추측하지 말고 확인한다.
3. 해당 평가 폴더의 구조와 전용 지침을 먼저 읽는다.
4. PDF 분석, 시험 출제, 채점 또는 사이트 등록에는 `skills/ncs-exam-production/SKILL.md`를 사용한다.
5. 선택하지 않은 다른 평가 폴더는 수정하지 않는다.

## 문제 제작 공통 원칙

- 수행준거 원문, 순서와 개수를 보존하고 요구사항 및 채점 문항과 일대일로 연결한다.
- 수행준거마다 직접 증빙과 구체적인 4단계 점수 구간을 작성한다.
- 별도 지시가 없으면 문항별 배점은 정수이며 합계는 100점이다.
- 학생 시작 코드와 강사용 정답을 분리하고 학생용 자료에 정답을 노출하지 않는다.
- 같은 평가 폴더의 코드와 원본만 기준으로 사용한다.
- 요구되지 않은 백엔드, 데이터베이스, 서버, 프레임워크 또는 배포 조건을 추가하지 않는다.
- 한글 UTF-8, 상대 경로, 내부 링크, 파일 존재 여부와 코드 연결 순서를 검증한다.

## 채점 트리거와 입력

사용자가 `채점 진행해줘`라고 입력하면 먼저 `채점할 능력단위명을 입력해주세요.`라고 묻고 다음 답을 기다린다.

능력단위명이 확정되면 다음 자료를 확인한다.

- 해당 평가 폴더의 수행준거 파일
- 해당 평가 폴더의 `Exam.md` 또는 시험 제작 자료
- 루트 또는 평가 폴더의 `피드백.md`
- 루트 또는 평가 폴더의 `평가_리포지터리_주소.txt`

필수 자료가 없으면 다른 평가 자료로 대체하지 말고 누락 항목을 보고한다.

## 채점 공통 원칙

1. 학생명, 저장소 URL, 리포지터리명, 기본 브랜치와 채점 커밋을 기록한다.
2. 학생 저장소는 읽기 전용으로 검토하고 학생 코드를 수정하거나 push하지 않는다.
3. 수행준거별 직접 증빙을 수집하고 `Exam.md`의 기준으로 절대평가한다.
4. 확인하지 못한 동작은 통과로 추정하지 않고 보류 사유를 기록한다.
5. 동일한 결함을 여러 문항에서 중복 감점하지 않는다.
6. 모든 학생에게 코드 피드백과 화면 피드백을 작성한다.
7. 학생 공개용 피드백에는 내부 점수 산식, 순위 또는 강사용 정답 전체를 노출하지 않는다.
8. 결과는 해당 평가 폴더의 `채점 완료/<학생 이름>.txt`에 저장한다.

평가별 규칙이 없으면 다음 공통 환산식을 사용한다.

```text
등록총점 = ROUND(60 + (원점수 × 0.4), 0)
문항별 이상적 등록점수 = 문항 배점 × 0.6 + 문항 원점수 × 0.4
```

문항별 점수는 이상적 등록점수를 내림한 뒤 최대잔여법으로 배분하며 합계가 등록총점과 같아야 한다.

## 사이트 등록 안전 원칙

- 로컬 결과가 완성되고 검증된 학생만 등록한다.
- 사이트 과정명, 능력단위명, 수행준거와 학생명을 로컬 자료와 대조한다.
- 학생 매칭, 수행준거 수, 기존 점수 또는 권한이 불명확하면 저장하지 않는다.
- 입력 후 상세 화면에서 학생명, 문항별 점수, 총점과 피드백을 다시 확인한다.
- 확인 시각과 결과를 해당 평가의 학생별 결과 파일에 기록한다.

## 완료 검증

- 선택한 능력단위명과 작업한 하위 폴더가 일치한다.
- 수행준거 수와 문항 수가 일치하고 배점 합계가 정확하다.
- 모든 점수에 직접 증빙 또는 미확인 사유가 있다.
- 학생 수, 저장소 수와 결과 파일 수가 일치한다.
- 학생용과 강사용 자료가 분리되어 있다.
- 다른 능력단위평가의 자료가 변경되지 않았다.
- 한글 인코딩, 경로, 링크와 파일 존재 여부를 확인했다.

## 검토 역할

- NCS 원문 및 수행준거 추적성: `.agents/ncs-source-analyst.md`
- 프론트엔드 문제·정답 및 학생 코드: `.agents/frontend-exam-reviewer.md`
- 산출물, 총점, 피드백 및 등록 결과: `.agents/assessment-qa-reviewer.md`

최종 판단과 외부 사이트 등록 책임은 주 에이전트가 맡는다.
