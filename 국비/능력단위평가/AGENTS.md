# 능력단위평가 공통 지침

NCS 평가의 원본·시험·제출물·채점 결과는 능력단위별 폴더에서 관리한다. 이 폴더에는 공통 출제 예시와 피드백 지침을 둔다. 자동화는 상위 국비 폴더의 [.agents/skills](../.agents/skills)와 [scripts](../scripts)에 둔다.

## 기준 자료

요청·대화·현재 평가 폴더에서 대상을 확정하고 해당 폴더의 AGENTS.md와 피드백.md를 읽는다. 원문·수행준거는 문장·순서·개수의 기준이며 Exam.md는 현재 과제·배점·제출 방식의 기준이다. 사용자 최신 지시와 평가 전용 조건을 우선한다. 서로 다른 평가의 정답·결함·제출 조건·학생 결과를 섞지 않는다.

- 수행준거와 문항을 일대일로 연결하고 직접 증빙 및 문항별 4단계 점수 구간을 작성한다.
- 별도 지시가 없으면 정수 배점 합계는 100점이다. 총점 100점 평가의 공통 환산 및 최대잔여법은 [채점 절차](../.agents/skills/ncs-exam-production/references/grading.md)에만 정의한다.
- 학생용 안내·서식과 강사용 정답·판단 기록을 구분한다. 학생 제출물과 코드를 수정하거나 push하지 않는다.
- 해당 평가가 요구하지 않는 코드·브라우저·백엔드·배포·실제 제3자 증빙을 추가하지 않는다.
- 모든 점수는 직접 증빙에 연결한다. 확인하지 못한 동작을 통과로 쓰거나 미판독을 임의 0점으로 처리하지 않는다. 같은 원인으로 반복 감점하지 않는다.
- 공개 피드백의 문체와 근거 기준은 [피드백.md](피드백.md)를 사용한다. 기존 전용 피드백.md에는 해당 평가의 차이만 추가한다.

## 작업 절차와 검증

[ncs-exam-production](../.agents/skills/ncs-exam-production/SKILL.md)에서 출제·채점·등록 중 필요한 절차를 사용한다. 이미 확정된 능력단위명을 다시 묻지 않는다. 새 전용 지침은 공통 문서를 복제하지 말고 실제 차이만 작성한다.

`최종 결과 산출물/`은 평가별 전달 자료, `채점 자료/`는 제출물·근거, `채점 완료/`는 완성된 학생별 결과다. 폴더와 빈 완료 기록을 미리 만들지 않는다.

국비 폴더의 `python -B scripts/harness.py check --records`로 Exam·수행준거 ID·채점 JSON의 계산을 확인한다. 원문 PDF 대조·학생별 증빙의 타당성·정답 노출·실제 사이트 저장은 해당 절차에서 별도로 검토한다. 학생 수와 제출물·결과 파일 수도 대조한다.

기존 평가 폴더의 `.검증/`는 과거 생성·채점·등록 기록이다. 그 안의 스크립트는 파일을 덮어쓰거나 완료 시각을 변경할 수 있으므로 검증 목적으로 일괄 실행하지 않는다. 현재 공통 검증은 읽기 전용 harness.py를 사용한다.
