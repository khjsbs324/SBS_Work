# 구현 학생 공개용 채점기준

## 평가 개요

- 개인평가 240분
- 제출: `이름_구현.zip`, `이름_구현보고서.pdf`
- 총점: 100점

## 평가 영역

### 1. 콘텐츠 구현하기 — 32점

- 프로젝트 목적과 디자인 방향에 맞게 전체 콘텐츠를 구조화했는가
- 콘텐츠의 위계와 특성에 맞는 화면·탐색 흐름을 제시했는가
- 필요한 멀티미디어·상호작용 기능을 구현 가능한 수준으로 제안했는가

### 2. 기능 요소 구현하기 — 34점

- 웹 브라우저, 데스크톱·모바일 등 대상 매체에 맞게 콘텐츠를 구현했는가
- 프로젝트 목적에 필요한 디지털 미디어 기능요소를 제작했는가
- HTML·CSS·JavaScript와 자산이 로컬에서 안정적으로 작동하는가

### 3. 개발 요소 구현하기 — 34점

- 실제 검토 의견 또는 강사 제공 이슈를 기술 문제와 연결해 처리했는가
- 개발에 필요한 디자인 수치·상태·자산·반응형 정보를 명확하게 전달했는가
- 협의 결과를 반영해 수정하고 기능·성능·접근성을 다시 확인했는가

## 높은 평가를 받는 결과

- 사이트맵·화면·기능·파일과 보고서의 ID가 서로 연결된다.
- 핵심 과업을 데스크톱과 모바일에서 끝까지 수행할 수 있다.
- 기능의 정상 상태뿐 아니라 오류·빈 상태와 대안을 고려했다.
- 협업 이슈마다 반영·보류·제외 이유와 실제 구현 결과가 있다.
- ZIP을 다른 폴더에 풀어도 별도 수정 없이 실행된다.
- 수정 전후와 재검증 조건·결과를 직접 확인할 수 있다.

## 유의 사항

- 화려한 애니메이션이나 기능 개수만으로 높은 점수를 받지 않습니다.
- 특정 프레임워크, 외부 배포, 서버·데이터베이스는 필수가 아닙니다.
- 실제 검토 의견과 강사 제공 이슈를 구분하고 응답을 임의로 만들지 않습니다.
- 보고서 설명과 실제 코드·브라우저 동작이 다르면 실제 결과를 기준으로 평가합니다.
