# 구현 평가자료

개인 브랜딩 포트폴리오 사이트의 콘텐츠 구조·시각적 흐름·기능 요소를 브라우저에서 실행 가능하게 구현하고, 개발 전달·협업 이슈·수정·재검증을 거쳐 결과물을 최적화하는 개인 포트폴리오 평가다.

- `01_강사용_수업진행안.md`: 240분 운영, 강사 제공 이슈와 회수·검증 절차
- `02_학생용_과제안내서.md`: 구현 범위, 제출 규칙과 평가 핵심
- `03_학생_제출_산출물.md`: 구현보고서 작성 양식과 최종 점검표
- `04_강사용_정답_및_채점표.md`: 등록용 정답, 직접 증빙 확인표와 채점표
- `05_학생공개용_채점기준.md`: 영역별 배점과 학생 공개용 판단 기준

학생에게는 02번, 03번, 05번을 제공한다. `Exam.md`와 01번·04번은 강사용이다.
