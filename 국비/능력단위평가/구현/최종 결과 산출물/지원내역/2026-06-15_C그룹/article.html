1. 한 단계씩 구현 시작하기

처음부터 네 카드를 모두 완성하려고 하기보다 파일 연결 → 카드 한 개 → 네 개 반복 → Flex 배치 순서로 진행하세요. 각 단계에서 실제 화면을 확인한 뒤 다음으로 넘어갑니다.

단계 폴더확인할 것
01_connectionCSS가 연결되어 제목 색과 글꼴이 적용됩니다.
02_one_card이미지와 정보가 카드 한 개 안에 묶입니다.
03_four_cards네 카드에 같은 내부 구조가 있습니다.
04_flex_layout같은 카드가 가로 배치되고 좁은 화면에서는 줄이 바뀝니다.

권장 시간은 약 180분입니다. 파일 연결 25분, 카드 구조 40분, 반복과 배치 60분, 스타일·점검·질문 55분 순서로 나누어 연습하세요.

파일은 원래 평가 정답이 아닌 기초 연습 예제입니다. 기존 평가의 조건과 점수는 바꾸지 않습니다. 모르는 부분은 파일명과 화면을 함께 보여 주며 질문하세요.

2. HTML과 CSS 파일 연결하기

먼저 압축을 해제한 다음 단계 폴더의 index.html을 여세요. HTML의 link 경로와 실제 CSS 파일명, 대소문자를 대조합니다. 파일을 저장한 뒤 새로고침하고 현재 보고 있는 페이지가 수정한 파일인지 확인하세요.

<link rel="stylesheet" href="./style.css" />

같은 폴더에 index.html과 style.css가 있으면 ./style.css로 연결합니다. ../는 한 단계 위 폴더를 뜻합니다. 확장자를 숨긴 상태에서는 style.css.txt처럼 저장되지 않았는지도 확인하세요.

practice/
  images/
    book-01.svg
  01_connection/
    index.html
    style.css

01_connection/index.html을 열면 단순한 세로 화면이 나타납니다. 이 단계에서는 아직 카드 모양을 완성하지 않았습니다. site-header의 파란색이 CSS 연결을 확인하는 단서입니다.

따라 하기: CSS의 제목 색을 한 번 바꾸고 저장·새로고침하세요. 바뀌지 않으면 보고 있는 파일과 실제 저장 위치부터 확인합니다.

3. 카드 한 개의 포함 관계 알기

태그는 콘텐츠를 감싸며 시작과 끝이 한 쌍인 경우가 많습니다. 카드 한 개 안에 이미지·제목·설명·가격·옵션·버튼을 함께 둡니다. 들여쓰기로 누가 누구를 포함하는지 표시하세요.

<article class="book-card">
  <h2 class="book-title">도서 제목</h2>
  <p class="book-desc">도서 설명</p>
  <div class="book-meta">가격과 옵션</div>
  <button type="button" class="practice-button">태그 연습</button>
</article>

따라 하기: 02_one_card를 열고 각 화면 요소가 어떤 태그인지 찾아 표시하세요. 한 태그의 글자를 바꾸어 실제 화면에서 그 위치만 바뀌는지 확인합니다.

4. 한 카드에서 네 카드로 반복하기

먼저 카드 한 개의 구조가 완성됐는지 확인한 뒤 같은 부모 안에서 네 번 반복합니다. 이미지 네 개와 정보 네 개를 각각 따로 모으지 말고, 각 카드 안에 관련 정보를 함께 둡니다.

<div class="book-list">
  <article class="book-card">첫 번째 카드</article>
  <article class="book-card">두 번째 카드</article>
  <article class="book-card">세 번째 카드</article>
  <article class="book-card">네 번째 카드</article>
</div>

03_four_cards는 완성된 카드 네 개를 세로로 보여 주는 단계입니다. 아직 가로로 놓이지 않아도 반복 구조를 확인할 수 있습니다. 위 코드는 포함 관계를 보여주는 축약 예시이며 첨부 파일에는 카드 내부 콘텐츠가 있습니다.

따라 하기: 네 카드에서 제목·설명·가격·옵션·버튼이 모두 있는지 확인하세요. 빈 카드가 있으면 첫 카드의 구조와 대조하고 닫는 태그를 점검합니다.

5. 클래스명과 기본 스타일 연결하기

HTML의 class는 이름표이고 CSS의 .클래스명은 그 이름표를 찾는 선택자입니다. 글자가 다르면 연결되지 않습니다. 비슷하게 보이는 오타도 확인하세요.

<!-- HTML -->
<p class="book-desc">설명</p>

/* CSS */
.book-desc {
  color: #60748a;
  margin-bottom: 16px;
}

위 margin-bottom은 요소의 아래 바깥 여백입니다. padding은 카드 안쪽의 여백입니다. 다른 속성을 한꺼번에 바꾸기보다 한 값을 바꾼 뒤 화면 변화를 확인하세요.

따라 하기: 설명의 색상과 카드 안쪽 padding을 각각 바꿔 보세요. 바뀌는 대상이 다르다는 것을 말로 설명해 봅니다.

6. Flex로 카드 가로 배치하기

Flex는 카드가 들어 있는 부모에 적용합니다. 안쪽 카드 하나에만 display:flex를 넣으면 네 카드 전체가 가로로 놓이지 않습니다.

.book-list {
  display: flex;
  flex-wrap: wrap;
  gap: 24px;
}

04_flex_layout에는 카드 너비와 좁은 화면의 줄바꿈 규칙도 포함되어 있습니다. 컨테이너와 아이템을 구분하고 같은 카드가 너비에 따라 어떻게 놓이는지 관찰하세요. 예제 너비는 연습 조건이며 원래 평가의 추가 요구가 아닙니다.

단어뜻
컨테이너Flex를 적용한 부모
아이템그 부모의 직접 자식
gap아이템 사이의 간격
wrap공간이 부족할 때 다음 줄로 배치

따라 하기: gap을 다른 값으로 바꿔 보고 카드 안쪽 여백과 어떤 차이가 있는지 확인하세요.

7. 단계별 화면과 텍스트 확인하기

시작 단계: 카드 한 개

다음 목표: 카드 네 개와 Flex 배치

위는 02_one_card와 04_flex_layout을 같은 너비에서 확인한 화면입니다. 한 카드가 완성된 뒤 네 카드가 같은 구조와 스타일로 반복되는지 보세요.

점검: 글자가 빠지지 않았는가 / 이미지가 보이는가 / 가격·옵션이 같은 카드 안에 있는가 / 예제 목표와 다른 부분을 어디서 수정해야 하는가. 색과 문구는 실제 과제의 원본을 별도로 대조합니다.

8. 버튼·초점과 오류 질문하기

실행할 동작은 보통 button, 다른 위치로 이동하는 것은 링크로 표현합니다. 첨부 예제의 버튼은 태그와 초점 연습용입니다. 실제 구매나 선택 변경 기능은 연결하지 않았습니다.

<button type="button" class="practice-button">태그 연습</button>

Tab 키로 링크와 버튼까지 이동하면 초점 표시를 확인할 수 있습니다. 보이는 모양만 같다고 기본 동작까지 같은 것은 아닙니다.

증상먼저 확인
전체 스타일이 없음CSS 파일명·경로·저장 위치
한 요소만 다름클래스명과 해당 CSS 선택자
포함 관계가 이상함시작·닫는 태그와 들여쓰기
배치가 다름목록 부모의 Flex와 카드 너비

질문 문장: “[파일명]의 [태그·클래스]에서 [화면 증상]이 보입니다. [확인한 것]까지 했지만 [모르는 부분]이 어렵습니다.” 코드와 화면을 함께 보여 주세요.

9. 한국어 무료 강의와 함께 복습하기

학습 후 할 일: 카드의 padding과 바깥 간격을 서로 다른 값으로 바꿔 보세요.

강의·예제 열기

영상에서 보여주는 값은 설명용 예시입니다. 현재 과제의 고정 클래스명·문구·간격 등은 원래 과제 명세를 대조하세요. 글과 함께 제공되는 영상은 무료 공개 콘텐츠이며 시청 구간은 위 주제명을 기준으로 선택할 수 있습니다.
