신윤아 학생은 상단의 언어·SNS·일곱 개 주 메뉴·검색 표시를 구성했고, 메뉴에 마우스를 올렸을 때 글자색이 바뀌는 것도 확인했습니다. NEW ARRIVALS는 1200px 안쪽 폭과 22px 간격, 이미지 다섯 개의 크기와 순서를 정확하게 맞췄습니다. 왼쪽 제목과 작은 이미지를 세로 Flex로 묶고 `space-between`으로 아래 끝을 맞춘 방식도 적절합니다. 보완할 부분은 상단의 유동 폭과 신제품 영역의 중복 여백입니다.

1. 상단 > 94% 대신 기준 내부 폭 사용

[학생 코드 — 모나미 1차/style.css]
```css
.head_top .conwrap { width: 94%; }
.category { width: 94%; margin: 0 auto; display: flex; }
```

[수정 예시]
```css
.head_top .conwrap,
.category {
  width: 1400px;
  margin-left: auto;
  margin-right: auto;
}
```

현재 상단 내부 폭은 1920px 화면에서 약1791px, 1440px 화면에서 약1340px로 달라집니다. 그래서 메뉴 사이가 넓은 화면에서는 벌어지고 다른 데스크톱에서는 좁아집니다. 이번 완성 예시의 기준인 1400px을 두 줄에 함께 적용하면 로고와 메뉴의 위치를 안정적으로 맞출 수 있습니다. 바깥 흰색 배경과 내부 콘텐츠의 폭은 구분해서 설정하세요.

2. 상단 > 언어 표시와 문서 언어

[학생 코드 — index.html]
```html
<html lang="en">
<div class="lang">
  <img src="./image/lang_kor.png" alt="한국어">
  <span>KOR</span>
</div>
```

[수정 예시]
```html
<html lang="ko">
```

화면의 주된 내용이 한국어이므로 문서의 기본 언어도 `ko`로 지정하세요. 언어 표시에는 국기와 KOR가 잘 들어가 있습니다. 그 옆에 정답의 아래 방향 표시를 추가하면 펼침 형태도 맞출 수 있습니다. 실제 언어 전환 기능을 만드는 것까지 요구하는 것은 아닙니다.

3. NEW ARRIVALS > 바깥과 안쪽의 중복 패딩

[학생 코드]
```css
.new {
  height: 999px;
  padding: 75px 0 90px;
  box-sizing: border-box;
}
.new .con {
  height: 821px;
  padding: 75px 0 90px;
}
.toparea { margin: 13px 0 22px; }
```

[수정 예시]
```css
.new {
  height: auto;
  padding: 88px 0 90px;
}
.new .con {
  height: auto;
  padding: 0;
}
.toparea { margin: 0 0 22px; }
```

바깥 `.new`와 안쪽 `.con`에 같은 패딩을 두 번 적용했습니다. 그 결과 첫 콘텐츠는 영역 시작에서 163px 아래에 놓이고, 안쪽 박스도 설정한 821px보다 큰 986px 높이가 됩니다. 위아래 여백은 바깥 영역 한 곳에서만 담당하게 하고 안쪽은 실제 내용의 높이에 따라 늘어나도록 정리하세요. 현재의 이미지 크기와 1200px 폭, 행 간 22px 간격은 유지하면 됩니다.

4. NEW ARRIVALS > 제품을 설명하는 alt

[학생 코드]
```html
<img src="./image/new1.jpg" alt="new1">
<img src="./image/new2.jpg" alt="new2">
```

[수정 예시]
```html
<img src="./image/new1.jpg" alt="FX ZETA C3 볼펜, 여러 색상">
<img src="./image/new2.jpg" alt="지퀀스 노트, 세 가지 색상">
```

이미지의 경로와 크기는 정확합니다. 대체 설명은 파일 번호보다 사진에 담긴 제품을 설명하도록 작성하세요. 나머지 세 이미지에도 프리미엄 펜과 케이스, 만년필과 케이스, 60색 마커처럼 내용을 구분해 적으면 됩니다. 카드의 20px 둥글기는 이미 자연스럽게 표현되어 있으므로 전체 여백을 먼저 보완한 뒤 세부 수치를 정리하는 순서가 좋습니다.

최종점수는 96점입니다. 상단 내부 폭을 맞추고 신제품의 중복 패딩을 제거한 다음, 두 데스크톱 너비에서 이미지 크기와 행 간격이 그대로 유지되는지 확인하세요.
