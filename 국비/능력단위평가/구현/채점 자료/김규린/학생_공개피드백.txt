김규린 학생은 HOME·SITE MAP·CONTACT US와 모나미 로고를 연결하고, 유틸리티와 메인헤더를 나누는 기본 틀을 작성했습니다. 로고 파일과 CSS는 정상적으로 불러와집니다. 현재 화면에는 상단 영역만 있으며, 주 메뉴와 아이콘은 실제 콘텐츠 대신 “메뉴”, “아이콘”이라는 글자로 남아 있습니다. 두 영역을 선택해 구현하는 과제이므로 상단의 실제 요소를 채우고 두 번째 영역을 추가하는 것이 우선입니다.

1. 상단 > 실제 메뉴와 임시 글자 구분

[학생 코드 — EXAM/index.html]
```html
<div class="menu">메뉴</div>
<div class="icon">아이콘</div>
```

[주 메뉴 수정 예시]
```html
<nav class="menu">
  <ul>
    <li>모나미소개</li>
    <li>모나미제품</li>
    <li>NEWS & VIDEO</li>
    <li>브랜드스토어</li>
    <li>모나미 미술대회</li>
    <li>고객지원</li>
    <li>기업 구매 / 개발</li>
  </ul>
</nav>
```

부모 상자를 만든 것과 필요한 내용을 구현한 것은 구분해야 합니다. “메뉴”를 위와 같이 실제 일곱 개 항목으로 바꾸고, 아이콘 영역에는 제공 자료의 검색 이미지와 메뉴 표시를 배치하세요. 이 과제에서는 모양과 배치를 구현하는 범위부터 완성하면 됩니다.

2. 상단 > 안쪽 폭과 가로 정렬

[학생 코드 — EXAM/style.css]
```css
.con { width: 1050px; height: 58px; display: flex; }
.m-header-con { display: flex; }
```

[수정 예시]
```css
body { margin: 0; }
.con { width: 1400px; }
.m-header-con {
  width: 1400px;
  height: 89px;
  margin: 0 auto;
  display: flex;
  justify-content: space-between;
  align-items: center;
}
.menu ul { display: flex; gap: 24px; }
```

현재 위쪽 메뉴는 1050px 컨테이너를 사용하지만 아래쪽 메인헤더에는 같은 내부 폭이 없어 로고와 임시 글자가 화면 왼쪽에 붙습니다. 두 줄을 1400px 안쪽 폭에 맞추고, 로고·주 메뉴·아이콘을 부모의 가로 공간 안에서 배치하세요. 이미 Flex를 시작한 점을 살려 부모에서 정렬과 간격을 정하는 연습을 하면 됩니다.

3. 상단 > 언어·SNS 묶음과 최종 테두리

[학생 코드]
```css
.utility-con { justify-content: flex-end; align-items: center; }
.main-header { border: 1px solid red; height: 89px; }
```

현재는 오른쪽 메뉴만 있으므로 `flex-end`가 적용되어 있습니다. 제공된 언어·SNS 이미지를 추가해 왼쪽 묶음을 만든 다음, 그 묶음과 오른쪽 메뉴를 `.utility-con`의 자식으로 두고 `justify-content: space-between`으로 나누세요. 빨간 테두리는 구조 확인용 표시이므로 최종 화면에서는 `border: 1px solid #eee`처럼 완성 예시에 맞춰 정리하는 것이 좋습니다. 이미 로고의 크기와 대체 설명을 작성했으므로 다른 이미지도 같은 방식으로 파일 경로와 표시 크기를 확인하세요.

4. 두 번째 선택 영역 추가

제출된 HTML은 상단을 닫은 뒤 바로 끝나며, 두 번째 영역의 HTML·CSS는 없습니다. 예를 들어 NEW ARRIVALS를 선택한다면 제목과 설명, 첫 행의 두 이미지, 아래 행의 세 이미지를 한 영역으로 묶고 순서대로 완성할 수 있습니다. 이 예시는 다음 수정 방향이며, 현재 제출물에 해당 영역이 구현되어 있다는 뜻은 아닙니다. 우선 상단의 임시 글자를 실제 콘텐츠로 바꾼 뒤 두 번째 영역을 선택해 작업하세요.

최종점수는 70점입니다. 먼저 상단의 실제 메뉴·아이콘·언어·SNS를 채우고, 같은 방식으로 두 번째 선택 영역을 완성하시기 바랍니다.
