김형관 학생은 상단의 언어 표시와 SNS, 로고, 일곱 개 메뉴, 검색·전체 메뉴 표시를 구성했습니다. 1400px 안쪽 폭과 메뉴 높이를 적용했고, 마우스를 올렸을 때 메뉴 글자색이 바뀌는 것도 확인했습니다. NEW ARRIVALS는 제품 이미지 다섯 개를 모두 연결했지만, 제목과 이미지가 서로 다른 부모에 놓여 있고 이미지 순서도 일부 바뀌어 있습니다. 이번에는 상단과 신제품 두 영역을 기준으로 살펴보았습니다.

1. 상단 > 메뉴 문구 확인

[학생 코드 — 시험/index.html]

<li>CONATACT US</li>

[수정 예시]

<li>CONTACT US</li>

상단의 실제 콘텐츠는 대부분 채워져 있습니다. 이 문구의 오타를 정정하고, 같은 방식으로 메뉴 이름을 원본과 한 번씩 대조하세요. 검색 이미지와 세 줄 메뉴 표시도 정상적으로 연결되어 있으므로 현재의 기본 구조는 유지해도 됩니다.

2. NEW ARRIVALS > 제목과 이미지를 같은 부모 안에 배치

현재 .new를 닫은 뒤 이미지 두 행을 작성했기 때문에, 제목에 적용한 1200px 폭이 이미지 행에는 적용되지 않습니다. 제목과 첫 이미지를 왼쪽 묶음으로 만들고, 오른쪽 노트 이미지와 함께 첫 행을 구성하세요. 위 예시의 ...는 현재 구조를 간단히 표시한 것이며 실제 HTML에 넣는 문자가 아닙니다.

3. NEW ARRIVALS > Flex 값과 행의 간격

[학생 코드 — 시험/style.css]

.toparea {
  display: flexbox;
  align-items: center;
}

[수정 예시]

.new { width: 1200px; margin: 0 auto; padding: 88px 0 90px; }
.toparea, .btnarea {
  display: flex;
  gap: 22px;
  align-items: flex-start;
}
.new-left { width: 392px; }
.new-heading { height: 155px; }
.btnarea { margin-top: 22px; }
.new img { display: block; border-radius: 22px; }
.new h2 { margin: 0; font-size: 32px; font-weight: 500; }
.title-line { width: 26px; height: 3px; background: #c81939; margin: 12px 0 10px; }
.new-heading p { margin: 0; font-size: 13px; }

display: flexbox는 적용되는 값이 아닙니다. 브라우저에서도 .toparea가 block으로 남아 있는 것을 확인했습니다. flex로 바꾸고 부모를 바로잡으면 첫 행은 392 + 22 + 786 = 1200px이 됩니다. 아래 행도 이미지 392px·450px·314px과 간격 두 곳을 합쳐 같은 폭에 맞추세요.
