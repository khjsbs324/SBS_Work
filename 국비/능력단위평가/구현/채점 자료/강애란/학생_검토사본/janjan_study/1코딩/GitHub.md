# Git 로컬(Local)과 원격(Remote)

## 1. 개념 정리

| 구분         | 의미             |
| ---------- | -------------- |
| 로컬(Local)  | 내 컴퓨터에 있는 저장소  |
| 원격(Remote) | GitHub에 있는 저장소 |

## 2. 구조 도식화

로컬 저장소 (Local)

내 컴퓨터에 파일 저장

저장소 연결 및 파일 공유

원격 저장소 (Remote)

GitHub에 파일 저장

## 3. 핵심 정리

- 로컬: 내 컴퓨터에 저장소가 있다.
- 원격: GitHub에 저장소가 있다.
- 활용: GitHub에 파일을 보관하면 집에서도 로그인하여 파일을 확인하고 관리할 수 있다.
