# 라임 유사 서비스 레퍼런스 대시보드

| --- | --- | --- | --- |
| ★★★ | [청소년1388](https://www.1388.go.kr/) | 청소년 대상 채팅·게시판 상담과 심리검사 | [온라인 상담실 안내](https://www.1388.go.kr/cco/YTOSP_SC_CCI_01)의 상담 진입 경로, 홈의 서비스 분류 |

| ★★★ | [트로스트](https://trost.co.kr/) | 상담·심리검사·커뮤니티가 결합된 서비스 | 상담사 찾기, 심리검사 메뉴, 콘텐츠 탐색 구조 |
| ★★☆ | [Finch](https://finchcare.com/) | 캐릭터가 사용자를 맞이하는 자기돌봄 앱 | 마스코트의 정서적 역할, 친근한 온보딩. [앱 홈 안내](https://help.finchcare.com/hc/en-us/articles/37780000231309-Exploring-the-Finch-Home-Page) 참고 |
| ★★☆ | [Daylio](https://daylio.net/) | 간단한 감정 선택과 기록 | 감정 선택 단계, 아이콘·색상으로 감정을 구별하는 방식 |
| ★☆☆ | [Wysa](https://www.wysa.com/) | 캐릭터를 앞세운 대화형 마음건강 서비스 | 챗봇 소개와 대화 진입 표현. 라임의 사람 상담과 서비스 방식은 다름 |

## 빠른 비교

| 만들 화면 | 먼저 볼 곳 | 참고할 점 |
| --- | --- | --- |
| 홈 대시보드 | 마인드카페, 청소년1388 | 상담·검사·콘텐츠의 우선순위와 바로가기 |
| 상담원 목록/상세 | 마인드카페, 트로스트 | 사진, 전문 분야, 상담 가능 상태, 신청 행동 |
| 기분 체크인 | Daylio, Finch | 빠른 선택과 감정에 반응하는 캐릭터 |
| 상담 시작 대화 | 청소년1388, Wysa | 상담 진입 안내와 메시지형 입력의 흐름 |

이 링크들은 **정보 구조와 시각 표현을 살펴보기 위한 레퍼런스**다. 청소년1388은 공공 상담 서비스이며, Finch·Daylio·Wysa는 라임과 대상 또는 상담 방식이 다르다.
