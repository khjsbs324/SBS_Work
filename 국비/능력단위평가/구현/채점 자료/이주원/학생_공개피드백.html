1. 상단 > 기본 여백과 내부 폭 통일

[학생 코드 — 261023_Test/style.css]

body { font-family: sans-serif; }
.conwrap { width: 1440px; height: 44px; }
.m-nav-inner { width: 1400px; height: 89px; }

[수정 예시]

body { margin: 0; font-family: sans-serif; }
.conwrap { width: 1400px; }
.img-con { display: flex; gap: 7px; }

body의 기본 8px 바깥 여백이 남아 있어 상하단 선도 화면 가장자리에서 떨어져 있습니다. 위쪽은 1440px, 아래쪽은 1400px이라 내부의 시작점도 다릅니다. 기본 여백을 제거하고 두 내부 폭을 맞추세요. SNS 간격은 이미지 각각에 gap을 넣기보다 이미지들을 담는 .img-con을 Flex 부모로 만들고 간격을 지정하면 정확해집니다.

2. 상단 > 검색·전체 메뉴 아이콘 크기

[학생 코드]

.search-icon { font-size: 30px; }
.menu-icon { font-size: 30px; }

[수정 예시]

.search-icon { font-size: 19px; }
.menu-icon { font-size: 20px; }

아이콘 자체는 정상적으로 표시됩니다. 현재 크기가 메뉴 글자와 다른 요소에 비해 커 보이므로 검색은 약19px, 전체 메뉴 표시는 약20px을 기준으로 맞추세요. 아이콘 도구를 바꿀 필요는 없으며, 표시된 실제 모양과 시각적인 크기를 기준으로 조정하면 됩니다.

3. NEW ARRIVALS > 첫 행의 상단과 아래 끝 정렬

[학생 코드]

.top-products-l { display: flex; flex-direction: column; }
.top-product-l { margin-top: 36px; }
.top-products-right { margin-top: 18px; }

[수정 예시]

.top-products-left {
  width: 392px;
  height: 360px;
  display: flex;
  flex-direction: column;
  justify-content: space-between;
}
.top-product-l { margin-top: 0; }
.top-products-right { margin-top: 0; }
.top-area img, .bot-img img { display: block; }

HTML의 실제 부모 이름은 .top-products-left인데 CSS에는 .top-products-l로 적혀 있습니다. 부모 이름을 맞추고 왼쪽을 360px 높이의 세로 Flex로 만들면 제목은 위, 첫 이미지는 아래에 놓을 수 있습니다. 오른쪽 이미지는 현재 위에서 18px 내려가 있으므로 이 여백을 제거하세요. 이미지를 block으로 바꾸면 인라인 이미지 아래의 글자 기준선 공간도 없어집니다. 현재 이미지의 너비·높이와 두 행의 22px 간격은 그대로 유지하면 됩니다.
