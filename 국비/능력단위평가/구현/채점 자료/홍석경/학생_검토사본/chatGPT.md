# SNS 아이콘 크기와 간격

모나미 메인 페이지의 `.head_top .sns`를 브라우저에서 측정한 값입니다. 측정 당시 `.head_top`의 높이는 59px입니다.

| 항목 | 측정값 |
| --- | ---: |
| 페이스북 아이콘 크기 | 30 × 30px |
| 인스타그램 아이콘 크기 | 30 × 30px |
| 유튜브 아이콘 크기 | 30 × 30px |
| 페이스북 ↔ 인스타그램 간격 | 7px |
| 인스타그램 ↔ 유튜브 간격 | 7px |
| 아이콘 위쪽 여백 | 14px |
| 아이콘 아래쪽 여백 | 15px |
| 세 아이콘이 차지하는 전체 너비 | 104px |

위아래 여백은 `.head_top`의 바깥 경계와 아이콘 이미지 사이의 거리입니다. `.sns`에는 `padding-left: 93px`이 적용되어 있고, 각 아이콘의 `li`에는 `margin-left: 7px`이 적용되어 있습니다.

## 상단 메뉴(`.topmenu`) 크기와 간격

같은 화면에서 `HOME`, `SITE MAP`, `CONTACT US` 링크를 측정한 값입니다. 위아래 여백은 높이 59px인 `.head_top`을 기준으로 합니다.

| 항목 | 측정값 |
| --- | ---: |
| `.topmenu` 전체 크기 | 약 226.6 × 20px |
| `.topmenu` 위쪽 여백 | 20px |
| `.topmenu` 아래쪽 여백 | 19px |
| 링크 텍스트 영역 높이 | 14px |
| 링크 텍스트 영역 위쪽 여백 | 25px |
| 링크 텍스트 영역 아래쪽 여백 | 20px |
| `HOME` ↔ `SITE MAP` 링크 사이 | 22px |
| `SITE MAP` ↔ `CONTACT US` 링크 사이 | 22px |
| 링크 글자 크기 | 11px |
| 링크 글꼴·굵기 | Montserrat, 400 |

메뉴 사이 22px은 다음 항목의 `margin-left: 10px`과 `padding-left: 12px`의 합입니다. 글자 자체의 `letter-spacing`은 `normal`이며 별도 픽셀 값이 지정되어 있지 않습니다. `SITE MAP`과 `CONTACT US` 앞에는 구분선 배경 이미지가 있습니다.
