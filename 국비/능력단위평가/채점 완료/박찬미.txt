## 사이트 입력용 피드백

1. 컨테이너 변수 오타

css
/* 학생 코드 */
.con {
  max-width: var(--containner);
}

css
/* 정답 코드 */
.con {
  max-width: var(--container);
}

피드백:
5열 Grid와 모바일 폭은 고쳤지만 컨테이너 변수명은 아직 --containner입니다. 1920px에서 계산된 max-width가 none이 되어 기준의 1600px 중앙 컨테이너보다 콘텐츠가 넓게 배치됩니다. component.css에 선언된 --container와 철자를 맞춰야 세 결함이 모두 해결됩니다.
