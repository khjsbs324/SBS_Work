# 디자인 구성요소 설계 포트폴리오 평가

## 과제 목표

나의 개인 브랜딩 포트폴리오 사이트를 대상으로 정보구조와 사용자 흐름을 설계하고, 와이어프레임과 디자인 가이드, UI 구성요소의 상태를 정의합니다. 데스크톱·태블릿·모바일의 다른 환경에서도 같은 브랜드와 사용 경험을 유지할 수 있는 표준을 설계합니다.

## 작업 순서

1. 프로젝트 목표, 사용자, 콘텐츠, 기능, 화면과 자산을 정리합니다.
2. 콘텐츠를 그룹화·레이블링하고 사이트맵과 사용자 흐름을 만듭니다.
3. 메인, 프로필, 프로젝트 목록, 프로젝트 상세, 문의 화면의 와이어프레임을 작성합니다.
4. 출처가 있는 트렌드·유사 사례를 비교하고 적용·배제 전략을 정합니다.
5. 레이아웃, 그리드, 색채, 타이포그래피, 이미지와 아이콘 규칙을 만듭니다.
6. 버튼, 내비게이션, 카드, 폼, 피드백 요소의 상태와 오류·복구 흐름을 설계합니다.
7. 사용자 경험 근거를 바탕으로 시각 변화와 예상 효과를 정리합니다.
8. 데스크톱·태블릿·모바일 환경과 표준을 설정하고 디바이스별 화면을 설계합니다.

## 필수 화면과 디바이스

- 화면: 메인, 프로필, 프로젝트 목록, 프로젝트 상세, 문의
- 디바이스: 데스크톱, 태블릿, 모바일
- 권장 기준 폭: 데스크톱 1440px, 태블릿 768px, 모바일 390px. 다른 기준을 사용하면 선택 이유를 적습니다.

## 제출물

```text
이름_디자인구성요소설계.pdf
이름_디자인구성요소설계_원본.zip
```

ZIP에는 편집 가능한 원본, 링크 자산과 폰트·이미지 출처 정보를 포함합니다. HTML·CSS·JavaScript 코드나 배포 링크는 필수가 아닙니다.

## 평가에서 중요한 내용

- 정보와 인터페이스 요소의 분석 근거
- 전체 화면과 흐름을 파악할 수 있는 와이어프레임
- 브랜드·사용자·콘텐츠에 맞는 트렌드 선택과 디자인 가이드
- 상태·오류·복구가 포함된 사용 가능한 UI 구성요소
- 단순 크기 변형이 아닌 디바이스별 정보·탐색·조작 적응
