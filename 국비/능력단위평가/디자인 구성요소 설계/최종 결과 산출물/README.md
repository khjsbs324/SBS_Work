# 디자인 구성요소 설계 평가자료

개인 브랜딩 포트폴리오 사이트의 정보구조, 와이어프레임, 디자인 가이드, UI 상태와 디바이스별 표준을 설계하는 포트폴리오 평가다.

- `01_강사용_수업진행안.md`: 240분 운영과 회수 순서
- `02_학생용_과제안내서.md`: 과제 범위와 제출 규칙
- `03_학생_제출_산출물.md`: PDF 포트폴리오 작성 양식
- `04_강사용_정답_및_채점표.md`: 직접 증빙과 문항별 채점표
- `05_학생공개용_채점기준.md`: 영역별 학생 공개용 기준

학생에게는 02번, 03번, 05번을 제공한다. `Exam.md`와 01번·04번은 강사용이다.
