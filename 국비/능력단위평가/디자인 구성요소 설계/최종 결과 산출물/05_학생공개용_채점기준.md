# 디자인 구성요소 설계 학생 공개용 채점기준

## 1. 스토리보드·와이어프레임 설계 — 25점

- 프로젝트 목표와 사용자에 필요한 콘텐츠·기능·화면·자산을 파악했는가
- 정보를 쉽게 찾을 수 있도록 그룹·레이블·사이트맵·사용자 흐름을 설계했는가
- 핵심 화면의 정보 위계·그리드·내비게이션·상호작용을 와이어프레임으로 표현했는가

## 2. 심미성과 디자인 가이드 — 25점

- 브랜드 목적과 콘텐츠에 맞는 그리드·색채·타이포그래피·이미지·아이콘 규칙을 정했는가
- 정보 위계, 비례, 균형, 대비, 정렬과 여백을 이용해 조화롭고 가독성 있게 설계했는가
- 출처가 있는 트렌드·유사 사례를 분석하고 자신의 브랜드에 맞는 적용·배제 전략을 정했는가

## 3. 사용성 구성요소 — 25점

- 사용자의 목표·기기·상황·제약에 맞게 탐색·입력·피드백을 구조화했는가
- 콘텐츠 유형과 읽기 순서에 맞게 텍스트·이미지·메타정보·행동 요소를 구성했는가
- 사용자 경험 근거를 토대로 포커스·선택·로딩·빈 상태·오류·복구 변화를 예측했는가

## 4. 매체별 환경과 표준 — 25점

- 데스크톱·태블릿·모바일의 화면·입력·사용 맥락에 따른 UI 요소 차이를 설명했는가
- 뷰포트·입력·방향·탐색·관람 조건과 점검 환경을 설정했는가
- 공통 아이덴티티를 유지하면서 그리드·여백·서체·이미지·내비게이션·터치 영역·정보 우선순위를 디바이스별로 표준화했는가

## 제출 전 확인

- PDF에서 설계 과정과 프레임 ID를 추적할 수 있어야 합니다.
- ZIP에서 편집 가능한 설계 소스와 사용 자산을 확인할 수 있어야 합니다.
- 코드·배포는 필수가 아니며, 시각적 화려함보다 정보구조·사용성·설계 규칙을 우선합니다.
