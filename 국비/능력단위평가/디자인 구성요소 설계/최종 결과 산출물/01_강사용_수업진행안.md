# 디자인 구성요소 설계 강사용 수업진행안

## 운영 조건

- 개인평가 240분
- 입력: 개인 브랜딩·포트폴리오 콘텐츠 또는 제공 브랜드 브리프
- 제출: PDF 1개, 편집 가능한 원본 ZIP 1개
- 코드 구현·배포는 필수가 아님

## 시간 운영

1. 0~35분: 목표·사용자·콘텐츠·기능 요소 파악, 콘텐츠 인벤토리
2. 35~70분: 그룹·레이블링, 사이트맵, 사용자 흐름과 인터페이스 요소 분석
3. 70~120분: 핵심 5개 화면 와이어프레임과 상호작용·오류·복구 메모
4. 120~155분: 트렌드·유사 사례 분석, 전략 콘셉트와 디자인 가이드
5. 155~195분: UI 구성요소와 상태, 사용자 경험 근거 기반 시각 변화 예측
6. 195~225분: 데스크톱·태블릿·모바일 사양, 브레이크포인트·표준·화면 설계
7. 225~240분: PDF·ZIP 정리, 파일명·프레임 ID·누락·열림 확인

## 운영 유의 사항

- 콘텐츠가 미완성이라도 설계 구조를 판단할 수 있는 실제 제목·메타정보·요약을 사용하게 한다. 무의미한 더미 텍스트만으로 설계하지 않게 한다.
- 트렌드 사례를 그대로 복제하지 않고 적용·배제 원칙을 작성하게 한다.
- 반응형 화면은 수치만 다른 같은 레이아웃이 아니라 정보 우선순위·탐색·입력·터치 영역의 차이를 보여주게 한다.
- 사용자 반응을 실제 통계로 창작하지 않고 기존 리서치, 점검 기록 또는 가설로 구분한다.

## 회수 순서

1. PDF·ZIP 파일명과 열림을 확인한다.
2. PDF 프레임 ID와 ZIP 소스의 대응을 확인한다.
3. 요소 목록→정보구조→와이어프레임의 연결을 확인한다.
4. 트렌드 분석→전략 콘셉트→디자인 가이드의 연결을 확인한다.
5. UI 상태·오류·복구와 사용자 경험 근거를 확인한다.
6. 세 디바이스의 사양·표준·화면 적응을 확인한다.
7. `Exam.md` DS-01~DS-12에 직접 증빙을 연결해 채점한다.
