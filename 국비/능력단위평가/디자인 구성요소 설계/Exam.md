# 디자인 구성요소 설계 평가 기준

## 평가 개요

- 능력단위: 디자인 구성요소 설계
- 능력단위 코드: `0802010415_23v3`
- 과제명: 개인 브랜딩 포트폴리오 사이트 구성요소 설계
- 평가 형식: 개인 포트폴리오
- 시험 시간: 240분
- 필수 제출: `이름_디자인구성요소설계.pdf` 1개, `이름_디자인구성요소설계_원본.zip` 1개
- 문항 수: 12개 / 총점: 100점

## 과제 개요

개인 브랜딩과 웹디자인 포트폴리오를 위해 콘텐츠와 기능을 분석하고 정보구조·사이트맵·사용자 흐름을 설계한다. 메인·프로필·프로젝트 목록·프로젝트 상세·문의 화면의 와이어프레임을 만들고, 리서치를 기반으로 디자인 가이드와 UI 구성요소의 상태를 정의한다. 이를 데스크톱·태블릿·모바일 환경에 맞게 표준화하고 사용성과 일관성을 점검한다.

## 필수 증빙

1. 프로젝트 목표·사용자·핵심 콘텐츠·기능과 요소 목록
2. 콘텐츠 인벤토리, 그룹·레이블링, 사이트맵과 사용자 흐름
3. 메인·프로필·프로젝트 목록·상세·문의 화면 와이어프레임
4. 트렌드·유사 사례 분석과 적용·배제 전략
5. 레이아웃·그리드·색채·타이포그래피·이미지·아이콘 디자인 가이드
6. 버튼·내비게이션·카드·폼·피드백 등 UI 구성요소의 상태와 오류·복구 흐름
7. 사용자 경험 근거에 따른 시각 변화 예측과 수정 전후
8. 데스크톱·태블릿·모바일 사양, 브레이크포인트와 디바이스별 화면 설계

## 공통 판단 원칙

1. 원문 학습목표의 문장·순서·개수를 유지한다.
2. 결과의 미적 취향보다 정보구조, 사용성, 디자인 규칙과 매체 적응을 평가한다.
3. 코드 구현과 배포는 필수 조건이 아니다.
4. 같은 원인의 문제를 여러 문항에서 중복 감점하지 않는다.
5. PDF와 원본 ZIP에서 확인한 직접 증빙만 점수와 연결한다.

## 수행준거별 채점기준

### DS-01. 프로젝트 디자인 요소 파악 — 8점

- 원문: 프로젝트 관련 디자인 개발에 필요한 요소를 파악할 수 있다.
- 증빙: 프로젝트 목표·사용자·콘텐츠·기능·화면·자산 목록과 우선순위.
- 7~8점: 프로젝트 목표와 사용자를 기준으로 필요한 콘텐츠·기능·화면·자산을 누락 없이 파악하고 우선순위를 정했다.
- 5~6점: 주요 요소는 파악했으나 일부 사용자 요구, 자산 또는 우선순위 근거가 부족하다.
- 3~4점: 화면과 콘텐츠를 나열했지만 프로젝트 목표와의 연결이 약하다.
- 0~2점: 필요 요소 분석이 없거나 핵심 화면·기능이 누락됐다.

### DS-02. 인터페이스 요소·항목 분석 — 8점

- 원문: 인터페이스(interface) 필요 요소와 항목들을 분석할 수 있다.
- 증빙: 콘텐츠 인벤토리, 그룹·레이블, 사이트맵, 사용자 흐름과 UI 요소 매핑.
- 7~8점: 정보를 사용자 멘탈모델에 맞게 그룹화·레이블링하고 탐색·입력·피드백 요소를 화면과 흐름에 연결했다.
- 5~6점: 정보구조와 주요 인터페이스 요소는 있으나 일부 레이블·흐름 또는 상태 분석이 부족하다.
- 3~4점: 메뉴와 요소를 나열했으나 사용자 흐름과의 연결이 약하다.
- 0~2점: 인터페이스 요소 분석을 확인하기 어렵다.

### DS-03. 전체 와이어프레임 작성 — 9점

- 원문: 전체적인 와이어 프레임(wire frame)을 작성할 수 있다.
- 증빙: 메인·프로필·목록·상세·문의 화면, 그리드·영역·내비게이션·상호작용 메모.
- 9점: 핵심 화면의 정보 위계·그리드·내비게이션·상호작용을 일관된 프레임과 메모로 설계하고 전체 흐름을 추적할 수 있다.
- 7~8점: 핵심 화면과 흐름은 완성됐으나 일부 그리드, 상태 또는 화면 전환 메모가 부족하다.
- 4~6점: 와이어프레임은 있지만 화면 간 일관성과 정보 우선순위가 불명확하다.
- 0~3점: 핵심 화면이 누락됐거나 전체 흐름을 판단할 수 없다.

### DS-04. 통합 아이덴티티 디자인 가이드 — 9점

- 원문: 서비스, 제작물의 통합적인 아이덴티티를 고려하여 디자인 가이드를 조합할 수 있다.
- 증빙: 레이아웃·그리드·색채·타이포그래피·이미지·아이콘 규칙과 화면 적용.
- 9점: 브랜드 목적과 콘텐츠 성격을 일관된 시각 규칙으로 조합하고 모든 화면과 UI 요소에 적용할 수 있게 정의했다.
- 7~8점: 주요 가이드는 일관되지만 일부 요소의 적용 규칙이나 화면 연결이 부족하다.
- 4~6점: 색·서체·그리드는 있지만 통합 아이덴티티와 재사용 규칙이 약하다.
- 0~3점: 가이드가 누락됐거나 구성요소들이 서로 다른 브랜드처럼 보인다.

### DS-05. 심미적 구성요소 활용 — 8점

- 원문: 조형적 아름다움을 표현하기 위하여 디자인의 심미적 요소를 활용할 수 있다.
- 증빙: 비례·균형·대비·반복·정렬·여백, 이미지·아이콘 조형과 가독성.
- 7~8점: 비례·균형·대비·정렬·여백을 의도한 분위기와 정보 위계에 맞게 적용해 조화롭고 가독성 있는 구성을 설계했다.
- 5~6점: 전체 조화는 적절하지만 일부 위계, 대비, 여백 또는 그래픽 일관성이 부족하다.
- 3~4점: 시각 요소를 사용했으나 설계 의도와 정보 전달보다 장식 위주다.
- 0~2점: 시각 구성이 설계 의도와 모순되거나 가독성을 크게 방해한다.

### DS-06. 트렌드 분석 기반 전략 콘셉트 — 8점

- 원문: 트렌드 분석을 통해 전략적인 콘셉트를 확보할 수 있다.
- 증빙: 출처가 있는 유사 사례·트렌드 비교, 적용·배제 원칙과 전략 콘셉트.
- 7~8점: 출처가 명확한 사례를 비교해 형태가 아닌 원리를 추출하고 사용자·콘텐츠·브랜드에 맞는 적용·배제 전략을 수립했다.
- 5~6점: 사례 분석과 전략은 있지만 일부 선택·배제 근거나 자신의 프로젝트 적용 방법이 부족하다.
- 3~4점: 사례를 수집했지만 최신 표현을 나열하는 데 머물러 전략으로 전환되지 않았다.
- 0~2점: 트렌드 분석 근거가 없거나 사례를 그대로 모방했다.

### DS-07. 사용자 환경에 맞는 시각 구조화 — 9점

- 원문: 사용자 환경에 적합하도록 시각적으로 구조화할 수 있다.
- 증빙: 핵심 과업·사용 환경·제약, 탐색·입력·피드백 구조와 접근성.
- 9점: 사용자의 목표·기기·상황·제약을 반영해 탐색·입력·피드백을 논리적으로 구조화하고 핵심 과업을 직관적으로 완료할 수 있다.
- 7~8점: 주요 과업과 구조는 적합하지만 일부 제약·피드백·접근성 고려가 부족하다.
- 4~6점: 화면 구조는 있지만 사용자 환경과 핵심 과업에 따른 우선순위가 약하다.
- 0~3점: 구조가 사용 흐름을 방해하거나 핵심 과업을 완료하기 어렵다.

### DS-08. 시각 특성에 맞는 콘텐츠 구성 — 8점

- 원문: 시각적 특성에 맞게 콘텐츠를 구성할 수 있다.
- 증빙: 제목·본문·이미지·메타정보·행동 요소의 위계, 카드·목록·상세 구성.
- 7~8점: 콘텐츠 유형과 읽기 순서에 맞게 텍스트·이미지·메타정보·행동 요소의 위계를 조절하고 재사용 가능하게 구성했다.
- 5~6점: 주요 콘텐츠는 명확하지만 일부 유형의 위계·밀도·가독성이 부족하다.
- 3~4점: 콘텐츠를 배치했지만 콘텐츠 유형과 시각 표현의 관계가 약하다.
- 0~2점: 핵심 콘텐츠가 누락됐거나 위계가 불명확해 정보 파악이 어렵다.

### DS-09. 사용자 경험 데이터 기반 시각 변화 예측 — 8점

- 원문: 사용자 경험에 따른 데이터를 활용하여 시각적 변화를 예측할 수 있다.
- 증빙: 행동·과업·오류·접근성 근거, 상태 변화 표, 수정 전후와 확인 조건.
- 7~8점: 사용자 행동·과업·오류·제약 근거를 토대로 포커스·선택·로딩·빈 상태·오류·복구의 시각 변화와 예상 효과를 제시했다.
- 5~6점: 주요 상태 변화와 근거는 있지만 일부 오류·복구·확인 조건이 부족하다.
- 3~4점: 상태 화면은 있지만 사용자 경험 근거와 변화 예측의 연결이 약하다.
- 0~2점: 상태 변화가 없거나 사용자 반응을 근거 없이 단정했다.

### DS-10. 매체별 구성요소 이해 — 8점

- 원문: 다양한 매체의 특성에 따른 구성요소를 이해할 수 있다.
- 증빙: 데스크톱·태블릿·모바일 비교, 헤더·내비게이션·콘텐츠·푸터·입력 요소 차이.
- 7~8점: 각 매체의 화면·입력·사용 맥락을 비교하고 공통 요소와 다르게 설계할 요소를 구체적으로 설명했다.
- 5~6점: 주요 매체 차이를 이해했으나 일부 입력 방식, 사용 맥락 또는 UI 요소 차이가 부족하다.
- 3~4점: 화면 크기 차이만 언급하고 구성요소의 역할·조작 차이를 설명하지 못했다.
- 0~2점: 매체별 특성 분석이 없거나 서로 다른 환경을 같게 설계했다.

### DS-11. 매체 다양성을 고려한 환경 설정 — 8점

- 원문: 매체의 다양성을 고려하여 환경을 설정할 수 있다.
- 증빙: 뷰포트·해상도·운영체제·입력·방향·네트워크·관람 조건과 테스트 범위.
- 7~8점: 디바이스별 뷰포트, 입력, 방향, 탐색과 관람 조건을 명시하고 설계·점검 환경을 실행 가능하게 정했다.
- 5~6점: 주요 환경과 점검 범위는 있지만 일부 조건·제약 또는 우선순위가 부족하다.
- 3~4점: 해상도 목록은 있지만 실제 사용 환경과 점검 방법이 불명확하다.
- 0~2점: 매체별 환경 설정을 확인할 수 없다.

### DS-12. 디바이스 표준화 설정 — 9점

- 원문: 매체의 특성에 따른 다양한 디바이스(device)의 표준화를 설정할 수 있다.
- 증빙: 브레이크포인트, 그리드·여백·타입·터치 영역·정보 우선순위 규칙과 디바이스별 화면.
- 9점: 공통 아이덴티티를 유지하면서 그리드·여백·서체·이미지·내비게이션·터치 영역과 정보 우선순위를 디바이스별 표준으로 정의했다.
- 7~8점: 주요 표준과 화면은 적절하지만 일부 브레이크포인트, 터치 또는 정보 우선순위 규칙이 부족하다.
- 4~6점: 화면 크기별 시안은 있지만 공통 규칙과 적응 규칙을 구분하기 어렵다.
- 0~3점: 디바이스별 표준이 없거나 작은 화면에서 정보·조작 가능성이 크게 손실됐다.
