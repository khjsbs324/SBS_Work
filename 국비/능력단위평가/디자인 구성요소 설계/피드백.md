# 디자인 구성요소 설계 피드백 지침

학생 피드백은 `관찰 → 설계 의도 → 적합성 → 사용자에게 미치는 영향 → 구체적 보완 방법`의 순서로 작성한다.

- PDF 페이지·프레임 ID·설계 소스를 근거로 사용한다.
- 예쁘다·촌스럽다는 표현 대신 정보 위계, 탐색, 가독성, 조작, 오류 복구와 디바이스 적응을 언급한다.
- 설계 의도와 실제 화면 구조가 다를 때는 어느 사용자 과업에 어떤 영향을 주는지 설명한다.
- 특정 시각 예시를 따라 하라고 하지 않고 학생의 브랜드 방향을 유지하면서 문제를 해결하는 방법을 제시한다.

예: “모바일 프레임 M-03에서 프로젝트 제목·역할·제작 시기·태그가 모두 같은 위계로 보여 목록 탐색이 지연됩니다. 제목과 핵심 역할을 먼저 읽히게 하고 보조 메타정보를 접거나 상세 화면으로 이동하도록 정보 우선순위를 재설정해 보세요.”
