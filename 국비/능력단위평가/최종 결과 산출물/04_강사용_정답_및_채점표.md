# 강사용 정답 및 채점표

> 평가 종료 전 학생에게 공개하지 않습니다.

## 1. 정답 HTML 연결 순서

```html
<link rel="stylesheet" href="./css/normal.css">
<link rel="stylesheet" href="./css/root.css">
<link rel="stylesheet" href="./css/component.css">
<link rel="stylesheet" href="./css/btn_cpn.css">
<link rel="stylesheet" href="./css/item_cpn.css">
<link rel="stylesheet" href="./css/layout_cpn.css">
<link rel="stylesheet" href="./css/style.css">
<link rel="stylesheet" href="./css/media.css">
```

연결 순서는 기반 규칙 → 원시 토큰 → 의미 토큰 → 공통 요소 → 공통 배치 → 페이지 스타일 → 반응형 재정의 순이다.

## 2. CSS 분리 정답 기준

| 파일 | 정답 코드의 책임 | 대표 내용 |
|---|---|---|
| `normal.css` | 기본화 | Pretendard 폰트, box-sizing, margin reset, body·링크·목록 기본값 |
| `root.css` | 원시 토큰 | 색상, 글자 크기·굵기, 숫자 간격, radius, container 변수 |
| `component.css` | 의미 토큰 | main, ink, muted, line, surface, grid padding 등 프로젝트 별칭 |
| `btn_cpn.css` | 조작 요소 | 공통 버튼, 아이콘, tab, more, slide, scroll-top, header icon |
| `item_cpn.css` | 표시 항목 | 글자 유틸리티, img-wrap, 상품명·가격·swatch |
| `layout_cpn.css` | 공통 배치 | `.con`, `.section`, `.grid-5/4/3/2`, section-head |
| `style.css` | 페이지 섹션 | header, hero, quick links, collection, outlet, trending, promotions, lookbook, footer, mobile nav |
| `media.css` | 반응형 | 1600, 1024, 768, 480px 재정의 |

선택자 위치가 정답과 완전히 같지 않더라도 책임이 논리적이고 중복·누락 없이 캐스케이드가 유지되면 인정할 수 있다.

## 3. 의도적 결함 정답

| ID | 선택자 | 문제 코드 | 실제 증상 | 정답 코드 | 확인 방법 |
|---|---|---|---|---|---|
| BUG-01 | `.con` | `max-width: var(--containner);` | 미정의 변수로 선언이 무효가 되어 컨테이너 최대 폭이 적용되지 않음 | `max-width: var(--container);` | 1920px에서 Computed `max-width`, 좌우 여백 확인 |
| BUG-02 | `.grid-5` | `grid-template-columns: repeat(5 1fr);` | 함수 인수의 콤마 누락으로 Grid 열 정의가 무효 | `grid-template-columns: repeat(5, 1fr);` | Layout/Computed에서 열 정의 확인 |
| BUG-03 | `body` | `min-width: 1600px;` | 1600px 미만에서도 body가 줄어들지 않아 태블릿·모바일 전 구간에 가로 스크롤 발생 | `min-width` 선언 삭제 | 1024/768/480px에서 가로 스크롤과 Computed `min-width` 확인 |

BUG-03은 flex 속성의 문제가 아니다. 미디어 쿼리에 따라 Grid와 메뉴 클래스는 바뀌지만 `body`의 최소 너비가 1600px로 고정되어 전체 문서 폭이 줄지 않는 것이 원인이다. 정답 코드의 `normal.css`에는 해당 `min-width` 선언이 없다.

## 5. 감점 기준

- 정답 폴더를 그대로 복사: 수행 과정 항목 0점 및 재평가
- CSS를 8개로 만들었으나 내용은 한 파일에 남김: 분리 항목 최대 5점
- HTML 콘텐츠 삭제로 화면을 억지로 맞춤: 관련 오류 항목 감점
- 세 결함의 결과만 적고 진단 근거가 없음: 결함별 최대 5점
- 반응형 테스트를 수행하지 않음: 해당 항목 0점
- 하나의 커밋에 모든 작업을 저장: Git/GitHub 항목 최대 4점
