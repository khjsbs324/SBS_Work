# 역할 분담표

## 역할과 책임

| 담당자 | 주 역할 | 담당 산출물 | 검토자 | 완료 기준 |
|---|---|---|---|---|
| 김학습 | PM·QA | 일정, 추적표, 최종보고서 | 전원 | 문서 ID 연결·승인 완료 |
| 이디자인 | UX/UI | 디자인 리뷰·수정·테스트 | 박콘텐츠 | DES 요구사항 통과 |
| 박콘텐츠 | 콘텐츠·접근성 | 콘텐츠 리뷰·자막·구조 | 이디자인 | CON 요구사항 통과 |
| 최개발 | JavaScript·GitHub | 상호작용 수정·PR·Pages 테스트 | 김학습 | FUN/GH 요구사항 통과 |

## RACI 예시

| 업무 | PM | 디자인 | 콘텐츠 | 개발 |
|---|---|---|---|---|
| 요구사항 분석 | A/R | C | C | C |
| 디자인 수정 | C | A/R | C | C |
| 접근성 콘텐츠 수정 | C | C | A/R | C |
| JavaScript·GitHub 수정 | C | C | C | A/R |
| 재검증 | A/R | R | R | R |
| 최종 승인 | A | C | C | C |

`R`: 수행, `A`: 최종 책임, `C`: 협의

## 협업 규칙

- 매일 17시에 결함 상태와 차단 이슈를 공유한다.
- 우선순위 `상` 결함은 발견 즉시 PM에게 알린다.
- 수정자는 자신의 변경을 단위 테스트하고, 다른 팀원이 재검증한다.
- 파일 버전 충돌이 발생하면 PM이 기준본을 지정한다.
