3. BEST PICKS 5열 Grid

css
/* 학생 코드 */
.grid-5 {
  /* display: grid; */
  display: flex;
  flex-direction: row;
  grid-template-columns: repeat(5 1fr);
}

css
/* 정답 코드 */
.grid-5 {
  display: grid;
  grid-template-columns: repeat(5, 1fr);
}

피드백:
repeat()의 반복 횟수와 트랙 크기 사이에 쉼표가 빠져 있고, Grid 대신 Flex로 변경되어 있습니다. Flex 상태에서는 media.css의 3열·2열 grid-template-columns가 동작하지 않습니다. 이번 과제는 1920px에서 5열, 1024px에서 3열, 768px과 480px에서 2열 Grid가 핵심이므로 display:grid와 올바른 repeat(5, 1fr) 문법을 함께 적용해야 합니다.
