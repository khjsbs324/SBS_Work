## 사이트 입력용 피드백

1. 컨테이너 변수명

css
/* 학생 코드 */
.con {
  max-width: var(--containner);
}

css
/* 정답 코드 */
.con {
  max-width: var(--container);
}

피드백:
보고서에서는 수정 방법을 정확히 적었지만 최종 layout_cpn.css에는 --containner가 남아 있습니다. 이 때문에 1920px에서 max-width가 none으로 계산되고 콘텐츠 최대 폭과 좌우 중앙 정렬이 기준과 달라집니다.

2. BEST PICKS Grid

css
/* 학생 코드 */
.grid-5 {
  grid-template-columns: repeat(5 1fr);
}

css
/* 정답 코드 */
.grid-5 {
  display: grid;
  grid-template-columns: repeat(5, 1fr);
}

피드백:
repeat()의 쉼표가 빠져 5열 선언이 무효입니다. 실제 계산값도 데스크톱에서 Grid가 아닌 Flex와 columns:none으로 확인됩니다. 쉼표를 추가하고 Grid 표시가 다른 규칙에 의해 덮이지 않는지 Computed에서 다시 확인해야 합니다.

3. body 고정 폭

css
/* 학생 코드 */
body {
  min-width: 1600px;
}

css
/* 정답 코드 */
body {
  word-break: keep-all;
}

피드백:
normal.css의 min-width:1600px이 남아 있어 1024px·768px·480px 모두 문서 폭이 1600px으로 계산됩니다. 보고서에서 이 원인을 찾았으므로 동일한 제출 폴더의 실제 코드를 수정하고 가로 스크롤이 사라졌는지 재확인해야 합니다.

4. style.css 중복 연결

html
<!-- 학생 코드 -->
<link rel="stylesheet" href="./css/style.css">
<link rel="stylesheet" href="./css/media.css">
<link rel="stylesheet" href="./css/style.css">

html
<!-- 정답 코드 -->
<link rel="stylesheet" href="./css/style.css">
<link rel="stylesheet" href="./css/media.css">

피드백:
media.css 뒤에서 style.css를 다시 연결해 반응형 오버라이드보다 페이지 기본 규칙이 뒤늦게 재적용될 수 있습니다. 현재도 같은 파일을 두 번 요청하고 규칙을 중복 평가하므로 마지막 중복 링크를 제거해야 캐스케이드 순서가 명확해집니다.
