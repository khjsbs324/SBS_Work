# CSS 분리·오류 수정 실습 최종 산출물

이 폴더는 `문제 코드`와 `정답`을 직접 비교해 만든 최종 수업 자료다. 기존의 많은 산출물 폴더를 사용하지 않고 아래 4개 문서만으로 배포·수행·평가할 수 있다.

## 파일 구성

| 파일 | 대상 | 용도 | 공개 시점 |
|---|---|---|---|
| `01_강사용_수업진행안.md` | 강사 | 준비, 진행, 힌트, 마감 안내 | 강사용 |
| `02_학생용_과제안내서.md` | 학생 | 과제 목표, 작업 절차, 제출 규칙 | 수업 시작 |
| `03_학생_제출_산출물.md` | 학생 | 작성 후 제출하는 단일 보고서 양식 | 수업 시작 |
| `04_강사용_정답_및_채점표.md` | 강사 | 정답 3건, CSS 분리 기준, 채점표 | 평가 종료 후 |

## 강사 배포 방법

학생에게 다음 세 가지를 전달한다.

1. `문제 코드/index.html`
2. `문제 코드/css/style.css`
3. `문제 코드/정답.png`
4. 이 폴더의 `02_학생용_과제안내서.md`
5. 이 폴더의 `03_학생_제출_산출물.md`

`정답` 폴더와 `01_강사용_수업진행안.md`, `04_강사용_정답_및_채점표.md`는 평가 종료 전 공개하지 않는다.

## 과제 한 줄 요약

하나로 합쳐진 `style.css`를 역할별 8개 CSS 파일로 분리하고, 컨테이너·Grid·반응형 화면을 깨뜨리는 CSS 오류 3건을 개발자 도구로 찾아 수정한 뒤 GitHub에 과정과 결과를 제출한다.
