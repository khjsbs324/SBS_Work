# 학생용 과제안내서

## 과제명

MALBON 반응형 페이지 CSS 분리 및 레이아웃 오류 수정

## 과제 목표

제공된 `style.css`에는 모든 스타일이 한 파일에 섞여 있고, 화면을 깨뜨리는 오류가 3곳 포함되어 있습니다. CSS를 역할별 파일로 정리하고, `정답.png`와 비교하여 오류 3건을 찾아 수정합니다.

## 제공 파일

```text
문제 코드/
├─ index.html
├─ 정답.png
└─ css/
   └─ style.css
```

## 해야 할 일

### 1. GitHub 작업 준비
1. 본인 저장소에 문제 코드를 올립니다.
2. 원본 상태를 첫 커밋으로 남깁니다.

권장 커밋 예시:

```text
chore: add initial problem files
refactor: split base tokens and components
refactor: separate layout and responsive styles
fix: correct three layout defects
docs: add test evidence and report
```

### 2. CSS를 8개 파일로 분리

다음 파일명을 사용합니다.

| 순서 | 파일 | 담을 내용 |
|---:|---|---|
| 1 | `.css` | 폰트 선언, reset, 기본 HTML 요소 |
| 2 | `.css` | 색상·크기·간격 등 원시 CSS 변수 |
| 3 | `.css` | 프로젝트에서 사용하는 의미 기반 변수 |
| 4 | `.css` | 버튼, 아이콘, 탭 버튼, 이동 버튼 |
| 5 | `.css` | 글자 유틸리티, 이미지, 상품·스와치 항목 |
| 6 | `.css` | `.con`, Grid, 공통 섹션 배치 |
| 7 | `.css` | 헤더부터 푸터까지 페이지별 스타일 |
| 8 | `.css` | 1600/1024/768/480px 반응형 규칙 |

`index.html`에서 위 순서대로 연결합니다. 파일을 나눈 뒤 원본 화면이 더 깨지면 연결 순서나 누락된 선택자를 먼저 확인합니다.

### 3. 레이아웃 오류 3건 찾기

정답.png와 문제 화면을 비교해 다음 현상을 진단합니다.

- 넓은 화면에서 콘텐츠 최대 폭과 좌우 정렬
- BEST PICKS 상품의 5단 Grid
- 1600px보다 좁은 태블릿·모바일 화면에서 발생하는 페이지 전체 가로 스크롤

보고서에는 선택자, 문제 선언, 증상, 개발자 도구에서 확인한 내용, 수정 선언을 기록합니다.

### 4. 반응형 테스트

| 너비 | 필수 확인 |
|---:|---|
| 1920px | 컨테이너 최대 폭과 좌우 여백 |
| 1600px | 컨테이너 여백 전환 |
| 1024px | GNB/모바일 메뉴, 상품 Grid, 가로 스크롤 없음 |
| 768px | 2단 Grid, 컬렉션 세로 배치, body 너비 |
| 480px | 모바일 글자·간격·푸터, 가로 스크롤 없음 |

### 5. Pull Request 작성

PR에 다음 내용을 포함합니다.

- 변경한 CSS 파일 목록
- 오류 3건의 원인과 수정 내용
- 테스트한 화면 너비와 결과
- 수정 전후 스크린샷
- 남은 문제 또는 제한사항

## 변경 금지

- 상품·배너·텍스트 등 HTML 콘텐츠를 임의 삭제하지 않습니다.
- JavaScript, 프레임워크, 백엔드를 추가하지 않습니다.
- 정답 코드를 복사하지 않고 문제 코드에서 직접 분리·진단합니다.
- 외부 사이트를 공격하거나 허가되지 않은 코드를 사용하지 않습니다.
