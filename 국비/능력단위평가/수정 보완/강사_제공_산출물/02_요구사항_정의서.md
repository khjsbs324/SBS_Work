# 요구사항 정의서

## 기술 제한

- 허용: HTML, CSS, Vanilla JavaScript, Git, GitHub, GitHub Pages
- 제외: Node 기반 애플리케이션, 프레임워크, 백엔드, DB, 외부 API, 실제 인증

## 비기능 기준

- HTML 유효성, CSS 문법, 콘솔 오류를 점검한다.
- JavaScript는 DOM 로드 이후 실행하며 존재하지 않는 요소 접근을 방어한다.
- `localStorage`에는 이름·이메일 등 개인정보를 저장하지 않는다.
- 외부 이미지·폰트·코드의 라이선스와 출처를 README에 기록한다.
