## 지도 포인트

- 프런트엔드 폼 검증은 UX 데모이며 보안 또는 실제 전송 검증이라고 표현하지 않게 한다.
- `localStorage`는 비민감 예시 상태에만 사용하고 실패할 수 있음을 가르친다.
- 로컬에서 성공해도 GitHub Pages의 하위 경로와 대소문자 환경에서 다시 확인하게 한다.
- JavaScript 수정 후 비활성 상태의 콘텐츠 접근성과 다른 위젯의 회귀를 확인하게 한다.
