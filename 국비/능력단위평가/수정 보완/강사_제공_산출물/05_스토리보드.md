# 스토리보드

## 화면 목록

| 화면 ID | 파일 | 주요 기능 | 다음 화면 |
|---|---|---|---|
| SCR-001 | `index.html` | 반응형 메뉴, 추천 강좌 | SCR-002 |
| SCR-002 | `courses.html` | 필터 버튼, 강좌 카드 | SCR-003 |
| SCR-003 | `course-detail.html` | 탭·아코디언, 학습 시작 | SCR-004 |
| SCR-004 | `lesson.html` | 영상 자막, 진도 체크·초기화 | SCR-005 |
| SCR-005 | `contact.html` | 문의 폼 검증·성공 데모 | SCR-001 |

## 공통 헤더

- 로고 링크, 데스크톱 메뉴, 모바일 메뉴 버튼
- 현재 페이지는 텍스트와 `aria-current="page"`로 표시
- 메뉴 버튼의 접근 가능한 이름과 확장 상태 제공

## 주요 화면

### SCR-003 강좌 상세

- 탭: 소개, 커리큘럼, 강사 소개
- 아코디언: 차시별 학습 내용
- JS 실패 시에도 모든 패널 콘텐츠가 HTML에 존재하고 읽을 수 있어야 한다.

### SCR-004 동영상 학습

- `<video controls>`와 `<track kind="captions">` 사용
- 진도 체크박스는 `localStorage`에 강좌 ID와 완료 여부만 저장
- `진도 초기화`는 확인 후 해당 강좌 키만 삭제

### SCR-005 문의 폼

- 이름, 이메일, 문의 유형, 내용, 동의 체크박스
- 교육용 데모이므로 실제 전송하지 않으며 개인정보 입력 금지 안내
- 오류 요약과 필드별 오류, 성공 메시지 제공
