# 강사 제공 산출물 안내

이 폴더는 NCS 학습모듈 `수정 보완(LM0802010406_13v1)` 수업에서 강사가 학습자에게 제공할 자료의 작성 예시이다. 모든 문서는 가상의 **한빛교육 반응형 학습 포털 개선 프로젝트(EDU-PORTAL-2026)**를 공통 사례로 사용한다.

## 권장 제공 순서

1. `01_프로젝트_브리프.md`: 프로젝트 배경과 범위 안내
2. `02_요구사항_정의서.md`: 검증 기준이 되는 요구사항 제공
3. `03_요구사항_분석서.md`: 우선순위·인수 조건·추적 관계 설명
4. `04_웹_스타일가이드.md`: 심미적 디자인 기준 제공
5. `05_스토리보드.md`: 화면 구조와 사용자 흐름 제공
6. `06_콘텐츠_명세서.md`: 콘텐츠·접근성 기준 제공
7. `07_기능별_프로세스_정의서.md`: 기능 정상 동작 기준 제공
8. `08_리뷰_환경_및_시나리오.md`: 테스트 환경과 절차 제공
9. `09_결함이_포함된_과제_설명서.md`: 학습자가 찾아야 할 의도적 결함 안내
10. `10_평가_루브릭.md`: 제출물별 채점 기준 제공
11. `11_강사용_정답_및_피드백_가이드.md`: 정답·지도 포인트(학생 배포 금지)
12. `12_수업운영_체크리스트.md`: 수업 전·중·후 운영 점검

## 운영 원칙

- 1~10번은 학생에게 배포할 수 있다.
- 11번은 평가 종료 전 학생에게 공개하지 않는다.
- 요구사항 ID는 학생 제출물에서도 동일하게 사용해 추적성을 유지한다.
- 예시에 기재된 개인정보와 기관명은 모두 가상이다.
