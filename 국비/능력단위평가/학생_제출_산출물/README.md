# 학생 제출 산출물 안내

이 폴더는 `EDU-PORTAL-2026` 프로젝트를 수행한 학생 팀의 모범 제출 예시이다. 실제 제출 시 대괄호 예시나 가상 담당자명을 본인 정보로 바꾸고, 수행하지 않은 테스트를 통과로 표시하지 않는다.

## 폴더 구성

- `00_공통`: 표지, 역할 분담, 산출물 목록, 요구사항 추적표
- `01_디자인`: 심미적 디자인 리뷰·수정·단위 테스트·재검증
- `02_콘텐츠`: 콘텐츠 사용성·접근성 리뷰·수정·재검증
- `03_기능`: JavaScript 상호작용·GitHub·Pages 리뷰, 수정, 단위 테스트, 재검증
- `04_최종`: 최종 결과보고서와 회고

## 파일명 규칙

`팀명_문서명_v주버전.부버전_YYYYMMDD.md`

예: `A팀_디자인리뷰체크리스트_v1.0_20260905.md`

## 공통 작성 규칙

- 요구사항 ID: `DES-001`, `CON-001`, `FUN-001` 형식
- 결함 ID: `DEF-DES-001`, `DEF-CON-001`, `DEF-FUN-001` 형식
- 테스트 ID: `TC-DES-001-01`, `TC-CON-001-01`, `TC-FUN-001-01` 형식
- 모든 결함은 기대 결과, 실제 결과, 재현 절차, 환경, 우선순위, 증빙을 포함한다.
- 모든 수정은 변경 파일/화면, 담당자, 완료일, 단위 테스트와 연결한다.
- 최종 제출 전 개인정보, 실제 이메일, 개인 액세스 토큰, 비공개 저장소 정보를 제거한다.

## 제출 전 점검

- [ ] 문서 제목, 버전, 작성자, 작성일이 있다.
- [ ] 요구사항 ID와 결함 ID가 문서 간 일치한다.
- [ ] 우선순위 `상` 결함이 모두 종료되었다.
- [ ] 실패한 테스트는 숨기지 않고 조치 계획을 적었다.
- [ ] 수정 전후 증빙 파일명이 문서와 일치한다.
- [ ] 출처와 AI 사용 내역을 기록했다.
