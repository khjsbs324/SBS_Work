# AI 기획과 발상 비NCS 실기평가 자료

이 평가는 ChatGPT와 Firefly를 활용하여 개인 포트폴리오 사이트를 위한 퍼스널 브랜딩을 기획하는 기관 자체 비NCS 실기평가다. 자기분석과 목표 사용자 설정에서 시작해 브랜드 아이디어·메시지·비주얼 대안을 생성하고, 학생이 비교·선택·수정하여 사이트 정보구조와 주요 화면 시안으로 구체화한다.
