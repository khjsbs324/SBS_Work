# 강사용 정답 및 채점표

## 1. 정답의 성격

이 과제에는 하나의 고정된 브랜드 정답이 없다. 다음 연결이 제출물의 직접 증빙으로 성립해야 한다.

`자기 근거 → 목표 사용자·사이트 목적 → ChatGPT 프롬프트·대안 → 브랜드 선택·메시지 → Firefly 프롬프트·생성안 → 학생 후편집·비주얼 체계 → 정보구조·주요 화면 → 사실·독창성·출처·개인정보 검토`

AI 출력의 양이나 시각적 화려함보다 학생의 문제 설정, 판단, 편집과 사이트 적용의 일관성을 평가한다.

## 2. 등록용 정답 문구

자기분석과 목표 사용자 설정, 퍼스널 브랜드 콘셉트·키워드·슬로건, ChatGPT를 활용한 아이디어 발상 과정, Firefly를 활용한 브랜드 이미지 제작 과정, 컬러·서체·그래픽 모티프가 포함된 비주얼 아이덴티티, 포트폴리오 사이트 정보구조와 주요 화면 시안, 최종 결과물 선정·보완 근거 및 AI·저작권 검토가 포함된 퍼스널 브랜딩 기획안.

## 3. 접수 확인

- [ ] 기획서 PDF의 글·표·이미지를 식별할 수 있다.
- [ ] 편집 원본 또는 공유 링크를 열 수 있다.
- [ ] 최종 이미지 파일이 보고서·원본과 일치한다.
- [ ] ChatGPT와 Firefly의 프롬프트·결과·학생 수정 기록을 확인할 수 있다.
- [ ] 주요 화면 3개와 사이트 정보구조가 있다.
- [ ] 사실·독창성·외부 자산·개인정보 점검표가 있다.

## 4. 직접 증빙 확인 순서

1. 자기분석의 경험·작업물 근거와 실제 제출 내용을 대조한다.
2. 목표 사용자·사이트 목적·필요 인상의 연결을 확인한다.
3. ChatGPT 프롬프트·응답·후속 질문과 학생 수정 내용을 확인한다.
4. 브랜드 대안 비교와 최종 콘셉트·메시지 체계를 확인한다.
5. Firefly 프롬프트·생성안·변형·비교와 선택을 확인한다.
6. AI 원본과 학생 후편집 결과, 비주얼 규칙을 대조한다.
7. 참고 사이트 분석과 학생 사이트의 차이를 확인한다.
8. 사이트맵·콘텐츠 우선순위와 주요 화면 적용을 확인한다.
9. 사실·출처·이용 조건·개인정보와 최종 파일 구조를 확인한다.

## 6. 경계 사례

- 프롬프트가 길어도 자기 맥락과 목적이 없으면 높은 수준으로 보지 않는다.
- AI가 제안한 브랜드명·슬로건을 그대로 사용해도 실제 근거·비교·검증과 학생의 선택 이유가 없으면 높은 수준으로 보지 않는다.
- 생성 이미지 수가 많아도 프롬프트 변화와 비교 기준이 없으면 대안 탐색으로 인정하기 어렵다.
- AI 이미지에 문자가 깨졌거나 인체·구조 오류가 남아 있으면 적용 맥락과 후편집 여부를 확인한다.
- 참고 사이트와 메뉴 이름이 같다는 사실만으로 복제로 판단하지 않는다. 고유 상징·카피·이미지·시각 체계·레이아웃의 실질적 유사성을 함께 본다.
- 외부 자산의 이용 조건을 확정하지 못했더라도 불확실성을 기록하고 대체·보류했다면 검토 과정으로 인정한다.
- 사이트를 코딩하거나 배포했더라도 AI 기획·선택·검증의 직접 증빙이 없는 문항 점수를 자동으로 높이지 않는다.

## 7. 중복 감점 방지

- 하나의 링크 접근 장애로 여러 항목을 확인하지 못하면 접근 문제와 영향 범위를 별도로 기록한다.
- 자기 근거가 없는 과장 문구가 메시지와 화면에 반복되어도 주된 항목에서만 감점하고, 사실 검토 항목은 발견·수정 여부를 평가한다.
- 참고 사이트 복제가 정보구조와 화면 모두에 영향을 주면 원인을 한 번 기록하고 각 항목에서는 분석·차별화 시도 여부를 구분해 본다.
- 보고서 미관은 평가하지 않는다. 가독성 때문에 직접 증빙을 확인할 수 없는 범위만 기록한다.

- [ ] AI 출력과 학생의 선택·수정·추가를 구분했다.
