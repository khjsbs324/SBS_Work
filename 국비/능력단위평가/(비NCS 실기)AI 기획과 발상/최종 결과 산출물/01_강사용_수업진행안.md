# 강사용 수업진행안

## 1. 평가 개요

| 항목 | 내용 |
|---|---|
| 평가 구분 | 비NCS 실기평가·기관 자체 기준 |
| 교과목 | AI 기획과 발상 |
| 시험 문제 | ChatGPT와 Firefly를 활용하여 나의 포트폴리오 사이트를 위한 퍼스널 브랜딩 기획 결과물을 제출해 주세요. |
| 평가 방식 | 개인 실기 및 포트폴리오 평가 |
| 평가 시간 | 300분 |
| 필수 제출 | 기획서 PDF, 편집 원본 또는 공유 링크, 최종 이미지 파일 |
| 문항·총점 | 10문항, 100점 |

## 2. 평가 목표

학생이 자신의 경험·역량·작업물을 근거로 포트폴리오 사이트의 브랜드 방향을 설정하고, ChatGPT와 Firefly를 목적에 맞게 활용해 다양한 언어·시각 아이디어를 만들 수 있는지 평가한다. AI 결과를 그대로 제출하는 것이 아니라 비교·검증·선택·수정하여 브랜드 메시지, 비주얼 아이덴티티, 정보구조와 주요 화면 시안으로 통합하는 능력을 확인한다.

## 3. 평가 전 준비

- [ ] 평가계획서 원문과 기관 자체 평가요소임을 안내한다.
- [ ] 학생이 실제 이력·자격·프로젝트·보유 기술을 확인할 자료를 준비하게 한다.
- [ ] ChatGPT와 Firefly 접속·로그인·저장 환경을 점검한다.
- [ ] 프롬프트와 결과를 번호로 기록할 제출 템플릿을 배포한다.
- [ ] 참고 사이트는 구조 분석용이며 복제 과제가 아님을 안내한다.
- [ ] 민감한 개인정보·타인의 비공개 자료를 AI 도구에 입력하지 않도록 안내한다.
- [ ] AI 서비스 장애 시 이전에 저장한 결과 또는 강사 제공 대체 자료 사용 기준을 준비한다.

## 4. 300분 진행

| 단계 | 시간 | 학생 활동 | 강사 확인 |
|---|---:|---|---|
| 과제·참고 구조 분석 | 20분 | 평가 범위와 참고 사이트의 구성 원리 분석 | 복제가 아닌 분석인가 |
| 자기분석·목표 사용자 | 35분 | 경험·강점·작업물, 사이트 목적·필요 인상 정리 | 실제 근거와 사용자가 연결되는가 |
| ChatGPT 아이디어 발상 | 45분 | 프롬프트 설계, 대안 생성, 후속 질문 | 맥락·제약·출력 형식이 있는가 |
| 콘셉트·메시지 선정 | 30분 | 대안 비교, 콘셉트·키워드·슬로건·소개 문장 확정 | 선택·수정 근거가 있는가 |
| Firefly 시각 탐색 | 55분 | 이미지 프롬프트, 생성·변형·비교·선정 | 대안과 조건 변화가 추적되는가 |
| 비주얼 아이덴티티 | 45분 | 후편집, 컬러·서체·모티프·이미지 규칙 | AI 원본과 학생 보완이 구분되는가 |
| 사이트 구조·화면 시안 | 50분 | 정보구조와 인트로/메인·프로필·프로젝트 화면 | 브랜드와 콘텐츠 위계가 연결되는가 |
| 검증·패키지 | 20분 | 사실·유사성·출처·개인정보, 파일·링크 확인 | 최종 결과를 재현·확인할 수 있는가 |
| 합계 | 300분 |  |  |

## 5. 진행 중 관찰 포인트

- 학생이 자신의 실제 자료를 먼저 분석하고 AI에 맥락을 제공하는가.
- 같은 질문을 반복하지 않고 제약·비교 기준·출력 형식을 조정하는가.
- AI가 제안한 브랜드 문구의 과장·상투성·사실 오류를 검토하는가.
- Firefly 생성안의 문자·인체·구조 오류와 참고작 유사성을 살피는가.
- 생성 결과를 직접 보정하고 재사용 가능한 시각 규칙으로 정리하는가.
- 브랜드가 사이트의 카피·정보구조·프로젝트 분류와 화면 위계에 적용되는가.
- 참고 사이트의 고유 상징·카피·이미지·레이아웃을 복제하지 않는가.

## 6. 강사 개입 범위

허용:

- 평가 범위, 시간, 제출 규칙과 도구의 일반 기능 안내
- 개인정보·사실 확인·출처 기록 방법 안내
- 링크 권한과 파일 열림 같은 제출 기술 문제 안내

금지:

- 학생 대신 브랜드 콘셉트·슬로건·비주얼을 선택하는 행위
- 특정 프롬프트·생성 이미지·레이아웃을 정답으로 지시하는 행위
- 학생의 실제 경험에 없는 경력·성과를 만들어 주는 행위

## 7. 회수와 채점 순서

1. PDF, 편집 원본과 최종 이미지가 열리는지 확인한다.
2. 자기분석의 근거 사례와 브랜드 자원을 대조한다.
3. 목표 사용자·사이트 목적·전달 인상을 확인한다.
4. ChatGPT 프롬프트·응답·후속 질문·학생 수정 기록을 확인한다.
5. 브랜드 대안 비교와 콘셉트·메시지 체계를 확인한다.
6. Firefly 프롬프트·생성안·변형·선정·후편집을 확인한다.
7. 비주얼 규칙과 사이트 정보구조·주요 화면 적용을 확인한다.
8. 사실·독창성·외부 자산·개인정보 검토와 파일 구조를 확인한다.
9. `Exam.md`의 AI-01~AI-10에 직접 증빙 위치와 점수를 기록한다.

## 8. 미확인 처리

- AI 대화 공유 링크가 열리지 않아도 보고서에 프롬프트·결과·후속 질문이 충분히 기록되어 있으면 인정한다.
- Firefly 생성 이력이 없어도 원본 생성안·프롬프트·후편집 전후를 식별할 수 있어야 한다.
- 외부 자산의 이용 조건이 불명확하면 확인 불가로 기록하고 대체·보류 판단 여부를 본다.
- 미확인 자료를 추측하여 인정하거나 자동 0점 처리하지 않는다.
