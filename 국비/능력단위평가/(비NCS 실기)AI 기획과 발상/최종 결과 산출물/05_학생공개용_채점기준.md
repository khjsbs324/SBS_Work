# 학생공개용 채점기준

## 평가에서 보는 흐름

이 평가는 AI가 만든 결과를 많이 보여 주는 과제가 아닙니다. 다음 과정이 근거와 함께 연결되는지를 봅니다.

`나의 실제 경험 → 목표 사용자·사이트 목적 → ChatGPT 아이디어 → 비교·선택·메시지 → Firefly 시각 대안 → 직접 보완·비주얼 체계 → 사이트 구조·화면 → 검증·최종 정리`

## 평가 영역

### 1. 자기분석과 사이트 목표

확인 내용:

- 경험·역량·성향·작업 강점에 실제 근거가 있는가
- 목표 방문자와 방문 상황을 구체적으로 정했는가
- 사이트 목적·핵심 행동·전달할 인상이 연결되는가

### 2. ChatGPT 활용과 브랜드 아이디어

확인 내용:

- 목적·맥락·제약·출력 형식을 포함해 질문했는가
- 후속 질문으로 결과를 발전시켰는가
- 서로 다른 브랜드 대안을 같은 기준으로 비교했는가
- AI 제안을 검토하고 본인에게 맞게 선택·조합·수정했는가

### 3. 브랜드 메시지

확인 내용:

- 콘셉트·키워드·슬로건·자기소개 문장이 일관되는가
- 실제 경험과 목표 사용자에 맞는 표현인가
- 과장·상투적 표현과 사실 오류를 제거했는가

### 4. Firefly 활용과 시각 대안

확인 내용:

- 콘셉트·구도·스타일·색·용도·제외 조건을 프롬프트에 반영했는가
- 조건을 바꾸며 의미 있는 이미지 대안을 만들었는가
- 브랜드 적합성·독창성·적용성·오류를 비교했는가

### 5. 후편집과 비주얼 아이덴티티

확인 내용:

- AI 원본의 오류와 한계를 직접 보완했는가
- 컬러·서체·그래픽 모티프·이미지 스타일의 규칙이 있는가
- 사용 예와 금지 예를 통해 일관성을 설명했는가

### 6. 사이트 기획과 주요 화면

확인 내용:

- 참고 사이트의 구성 원리를 분석하고 본인 콘텐츠에 맞게 바꿨는가
- 사이트 정보구조와 콘텐츠 우선순위가 목표 사용자 행동에 맞는가
- 인트로 또는 메인, 프로필, 프로젝트 목록에 브랜드가 일관되게 적용됐는가

### 7. 검증과 최종 정리

확인 내용:

- AI 문구의 경력·자격·수치·프로젝트 정보를 확인했는가
- 참고작과 실질적으로 다른 결과인지 점검했는가
- 외부 자산의 출처·이용 조건과 개인정보 공개 범위를 확인했는가
- AI가 제공한 부분과 본인이 판단·수정한 부분을 구분했는가

## 공통 4수준 성취기준

| 수준 | 판단 기준 |
|---|---|
| 매우 충실 | 실제 자기 근거와 목표가 명확하고 AI 활용·대안 비교·학생 보완·사이트 적용·검증이 빠짐없이 연결됩니다. |
| 충실 | 주요 과정과 결과는 확인되지만 일부 근거·프롬프트 발전·대안 비교·후편집·화면 적용 또는 검토가 부족합니다. |
| 부분 충실 | 결과물은 있으나 AI 출력을 그대로 사용한 부분이 많고 자기 근거와 선택·수정 과정의 연결이 약합니다. |
| 미충족 | 자기분석, AI 활용 기록, 브랜드 체계, 주요 화면 또는 검증의 핵심 증빙을 확인하기 어렵습니다. |

## 작업할 때 기억할 점

- AI보다 먼저 자신의 실제 경험과 작업물을 정리하세요.
- 첫 결과를 정답으로 사용하지 말고 여러 대안을 같은 기준으로 비교하세요.
- AI가 만든 문장과 이미지를 반드시 사실 확인하고 직접 수정하세요.
- 참고 사이트의 고유 표현을 복제하지 말고 본인의 작업물에 맞게 재구성하세요.
- 완성 화면만 보여 주지 말고 프롬프트·선택·후편집·검증 과정을 남기세요.

사이트 코딩과 배포는 이 평가의 필수 대상이 아닙니다.
