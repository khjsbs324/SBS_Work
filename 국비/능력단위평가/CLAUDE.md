# CLAUDE.md

이 파일은 Claude Code가 `능력단위평가` 작업공간에서 따라야 하는 공통 지침이다.

## 작업공간 구조

이곳은 여러 NCS 능력단위평가를 관리한다. 루트는 공통 규칙과 도구를 제공하고 실제 평가 자료는 능력단위별 하위 폴더에 둔다.

```text
능력단위평가/
├─ AGENTS.md                     공통 운영 지침
├─ CLAUDE.md                     Claude 공통 지침
├─ 피드백.md                     공통 채점·피드백 기준
├─ 평가_리포지터리_주소.txt      공통 학생 저장소 목록
├─ 문제 출제 예시.pdf            공통 출제 참고 자료
├─ .agents/                      공통 검토 역할
├─ skills/                       공통 작업 스킬
└─ <능력단위명>/                 평가별 원본과 산출물
```

## 작업 대상 선택

1. 작업 전에 사용자가 지정한 능력단위명과 일치하는 하위 폴더를 확정한다.
2. 평가명이 없거나 여러 폴더와 일치하면 추측하지 말고 확인한다.
3. 평가 폴더에 전용 `AGENTS.md`, `CLAUDE.md`, `피드백.md`가 있으면 공통 문서와 함께 읽는다.
4. 평가 전용 문서가 더 구체적이면 해당 평가 범위에서 전용 문서를 우선한다.
5. 선택하지 않은 다른 평가 폴더는 수정하지 않는다.

## 자료 분리

평가별 폴더에는 NCS 원본과 요약, 수행준거, 시험지, `Exam.md`, 문제·정답 코드, 산출물, 채점 결과와 증빙을 둔다.

루트에는 공통 지침과 스킬, 출제 형식 참고 자료, 공통 학생 저장소 목록 및 공통 피드백 원칙을 유지한다.

## 문제 제작

- `skills/ncs-exam-production/SKILL.md`와 선택한 평가의 원본·수행준거를 읽는다.
- 수행준거 수와 채점 문항 수를 일치시킨다.
- 문제 코드와 정답은 반드시 같은 평가 폴더의 자료끼리 비교한다.
- 학생용 자료와 강사용 정답을 분리한다.
- 별도 지시가 없으면 총점은 100점이며 수행준거별 4단계 기준을 작성한다.
- 특정 평가의 결함, 선택자, 화면 너비 또는 시나리오를 다른 평가에 자동 적용하지 않는다.
- 최종 산출물은 해당 평가 폴더에 저장한다.

## 채점과 피드백

- `채점 진행해줘` 요청을 받으면 능력단위명을 먼저 확인한다.
- 해당 평가 폴더의 수행준거와 `Exam.md`를 기준으로 증빙 중심 절대평가를 수행한다.
- 학생 저장소와 배포 화면을 확인하고 채점 커밋 및 검토 환경을 기록한다.
- 실행하지 않은 테스트나 확인하지 못한 화면을 정상으로 기록하지 않는다.
- 학생 공개용 피드백에는 원점수, 환산 공식, 순위, 내부 판정 또는 강사용 정답 전체를 넣지 않는다.
- 결과는 해당 평가 폴더의 `채점 완료`에 저장한다.
- 사이트 등록 전후에 학생명, 능력단위명, 수행준거, 점수 합계와 피드백을 다시 검증한다.

## 품질 확인

- 평가 폴더 선택이 정확하다.
- 수행준거와 문제·루브릭의 추적성이 유지된다.
- 배점 합계 및 환산 합계가 정확하다.
- 모든 판단에 파일, 코드, 화면, 동작 또는 Git 기록 근거가 있다.
- 학생용과 강사용 자료가 분리되어 있다.
- 상대 경로와 내부 링크가 실제 파일 위치와 일치한다.
- 한글 문서는 UTF-8로 저장한다.
- 다른 능력단위평가 파일을 혼합하거나 변경하지 않는다.

세부 절차와 안전 규칙은 루트 `AGENTS.md`를 따른다.

## `문제 등록` 명령

사용자가 `문제 등록`이라고 하면 같은 폴더의 `AGENTS.md`에 정의된 문제 등록 파이프라인을 끝까지 실행한다.

- 요청에 능력단위명이 있으면 정확히 일치하는 하위 폴더를 선택한다.
- 이름이 없으면 현재 작업 폴더명 또는 대화에서 마지막으로 확정된 능력단위명을 사용한다.
- 확정할 수 없거나 후보가 여러 개면 능력단위명을 묻는다.
- 선택한 평가 폴더의 전용 지침, 수행준거, `Exam.md`, 학생·강사용 자료를 기준으로 등록 내용을 작성한다.

기본 사이트 이동 순서는 다음과 같다.

```text
능력단위평가
→ 해당 능력단위 평가내역
→ 전체점수 옆 평가도구 탭
→ 평가문제등록
→ 문제등록 또는 기존 문제 수정
→ 상세정보 재검증
```

## 평가기준과 채점기준 구분

### 평가기준

- 화면 위쪽에서 능력단위요소, 수행준거와 배점을 설정하는 영역이다.
- 모든 능력단위요소와 수행준거를 선택한다.
- 수행준거 원문은 수정·요약하거나 상세 루브릭으로 교체하지 않는다.
- 수행준거별 배점은 `Exam.md`와 대응시키고 총점을 100점으로 맞춘다.

### 채점기준

- 화면 아래쪽 문제등록 영역의 학생 공개용 편집란이다.
- 상세한 4단계 점수 기준은 이곳에 작성한다.
- `DC-01`, `DC-12`, `증빙:` 같은 내부 표기를 제거한다.
- 항목 제목은 `기본 스타일가이드 요소 분석 — 8점`처럼 자연어로 작성하고 굵게 표시한다.
- 항목별 최고점부터 최저점까지 구체적인 점수 구간을 작성한다.
- 총점 제목도 굵게 표시한다.
- 내부 판정, 강사용 메모, 자동화 과정 또는 도구 사용 흔적을 학생에게 노출하지 않는다.

## 등록 및 검증 규칙

- 같은 문제가 있으면 중복 등록하지 말고 수정한다.
- 과정명·교과목·능력단위명·평가도구를 로컬 자료와 대조한다.
- 문제, 설명, 정답과 채점기준을 각각 올바른 입력란에 작성한다.
- 파일 제출이 필요하면 업로드 기능을 사용하고 URL 제출이 필요하면 링크 기능을 사용한다.
- 저장 전 수행준거 수와 배점 합계를 확인한다.
- 저장 후 상세정보에서 수행준거 원문, 채점기준 내용과 굵은 제목, 기능 설정 및 `100 / 100`을 다시 확인한다.
- 오류가 발생하면 기존 데이터 보존 여부를 확인하고 잘못된 입력란만 수정한다.
