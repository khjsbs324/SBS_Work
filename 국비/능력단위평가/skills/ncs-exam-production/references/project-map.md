# 프로젝트 자료 구조

## 자료 우선순위

1. 사용자의 최신 요청
2. 현재 `문제 코드`와 `정답` 폴더의 파일
3. 해당 NCS 원본 PDF
4. 등록 형식과 채점기준의 상세 수준을 확인하기 위한 `문제 출제 예시.pdf`
5. 기존에 작성된 Markdown 및 생성된 PDF

## 주요 출력 위치

- `최종 결과 산출물/`: 강사용 및 학생용 최종 전달 자료
- `학생_제출_산출물/`: 사용자가 요청한 경우에만 제공하는 상세 학생용 서식
- `수정 보완 시험 출제.pdf`: 인쇄 및 등록 참고용 시험 문서
- `pdf요약결과.md`: 원본 자료 분석 결과

## 필수 검증 사항

- 학생 수행 범위에 백엔드 작업이 없어야 한다.
- 문제 코드와 정답은 시험에서 요구하는 부분만 달라야 한다.
- CSS 연결 순서가 정확하고 참조한 파일이 실제로 존재해야 한다.
- 사용자가 다른 총점을 지정하지 않았다면 수행준거 배점의 합계는 100점이어야 한다.
- 각 수행준거에 작업별 증빙과 점수 구간이 있어야 한다.
- 사이트에 등록된 상세 내용이 로컬 최종 자료와 일치해야 한다.
