## 2. 프로젝트 브리프

### 2.1 배경과 문제

- **프로젝트 배경**: 2026년 국내 다류(Tea) 시장은 '건강(Health)·편의(Convenience)·경험(Experience)'을 중심으로 재편되고 있으며, 제로·저당 웰니스 음료와 2030 세대의 취향 중심 소비(밀크티·에이드·논알콜 하이볼 등 DIY 레시피)가 급성장하고 있습니다. 그러나 기존 다류 브랜드 웹사이트는 복잡한 다도 방식을 요구하거나 추상적인 감성 문구 위주로만 상품을 나열하여, 바쁜 2030 소비자가 직관적으로 맛과 조합을 이해하고 구매하기 어렵습니다.
- **해결할 사용자 문제**:
  1. **초기 화면의 정보·박스 과밀 문제**: 초기 시안(`03.브랜드AI초안.html.html`, `03.서브AI초안.html.html`)에서 상단 11인 페르소나 전환 바, 과도한 박스 테두리, 다중 스펙 설명이 한꺼번에 노출되어 인지 부하와 시각적 피로도가 높음.
  2. **차(Tea) 맛·조합 예측의 어려움**: 초기 서브페이지(`03.서브AI초안.html.html`, 20종 구성)에서는 세부 카테고리 칩과 소형 필터가 복잡하게 얽혀 있어 DIY 블렌딩(밀크티, 에이드, 하이볼)에 필요한 재료를 한눈에 모아보기 어렵고 구매 실패 우려가 큼.
  3. **복잡한 구매·장바구니 동선**: 카테고리 탐색 후 장바구니에 담거나 수량을 조절할 때 불필요한 탭 전환(일반/B2B/전화 대리주문 3모드 드로어)과 복잡한 입력 폼이 몰입을 방해함.
- **대상 사용자와 사용 맥락**:
  - **주요 대상**: 만성 피로와 카페인 부작용(수면 장애, 속 쓰림)을 겪으면서도 '헬시 플레저(Healthy Pleasure)'와 '길티프리(Guilty-Free) 리추얼'을 추구하는 2030 직장인 및 학생, 그리고 오피스·호텔 웰니스 기프팅/대량 조달 담당자.
  - **사용 맥락**: 퇴근 후 휴식이나 오후 업무 집중이 필요한 순간 데스크톱·모바일 웹으로 접속하여, 브랜드 세계관과 핵심 기술(찬물 1초 융해, KTR 3無 인증, 24시간 루틴)을 빠르게 훑어본 뒤 원하는 DIY 조합 레시피나 카테고리 상품을 필터링해 장바구니에 담고 즉시 주문·견적 문의를 수행함.
- **프로젝트 목표**:
  1. 메인·브랜드 소개 화면(`04.브랜드AI수정안.html.html`)의 불필요한 박스 테두리와 과밀 정보를 덜어내고, `[01] 브랜드 철학 → [02] 1초 융해 기술 → [03] 친환경 순환 → [04] 24H 루틴 → [05] 4대 대표 시그니처 → [06] 감각 큐레이션 → [07] 감각 스튜디오 → [08] 오프라인 쇼룸`의 정돈된 에디토리얼 위계를 구축한다.
  2. 메인 화면과 독립된 전체 상품 서브페이지(`04.서브AI수정안.html.html`)를 분리 연결하여, 4대 대표 시그니처와 32종 블렌딩 & DIY 믹솔로지 도감을 쾌적하게 탐색하게 한다.
  3. '1초 믹솔로지 추천 레시피(크리미 밀크티, 3단 오로라 에이드, 논알콜 스모키 하이볼)' 조합 탭과 7개 카테고리 필터, 직관적인 장바구니 수량(`− / +`) 조절 및 결제/견적 연동 동선을 완성한다.
- **핵심 과업**: 브랜드 메인 페이지(`04.브랜드AI수정안.html.html`)에서 브랜드 핵심 가치와 24시간 루틴·대표 시그니처를 탐색한 뒤, 전체 상품 서브페이지(`04.서브AI수정안.html.html`)로 이동하여 **'1초 믹솔로지 추천 레시피 조합 탭' 또는 '카테고리 필터'로 원하는 상품을 필터링·상세 확인하고 장바구니에 담아 수량 조절 및 주문·견적 완료**에 이르는 전체 과업.

## 6. 아이디어 발상과 썸네일 스케치

### 6.1 발상 과정

- **사용한 발상 방법**:
  1. **기존 시안 문제점 역추적(Pain-Point Decomposition)**: 초기 시안(`03.브랜드AI초안.html.html`, `03.서브AI초안.html.html`)을 직접 조작하며 발견된 '구간별 정보와 박스 과다', '긴 스크롤 내 카탈로그 매몰 및 복잡한 소형 필터', '장바구니 3모드 탭의 복잡성'을 해체하여 제거·통합·분리 대안을 도출함.
  2. **사용자 여정 기반 3단 프레임 스케치(3-Stage Flow Sketching)**: `브랜드 소개(메인) → 서브페이지(상품) → 장바구니`의 3개 핵심 화면을 한 장의 캔버스(`스토리 보드.jpg`)에 나란히 배치하고, 상단에는 **[수정 전]** 구조와 문제점을, 하단에는 **[수정 후]** 개선 구조와 화살표 동선을 직접 손스케치로 비교 설계함.
- **도출한 핵심 단어·아이디어**:
  - `정보 간소화 (De-boxing)`: 겹겹이 쌓인 박스 테두리를 걷어내고 여백과 1px 구분선으로 정리.
  - `메인-서브 역할 분리 (Page Split)`: 브랜드 서사 몰입(메인)과 32종 상품 탐색(서브페이지)을 분리하고 명확한 CTA 버튼으로 연결.
  - `조합 탭 필터링 (Recipe Mix Tab)`: DIY 티 브랜드의 특성을 살려 조합 탭 클릭 시 해당 레시피에 쓰이는 제품들이 즉시 보이도록 설계.
  - `장바구니 직결 (1-Step Cart)`: 복잡한 배너 선택 대신 상품 클릭 시 즉시 담기고 `− / +` 버튼만으로 수량과 결제를 끝내는 미니멀 장바구니.
- **스케치에서 확인할 질문**:

- **효과성 (Effectiveness)**: 사용자가 메인 브랜드 소개 화면에서 전체 상품 서브페이지로 정확히 이동하고, 원하는 DIY 레시피 조합 탭(3종) 또는 카테고리 탭(7종)을 선택해 목표 상품을 장바구니에 담아 주문·견적 확인까지 도달하는 과업 완수율 **100%** 달성.
- **효율성 (Efficiency)**: 메인 핵심 가치 확인 → 서브페이지 진입 → 조합 탭 필터링 → 장바구니 수량 조절 및 결제/문의 클릭까지의 전체 조작 단계를 **5클릭 이내**, 총 소요 시간을 기존 평균 3분 50초(230초)에서 **1분 30초(90초) 이내**로 60% 이상 단축.
- **이해·학습 용이성 (Learnability)**: 별도의 설명 없이도 첫 방문자가 `[01]~[08]` 섹션 위계와 '1초 믹솔로지 추천 레시피' 조합 탭의 역할을 3초 안에 이해하고, 다크/라이트 배경 어디서나 **100% 고대비(`#111111` vs `#ffffff`)**로 텍스트를 판독할 수 있을 것.
- **만족 또는 신뢰 (Satisfaction & Trust)**: 과도한 박스 테두리를 제거한 에디토리얼 여백과 KTR 3無·FITI 0%·PLA 100% 안전 기준 배너를 통해 프리미엄 웰니스 브랜드로서의 시각적 편안함과 신뢰감을 동시에 제공할 것.

### 11.3 남은 위험과 다음 단계

- **아직 확인하지 못한 가정**:
  1. 현재 저충실도 와이어프레임에서는 모든 상품과 히어로 비주얼을 회색 플레이스홀더(`[ 이미지 영역 ]`)로 대체하여 정보 구조와 조작 흐름을 검증했습니다. 실제 고해상도 수색 변환 사진이나 시네마틱 영상이 삽입되었을 때 텍스트 가독성(특히 히어로 오버레이 구간)과 초기 로딩 속도(LCP)가 동일한 수준으로 유지되는지 추가 확인이 필요합니다.
  2. '1초 믹솔로지 추천 레시피' 조합 탭 클릭 시 현재는 해당 레시피 구성 상품 5종을 필터링해 보여주는데, 사용자가 개별 상품을 하나씩 담는 것보다 **'레시피 5종 한 번에 세트 담기(1-Click Bundle Add)'** 버튼을 더 선호하는지 A/B 테스트가 필요합니다.
- **추가로 필요한 데이터**:
  1. 32종 전 상품의 실제 촬영/렌더링 1:1 오브제 이미지 에셋 및 3단 오로라 수색 변환(pH 7.0 → 5.0 → 3.0) 고해상도 시퀀스 데이터.
  2. 실제 고객 리뷰 통계 데이터(단맛·산미·바디감 만족도 분포 및 연령대별 재구매율)와 오프라인 성수 쇼룸 시간대별 실시간 예약 가능 슬롯 API 데이터.
- **다음 프로토타입 단계에서 검증할 내용**:
  1. **고충실도(High-Fidelity) GUI 디자인 시스템 적용 검증**: 저충실도 와이어프레임으로 확정된 `04.브랜드AI수정안.html.html` 및 `04.서브AI수정안.html.html` 레이아웃 위에 WIKETEA 스타일가이드(오로라 그라데이션, 리얼 글래스 서피스, 제품 실사 컷)를 입혀 심미적 완성도와 가독성을 검증합니다.
  2. **모바일 실기기(390px) 터치 사용성 및 결제 퍼널 검증**: 모바일 환경에서 3대 레시피 조합 탭과 7대 카테고리 필터의 가로 스크롤/줄바꿈 조작성, 그리고 장바구니 모달에서 실제 간편결제·견적서 PDF 발급으로 이어지는 최종 전환율을 검증합니다.
