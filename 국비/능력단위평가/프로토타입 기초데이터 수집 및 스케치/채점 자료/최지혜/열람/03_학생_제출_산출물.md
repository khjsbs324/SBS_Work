## 2. 프로젝트 브리프

### 2.1 배경과 문제

- **프로젝트 배경:** 플로뜰리에는 4차 정련 소창 타월을 일상용·세안용·바스용·세트·선물용으로 판매하는 가상의 라이프스타일 브랜드다. 제품은 15종으로 구성되며 겹수, 크기, 용도, 가격과 세트 구성이 서로 다르다.
- **해결할 사용자 문제:** 제품 수가 많고 명칭이 유사해 사용자가 자신의 생활 방식에 맞는 상품을 빠르게 비교하기 어렵다. 브랜드의 핵심 가치인 ‘4차 정련’, ‘삶기 없이 바로 사용’, ‘순면 소재’도 상품 정보 속에서 쉽게 묻힐 수 있다.
- **대상 사용자와 사용 맥락:** 수건 교체를 고려하는 1~2인 가구, 민감성 피부 사용자, 영유아 가정, 신혼·답례 선물을 찾는 사용자. 모바일 또는 데스크톱에서 상품을 탐색하고 상세 정보를 확인한 뒤 장바구니에 담는 상황을 가정했다.
- **프로젝트 목표:** 15종의 상품을 용도별로 빠르게 좁히고, 베스트 상품을 우선 비교하며, 상세 확인·장바구니 담기·저가 체험 신청까지 한 흐름에서 수행할 수 있는 반응형 컬렉션 화면을 제작한다.
- **핵심 과업:** 컬렉션 이해 → 베스트 3 비교 → 필터·검색·정렬 → 상품 상세 확인 → 장바구니 담기 → 3,000원 손수건 체험 신청.
