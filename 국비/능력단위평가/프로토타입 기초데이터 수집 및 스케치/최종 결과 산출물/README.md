# 프로토타입 기초데이터 수집 및 스케치 평가자료

이 평가는 디지털 서비스 브리프를 바탕으로 기초데이터와 레퍼런스를 수집·분석하고, 스토리보드와 다안 스케치를 거쳐 저충실도 시안을 만든 뒤 간단한 사용성 점검 결과를 반영하는 개인 포트폴리오형 능력단위평가다.

## 파일 구성

| 파일 | 대상 | 용도 |
|---|---|---|
| `01_강사용_수업진행안.md` | 강사 | 평가 준비, 300분 운영, 관찰과 회수 |
| `02_학생용_과제안내서.md` | 학생 | 과제 목표, 작업 순서와 제출 규칙 |
| `03_학생_제출_산출물.md` | 학생 | 보고서 작성 양식과 제출 확인 |
| `04_강사용_정답_및_채점표.md` | 강사 | 직접 증빙 확인법과 10문항 채점표 |
| `05_학생공개용_채점기준.md` | 학생 | 평가 영역과 4수준 성취기준 |
