# 학생공개용 채점기준

## 평가에서 보는 흐름

이 평가는 예쁜 한 장의 화면보다 다음 과정이 근거와 함께 연결되는지를 봅니다.

`프로젝트 이해 → 자료 수집 → 레퍼런스 분석 → 스토리보드 → 여러 스케치 → 세부 시안 → 사용성 점검 → 수정`

## 평가 영역

### 1. 기초데이터와 레퍼런스

확인 내용:

- 프로젝트에 필요한 데이터의 유형과 목적을 정했는가
- 원출처, 확인일, 제작자와 이용 조건을 기록했는가
- 여러 레퍼런스를 같은 기준으로 비교했는가
- 장단점에서 적용·변형·제외할 원리를 도출했는가

### 2. 디자인 기획과 구현 설명

확인 내용:

- 사용자·목표·콘셉트·콘텐츠 우선순위가 스케치에 반영됐는가
- 각 화면의 목적과 주요 요소를 설명할 수 있는가
- 행동, 상태, 전환과 제약을 주석으로 전달했는가

### 3. 스토리보드와 인터렉션

확인 내용:

- 핵심 과업의 시작·진행·완료가 연결되는가
- 화면 전환, 입력과 결과 피드백이 표시됐는가
- 오류·빈 상태·완료 등 필요한 상태와 분기를 고려했는가
- 필요한 모션의 목적과 변화가 설명됐는가

### 4. 사용성 점검과 수정

확인 내용:

- 과업과 성공 조건을 정하고 저충실도 결과물을 점검했는가
- 관찰 사실과 자신의 해석을 구분했는가
- 문제의 영향과 우선순위를 정했는가
- 문제와 수정 전후를 같은 화면에 연결했는가

### 5. 썸네일 스케치와 대안 선택

확인 내용:

- 콘셉트와 스토리보드에 맞는 여러 대안을 만들었는가
- 구조·위계·조작 방식에 의미 있는 차이가 있는가
- 공통 기준으로 대안을 비교하고 선택·조합했는가

### 6. 세부 시안과 종합 패키지

확인 내용:

- 대상 매체에 맞는 그리드·스타일·컬러·텍스처·모션을 설명했는가
- 핵심 화면과 상태가 일관된 저충실도 시안으로 정리됐는가
- 브리프·자료·스토리보드·스케치·시안·수정의 대응을 확인할 수 있는가
- 원본의 파일·페이지·프레임과 버전이 정리됐는가

## 공통 4수준 성취기준

| 수준 | 판단 기준 |
|---|---|
| 매우 충실 | 필요한 증빙이 빠짐없이 있고 선택 이유와 연결 관계가 구체적입니다. 다른 사람이 같은 근거를 따라 결과와 수정 과정을 이해할 수 있습니다. |
| 충실 | 주요 결과와 근거는 확인되지만 일부 출처·상태·비교·주석·전후 연결이 부족합니다. 전체 과정은 이해할 수 있습니다. |
| 부분 충실 | 결과물은 있으나 수집·비교·선정·점검·수정의 근거가 약하거나 일부 단계가 끊겨 있습니다. 추가 설명이 많이 필요합니다. |
| 미충족 | 필수 결과가 없거나 프로젝트와 무관하며, 직접 증빙으로 과정과 판단을 확인하기 어렵습니다. |

## 감점만 피하기 위한 작업보다 중요한 것

- 자료를 많이 모으는 것보다 왜 필요한지 설명하세요.
- 유명한 화면을 따라 그리는 것보다 어떤 원리를 어떻게 바꾸어 적용했는지 적으세요.
- 첫 아이디어를 다듬기 전에 구조와 위계가 다른 대안을 비교하세요.
- 수행자 의견만 적지 말고 실제로 무엇을 했고 어디에서 멈췄는지 기록하세요.
- 수정본만 보여 주지 말고 어떤 문제 때문에 무엇이 달라졌는지 전후를 연결하세요.

완성형 앱, 코드와 서비스 배포는 이 평가의 필수 대상이 아닙니다.
