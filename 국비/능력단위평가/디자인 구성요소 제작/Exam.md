# 디자인 구성요소 제작 평가 기준

## 평가 개요

- 능력단위: 디자인 구성요소 제작 (`0802010416_23v3`)
- 평가 형식: 기본 스타일가이드 분석 → 개인 취향 리서치 → 스타일가이드 변형 → 브랜딩 와이어프레임 기반 웹디자인 → 비평·추가 리서치 → 최종 개선
- 기준 자료: `능력단위평가_디자인_구성요소_제작/`의 스타일가이드 13장과 `최종 웹디자인.jpg`
- 평가 중심: 구성요소를 정답과 동일하게 설계했는지가 아니라, 학생의 설계의도·디자인의도가 리서치와 웹디자인에 타당하게 반영됐는지를 평가한다.
- 문항 수: 12개 / 총점: 100점

## 13가지 스타일가이드

1. 표지
2. Getting Started
3. Foundations — Colors
4. Foundations — Typography
5. Foundations — Spacing & Sizing
6. Foundations — Radius & Effects
7. Components — Button
8. Components — Badge
9. Components — Progress
10. Components — Question Number
11. Components — Quiz Option
12. Components — Timer
13. Components — Card

각 번호는 초안과 최종안 PNG를 모두 제출한다. 최종안은 초안 13장을 모두 변경할 필요가 없으며, 비평·리서치·개선 의도가 명확한 최소 3장만 달라도 인정한다. 변경하지 않은 항목도 유지 이유를 `03_학생_제출_산출물.md` 형식으로 작성해야 한다.

8. 최종 웹디자인 제작

## 수행준거별 채점기준

### DC-01. 기본 스타일가이드 요소 분석 — 8점
- 증빙: 13개 항목별 원본 파악 내용과 수정·유지 의견
- 7~8점: 13개 항목의 역할, 상태와 상호 관계를 정확히 파악하고 각 항목에 구체적인 의견을 작성했다.
- 5~6점: 대부분의 역할을 파악했으나 일부 의견이 형식적이거나 항목 간 관계 설명이 부족하다.
- 3~4점: 파일은 확인했지만 단순 감상 위주이고 여러 항목의 목적을 잘못 이해했다.
- 0~2점: 기본 스타일가이드 분석 또는 다수 항목의 의견이 누락됐다.

### DC-02. 포트폴리오 프로세스 정보 구성 — 8점
- 증빙: 8단계 과정 기록, 초안·비평·리서치·최종안의 연결
- 7~8점: 8단계의 입력·판단·결과가 순서대로 명료하고 변경 이유를 추적할 수 있다.
- 5~6점: 전체 과정은 있으나 일부 단계의 근거나 연결이 약하다.
- 3~4점: 결과물은 있으나 제작 과정의 순서와 판단을 충분히 확인하기 어렵다.
- 0~2점: 과정 기록이 없거나 초안과 최종안만 단편적으로 제출했다.

### DC-03. 브랜딩 와이어프레임과 디자인 흐름 — 8점
- 증빙: 학생의 브랜딩 와이어프레임, 초안·최종 웹디자인, 기획 설명
- 7~8점: 브랜드 목적, 콘텐츠 우선순위와 화면 흐름이 와이어프레임부터 최종 웹디자인까지 일관된다.
- 5~6점: 주요 흐름은 일관되나 일부 영역의 우선순위나 전환 근거가 부족하다.
- 3~4점: 와이어프레임과 결과물의 구조 차이가 크고 변경 근거가 약하다.
- 0~2점: 와이어프레임이 없거나 웹디자인과 연결되지 않는다.

### DC-04. 통합 아이덴티티와 스타일가이드 변형 — 10점
- 증빙: Colors, Typography, Spacing, Radius와 Components 전반
- 9~10점: 학생의 디자인 의도가 13개 항목에 일관된 시각 언어로 반영되고 웹디자인과 연결된다.
- 7~8점: 주요 아이덴티티는 일관되나 일부 항목 또는 웹 화면에서 표현이 흔들린다.
- 4~6점: 개별 항목은 수정됐지만 공통 아이덴티티나 적용 규칙이 약하다.
- 0~3점: 원본의 단순 색상 교체 수준이거나 항목 간 일관성을 확인하기 어렵다.

### DC-05. 심미적 균형과 디자인 의도의 적합성 — 10점
- 증빙: 초안·최종 스타일가이드와 웹디자인의 위계·조화·가독성
- 9~10점: 의도한 분위기와 대상 사용자에 맞게 색, 서체, 여백, 대비와 형태가 조화를 이룬다.
- 7~8점: 의도와 결과가 대체로 적합하나 일부 위계·대비·밀도 조정이 필요하다.
- 4~6점: 시각적 완성은 있으나 설명한 의도와 결과의 연결이 약하거나 불균형이 반복된다.
- 0~3점: 디자인 의도와 결과가 모순되거나 가독성과 사용을 크게 방해한다.

### DC-06. 선호 디자인 리서치와 전략 — 10점
- 증빙: 2단계 및 6단계 리서치 출처, 관찰, 선택·배제 기준
- 9~10점: 출처가 명확한 사례를 비교하고 형태가 아닌 원리를 추출해 자신의 전략으로 전환했다.
- 7~8점: 적절한 사례와 분석이 있으나 일부 선택이 취향 진술에 머문다.
- 4~6점: 사례 수집은 했지만 관찰과 적용 전략이 구체적이지 않다.
- 0~3점: 출처·분석이 없거나 사례를 그대로 모방했다.

### DC-07. 와이어프레임 기반 웹디자인 구조화 — 8점
- 증빙: `웹디자인_초안.html`, `웹디자인_최종.html`, 와이어프레임 비교
- 7~8점: 콘텐츠 구조와 주요 구성요소가 와이어프레임 의도에 맞게 웹 화면으로 구체화됐다.
- 5~6점: 핵심 구조는 반영됐으나 일부 콘텐츠 관계나 영역 구성이 달라졌다.
- 3~4점: 웹디자인이 완성됐지만 와이어프레임과 연결 근거가 약하다.
- 0~2점: 웹디자인 파일이 없거나 화면 구조를 판단할 수 없다.

### DC-08. 설계의도·디자인의도의 논리성과 적용 — 10점
- 증빙: 13개 번호별 기획 의도와 실제 스타일가이드·웹디자인
- 9~10점: 각 선택의 대상·문제·목적·기대 효과가 구체적이며 실제 결과에서 확인된다.
- 7~8점: 대부분의 의도와 결과가 연결되지만 일부 항목은 설명이 포괄적이다.
- 4~6점: 설명은 있으나 단순 선호 표현이 많고 결과와의 대응이 불명확하다.
- 0~3점: 기획 의도가 누락됐거나 결과와 관계없는 설명이다.

### DC-09. 자기 비평과 리서치 기반 개선 — 10점
- 증빙: 5~7단계 기록, 초안과 최종안의 최소 3개 변경 항목
- 9~10점: 초안 문제를 구체적으로 진단하고 추가 리서치 근거로 최소 3개 항목과 웹디자인을 효과적으로 개선했다.
- 7~8점: 문제 진단과 개선이 연결되나 일부 변경의 효과 검증이 부족하다.
- 4~6점: 변경은 확인되지만 비평·리서치·최종 결정의 연결이 약하다.
- 0~3점: 최소 변경 조건을 충족하지 못하거나 근거 없는 장식 변경만 있다.

### DC-10. 초안·최종 웹디자인의 매체 적합성 — 6점
- 증빙: 두 HTML의 브라우저 화면, 화면 너비별 레이아웃
- 6점: 브랜드와 콘텐츠 목적을 유지하면서 주요 화면 크기에서 안정적으로 표현된다.
- 4~5점: 주요 화면은 안정적이나 일부 너비에서 밀도·정렬·가독성 문제가 있다.
- 2~3점: 한 화면 기준으로만 제작되어 다른 너비에서 구조가 불안정하다.
- 0~1점: 브라우저에서 정상 확인할 수 없거나 핵심 콘텐츠가 크게 깨진다.

### DC-11. 파일 형식과 결과물 관리 — 6점
- 증빙: 정확한 파일명, PNG 26장, HTML 2개, 기획 설명 문서
- 6점: 모든 파일이 정확한 이름과 형식으로 열리며 초안·최종 대응 관계가 명료하다.
- 4~5점: 제출물은 모두 있으나 일부 파일명·순서·링크 정리가 미흡하다.
- 2~3점: 여러 파일이 누락되거나 초안과 최종안을 대응하기 어렵다.
- 0~1점: 핵심 제출물이 없어 평가 진행이 어렵다.

### DC-12. 스타일가이드와 웹디자인의 일관성 — 6점
- 증빙: 최종 스타일가이드 13장과 최종 HTML 대조
- 6점: 최종 스타일가이드의 색·서체·간격·효과와 구성요소 표현이 최종 웹디자인에 일관되게 적용됐다.
- 4~5점: 주요 규칙은 적용됐으나 일부 구성요소나 상태가 가이드와 다르다.
- 2~3점: 일부 색·서체만 반영됐고 가이드와 화면의 연결이 제한적이다.
- 0~1점: 최종 스타일가이드와 웹디자인이 서로 다른 디자인처럼 보인다.
