# 디자인 구성요소 제작 피드백 기준

## 목적

피드백은 학생의 스타일가이드가 기준 이미지와 얼마나 비슷한지를 평가하지 않는다. 학생이 세운 설계의도와 디자인의도가 브랜드, 대상 사용자, 리서치, 브랜딩 와이어프레임과 웹디자인에 적합하게 반영됐는지를 설명한다.

## 피드백 구성

1. 관찰: 학생이 실제로 유지·변경한 내용
2. 의도: 학생이 번호별 기획 설명에 작성한 목적
3. 적합성: 브랜드·사용자·리서치·와이어프레임과 맞는 부분 또는 충돌하는 부분
4. 영향: 위계, 분위기, 가독성, 일관성 및 사용 경험에 미치는 효과
5. 개선 방향: 학생의 의도를 더 잘 구현할 수 있는 원칙과 재검증 방법

## 반드시 다룰 내용

- 기본 스타일가이드 파악의 정확성
- 1차 선호 디자인 리서치의 출처와 분석
- 13개 초안의 공통 아이덴티티
- 웹디자인 초안과 브랜딩 와이어프레임의 연결
- 초안 자기 비평의 구체성
- 2차 개선 리서치와 최종 변경의 연결
- 최소 3개 변경 항목의 개선 효과
- 변경하지 않은 항목의 유지 이유
- 최종 스타일가이드와 최종 웹디자인의 일관성

## 좋은 피드백 예시 구조

```text
[관찰] Typography에서 제목의 크기 대비를 줄이고 본문 행간을 넓혔습니다.
[의도 대조] 학생은 차분하고 오래 읽기 쉬운 학습 화면을 의도했다고 설명했습니다.
[적합성] 제목의 긴박감은 줄고 본문 가독성은 높아져 대상 사용자와 의도에 대체로 맞습니다.
[영향] 다만 Card 제목까지 같은 대비를 적용해 정보 탐색 속도가 낮아졌습니다.
[개선 방향] 페이지 제목과 카드 제목의 위계를 분리하고 두 화면에서 5초 탐색 테스트로 재검증하세요.
```

## 피해야 할 피드백

- “원본과 다르다”만으로 감점하는 표현
- “예쁘다/별로다”처럼 근거 없는 취향 평가
- 학생이 작성하지 않은 브랜드 의도를 대신 추측하는 표현
- 모든 학생에게 같은 색·서체·레이아웃을 정답처럼 제시하는 방식
- 최종 변경 장수가 적다는 이유만으로 부정적으로 평가하는 방식

상세 문항과 배점은 `Exam.md`의 DC-01~DC-12를 따른다.
