박주연 학생의 사이트 제출 URL `UIUX_Design`은 현재 404로 확인되었습니다. 다만 같은 GitHub 계정에서 평가일인 8월 20일에 저장된 공개 저장소 `Test_0820`을 확인할 수 있어 해당 결과물을 근거로 채점했습니다. 이 저장소에는 스타일가이드 초안·최종 각 13장, NUNID 웹디자인 초안·최종 HTML, 상세 스토리보드와 리서치 링크가 포함되어 있습니다.

NUNID는 스킨케어와 메이크업의 경계를 줄인 하이브리드 뷰티 커머스로, 빠른 선택과 수치 기반 판단을 중시하는 20~30대 사용자를 대상으로 합니다. 스토리보드에는 고정 헤더, 제형 필터, 16개 상품 그리드, 임상 수치, 실사용 후기, Quick View, Quick Cart까지 목적·데이터·상태·접근성을 상세하게 설명했습니다. 실제 웹도 이 구조를 그대로 구현했고, 필터와 상품 버튼 일부가 상태 변화를 보이며 동작했습니다. 와이어프레임 의도에서 최종 화면까지의 구조 연결은 매우 분명합니다.

최종 스타일가이드는 파스텔 버터 옐로와 민트, 차콜, 넓은 여백, 12열 그리드, 부드러운 곡률을 사용해 감각적이면서 빠르게 읽히는 뷰티 커머스 인상을 잘 만들었습니다. 웹 화면의 제품 카드, 뱃지, CTA, 헤더와 푸터에도 같은 규칙이 일관되게 적용되어 심미적 완성도가 높습니다.

다만 과제의 필수 13개 요소와 실제 가이드 내용이 맞지 않습니다. 최종 9~13장은 Progress, Question Number, Quiz Option, Timer, Card가 아니라 Form Controls, Global Navigation, Product & Media Cards, Hero Banner, Footer로 대체되었습니다. 브랜드 사이트에 유용한 요소이지만 기본 스타일가이드의 역할과 상태를 분석한 뒤 재해석하는 과제 요구를 충족하지 못하므로, 필수 5개 요소를 복원하고 현재 확장 요소는 14번 이후 부록으로 분리해야 합니다.

기획 설명 문서는 양식만 남아 있고 학생명·브랜드·8단계 과정·13개 항목별 판단이 모두 비어 있습니다. Love.md도 LEGODT와 hince 두 링크만 제시해 구체적인 관찰, 선택·배제 기준과 적용 전략을 확인하기 어렵습니다. 스토리보드가 상세한 만큼 ‘레퍼런스의 파스텔 강조색→제형 분류’, ‘편집형 카드→수치 중심 상품 비교’처럼 출처와 적용을 연결하면 리서치 점검이 가능합니다.

초안과 최종은 팔레트 값, 가격·상품 정보, 일부 버튼과 카드 표현이 달라졌지만 자기 비평과 2차 리서치가 없어 변경 이유와 효과를 추적하기 어렵습니다. 최소 세 항목에 대해 문제, 추가 사례, 변경 내용, 기대 효과를 기록하고 유지 항목도 이유를 작성하세요. 1440·390px에서는 안정적이었으나 320px에서 약 71px의 가로 넘침이 있어 카드·필터의 최소 너비를 줄이고 320px 기준을 다시 확인해야 합니다.

전체적으로 NUNID의 스토리보드와 데스크톱 웹은 구조와 시각 완성도가 매우 높습니다. 그러나 제출 링크 오류, 빈 기획 문서, 제한적인 리서치 기록, 필수 구성요소 5종의 대체 때문에 최종점수는 85점으로 산정했습니다. 사이트 제출 URL을 실제 저장소로 수정하고 필수 13개 요소와 과정 기록을 보완하면 우수한 웹 결과물의 설계 근거까지 명확해질 수 있습니다. 고생하셨습니다^^
