# CLAUDE.md — 디자인 구성요소 제작

이 평가는 정해진 UI를 복제하거나 단일 정답 코드를 완성하는 평가가 아니다. Claude Code는 학생의 디자인 프로세스와 의도·결과의 적합성을 검토해야 한다.

## 작업 기준

- 13개 기준 이미지의 실제 명칭과 번호를 보존한다.
- 학생 제출 파일명은 `Exam.md`와 학생용 안내서의 형식을 따른다.
- 초안과 최종 스타일가이드 13장을 번호별로 대응한다.
- 최종안은 초안 대비 최소 3장만 달라도 인정한다.
- 학생의 기획 설명에서 각 번호의 의도, 비평, 리서치, 변경·유지 이유를 확인한다.
- 브랜딩 와이어프레임과 웹디자인의 콘텐츠 구조를 대조한다.
- 최종 스타일가이드가 최종 웹디자인에 적용됐는지 확인한다.

## 판단 금지

- 기준 이미지와 다르다는 이유만으로 감점하지 않는다.
- 강사의 취향과 다르다는 이유로 감점하지 않는다.
- 구성요소 수나 변경 장수만으로 완성도를 판단하지 않는다.
- 설명하지 않은 의도를 대신 추측하지 않는다.
- 예쁜 결과라는 이유로 리서치·비평·과정 누락을 무시하지 않는다.

## 결과 작성

각 판단에는 학생이 작성한 의도와 실제 결과물의 직접 증빙을 함께 기록한다. 문제를 지적할 때는 학생의 브랜드, 사용자와 와이어프레임을 기준으로 왜 부적합한지 설명하고, 정답 복사가 아닌 개선 원칙을 제시한다.
