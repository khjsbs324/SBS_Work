# 디자인 구성요소 제작 평가 지침

## 평가 목적

이 폴더의 능력단위는 `디자인 구성요소 제작(0802010416_23v3)`이다. `능력단위평가_디자인_구성요소_제작/`의 13개 기본 스타일가이드를 분석한 뒤, 학생이 자신의 디자인 취향과 브랜딩 와이어프레임을 근거로 스타일가이드와 웹디자인을 초안에서 최종안까지 발전시키는 포트폴리오 프로세스 평가이다.

## 최우선 판단 원칙

- 구성요소를 기준 이미지와 똑같이 제작했는지보다 설계의도와 디자인의도가 적합한지 평가한다.
- 학생의 브랜드, 대상 사용자, 리서치, 와이어프레임, 스타일가이드와 웹디자인의 연결을 본다.
- 취향 차이만으로 감점하지 않는다.
- 결과의 미려함만 보지 않고 분석·리서치·자기 비평·개선 과정을 함께 본다.
- 학생별 다른 브랜드와 시각 언어를 인정한다.

## 기준 자료

1. 사용자의 최신 지시
2. `Exam.md`
3. `능력단위평가_디자인_구성요소_제작/`의 13개 JPG와 `최종 웹디자인.jpg`
4. `디자인 구성요소 제작 수행준거.txt`
5. NCS 원본 PDF와 `pdf요약결과.md`
6. `최종 결과 산출물/`의 운영·제출 문서

## 평가 프로세스

1. 기본 스타일가이드 파악
2. 선호 디자인 리서치
3. 선호 디자인 기반 스타일가이드 전체 수정
4. 초안 스타일가이드 기반 웹디자인 제작
5. 마음에 들지 않는 디자인 확인
6. 개선용 디자인 추가 리서치
7. 최종 스타일가이드 제작
8. 최종 웹디자인 제작

## 제출 검증

- 스타일가이드 초안 PNG 13장
- 스타일가이드 최종 PNG 13장
- 웹디자인 초안·최종 HTML
- 디자인 기획 설명 문서
- 13개 항목 모두에 기획 의도와 수정·유지 의견
- 최종안에서 초안 대비 근거 있는 변경 최소 3장
- 리서치 출처와 브랜딩 와이어프레임

## 채점

- `Exam.md`의 DC-01~DC-12를 사용한다.
- 모든 점수에 학생 문서, 이미지, HTML 화면 또는 리서치 출처의 직접 증빙을 연결한다.
- 동일한 원인을 여러 문항에서 중복 감점하지 않는다.
- 파일 누락과 디자인 판단을 구분한다.
- 변경 장수가 많다는 이유만으로 높은 점수를 주지 않는다.
- 최종에서 변경하지 않은 항목도 유지 이유가 타당하면 인정한다.

## 피드백

피드백은 `관찰 → 학생 의도 → 적합성 → 영향 → 개선 방향` 순서로 작성한다. 단일 정답을 제시하기보다 학생의 의도를 더 명료하게 구현할 수 있는 방향을 안내한다.
