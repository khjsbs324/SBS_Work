# 디자인 구성요소 제작 평가자료

이 평가는 `능력단위평가_디자인_구성요소_제작/`의 13개 기본 스타일가이드를 파악하고, 학생이 자신의 디자인 취향과 브랜딩 와이어프레임을 근거로 스타일가이드와 웹디자인을 초안에서 최종안까지 발전시키는 포트폴리오 프로세스 평가이다.

- `01_강사용_수업진행안.md`: 8단계 운영 및 회수 절차
- `02_학생용_과제안내서.md`: 과제 내용과 제출 규칙
- `03_학생_제출_산출물.md`: 13개 항목별 기획 의도 작성 양식
- `04_강사용_정답_및_채점표.md`: 기준 자료와 의도 중심 채점 방법

학생에게는 기준 이미지 폴더, 02번과 03번 문서를 제공한다. `Exam.md`와 01번·04번 문서는 강사용이다.
