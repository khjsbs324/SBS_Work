# 강사용 기준 및 채점표

## 기준 자료

`능력단위평가_디자인_구성요소_제작/`의 13개 이미지는 학생이 파악하고 변형할 기본 스타일가이드이다. `최종 웹디자인.jpg`는 구성요소가 화면에 적용된 예시이지 학생이 동일하게 복제할 정답이 아니다.

## 채점 우선순위

1. 학생이 설명한 대상 사용자와 브랜드 방향
2. 리서치에서 추출한 디자인 원리
3. 와이어프레임과 스타일가이드의 구조적 연결
4. 13개 항목별 기획 의도와 실제 결과의 일치
5. 초안 자기 비평과 최소 3개 최종 개선 항목의 타당성
6. 최종 스타일가이드와 최종 웹디자인의 일관성

구성요소의 제작 정교함이나 기준 이미지와의 유사도는 보조 증빙으로만 사용한다. 설계의도와 디자인의도가 브랜드, 사용자, 리서치와 적합한지를 우선 판단한다.

## 빠른 확인표

- [ ] 초안 스타일가이드 PNG 13장
- [ ] 최종 스타일가이드 PNG 13장
- [ ] 초안·최종 스타일가이드의 번호별 대응
- [ ] 최종에서 실제 변경된 항목 최소 3장
- [ ] 웹디자인 초안·최종 HTML 각 1개
- [ ] 13개 항목별 기획 의도와 유지·변경 의견
- [ ] 선호 디자인 1차 리서치와 개선용 2차 리서치
- [ ] 브랜딩 와이어프레임과 웹디자인 구조의 연결
- [ ] 최종 스타일가이드와 최종 웹디자인의 연결

## 피드백 작성 방식

- 관찰: 학생이 실제로 선택하거나 변경한 내용
- 의도 대조: 학생이 작성한 설계·디자인 의도
- 적합성: 브랜드, 대상 사용자, 와이어프레임 및 리서치와의 관계
- 영향: 위계, 가독성, 일관성, 분위기와 사용 경험에 미치는 효과
- 개선 방향: 정답 복사가 아닌 의도를 더 잘 구현할 수 있는 방향

상세 배점과 4단계 기준은 `../Exam.md`의 DC-01~DC-12를 사용한다.
