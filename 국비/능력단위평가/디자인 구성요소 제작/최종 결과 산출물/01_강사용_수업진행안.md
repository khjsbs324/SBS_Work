# 강사용 수업진행안

## 평가 목적

학생이 기본 스타일가이드를 그대로 재현하는 능력보다, 기준을 분석하고 자신의 디자인 취향과 브랜딩 와이어프레임에 맞게 변형한 이유를 설명하며 초안을 비평·개선하는 과정을 평가한다.

## 기준 자료

- `능력단위평가_디자인_구성요소_제작/1.표지.jpg` ~ `13.Components_Card.jpg`
- `능력단위평가_디자인_구성요소_제작/최종 웹디자인.jpg`
- `Exam.md`

## 8단계 진행

1. 기본 스타일가이드 파악: 13개 페이지의 목적, 규칙과 연결 관계를 기록한다.
2. 선호 디자인 리서치: 좋아하는 디자인의 출처와 구체적인 이유를 분석한다.
3. 스타일가이드 전체 수정: 13개 항목을 자신의 콘셉트로 변형하여 초안을 만든다.
4. 초안 웹디자인 제작: 학생의 브랜딩 와이어프레임을 기준으로 HTML을 제작한다.
5. 불만족 디자인 확인: 초안에서 마음에 들지 않는 지점을 원인 중심으로 작성한다.
6. 추가 리서치: 문제 해결에 적합한 사례를 새로 조사하고 적용 원칙을 정한다.
7. 최종 스타일가이드 제작: 개선이 필요한 최소 3장을 수정한다. 나머지는 유지할 수 있으나 유지 이유를 작성한다.
8. 최종 웹디자인 제작: 최종 스타일가이드를 반영해 HTML을 개선한다.

## 운영 유의 사항

- 초안과 최종 스타일가이드 13장은 모두 제출한다.
- 최종안은 초안과 최소 3장만 달라도 인정한다. 변경 장수보다 비평과 개선 근거의 질을 본다.
- 학생별 브랜딩과 와이어프레임이 다르므로 기준 이미지와의 단순 유사도를 채점 기준으로 사용하지 않는다.
- 구성요소 설계 자체의 정교함보다 설계의도와 디자인의도가 대상 사용자·브랜드·리서치와 적합한지 평가한다.
- 다른 사례를 그대로 모방한 경우 출처와 변형 근거를 확인한다.

## 회수 순서

1. PNG 26장, HTML 2개와 기획 설명 문서를 확인한다.
2. 파일명을 정규 형식과 대조한다.
3. 초안과 최종 13장을 번호별로 짝지어 비교한다.
4. 변경한 최소 3장의 비평·리서치·개선 근거를 확인한다.
5. 브랜딩 와이어프레임과 두 HTML의 구조를 비교한다.
6. 최종 스타일가이드가 최종 웹디자인에 적용됐는지 확인한다.
7. `Exam.md` DC-01~DC-12에 직접 증빙을 연결해 채점한다.
