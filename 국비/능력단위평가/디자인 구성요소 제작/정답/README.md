# 강사용 판단 기준

이 평가에는 하나의 시각적 정답 HTML이 없다.

`능력단위평가_디자인_구성요소_제작/`의 13개 JPG와 `최종 웹디자인.jpg`는 기본 구조와 적용 사례를 파악하기 위한 기준 자료이다. 학생 결과는 기준 이미지와의 유사도보다 다음 내용을 중심으로 판단한다.

- 브랜드와 대상 사용자에 맞는 설계의도
- 리서치에서 추출한 디자인 원리
- 브랜딩 와이어프레임과 웹디자인의 연결
- 13개 스타일가이드 항목별 디자인 의도
- 초안 비평과 최종 개선 근거
- 최종 스타일가이드와 최종 웹디자인의 일관성

상세 기준은 `../Exam.md`와 `../최종 결과 산출물/04_강사용_정답_및_채점표.md`를 사용한다.
