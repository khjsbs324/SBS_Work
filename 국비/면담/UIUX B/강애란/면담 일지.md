* 면담 내용

  CSS와 JavaScript가 어렵고 이전에 배운 디자인 관련 내용도 많이 잊었다고 함. 게임 방식의 학습 자료가 도움이 되었다며 추가 자료를 요청하고, API 연동과 라이브러리 수정의 학습 범위를 질문함. 과정 자체에는 흥미가 있으나 이전 직장 경험으로 기획 업무의 책임에 부담을 느낀다고 함. 강사는 과정의 구현 범위를 설명하고 수업 중 질문 및 강사·멘토와의 상담을 안내했으며, Wi-Fi 연결 정보를 확인하기로 함.

---

## 강애란 학생 분석

과정 자체는 재미있지만 기획과 관련된 책임에는 두려움이 있다고 함. 이전 직장에서 책임이 전가되었던 경험을 이야기했으며, 별도 상담을 받으면서 이 문제의 해결을 시도하고 있다고 함. 학습에 대한 흥미와 업무 경험에서 비롯된 부담을 함께 표현하고 있음. CSS와 JavaScript가 어렵다고 말하면서도 게임 방식의 학습 자료를 요청하고, 자신의 수행에 대해 긍정적인 피드백을 받고 싶다고 직접 이야기함.

## 일지

### 1. 학습 상태 및 수업 적응

앞서 안내받은 개구리 게임 형태의 Flexbox 학습 자료가 도움이 되었다고 함. 게임 방식의 학습을 좋아한다며 JavaScript에도 비슷한 자료가 있는지 질문함. 무드보드에 이전 작업과 현재 주제 중 어떤 내용을 넣어야 하는지 물었으며, 강사는 과제 범위를 설명하고 수업 중 이해되지 않는 내용은 바로 질문하도록 안내함. 수업에 활용하려고 가져온 iPad의 Wi-Fi 연결 정보를 찾기 어렵다고 하여, 강사가 비밀번호를 확인하기로 함.

### 2. 직무 수행 및 NCS 학습 상태

기획과 디자인을 넘어 프로젝트의 API 연동까지 구현할 수 있는지 질문함. 이전 직장에서 사용했던 라이브러리나 프레임워크를 원하는 방식으로 수정하는 능력도 배우고 싶다고 함. CSS와 JavaScript를 잘하지 못한다고 스스로 평가했으며, 이전에 배운 디자인 관련 내용도 많이 잊어 어려움이 있다고 함. 강사는 과정에서 다루는 코딩과 API 구현의 범위를 설명함. 구체적인 기능의 독립 수행 수준이나 어려움의 해결 결과는 면담 내용에서 확인되지 않았음.

### 3. 진로 및 상담 확인 사항

이전 직장에서의 경험과 연결하여 기획 업무의 책임에 대한 부담을 이야기함. 수업을 들으면서 이 부담을 줄일 수 있을 것 같다고 함. 강사는 학습 중 감정적으로 힘든 부분이 있으면 강사나 담당 멘토와 이야기할 수 있다고 안내함. 구체적인 희망 직무, 취업 시기 및 포트폴리오 계획은 면담 내용에서 확인되지 않았음.
