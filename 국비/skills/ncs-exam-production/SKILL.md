# NCS 시험 산출물 제작

## 작업 절차

1. 편집하기 전에 `../../../AGENTS.md`와 현재 파일 구조를 확인한다.
2. `references/project-map.md`를 읽고 기준 자료와 출력 위치를 결정한다.
3. 텍스트 PDF는 내용을 추출한다. 스캔 PDF는 모든 관련 페이지를 이미지로 변환하여 확인하며 읽을 수 없는 내용을 추측하지 않는다.
4. `문제 코드`와 `정답`을 파일 및 동작 수준에서 비교한다. 현재 `문제 코드`를 학생의 시작 코드로 취급한다.
5. 사용자가 명시적으로 범위를 확대하지 않는 한 HTML, CSS, JavaScript, GitHub만 사용하고 백엔드 요구사항을 추가하지 않는다.
6. 정답이 포함된 강사용 자료와 정답이 없는 학생용 자료를 분리한다. 최종 전달 자료는 `최종 결과 산출물`에 간결하게 정리한다.
7. 해당 NCS 수행준거를 기준으로 채점기준을 작성한다. 각 수행준거마다 확인할 증빙과 구체적인 4단계 점수 구간을 작성하며 하나의 공통 등급표로 대체하지 않는다.
8. 등록된 문제를 수정할 때는 변경 대상이 아닌 항목을 보존한다. 저장 후 서버의 상세 화면에서 제목, 설명, 정답, 채점기준, 사용 설정, 수행준거 수 및 총점을 확인한다.
9. 완료를 보고하기 전에 파일 링크, 파일명, 총점 및 모든 산출물의 일치 여부를 검증한다.

## 품질 기준

- 추측보다 제공된 PDF와 코드에서 확인한 근거를 우선한다.
- 한글을 UTF-8로 저장하고 문자 깨짐 여부를 확인한다.
- 채점 증빙에 사용할 파일, 선택자, 화면 너비, 브라우저 패널, Git 기록 또는 화면 캡처를 구체적으로 명시한다.
- 문제 안내, 모범답안, 채점기준을 구분한다.
- 학생용 파일에 모범답안을 노출하지 않는다.
- 관련 없는 사용자 파일을 삭제하거나 다시 작성하지 않는다.

## 서브에이전트

독립적인 검토가 필요할 때 `../../../.agents/`의 역할 지침을 사용한다. 서로 겹치지 않는 작업을 배정하고 주 에이전트가 최종 일관성을 검증한다.
