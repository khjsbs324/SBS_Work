# 접근성 개선 명세서

## HTML 구조

```text
header
  nav (현재 페이지 aria-current)
main#main-content
  h1 강좌 상세
  section
    h2 강좌 소개
  section
    h2 커리큘럼
      h3 1차시 사용자 조사
footer
```

## 이미지·영상

| 대상 | 기존 | 수정 | 근거 |
|---|---|---|---|
| 로고 링크 | alt 없음 | `alt="한빛교육"` | 링크 목적 |
| 강좌 표지 | 파일명 낭독 | `alt="UX 기초 강좌 표지"` | 정보성 이미지 |
| 장식 별 | `alt="star"` | `alt=""` | 장식 이미지 |
| 학습 영상 | 자막 없음 | `<track kind="captions">`와 대본 | 청각 정보 대체 |

## 문의 폼

| 필드 | 오류 문구 | HTML 연결 |
|---|---|---|
| 이름 | `이름을 입력해 주세요.` | `aria-describedby="name-error"` |
| 이메일 | `example@email.com 형식으로 입력해 주세요.` | `aria-describedby="email-error"` |
| 문의 내용 | `문의 내용을 10자 이상 입력해 주세요.` | `aria-describedby="message-help message-error"` |

- 모든 필드에 보이는 `<label>`을 제공한다.
- 오류 요약은 첫 오류 링크를 제공하며 제출 시 포커스를 받는다.
- 정상 입력은 `문의가 제출된 것으로 표시했습니다. 실제로 전송되지는 않았습니다.`라고 알린다.
- 실제 개인정보를 입력하지 말라는 안내를 폼 앞에 둔다.

## JS 위젯

- 메뉴 버튼의 `aria-expanded`와 실제 표시 상태를 동기화한다.
- 탭의 선택 상태와 패널의 `hidden` 상태를 함께 변경한다.
- 모달은 열림·닫힘 시 포커스를 이동·복귀한다.
- JS 비활성 시에도 HTML에 있는 핵심 콘텐츠를 읽을 수 있다.
