# 개인 회고 및 AI 사용 기록

## 회고 예시

### 담당

Vanilla JavaScript 상호작용 수정과 GitHub PR·Pages 검증을 담당했다.

### 배운 점

- 로컬에서 정상인 절대 경로가 GitHub Pages 저장소 하위 경로에서는 실패할 수 있었다.
- 버튼 클릭만 처리하면 Enter 제출과 키보드 사용을 놓치므로 폼의 `submit` 이벤트를 기준으로 구현해야 했다.
- 시각적 열림 상태만 바꾸지 않고 `aria-expanded`, `aria-selected`, `hidden`을 함께 관리해야 했다.
- `localStorage`는 간단한 데모 상태에 유용하지만 개인정보 저장소나 실제 DB처럼 사용하면 안 된다.

### 다음 개선

- 공통 위젯 함수를 모듈 단위로 정리한다.
- PR 템플릿과 체크리스트로 배포 경로·콘솔 검사를 반복한다.
- JavaScript 비활성·저장소 차단 같은 실패 조건을 초기에 테스트한다.

## 준수

- 실제 개인정보, 비공개 저장소 내용, 개인 액세스 토큰을 AI에 입력하지 않았다.
- 생성된 코드는 그대로 사용하지 않고 HTML/CSS/JS 범위와 브라우저 동작을 검증했다.
- 수행하지 않은 테스트는 결과표에 포함하지 않았다.
