## 세부 계획

### FIX-DES-001 반응형 메뉴

- 변경 대상: 헤더, 내비게이션 컴포넌트, 모바일 오버레이
- 구현 기준: 768px 미만에서 메뉴 버튼 표시, 메뉴 열림 시 첫 링크로 포커스 이동, Escape로 닫기, 닫힌 후 버튼으로 포커스 복귀
- 산출물: 모바일 시안, 컴포넌트 상태표, 전후 캡처
- 단위 테스트: 320, 360, 390, 768px 및 200% 확대
- 위험: 오버레이가 본문 스크롤을 막지 못하거나 포커스가 배경으로 이동할 수 있음
- 대응: 포커스 순환과 스크롤 잠금 테스트

### FIX-DES-002 대비 개선

- 변경 대상: 보조문구와 비활성 텍스트 토큰
- 구현 기준: 일반 텍스트 4.5:1 이상, 큰 텍스트 3:1 이상
- 단위 테스트: 주요 상태별 자동 측정과 육안 확인
- 위험: disabled 상태와 placeholder를 본문으로 오인할 수 있음
- 대응: 상태별 사용 목적을 분리해 검사
