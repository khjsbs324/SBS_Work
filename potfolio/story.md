# story.txt 생성 지침

## 목적

학생명과 작품명이 확인된 포트폴리오 작업은 게시 등록에 필요한 내용만 담은 UTF-8 `story.txt`를 생성한다. 웹, DTP와 아트웍에는 링크, 동영상 URL, 이미지 파일명, 좋아요 수처럼 요청되지 않은 항목을 넣지 않는다. 모션 작업만 사용자가 입력한 유튜브 링크와 모션 전용 작품소개를 필수로 추가한다.

## 생성 시점과 위치

1. body와 섬네일 결과가 검수를 통과해 대표 컬러를 확정한 뒤, 원본 학생 폴더를 output으로 이동하기 전에 생성한다.
2. 기본 위치는 `input\<학과>\<학생명>\story.txt`이다. 완료 원본 이동 시 결과 파일과 함께 `output\<학과>\<학생명>\`으로 이동한다.
3. 학생 폴더가 이미 output으로 이동된 과거 작업을 보완할 때는 `output\<학과>\<학생명>\story.txt`에 직접 생성한다.
4. 기존 `story.txt`는 덮어쓰지 않고 내용을 확인한 뒤 필요한 경우 `story_v2.txt`, `story_v3.txt`를 사용한다.

## 작성 규칙

- 제목과 수강생에는 학생 폴더명을 사용한다. 담당강사 이름을 수강생으로 잘못 넣지 않는다.
- 작품명은 사용자가 지정한 이름을 우선하고, 없으면 원본 파일명과 작품 표기에서 확인한다.
- 모션 작업은 `[학생 이름][작품명][학과][유튜브 링크]`의 네 입력값을 모두 확인한 뒤 시작하며, 입력된 유튜브 링크를 임의로 단축하거나 수정하지 않는다.
- 수료과정, 표현작업, 기획, 제작프로그램, 비주얼스킬, 담당강사 형식은 루트 `AGENT.md`의 학과별 story 기본값을 사용한다.
- 학과 기본값의 `[직접 작성]`은 자동으로 추정하지 않는다. 사용자가 값을 주면 해당 부분을 교체하고, 값이 없으면 `[직접 작성]`을 유지한다.
- 컬러시스템은 실제 body와 섬네일을 확인해 작품을 대표하는 색상 5개를 선정한다. 주조색, 보조색, 강조색, 어두운 색, 밝은 중립색이 균형 있게 포함되도록 하고 대문자 6자리 HEX로 작성한다.
- 모션 작품소개는 `<작품명><을/를> 주제로한 모션그래픽 작품입니다. After Effect, Motion Graphic, Portfolio, SBS아카데미컴퓨터아트 대전, 수강생 포트폴리오` 형식으로 작성한다.
- 작품명 마지막 글자에 받침이 있으면 `을`, 없으면 `를`을 사용한다.
- 웹, DTP와 아트웍 출력에는 기본 필드만 사용한다. 모션 출력에는 기본 필드 뒤에 유튜브 링크와 작품소개를 추가하며 각 형식의 필드 순서를 바꾸지 않는다.

## 출력 형식

```text
제목: [대전] <학생명> 학생 작품
수강생: <학생명>
수료과정: <학과별 값>
작품명: <작품명>
표현작업: <학과별 값>
기획: <학과별 값>
제작프로그램: <학과별 값>
비주얼스킬:
<학과별 값>

컬러시스템:

#000000
#000000
#000000
#000000
#000000
담당강사: <학과별 값>
```

## 모션 전용 추가 출력 형식

모션 작업은 위 기본 출력 형식의 `담당강사` 다음에 아래 두 줄을 추가한다.

```text
유튜브 링크: <사용자가 입력한 유튜브 링크>
작품소개: <작품명><을/를> 주제로한 모션그래픽 작품입니다. After Effect, Motion Graphic, Portfolio, SBS아카데미컴퓨터아트 대전, 수강생 포트폴리오
```

예를 들어 작품명이 `우주여행`이면 받침이 있으므로 다음과 같이 작성한다.

```text
유튜브 링크: https://www.youtube.com/watch?v=example
작품소개: 우주여행을 주제로한 모션그래픽 작품입니다. After Effect, Motion Graphic, Portfolio, SBS아카데미컴퓨터아트 대전, 수강생 포트폴리오
```
