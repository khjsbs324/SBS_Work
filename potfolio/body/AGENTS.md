# 저장소 가이드라인

## 프로젝트 구조 및 모듈 구성

이 저장소는 일반 애플리케이션이 아니라 Photoshop 기반 이미지 합성 작업을 관리한다. 루트의 PowerShell 스크립트는 래스터 에셋을 준비하고, Photoshop ExtendScript 파일(`*.jsx`)은 PSD 구조를 검사하거나 스마트 오브젝트 내용을 교체한다. 생성한 스마트 오브젝트 입력 이미지는 `psd-smart-assets/`에 저장한다. 최종 결과물(`*.psd`, `*.png`, `*.jpg`)과 진단 보고서(`psd-*.txt`, `smart-object-sizes.txt`)는 저장소 루트에 생성된다. 원본 이미지와 템플릿은 현재 저장소 외부의 `C:\khjsbs\Po\웹`에 있다. 프로젝트를 이동할 때는 스크립트의 경로 상수를 함께 수정한다.

## 빌드, 테스트 및 개발 명령

별도의 패키지 관리자나 컴파일 과정은 없다. Windows PowerShell에서 다음 순서로 실행한다.

```powershell
powershell -ExecutionPolicy Bypass -File .\prepare-sbs-smart-object-assets.ps1
& 'C:\Program Files\Adobe\Adobe Photoshop 2024\Photoshop.exe' -r "$PWD\composite-tamburins-into-sbs-psd.jsx"
```

첫 번째 명령은 스마트 오브젝트 규격에 맞는 300 PPI 이미지를 생성한다. 두 번째 명령은 원본 PSD의 복제본에 이미지를 합성하고 평면화된 PNG/JPG를 내보낸다. 템플릿 레이어나 스마트 오브젝트 크기가 바뀌면 같은 Photoshop `-r` 옵션으로 `inspect-sbs-webpf.jsx`와 `inspect-sbs-smart-objects.jsx`를 실행해 구조를 다시 확인한다.

## 코딩 스타일 및 명명 규칙

PowerShell과 JSX 모두 들여쓰기에는 공백 4칸을 사용한다. PowerShell 함수는 `New-SmartAsset`처럼 승인된 동사-명사 형식을 사용하고, 매개변수는 PascalCase로 작성한다. 한글이 포함된 경로에는 `-LiteralPath`를 우선 사용한다. JSX 변수와 함수는 `camelCase`로 작성하고 Photoshop 상수는 명시적으로 지정한다. 필요한 경우 비ASCII 경로 부분을 유니코드 이스케이프로 표현한다. 스크립트 파일명은 소문자 kebab-case로 작성하며 `prepare-`, `inspect-`, `composite-`처럼 작업 목적이 드러나는 접두사를 사용한다.

## 테스트 지침

자동화된 테스트 프레임워크는 구성되어 있지 않다. 내보낼 때마다 픽셀 크기, 300 PPI 메타데이터, 스마트 오브젝트 경계 유지 여부, 페이드와 이미지 하단의 시각적 연결을 검사한다. `psd-composite-report.txt`에서 교체 전후 경계가 동일한지 확인한다. 이후 PNG를 100% 배율로 열어 글자가 선명하고 회색 자리표시자 영역이 없는지 검토한다.

## 커밋 및 풀 리퀘스트 지침

현재 디렉터리에는 Git 이력이 없어 기존 커밋 규칙을 확인할 수 없다. 커밋 제목은 `하단 오른쪽 스마트 오브젝트 크롭 수정`처럼 짧고 명령형으로 작성한다. 생성된 바이너리는 필수 결과물인 경우에만 커밋한다. 풀 리퀘스트에는 원본 또는 템플릿 변경 사항과 검증 절차를 적고, 시각적 변경에는 전후 비교 이미지를 첨부한다.

## 에셋 안전 지침

원본 PSD를 직접 수정하지 않는다. 내용을 교체하기 전에 복제본을 만들고 기존 레이어 이름과 변형 값을 유지한다. 최종 내보내기 전에는 원본 이미지를 불필요하게 재압축하지 않는다.

## 섬네일 단독 요청 시 간이 body 생성

사용자가 body 작업 없이 섬네일만 요청해도 학과별 body PSD 템플릿에 input 원본 전체 구성을 배치해 게시용 body를 추가 생성한다.

- 섬네일용 대표 장면이나 4:3 크롭을 사용하지 않고 원본 전체 구성을 유지한다.
- DTP·아트웍은 `body\아트웍,DTP`의 해당 PSD를 사용한다. 다른 학과는 각 학과에 지정된 PSD를 사용하며 다른 학과 템플릿으로 대체하지 않는다.
- 템플릿을 복제한 뒤 이미지를 가로 1000px로 배치하고 세로는 원본 비율에 따라 계산한다. 아트보드 세로 크기도 이미지 높이에 정확히 맞춘다.
- 최종 해상도는 300 PPI로 설정하고 레이어·아트보드를 유지한 `body.psd`와 고품질 `body.jpg`를 내보낸다.
- 결과는 섬네일과 같은 `output\<학과>\<학생명>\`에 저장한다. 기존 파일은 덮어쓰지 않고 `body_v2.psd`/`body_v2.jpg`, `body_v3.psd`/`body_v3.jpg`처럼 동일 버전을 사용한다.
- PSD에서 아트보드와 배치 이미지 경계가 일치하는지 확인한다. JPG는 100% 배율에서 글자 선명도, 비율 왜곡, 하단 잘림, 불필요한 크롭과 압축 흔적을 확인한다.
