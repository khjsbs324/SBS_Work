# 전체 학과 포트폴리오 제작 에이전트

## 역할과 작업 범위

이 파일은 `C:\khjsbs\Po\PF_AGENT` 전체 작업을 조정하는 최상위 지침이다. 사용자가 실행을 요청하면 학과, 학생명, 프로젝트명, 원본 경로를 식별하고 **body 제작 → body 검수 → 섬네일 제작 → 섬네일 검수** 순서로 진행한다. 하위 폴더의 Markdown 지침은 해당 단계의 세부 제작 규칙이며, 이 파일의 작업 순서와 출력 규칙은 항상 유지한다.

## 실행 명령 해석 및 학과 선택

권장 요청 형식은 `실행: <학과> / <학생명> / <프로젝트명> / <원본 경로>`이다. 일부 정보가 생략되면 요청 내용과 원본의 상위 폴더명에서 확인한다. 서로 충돌하거나 학과를 판별할 근거가 없을 때만 사용자에게 확인한다.

### 모션 전용 입력 형식

- 모션 작업만 `[학생 이름][작품명][학과][유튜브 링크]` 형식으로 입력받은 뒤 전체 제작을 시작한다.
- 학생 이름, 작품명, 학과, 유튜브 링크 네 항목이 모두 확인되어야 하며, 하나라도 누락되면 임의로 추정하지 않고 사용자에게 확인한다.
- 학과 입력이 `모션학과`, `모션` 또는 `모션그래픽`이면 출력 학과를 `모션`으로 통일하고 `input\모션\<학생 이름>\`의 MP4 원본을 사용한다.
- 유튜브 링크는 사용자가 입력한 문자열을 임의로 단축하거나 수정하지 않고 해당 작업의 `story.txt`에 기록한다.
- 웹, DTP와 아트웍 작업은 기존 권장 요청 형식과 input 파일 기반 실행 규칙을 그대로 사용한다.

| 사용자 표현 | 출력 학과 | body 작업 위치 |
| --- | --- | --- |
| 웹, 웹디자인 | `웹` | `body\웹` |
| DTP, 편집디자인 | `DTP` | `body\아트웍,DTP` |
| 아트웍, 디지털아트 | `아트웍` | `body\아트웍,DTP` |
| 모션, 모션그래픽 | `모션` | `body\모션` |

선택한 body 폴더에 Markdown 지침이나 적합한 PSD 템플릿이 없으면 다른 학과 템플릿으로 대체하지 않는다. 사용 가능한 파일을 다시 확인한 뒤 누락된 지침 또는 템플릿을 보고한다.

## input 파일 기반 실행

`input`은 미완료 작업 대기열이며 기본 구조는 `input\<학과>\<학생명>\`이다. 사용자가 `input 파일 기반으로 실행`, `input의 <학생명> 작업`, 또는 `input` 아래의 특정 경로를 지정하면 다음 규칙으로 별도 확인 없이 작업 대상을 식별한다.

1. `input` 바로 아래 폴더명을 학과로, 그 아래 폴더명을 학생명으로 사용한다. 요청 내용과 폴더 구조가 충돌하면 임의로 진행하지 않고 사용자에게 확인한다.
2. 학생 폴더 안의 이미지, PSD, PDF, 영상 등 실제 원본 파일을 모두 조사하고, 요청한 단계에 필요한 파일만 선택한다. 다른 학생 폴더의 파일은 참조하거나 이동하지 않는다.
3. 프로젝트명은 사용자가 지정한 이름을 우선하고, 없으면 원본 파일명과 작품에 표시된 명칭에서 식별한다. 서로 다른 프로젝트가 한 학생 폴더에 섞여 있어 구분이 불가능할 때만 확인한다.
4. 사용자가 `실행`만 요청하면 body 제작부터 섬네일까지 전체 파이프라인을 수행한다. `body만`, `섬네일만`처럼 단계를 지정하면 해당 단계만 수행한다. body 작업 없이 섬네일만 요청한 경우에는 input 원본에서 가장 적합한 대표 장면을 선택해 섬네일을 만들고, 원본 전체 구성을 사용한 가로 1000px body 이미지도 추가 생성한다.
5. 여러 학생 폴더의 일괄 실행을 요청하면 각 학생 폴더를 독립된 작업 단위로 처리하고, 한 학생의 원본·결과·파일명이 다른 학생 작업에 섞이지 않도록 한다.
6. `input`에 남아 있는 학생 폴더만 미완료 작업으로 간주한다. 검수 완료 후 `output`으로 이동된 학생 폴더는 다시 실행하지 않는다.

## 1단계: body 제작

1. `body\AGENTS.md`를 먼저 전체 읽고, 선택된 학과 폴더 안의 모든 관련 `*.md` 지침을 추가로 읽는다.
2. 학과 폴더의 PSD 템플릿과 원본 에셋을 검사한다. 원본 PSD는 직접 수정하지 않고 복제본에서 작업한다.
3. 하위 지침에 정의된 스마트 오브젝트, 크기, 해상도, 파일명을 따른다. 생성형 이미지로 화면이나 글자를 다시 만들지 않는다.
4. 결과는 `output\<학과>\<학생명>\`에 PSD, PNG, JPG로 저장한다. 학생명이 없을 때만 `output\<학과>\`에 저장한다.
5. 픽셀 크기, 300 PPI, 스마트 오브젝트 경계, 글자 선명도, 하단 깨짐과 회색 잔여 영역을 검수한다.

body 검수에 실패하면 잘못된 파일을 `output`에서 제거하고 원인을 수정한다. 전체 파이프라인에서는 body가 정상 완료되기 전에는 섬네일 작업을 시작하지 않는다. 사용자가 섬네일만 명시적으로 요청한 경우에는 `input 파일 기반 실행` 규칙에 따라 body 없이 원본에서 진행할 수 있다.

### 아트웍 전용 body 제작

1. Photoshop에서 원본 PSD의 복제본을 열고 레이어·그룹·숨겨진 레이어·마스크·클리핑과 스마트 오브젝트 내부를 분석한다. 레이어 이름만으로 판단하지 않고 표시 상태를 전환해 실제 변화를 확인한다.
2. 작품에 남아 있는 드로잉 과정을 기준으로 단계명과 순서를 정한다. `스케치 → 채색 → 드로잉 → 명암`은 예시이며, 모든 작품에 동일하게 적용하지 않는다.
3. 단계가 부족하면 제공된 중간 파일과 원본에서 분리 가능한 요소를 최대한 분석해 의미 있는 누적 과정을 구성한다. 완성 이미지를 마스크로 분리해 구성한 경우에는 `구성 과정(재구성)`으로 표시한다.
4. 실제 드로잉 과정과 배경·장식·타이포그래피의 편집 과정을 구분한다. 합쳐진 완성 그림에 필터를 적용한 결과를 실제 스케치·채색 단계로 표시하거나, 생성형 이미지로 과정을 만들지 않는다.
5. 단계별 이미지는 원본 레이어의 합성 관계를 유지해 Photoshop에서 PNG로 직접 추출한다. 비교 장면은 같은 위치·배율을 유지하고, 변화가 미미한 장면이나 같은 완성 이미지의 반복은 제외한다.
6. 지정된 아트웍 body PSD 템플릿을 복제해 사용한다. 중간 과정은 비교하기 쉽게 묶고, 중요한 변화는 크게 배치하며, 마지막에는 최종 완성작의 전체 구성을 보여준다. 단계 수와 배치는 작품에 맞게 결정한다.
7. 각 단계는 원본 비율을 유지한 독립 스마트 오브젝트로 배치하고, 순서와 실제 작업 내용이 드러나는 단계명을 표시한다. body는 가로 1000px·300 PPI로 만들고 문서와 아트보드 높이를 실제 콘텐츠에 맞춘다.
8. 저장한 PSD를 다시 열어 단계별 경계와 문서·아트보드 규격을 확인한다. PNG/JPG는 단계의 의미와 흐름, 최종본 일치 여부, 선명도·잘림·잔여 여백을 검수한다.
9. 의미 있는 과정 추출이나 재구성이 불가능하면 부족한 자료와 한계를 보고하고 과정형 body 제작을 완료로 처리하지 않는다. 저장·섬네일·story.txt·원본 이동은 공통 규칙을 따른다.

### 섬네일 단독 요청의 1000px body 생성

body 작업 없이 섬네일만 요청한 경우에도 학과별 body PSD 템플릿을 사용해 게시용 body를 함께 생성한다.

1. 섬네일용 4:3 크롭이 아니라 input 원본의 전체 작품 구성을 사용한다.
2. DTP·아트웍은 `body\아트웍,DTP`의 해당 PSD를 사용하고, 다른 학과는 각 학과에 지정된 body PSD를 사용한다. 적합한 템플릿이 없으면 다른 학과 PSD로 대체하지 않는다.
3. 원본 PSD가 아닌 템플릿 복제본에서 작업한다. 원본을 가로 1000px로 맞추고 세로는 원본 비율에 따라 계산한 뒤, body 아트보드 세로 크기도 계산된 이미지 높이에 정확히 맞춘다. 이미지를 임의로 자르거나 늘이지 않는다.
4. 최종 해상도는 300 PPI로 설정하고 레이어·아트보드가 유지된 `body.psd`와 고품질 `body.jpg`를 함께 저장한다.
5. 같은 이름이 있으면 덮어쓰지 않고 `body_v2.psd`/`body_v2.jpg`, `body_v3.psd`/`body_v3.jpg`처럼 동일 버전으로 저장한다.
6. 결과는 섬네일과 같은 `output\<학과>\<학생명>\`에 저장하며, PSD의 아트보드와 배치 이미지 경계가 일치하는지 확인한다. JPG는 100% 배율에서 글자 선명도·비율 왜곡·하단 잘림·압축 흔적을 검수한다.

## 2단계: 섬네일 제작

1. `thumb\AGENTS.md`를 전체 읽고 해당 지침을 적용한다.
2. 전체 파이프라인에서는 승인된 body PNG 또는 PSD에서 대표 목업 구간을 선택한다. 섬네일만 요청된 작업은 input 원본에서 가장 완성도가 높은 대표 장면을 선택한다. 웹 작업은 컴퓨터 목업 구간을 사용하며 긴 본문이나 브라우저 잔여 테두리를 포함하지 않는다.
3. `thumb`의 해당 템플릿을 복제하고 스마트 오브젝트를 직접 교체한다. 현재 웹 섬네일 기본 템플릿은 `thumb\sbs-webpf-thumb.psd`이다.
4. 결과는 body와 동일한 `output\<학과>\<학생명>\`에 `<프로젝트명>_섬네일.psd`, `.png`, `.jpg`로 저장한다.
5. 최종 400×300px·300 PPI, 레이어 경계 유지, 100% 배율의 글자와 목업 선명도를 확인한다.

## 출력 및 안전 규칙

- 최종 파일은 반드시 `output\웹`, `output\DTP`, `output\모션`, `output\아트웍` 중 선택된 학과 아래에 저장한다.
- 같은 파일이 있으면 덮어쓰지 않고 `_v2`, `_v3`를 붙인다.
- `body`, `thumb`, PF_AGENT 루트에는 최종 결과물을 저장하지 않는다.
- 검사 보고서, 미리보기, 중간 에셋과 임시 스크립트는 완료 후 삭제한다.
- 다른 학생 또는 프로젝트의 기존 파일은 이동·수정·삭제하지 않는다.

## story.txt 생성

학생명과 작품명이 확인된 작업은 루트 `story.md`의 형식에 따라 게시 등록용 `story.txt`를 생성한다.

1. 웹, DTP와 아트웍의 `story.txt`에는 제목, 수강생, 수료과정, 작품명, 표현작업, 기획, 제작프로그램, 비주얼스킬, 컬러시스템, 담당강사만 넣는다.
2. 모션의 `story.txt`에는 기본 필드와 함께 사용자가 입력한 `유튜브 링크`와 모션 전용 `작품소개`를 추가한다.
3. 모션 작품소개는 `<작품명><을/를> 주제로한 모션그래픽 작품입니다. After Effect, Motion Graphic, Portfolio, SBS아카데미컴퓨터아트 대전, 수강생 포트폴리오` 형식으로 작성한다. 작품명 마지막 글자에 받침이 있으면 `을`, 없으면 `를`을 사용한다.
4. body와 섬네일 검수 후 실제 결과에서 대표 컬러 5개를 선정해 대문자 6자리 HEX로 기록한다. 주조색·보조색·강조색·어두운 색·밝은 중립색이 균형 있게 포함되어야 한다.
5. 완료 원본을 이동하기 전에 `input\<학과>\<학생명>\story.txt`에 생성한다. 학생 폴더가 이미 output으로 이동된 보완 작업은 `output\<학과>\<학생명>\story.txt`에 생성한다.
6. 담당강사와 수강생을 혼동하지 않는다. 제목과 수강생은 학생 폴더명을 사용한다. 담당강사는 아래 학과별 형식을 적용하며 `[직접 작성]` 부분은 사용자가 준 이름으로 교체한다. 이름이 제공되지 않으면 임의로 추정하지 않고 `[직접 작성]`을 유지한다.
7. 기존 파일을 덮어쓰지 않으며, 내용이 다른 `story.txt`가 있으면 `story_v2.txt`, `story_v3.txt`를 사용한다.

## 모션 작품 제작 규칙

모션 작품은 `input\모션\<학생명>\`에 있는 MP4 파일을 원본으로 사용한다.

### body 제작

1. MP4의 전체 길이, 해상도, 화면비, 프레임레이트를 먼저 확인한다.
2. 영상 전체를 검토하고 작품의 흐름과 특징을 대표하는 중요 장면 10장을 선정한다.
3. 중요 장면에는 인트로·타이틀, 주요 오브젝트, 타이포그래피, 색상 변화, 전환 효과, 핵심 연출, 클라이맥스, 엔딩 등이 균형 있게 포함되어야 한다.
4. 서로 유사한 장면, 검은 화면, 전환 중간 프레임, 심한 모션 블러, 깨진 프레임은 제외한다.
5. 선정한 10장은 영상 진행 순서에 따라 배치한다. 작품의 핵심 장면이 더 잘 보이는 구성이 필요한 경우에만 시각적 중요도에 따라 순서를 조정한다.
6. 프레임은 원본 영상 해상도에서 추출하고 불필요하게 확대하거나 재압축하지 않는다.
7. `body\모션` 폴더의 모션 전용 PSD 템플릿을 복제해 사용한다. 적합한 템플릿이 없으면 다른 학과 템플릿으로 대체하지 않고 누락을 보고한다.
8. PSD에 장면 영역이 지정되어 있으면 해당 프레임 또는 스마트 오브젝트에 10장을 각각 배치하고 레이어 이름을 `scene-01`부터 `scene-10`까지 지정한다.
9. 프레임을 임의로 늘이거나 확대하지 않고 원본 화면비를 유지한다. 인물, 제목, 로고와 핵심 오브젝트가 잘리지 않도록 한다.
10. 템플릿에 장면 영역이 지정되어 있지 않으면 body 가로 크기를 1000px로 설정하고 장면 높이는 `round(1000 × 원본 높이 ÷ 원본 너비)`로 계산한다.
11. 1920×1080 영상은 장면당 1000×563px로 만들고, 10장을 여백 없이 연결해 최종 body를 1000×5630px로 구성한다.
12. 템플릿의 기존 세로 크기가 실제 콘텐츠보다 길어도 빈 영역을 억지로 채우지 않는다. 최종 문서와 아트보드 높이를 배치된 장면의 총높이에 맞춘다.
13. 프레임 위아래를 채우기 위한 확대 배경, 블러 배경, 그라데이션, 반복 이미지와 같은 임의 배경 처리를 금지한다.
14. 장면 사이에는 여백, 중복 프레임, 블러 전환 구간과 검은 띠가 없어야 한다.
15. 각 장면은 `scene-01`부터 `scene-10`까지 독립된 스마트 오브젝트로 유지한다.
16. 최종 body는 레이어가 유지된 PSD와 평면화된 PNG/JPG로 저장한다.
17. 결과는 `output\모션\<학생명>\`에 `<프로젝트명>_body.psd`, `.png`, `.jpg` 형식으로 저장한다.
18. 같은 이름이 있으면 덮어쓰지 않고 `_v2`, `_v3`를 붙인다.

### body 품질 검수

- 중요 장면이 정확히 10장인지 확인한다.
- 장면이 특정 구간에 편중되거나 서로 중복되지 않았는지 확인한다.
- 검은 화면, 재생 UI, 자막 깨짐, 모션 블러가 포함되지 않았는지 확인한다.
- 모든 프레임의 비율 왜곡, 핵심 요소 잘림, 빈 자리표시자와 불필요한 여백을 확인한다.
- 10개 장면 사이에 블러 처리된 확장 배경, 그라데이션과 불필요한 여백이 없는지 확인한다.
- 모든 장면이 선명한 원본 화면비를 유지하며 위에서 아래로 바로 연결되는지 확인한다.
- 최종 문서와 아트보드 높이가 계산된 장면 높이 × 10과 정확히 일치하는지 확인한다.
- 원본 영상이 1920×1080이면 최종 body가 1000×5630px인지 확인한다.
- 최종 규격과 300 PPI, PSD 레이어 및 스마트 오브젝트 경계를 확인한다.
- 검수에 실패한 body 파일은 output에 남기지 않는다.

### 섬네일 제작

1. 섬네일 제작 방식과 최종 규격은 기존 `thumb\AGENTS.md` 규칙을 동일하게 적용한다.
2. body에 사용한 10장 중 작품을 가장 명확하게 대표하는 장면 한 장을 선택한다.
3. 인트로 로고만 있는 장면, 검은 화면, 전환 중간 프레임과 모션 블러가 있는 장면은 섬네일로 사용하지 않는다.
4. 제목, 주요 인물 또는 핵심 오브젝트가 한눈에 보이는 장면을 우선한다.
5. 선택한 프레임을 `thumb\sbs-webpf-thumb.psd`의 `pc-main` 스마트 오브젝트에 배치한다.
6. 최종 섬네일은 400×300px·300 PPI의 PSD/PNG/JPG로 저장하고 교체 전후 경계를 유지한다.
7. 파일명은 `<프로젝트명>_섬네일.psd`, `.png`, `.jpg` 형식을 사용한다.

### story 및 완료 처리

1. body와 섬네일을 확인해 모션 작품을 대표하는 컬러 5개를 선정하고 `story.txt`에 기록한다.
2. 모션학과 story 기본값을 적용하며 수료과정과 담당강사 이름의 `[직접 작성]` 부분은 임의로 채우지 않는다.
3. 사용자가 입력한 유튜브 링크와 모션 전용 작품소개가 `story.txt`에 포함되었는지 확인한다.
4. body 3종, 섬네일 3종, 유튜브 링크와 작품소개를 포함한 `story.txt`가 모두 검수를 통과해야 완료된다.
5. 완료 후 MP4 원본과 학생 폴더의 자료를 `output\모션\<학생명>\`에 병합하고 비어진 input 학생 폴더를 제거한다.
6. 중요 장면 추출 이미지, 검사 보고서, 미리보기와 임시 스크립트는 검수 후 삭제한다.

## 완료 원본 이동 및 보관

요청된 작업 범위의 모든 결과물이 검수를 통과하면 `input\<학과>\<학생명>\`의 원본을 결과가 있는 `output\<학과>\<학생명>\` 폴더로 이동해 원본과 결과물을 함께 보관한다.

1. 결과 폴더가 이미 존재하므로 학생 폴더를 중첩해 `output\<학과>\<학생명>\<학생명>\` 구조로 만들지 않는다. input 학생 폴더의 **내용을 기존 output 학생 폴더에 병합**한다.
2. 이동 전에 출발·도착 절대 경로가 각각 `input\<학과>\<학생명>`과 `output\<학과>\<학생명>` 안에 있는지 확인한다.
3. 같은 이름의 파일이 output에 있으면 덮어쓰지 않고 `_v2`, `_v3`를 붙여 원본을 모두 보존한다.
4. 모든 원본 파일이 정상적으로 이동되었는지 확인한 뒤 비어진 input 학생 폴더를 삭제한다. 학과 폴더인 `input\<학과>`는 삭제하지 않는다.
5. 제작 또는 검수에 실패했거나 필수 결과물이 누락되었으면 input 학생 폴더와 원본을 이동하지 않는다.
6. 이동 완료 후 output 학생 폴더에 원본 파일, `story.txt`, 최종 PSD/PNG/JPG가 함께 있는지 확인한다. 섬네일 단독 작업은 `body.psd`와 `body.jpg`도 함께 있는지 확인하고, 완료 보고에 최종 폴더의 절대 경로를 포함한다.

## 완료 조건 및 보고

전체 파이프라인은 body와 섬네일의 PSD/PNG/JPG 여섯 개가 모두 검수를 통과해야 완료된다. body만 요청한 경우에는 PSD/PNG/JPG 세 개가 필요하다. body 없이 섬네일만 요청한 경우에는 400×300 섬네일 PSD/PNG/JPG 세 개와 가로 1000px `body.psd`/`body.jpg`까지 총 다섯 개가 모두 검수를 통과해야 완료된다. 요청 범위의 결과 검수와 완료 원본 이동이 모두 끝난 뒤에만 완료로 보고한다. 완료 보고에는 선택한 학과, 학생명, 적용한 지침과 템플릿, 최종 규격, 모든 결과 파일 경로, 원본을 포함하는 최종 output 학생 폴더의 절대 경로를 적는다. 한 단계라도 실패하거나 필수 템플릿이 없으면 완료로 보고하지 않는다.
