# 섬네일 제작 전용 지침

## 작업 목적

이 폴더는 포트폴리오 섬네일 제작 전용 작업공간이다. 모든 작업은 `C:\khjsbs\Po\PF_AGENT`를 기준으로 수행한다. 생성형 이미지로 원본 화면이나 글자를 다시 만들지 말고, 제공된 디자인과 PSD 스마트 오브젝트를 직접 합성해 선명도를 보존한다.

## 폴더 및 템플릿 구조

- `sbs-webpf-thumb.psd`: 400×300px 섬네일 템플릿. 기본 화면 레이어는 `pc-main`이다.
- `sbs-webpf-body.psd`: 웹 포트폴리오 본문 목업이 필요할 때 사용한다.
- `웹/`, `DTP/`, `모션/`, `아트웍/`: 카테고리별 원본 작업 공간이다. 없는 폴더는 실제 작업이 생길 때만 만든다.
- `output/<카테고리>/`: 완성 파일 전용 위치다. 루트나 원본 폴더에 결과물을 저장하지 않는다.

카테고리는 작업 요청 또는 원본의 최상위 폴더명을 따른다. 결과는 반드시 `output\웹`, `output\DTP`, `output\모션`, `output\아트웍` 중 하나에 저장한다. 카테고리가 불분명하면 임의로 선택하지 말고 확인한다.

## 섬네일 제작 절차

1. 원본과 템플릿을 검사하고 스마트 오브젝트 이름, 내부 크기, 해상도를 기록한다.
2. 웹 작업은 완성된 컴퓨터 목업 구간을 4:3 비율로 크롭한다. 로고, 긴 본문, 브라우저 잔여 테두리가 들어가지 않도록 한다.
3. 교체 에셋은 템플릿 스마트 오브젝트와 같은 400×300px·72 PPI로 준비한다. `pc-main` 내용을 교체한 뒤 레이어 경계가 `0,0,400,300`으로 유지되는지 확인한다.
4. 최종 문서 해상도만 리샘플링 없이 300 PPI로 변경한다.
5. 레이어가 유지된 PSD와 평면화된 PNG/JPG를 함께 내보낸다.

## 파일명 및 덮어쓰기 규칙

파일명은 `<프로젝트명>_섬네일.psd`, `.png`, `.jpg` 형식을 사용한다. 같은 이름이 있으면 덮어쓰지 말고 `_v2`, `_v3`를 붙인다. 원본 PSD는 항상 복제한 뒤 수정하며 레이어 이름, 변형 값, 색상 프로필을 보존한다.

## 품질 검수

최종 파일은 모두 400×300px·300 PPI여야 한다. PNG를 100% 배율로 열어 글자 선명도, 목업 잘림, 회색 자리표시자, 하단 잔여물, 불필요한 여백을 확인한다. PSD의 스마트 오브젝트 교체 전후 경계도 동일해야 한다. 검수에 실패한 파일은 `output`에 남기지 않는다.

## 완료 및 정리

완료 보고에는 카테고리, 최종 규격, PSD/PNG/JPG의 절대 경로를 적는다. 검사 보고서, 미리보기, 중간 에셋, 임시 스크립트는 검수 후 삭제하고 `output`에는 승인 가능한 최종 결과만 유지한다.
