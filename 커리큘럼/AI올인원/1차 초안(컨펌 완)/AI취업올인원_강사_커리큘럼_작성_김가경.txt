================================================== 7. 최종 결과물
수강생이 과정 종료 후 다음과 같은 결과 또는 역량을 가지고 나가는 것을
목표로 함.

-   결과물 1: 반복적으로 활용할 수 있는 개인 실무형 프롬프트 템플릿

-   결과물 2: 자신의 업무 또는 취업 준비 과정에 활용할 수 있는 AI Agent
    / 자동화 프로토타입

-   결과물 3: AI를 활용하여 자신의 직무에 맞는 포트폴리오를 기획하고
    제작할 수 있는 기초 능력 및 개인 프로젝트 결과물

※ 직무별로 요구되는 포트폴리오 형태가 다르기 때문에 완성된 포트폴리오의
형태를 통일하기보다는 수강생이 원하는 결과물을 AI로 기획·제작·개선할 수
있는 기초 역량을 확보하는 것을 목표로 함.

================================================== 8. 기존 AI 수업보다
고도화하면 좋을 부분 - 기존 프롬프트 수업에서 더 강화할 부분: 완전
기초적인 프롬프트 이론 및 단순 기능 설명은 축약하고, 실제 업무에서
반복적으로 활용할 수 있는 프롬프트 설계와 자동화 구축 작업을 강화.
단순히 좋은 답변을 한 번 생성하는 방법보다 동일하거나 유사한 업무를 반복
수행할 수 있는 구조를 만드는 데 중점을 두면 좋을 것으로 생각함.

-   에이전트 수업에서 더 강화할 부분: Agent 기능 소개에 그치지 않고
    수강생이 직접 업무를 단계별로 분해하고, AI가 어떤 순서로 작업해야
    하는지 설계하는 경험을 강화. ChatGPT Agent, MCP, Skills, API 등을
    개별 기능으로 설명하기보다 실제 하나의 업무 흐름 안에서 어떻게
    연결하여 활용할 수 있는지를 실습하는 방향을 추천.

-   취업 과정이기 때문에 추가하면 좋을 부분: 특정 직무에만 적용되는
    결과물보다 수강생 각자의 희망 직무에 맞게 AI를 활용할 수 있도록
    구성. 기업·직무 리서치, 포트폴리오 기획 및 제작, 개인 프로젝트 등
    실제 취업 준비 과정에서 AI를 활용하여 결과물을 만드는 경험을
    포함하면 좋을 것으로 생각함.

================================================== 10. 기타 의견 - 수업
운영 시 우려되는 부분: 수강생별 AI 활용 경험과 디지털 도구 숙련도의
차이가 클 경우 Agent, MCP, API 등의 실습 진행 속도에 차이가 발생할 수
있음. 중급 이상 과정인 만큼 기본적인 생성형 AI 사용 경험을 사전에 안내할
필요가 있음.

-   필요한 준비사항: · ChatGPT 사용 환경 및 계정 준비 · 실습에 필요한
    기능의 플랜별 사용 가능 여부 사전 확인 · MCP / API 실습에 필요한
    계정 및 연결 환경 사전 점검 · 수강생 개인별 자동화 주제 또는 희망
    직무를 선정할 수 있는 사전 안내 · 실습용 예제와 개인 프로젝트용
    템플릿 준비

-   추가 제안: 전체 과정은 AI 기능을 많이 소개하는 것보다 ’프롬프트 작성
    → 반복 가능한 작업 구조 설계 → Agent 구축 → MCP/API 연결 → 개인
    프로젝트 적용’의 하나의 흐름으로 연결하는 것이 좋을 것으로 생각함.

    과정 종료 시 특정 도구 사용법을 기억하는 것보다 새로운 업무가
    주어졌을 때 AI를 어떻게 활용하고, 어떤 부분을 Agent 또는 자동화로
    구축할 수 있는지 스스로 판단하고 설계하는 능력을 갖추는 것을 최종
    목표로 제안함.
