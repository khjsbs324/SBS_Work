# 훈련교과 편성 작업 지침

## 작업 범위와 기준 자료

모든 작업은 `SBS_Work/타임테이블/`을 기준으로 진행한다. 먼저 폴더의 PDF, 이미지, 스프레드시트, 텍스트 파일을 확인하고 다음 우선순위를 적용한다.

1. 사용자의 최신 지시와 직접 수정한 결과
2. 확정 편성시간이 표시된 원본 자료
3. 능력단위 정의와 평가 기준이 수록된 PDF
4. 구조·서식 참고용 예시 파일

자료가 충돌하면 임의로 결정하지 말고 충돌 항목을 명확히 보고한다. 예시 파일의 과목명이나 수치를 현재 과정에 그대로 복사하지 않는다.

## 편성 원칙

- 원본의 교과명·능력단위명과 편성시간을 정확히 사용한다.
- 셀의 시간이 부족하거나 남는다는 이유로 능력단위의 확정 총시간을 임의로 늘리거나 줄이지 않는다.
- 승인되지 않은 교과나 `교과 미편성` 같은 임의 항목을 추가하지 않는다.
- 사용자가 지정한 선후 관계, 담당 교사, 시간대 및 시작·종료 조건을 우선한다.
- 상세 커리큘럼이 요청되지 않았다면 능력단위의 실시 순서와 시간만 작성한다.
- 전체 가용시간과 실제 편성시간의 차이는 별도 항목으로 채우지 않고 공란 처리한다.

## 일정 및 시간 계산

훈련기간에서 주말과 지정 공휴일을 제외해 실제 훈련일을 계산한다. 일별 시간대가 여러 개이면 각 시간대의 셀은 분리 상태로 유지하되, 교과 진행 순서는 시간대 구분을 넘어 연속적으로 계산한다.

각 구간은 지정된 우선 시간대부터 채운다. 한 능력단위가 현재 셀의 가용시간을 초과하면 해당 셀에 실제 사용한 시간만 쓰고 잔여시간을 다음 셀로 넘긴다. 반대로 현재 셀의 합계가 가용시간보다 부족하면 다음 순서의 능력단위 일부를 앞으로 당겨 정확히 채운다. 이때 당겨 쓴 시간은 다음 셀의 잔여시간에서 반드시 차감한다. 능력단위를 임의 비율로 나누거나 같은 총시간을 여러 셀에 중복 기재하지 않는다.

오전과 오후는 각각 이어지는 시간대 흐름으로 계산한다. 오전에서 넘친 시간은 다음 오전 셀로, 오후에서 넘친 시간은 다음 오후 셀로 넘기는 것을 기본으로 한다. 사용자가 특정 능력단위를 오전 또는 오후에 고정하면 다른 시간대로 옮기지 않는다.

각 셀에 적힌 시간의 합은 헤더의 가용시간과 정확히 일치해야 한다. 예를 들어 `3H 66 / 2H 44` 구간은 오전 셀 합계가 66H, 오후 셀 합계가 44H여야 한다. 44H 셀에 4H와 30H만 있으면 다음 능력단위에서 10H를 당겨 와서 채우며, 기존 30H를 임의로 40H로 바꾸지 않는다.

표기 예: 총 70H 능력단위를 첫 셀에 60H 사용했다면 다음 셀에는 같은 명칭으로 10H를 작성한다. 두 셀의 합계는 반드시 70H여야 한다.

## 현재 UIUX 과정 확정 기준

현재 작업 중인 Google 스프레드시트의 `시트2`에서는 다음 기준을 유지한다.

- 월별 가용시간: 2026년 10월 51H/34H, 11월 63H/42H, 12월 66H/44H, 2027년 1월 57H/38H, 2월 54H/36H, 3월 66H/44H, 4월 55H
- 수정 보완 60H는 오전에 고정한다. 1월 오전 57H를 사용하고 잔여 3H는 2월 오전으로 넘긴다.
- 12월 오후는 스마트문화앱 UI 디자인 4H, 디자인 구성요소 설계 30H, 프로토타입 기초데이터 수집 및 스케치 10H로 합계 44H를 맞춘다.
- 디자인 구성요소 설계의 잔여 10H는 1월 오후로 넘긴다.
- 프로토타입 기초데이터 수집 및 스케치 30H는 12월 오후 10H와 1월 오후 20H로 나눈다.
- 프로토타입 제작 및 사용성 테스트는 총 40H를 유지한다.
- 디자인 구성요소 제작 60H는 8H + 11H + 36H + 5H로 분할한다.
- 시안 디자인 개발 심화 30H와 디지털디자인 사후관리 30H는 각각 총시간을 유지한다.
- 취업 포트폴리오 제작 100H는 1H + 44H + 55H로 분할해 마지막에 배치한다.
- 교과별 총시간과 모든 월별 셀 합계가 동시에 맞아야 하며, 한쪽을 맞추기 위해 다른 쪽의 확정시간을 변경해서는 안 된다.

## 능력단위 순서

순서는 교육적 선후 관계와 사용자 지시를 함께 반영한다. 일반적으로 기초·조사·설계에서 시작해 제작·구현·검증·보완·성과물 정리 순으로 배치하되, 과정 자료에 명시된 순서가 있으면 그 기준을 따른다.

결합하도록 지시된 능력단위는 하나의 표시명과 합산시간으로 관리한다. 분리하도록 지시된 능력단위는 각각 독립적으로 합계를 검산한다.

## 스프레드시트 수정 절차

1. 쓰기 전에 문서 메타데이터와 대상 셀의 최신 값을 읽는다.
2. 사용자가 지정한 시트와 범위만 수정한다.
3. 기존 행·열 구조, 셀 분리, 병합, 색상, 글꼴 및 정렬을 보존한다.
4. 월별 또는 구간별 가용시간에 맞춰 과목명과 배정시간을 입력한다.
5. 각 셀의 시간 합계와 각 능력단위의 분할시간 합계를 별도로 계산한다.
6. 수정 직후 같은 범위를 다시 읽어 실제 반영값을 확인한다.

사용자가 시트를 직접 고친 경우 그 상태를 최신 기준으로 삼는다. 이전 대화의 값만으로 덮어쓰지 않는다.

## 결과 파일 작성

사용자가 파일명을 지정하면 해당 이름과 형식을 그대로 사용한다. 기존 파일 수정 요청이면 새 파일을 만들지 않는다. 텍스트 결과는 과목 순서, 총시간, 분할시간을 간결하게 기록하며 요청하지 않은 상세 수업 내용은 넣지 않는다.

## 완료 전 검산

- 실제 훈련일과 시간대별 가용시간이 맞는가?
- 모든 분할시간의 합이 원본 편성시간과 일치하는가?
- 각 셀의 배정시간이 해당 구간의 가용시간을 초과하지 않는가?
- 각 셀의 배정시간 합계가 해당 구간의 가용시간보다 부족하지도 않은가?
- 부족한 셀에서 다음 능력단위 시간을 당겨 썼다면 이후 셀에서 정확히 차감했는가?
- 초과분을 다음 셀로 넘길 때 동일 시간대 고정 조건을 지켰는가?
- 지정된 시작 과목, 선후 순서, 마지막 과목이 지켜졌는가?
- 과목명 누락, 중복, 축약 또는 임의 교과 추가가 없는가?
- 요청 범위 밖의 셀과 다른 시트가 보존되었는가?
