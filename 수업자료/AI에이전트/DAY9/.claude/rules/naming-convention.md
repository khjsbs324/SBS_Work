# Naming Convention

## 파일명
- Markdown: kebab-case 또는 정의된 Page ID 사용
- PowerShell: kebab-case.ps1
- CSS/JS: kebab-case 또는 기능명 기준

## Page
- 표지: `p{n}`
- 서론: `ps{n}`, `ps{n}_{sub}`
- 본론: `pb{n}`, `pb{n}_{sub}`

## Element
- 제목: `title`
- 부제목: `subtitle`
- 본문: `body01`, `body02`
- 이미지: `image01`, `image02`
- 박스: `box01`, `box02`

## Token
- 색상: `surface-page`, `text-primary`
- 글자: `title`, `h1`, `h2`, `body1`, `body3`
- 이미지: `img-xl`, `img-lg`, `img-md`
- 레이아웃: `cover`, `section`, `image-right`
