# Spacing Tokens

| token | value |
|---|---:|
| space-1 | 8px |
| space-2 | 16px |
| space-3 | 24px |
| space-4 | 32px |
| space-5 | 48px |
| space-6 | 64px |
| space-7 | 96px |
| space-8 | 128px |

## Rule
- 동일 정보 그룹은 작은 간격을 사용한다.
- 다른 정보 그룹은 더 큰 간격을 사용한다.
- 새로운 값 추가 전 기존 spacing token으로 해결 가능한지 확인한다.
