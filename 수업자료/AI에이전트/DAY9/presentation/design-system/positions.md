# Position Tokens

## Simple Alignment
- left
- center
- right
- top
- bottom

## Compound Alignment
- top-left
- top-right
- center-center
- bottom-left
- bottom-right

## Absolute Position Examples

```yaml
position:
  x: 681
  y: 0
```

```yaml
position:
  x: 173
  y: 151
```

## Priority
absolute X/Y > compound alignment > simple alignment > layout default
