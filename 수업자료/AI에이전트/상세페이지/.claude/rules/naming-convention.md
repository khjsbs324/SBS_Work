# Naming Convention

## 섹션
- 파일: `s01-hero.md` 형식
- ID: `{type}{two-digit-sequence}` 형식 (`hero01`, `faq01`)
- type: 소문자 kebab-case (`how-to` 포함)

## 요소와 자산
- DOM 추적 ID: `{sectionId}.{elementName}`
- 이미지: 제품명보다 역할 중심 kebab-case (`hero-lifestyle.png`, `product-cutout.png`)
- CSS 클래스: BEM에 가까운 kebab-case
- 토큰: 의미 기반 (`surface-porcelain`, `text-muted`, `space-6`)

## 금지
`final`, `new`, `수정`, 날짜만으로 버전을 표현하지 않는다. 색상·좌표를 ID 이름에 넣지 않는다.
