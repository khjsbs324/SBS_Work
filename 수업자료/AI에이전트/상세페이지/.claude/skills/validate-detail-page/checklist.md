# Detail Page QA Checklist

## Content
- [ ] 고객 문제와 제품 가치의 연결이 명확하다.
- [ ] 동일 문구가 불필요하게 반복되지 않는다.
- [ ] 수치, 시험, 인증, 1위 표현은 근거가 있다.
- [ ] 치료·완치·질환 개선을 암시하지 않는다.
- [ ] 가상 정보임을 필요한 위치에 표시했다.

## Schema
- [ ] 파일명, ID, type, manifest가 일치한다.
- [ ] 9개 핵심 유형이 순서대로 존재한다.
- [ ] 유형별 필수 JSON 필드가 있다.

## Visual / Accessibility
- [ ] 1080px에서 가로 overflow가 없다.
- [ ] 본문 24px, 보조 문구 18px 이상이다.
- [ ] 텍스트 대비와 alt가 적절하다.
- [ ] 제품 컷은 contain, 연출/제형 이미지는 의도된 crop이다.

## Build
- [ ] HTML에 9개 섹션이 있다.
- [ ] 모든 로컬 자산이 출력 폴더로 복사됐다.
- [ ] PDF에 섹션 잘림이나 빈 페이지가 없다.
