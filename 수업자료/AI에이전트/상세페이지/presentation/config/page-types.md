# Section Types

| type | 고객 질문 | 필수 역할 |
|---|---|---|
| hero | 무엇을 파는가? | 제품, 한 문장 가치, 용량/가격, 첫 CTA |
| problem | 왜 필요한가? | 과장 없이 공감 가능한 사용 상황 |
| benefit | 무엇이 좋은가? | 핵심 사용 가치 3개 이내 |
| evidence | 왜 믿을 수 있는가? | 성분·제형 설계 근거와 한계 고지 |
| detail | 실제로 어떤가? | 제형, 마무리감, 패키지/사용 장면 |
| how-to | 어떻게 쓰는가? | 단계, 양, 순서, 사용 팁 |
| spec | 구매 전 무엇을 확인할까? | 상품 정보, 대상, 주의 문구 |
| faq | 망설임은 무엇인가? | 실제 구매 질문과 안전한 답변 |
| cta | 지금 무엇을 하면 되는가? | 제품 요약, 가격, CTA, 법적 고지 |

섹션 type은 역할만 표현한다. 색상, 이미지 위치, 캠페인명은 type에 포함하지 않는다.
