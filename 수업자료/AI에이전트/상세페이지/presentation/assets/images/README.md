# Detail Page Image Assets

## 현재 자산

| file | role | recommended rendering |
|---|---|---|
| hero-lifestyle.png | 히어로 연출 이미지 | 888×520 영역, cover, focal center 68% |
| product-cutout.png | 투명 제품 단독 컷 | contain, 투명 배경 유지 |
| cream-texture.png | 제형 매크로 이미지 | 888×410 영역, cover |

## 교체 규칙

- 파일명은 역할 중심 kebab-case를 유지한다.
- PNG/JPG/WebP/SVG를 사용할 수 있다.
- 의미 있는 이미지에는 한국어 alt를 페이지 JSON에 작성한다.
- 제품 컷은 충분한 투명 여백을 남기고 임의로 늘리지 않는다.
- 상업 사용 전 생성/촬영 원본, 모델·소품 권리, 보정 범위를 확인한다.
- 이미지가 없으면 렌더러가 CSS placeholder를 표시하고 validation은 경고한다.

## 추가 권장 자산

실제 캠페인으로 확장할 때는 사용 장면, 패키지 후면, 용기 크기 비교, 전성분/법정 표기 컷을 별도로 준비한다.
