# Layout Tokens

## hero-editorial
브랜드 내비게이션 → 메시지 → 888×640 연출 이미지 → 제품/가격 요약의 세로 편집형 구성.

## problem-cards
공감 문장과 3개 상황 카드를 3열로 배치하고 마지막 한 문장으로 다음 섹션을 연결한다.

## benefit-grid
번호가 있는 핵심 가치 3개를 카드로 정리한다. 효능보다 사용 경험과 설계 관점을 우선한다.

## evidence-ledger
성분 3개를 ledger 형식으로 설명하고, 하단 disclosure에서 일반 정보와 개인차를 밝힌다.

## texture-story
제형 이미지와 제품 컷을 교차 배치해 텍스처·흡수감·마무리감을 설명한다.

## step-flow / spec-table / faq-list / closing-offer
순서, 구매 정보, 질문, CTA에 각각 최적화된 단일 흐름 레이아웃. PDF에서 섹션별 한 페이지를 보장한다.
