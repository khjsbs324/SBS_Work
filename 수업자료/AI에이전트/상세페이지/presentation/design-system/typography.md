# Typography Tokens

| token | size | line-height | weight | use |
|---|---:|---:|---:|---|
| display-xl | 88px | 1.04 | 500 | 히어로 핵심 문장 |
| display-lg | 72px | 1.08 | 500 | CTA/감성 메시지 |
| heading-1 | 56px | 1.16 | 600 | 섹션 제목 |
| heading-2 | 40px | 1.24 | 600 | 카드/기능 제목 |
| heading-3 | 30px | 1.34 | 600 | 하위 정보 제목 |
| body-lg | 28px | 1.58 | 400 | 도입 본문 |
| body | 24px | 1.62 | 400 | 일반 본문 |
| body-sm | 21px | 1.58 | 400 | 표/FAQ 답변 |
| caption | 18px | 1.55 | 400 | 고지/주석 |
| eyebrow | 16px | 1.3 | 700 | 영문 섹션 라벨, letter-spacing 0.18em |

영문 display는 Georgia 계열, 한국어는 `Noto Serif KR` 또는 시스템 명조를 우선한다. 본문은 Pretendard/Noto Sans KR/시스템 sans를 사용한다.
