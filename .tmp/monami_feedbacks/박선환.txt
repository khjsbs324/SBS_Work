박선환 학생은 언어·SNS·유틸리티를 가로로 배치하고, BEST PRODUCT의 제목·설명·카테고리와 일곱 개 상품 이미지를 작성했습니다. 제출 메모에도 상품 영역의 크기와 탭 규격을 정리해 두었습니다. 실제 화면에서는 상품이 가로 목록으로 이어지지 않고 세로로 쌓여 회색 배경 아래까지 넘어갑니다. 이번에는 작업 내용과 메모가 확인되는 상단과 인기상품 영역을 중심으로 살펴보았습니다.

1. 상단 > 유틸리티 아래의 메인헤더

언어·SNS와 HOME 계열의 정렬은 잘 되어 있습니다. 현재 `.head_top` 다음에는 바로 `.main_banner`가 이어져, 모나미 로고와 주 메뉴·검색 표시를 담는 줄이 없습니다. 상단을 완성하려면 두 줄을 구분해야 합니다. `.head_top` 아래에 메인헤더의 부모를 추가하고 제공 자료의 로고, 일곱 메뉴, 검색·전체 메뉴 표시를 배치하세요. 언어 선택이나 실제 페이지 이동 기능을 추가하는 작업보다 표시 요소와 정렬을 먼저 완성하면 됩니다.

2. BEST PRODUCT > 카테고리 span에 크기가 적용되지 않는 이유

[학생 코드 — monami 시험/style.css]
```css
#actions .tab_premium {
  width: 157px;
  height: 36px;
  border: 2px solid #bcbcbc;
}
```

[수정 예시 — 기존 규칙 뒤에 추가]
```css
.actions { gap: 6px; }
#actions span {
  display: flex;
  justify-content: center;
  align-items: center;
  box-sizing: border-box;
}
#actions .tab_premium {
  border-color: #c81939;
  color: #c81939;
}
```

현재 `span`은 `inline` 상태라 지정한 너비와 높이를 가진 상자로 보이지 않습니다. 실제 첫 탭의 너비는 약68px로 표시되었습니다. `display: flex`를 주면 157×36px 상자 안에서 글자를 정렬할 수 있습니다. 첫 탭의 선택 표시도 넣어 주세요. 카테고리별 데이터를 전환하는 기능은 이번 수정 범위에 추가할 필요가 없습니다.

3. BEST PRODUCT > 가로 목록의 부모에 Flex 적용

[학생 코드]
```css
.product_list_image > ul > li {
  width: 266px;
  height: 390px;
  gap: 18px;
  display: flex;
  padding-top: 40px;
  border-radius: ;
}
```

[수정 예시]
```css
.products_con { height: auto; }
.product_list { width: 100%; overflow-x: auto; }
.product_list_image > ul {
  display: flex;
  width: 3016px;
  gap: 9px;
}
.product_list_image > ul > li {
  flex: 0 0 266px;
  width: 266px;
  height: 505px;
  display: block;
  padding-top: 0;
  border-radius: 16px;
  overflow: hidden;
  background: #fff;
}
.product_list_image > ul > li > img {
  display: block;
  width: 100%;
  height: 390px;
  object-fit: cover;
}
```

상품 여러 개를 가로로 나열하려면 각 `li`가 아니라 그들을 담는 `ul`에 Flex를 적용해야 합니다. 현재 `li` 안의 이미지에만 가로 배치 방식이 적용되어 목록 자체는 세로로 쌓입니다. 그래서 목록 높이가 약3010px이 되어 바깥 회색 영역보다 길어집니다. 부모를 가로 목록으로 바꾸고 바깥의 고정 높이를 풀어 한 번에 정리하세요. 값이 비어 있는 `border-radius`도 유효한 값으로 작성해야 합니다.

4. BEST PRODUCT > 이미지 아래 상품 정보와 나머지 카드

[현재 카드]
```html
<li><img src="./image/list/product-01.jpg" alt="상품이미지"></li>
```

[카드 구조 예시]
```html
<li>
  <img src="./image/list/product-01.jpg" alt="사진에 맞는 실제 상품명">
  <div class="product-info">
    <p>프리미엄 펜</p>
    <p class="product-name">사진에 맞는 실제 상품명</p>
  </div>
</li>
```

현재 일곱 이미지 파일은 모두 정상적으로 표시됩니다. 각 카드에는 사진뿐 아니라 분류와 상품명이 필요합니다. 위 예시의 문구를 그대로 쓰지 말고 실제 사진의 제품 이름을 확인해 바꾸세요. 정답 목록의 11개와 비교하면 네 개 카드가 더 필요합니다. 제공 자료에서 해당 이미지를 추가하고 같은 카드 구조를 반복하세요. `3016px`은 11개 카드 너비와 간격을 합친 값입니다. 스크롤 영역에 `tabindex="0"`을 주고, 완성한 마지막 카드까지 이동할 수 있는지도 확인하면 좋습니다.

최종점수는 {FINAL}점입니다. 먼저 `ul`을 가로 목록으로 바꿔 넘침을 정리하고, 탭 크기와 상품명·카드 수를 완성하세요.
