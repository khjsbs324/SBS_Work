전해주 학생은 언어·SNS·HOME 계열을 가로로 배치했고, BEST PRODUCT의 제목·빨간 선·소개 문장을 구성했습니다. 국기와 SNS 이미지도 정상적으로 연결됩니다. 현재 상단에는 로고와 주 메뉴 줄이 없고, 인기상품에는 제목 아래의 카테고리와 상품 목록이 작성되지 않았습니다. 이번에는 실제 작업한 상단과 인기상품 두 영역을 기준으로 보완점을 정리했습니다.

1. 상단 > 언어 상자의 축소와 실제 메뉴 문구

[학생 코드 — 모나미시험/style.css]
```css
.head-left { width: 204px; display: flex; }
.language { width: 86px; padding: 5px; }
.sns { width: 204px; padding-left: 7px; padding-right: 7px; }
```

[수정 예시]
```css
.head-left { width: auto; gap: 14px; }
.language {
  flex: 0 0 86px;
  width: 86px;
  height: 28px;
  padding: 0;
  box-sizing: border-box;
}
.sns { width: auto; padding: 0; }
```

왼쪽 부모와 SNS 자식에 모두 204px 너비가 지정되어 언어 상자까지 같은 공간에 들어가려 합니다. 그래서 언어 상자는 작성한 너비보다 작은 약81px로 표시됩니다. 왼쪽 부모는 내용에 따라 늘어나게 하고, 언어 상자는 줄어들지 않도록 설정하세요. 오른쪽의 `CONTECT US`는 `CONTACT US`로 바꾸면 됩니다.

2. 상단 > 로고와 주 메뉴 줄 추가

현재 `.head-top` 다음에는 바로 배너가 이어집니다. 유틸리티만으로 상단 전체가 완성된 것은 아니므로, 그 아래에 1400px 내부 부모와 89px 높이의 메인헤더를 추가하세요. 제공 자료의 로고, 일곱 개 주 메뉴, 검색·전체 메뉴 표시를 같은 부모 안에 가로로 배치하고 세로 가운데를 맞추면 됩니다. 먼저 표시와 정렬을 완성하는 데 집중하세요.

[제목 아래에 추가할 카드 구조 예시]

제출 ZIP에는 상품 이미지 11개가 준비되어 있지만 현재 HTML에서는 사용되지 않았습니다. 위 예시는 이미 들어 있는 첫 이미지 파일을 연결하는 방법입니다. 각 파일에 맞는 상품명을 확인하고 같은 구조로 11개를 작성하세요. 그 위에는 프리미엄 펜·펜/펜슬·마카/컬러링·노트/사무용품의 표시도 추가해야 합니다.

5. 코드 문법 정리

[학생 코드]
```css
font-weight: auto;
```

[수정 예시]
```css
font-weight: 400;
```

`font-weight`에 `auto`는 적용되지 않으므로 사용할 굵기를 숫자나 `normal`로 지정하세요. HTML에서는 `.product`를 닫은 다음 `</div>`가 하나 더 있으므로 여는 태그와 짝을 확인해 제거해야 합니다. 현재 페이지는 표시되지만 브라우저의 자동 보정에 기대지 않도록 정리하는 연습이 필요합니다.
